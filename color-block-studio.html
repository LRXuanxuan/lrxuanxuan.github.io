使用说明

围绕明暗归纳、色彩归纳、线条取舍和局部压黑练习。自动处理给出观察起点，取舍由你完成；不会自动判断形体结构或给绘画评分。

分组、改色与局部修改

明暗支持 2 / 3 / 5 组，分界采用 L* 明度；色板调整输出灰阶。勾选覆盖位置后点色块，可对照该组在原图中的范围。色彩默认固定分块，改色不移动边界；重新分块、合并两组均是独立操作。

在线条取舍中，可以补画、恢复候选、删线或减弱线条；在局部压黑中，可以补黑、留白和擦除修改。笔刷支持鼠标、触控笔和触摸。放大后可开启拖动画布，原图和结果始终对齐。

撤销与方案对照

撤销 / 重做覆盖参数、色板、模式切换与局部笔画，快捷键 Ctrl / ⌘ Z 和 Ctrl / ⌘ Shift Z。保留最多 20 步，复杂大图会按内存占用缩短。记为 A 后继续修改 B，查看 A 时是只读状态，返回 B 后继续编辑和导出。

四个练习方向分别保留当前图片的设置，来回切换不会丢掉调色和笔画。换图或刷新会开始新的练习，请先导出要保留的结果。自选图片只在浏览器中处理。

收起侧栏

画布上方的“收起侧栏”可隐藏参数区，为图片留出空间；同一位置点击“展开侧栏”即可继续调整。收起不会清空图片、参数或笔画。

界面外观

右上角可选浅色、深色或跟随系统，与博客共用外观偏好。切换只改变界面，不改变图片、调色板和导出文件的颜色。

开始一次练习

  1. 拖入图片、在侧栏选择本机图片，或按 Ctrl+V 粘贴。
  2. 选一个练习方向，先看大块关系。需要细调时再展开柔化、碎块或线条候选参数。
  3. 记为 A 后调整分组、色板或局部笔画，再与 A 对照，最后导出要保留的结果。

导出

  • 导出 PNG：当前练习的结果图，包含局部修改。工作图长边最多 2000 px。
  • 按原图尺寸：把当前结果按原图比例缩放，长边上限 6000 px。保留当前分块和笔画，不重新推算细节；放大不会增加原本没有的细节。
  • 参考卡与打印：使用当前结果；色彩与明暗卡含色值、占比，线条与黑块卡记录候选参数。减弱线条会以灰色保留。

线条取舍

自动边缘是待选择的候选，不能区分外轮廓、遮挡、结构转折与衣服花纹。用补画、删去、减弱来表达主次；“保留线条”和“擦除修改”会恢复该处的自动候选。线条量、粗细、平滑和清理碎线可在折叠参数中微调，或从简洁 / 标准 / 丰富预设起步。

排线明暗示意

排线默认关闭。它按照画面明暗，用固定方向与密度示意暗部；不会识别人体或衣褶的转面方向。角度、密度和强度可用于比较，不能把结果当作顺着形体排线的答案。肤色保护仅是颜色近似，也可能影响木头、暖色衣物等区域。

局部压黑

切到「局部压黑」，用 L* 明度分界生成黑块候选，再手动补黑或留白。候选也会包含深色衣物、头发和暗背景，不能把它们都当成投影。先单看黑块的大形，必要时关闭“只看黑块”以叠加线条；纯黑面积仅作观察记录，没有固定合格比例。

粘贴截图

点「从剪贴板粘贴」：能读剪贴板时会直接载入图片；如果浏览器拦截剪贴板权限，会弹出一个粘贴框，点一下框再按 Ctrl+V 即可。也可以用截图工具截图后直接在页面任意位置 Ctrl+V。处理书籍 / 影视截图不需要先保存成文件。

透明色 / 白色（抓型）

「色块」和「灰度」模式里，点一个色块，下方有「正常 / 透明 / 白色」三个按钮。把背景色或不需要的颜色设为透明/白色，只留下主体形状，便于抓型。透明会导出带 alpha 的 PNG（预览显示棋盘格，打印/参考卡按纸白处理）；白色则把像素直接改成白色，导出不带透明。多个颜色可以分别设置，点「全部恢复正常」可一键复原。

保存多种结果

「保存…」中可勾选原图、线条 / 黑块、色块 / 明暗、参考卡：选一项直接下载，选多项打包成 ZIP。当前线条或黑块结果保留局部笔画；从别的模式保存时，优先使用本张图片已保留的模式结果。换图或刷新前请主动保存。

明暗归纳

支持 2 / 3 / 5 组。分界使用 L* 明度（0 暗—100 亮）；五组时，在暗端和亮端各自动细分一级。输出灰阶滑杆使用 0–255（0 黑、255 白），它改变每组呈现的深浅，不移动分组边界。“均分明度”按输出灰度值均分，不代表 L* 等距，也不是唯一合适的明暗安排。

批量处理

展开「批量处理」，选择文件夹或一组图片，按当前模式和参数分别计算，再打包为 ZIP。本图的固定分块与局部笔画不会套到其他图片。处理中可停止，已完成的结果仍会打包；图片较多时，建议使用 1000–1600 px 工作尺寸。

打印参考卡

点「打印参考卡…」会生成一张 A4 竖版纸面并弹出打印窗口；可以勾选「同时打印原图」，做成左边原图、右边色块结果的对照页。在打印窗口里也可以选「另存为 PDF」。

术语 & 小技巧

  • 这个功能叫「色彩量化 / 限色」，美术上也叫「色彩归纳」「色块概括」。
  • 练明暗：从三组开始，缩小看大形，再决定是否需要五组。
  • 练限色：先固定分块，再把色板换成手上的颜料色，单独比较颜色关系。
  • 快捷键：Ctrl+V 粘贴，Ctrl+S 导出 PNG。

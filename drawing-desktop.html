几件实用的小事

安装时需要联网吗？

应用使用电脑上的 Microsoft WebView2 Runtime。已经安装该运行环境时可直接使用；缺少时，安装版会联网补装。环境准备好后，本机绘画、图片/PDF 参考和导出都可离线使用。博客入口、配色来源和查看新版等外部链接需要联网。

安装版和免安装版怎么选？

日常使用推荐安装版，会提供桌面和开始菜单入口。ZIP 解压后运行 Lightdraw.exe，适合已有 WebView2 的电脑。两种版本的草稿均保存在当前 Windows 用户目录，不会跟随 EXE 或 U 盘一起移动；搬到另一台电脑请使用 .lrxdraw 工程。

数位板压感和电脑性能呢？

保留原画室的数位笔压力输入、防抖和鼠标绘画路径。Wacom 的实际压感仍需配合驱动与 Windows Ink 设置，尚未对所有型号做实机验证。应用共用系统 WebView2，安装包不用附带整套浏览器；绘画时的内存仍取决于画布大小、图层和撤销记录。

如何保存和更新？

关闭主画窗前会等待当前修改保存；保存失败时保留窗口供你另存工程。重要作品请定期用“存工程”备份。更新时回到本页下载新版本，应用不会在后台下载更新。

关于发布者与文件校验

这是未使用代码签名证书签名的个人项目版本，Windows 可能显示发布者未验证。安装文件只通过本页链接的 GitHub Release 发布，同一版本附有 SHA256SUMS.txt，可核对下载文件的 SHA-256。源码与构建流程均在项目仓库公开。

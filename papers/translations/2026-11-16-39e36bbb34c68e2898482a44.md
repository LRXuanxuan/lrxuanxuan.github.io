**作者：** Steven Rivetti（IEEE 学生会员）、Gabor Fodor（IEEE 会士）、Emil Björnson（IEEE 会士）、Mikael Skoglund（IEEE 会士）

**摘要：** 本文研究 Kronecker 可分空间相关在何种条件下能够近似多输入多输出（multiple-input-multiple-output, MIMO）信道的协方差。我们提出一种几何感知的信道老化模型，其中同一传播环境同时决定 Weischelberger 空间耦合矩阵与时间相关系数。传播环境遵循受 3GPP 启发的分簇信道模型。我们考虑一个受用户设备（user equipment, UE）移动性引起的符号级信道老化影响的 MIMO 系统。我们同时调度上行与下行导频，从而在信道状态信息（channel state information, CSI）不完美的情况下推导各自的频谱效率（spectral efficiency, SE）。数值结果表明，信道老化的幅度强烈依赖于几何：与集中散射相比，弥散传播引起更强的时间去相关与 SE 退化。结果还识别出 Kronecker 可分性可应用的区间，以及需要几何感知 Weischelberger 耦合的区间。

**关键词：** Weischelberger 相关、联合相关衰落、时间相关、信道老化。

**I. 引言**

多输入多输出（MIMO）系统依赖准确的信道状态信息（CSI）来执行多用户（multi-user, MU）预编码与干扰抑制。在实际中，CSI 通过导频传输获取，并由于用户设备（UE）移动性与传播环境的动态演化而随时间逐渐过时。这一现象通常称为信道老化[1]，在高移动性场景中尤为普遍：此时帧内信道变化可能不可忽略[2]，导致可达频谱效率（SE）下降。信道时间相关的衰减常使用类 Jake 的各向同性散射模型建模，其产生的相关系数主要由 UE 速度幅值决定[3]。该模型虽在数学上易于处理，却无法刻画传播几何的影响：具有相同速度幅值的 UE，可能因其主导多径簇的位置不同而呈现不同的相关衰减。

传播几何由信道空间协方差矩阵表示。得益于数学上的可处理性，Kronecker 可分模型是应用最广的模型之一[4]。该模型把 MIMO 信道协方差表示为一侧基站（base station, BS）相关矩阵与一侧 UE 相关矩阵的乘积。这种可分假设忽略了 BS 与 UE 之间的联合相关，而该联合相关在多用户 MIMO 网络中尤为重要。Weischelberger 模型[5]通过引入耦合矩阵来克服这一局限，该矩阵描述功率如何在 BS–UE 特征模对之间分配[6]。然而，这种耦合常被视为抽象对象，而未被显式地与传播几何联系起来[7]。

一个统一框架应当使同一传播环境同时产生 MIMO 信道的空间相关与时间相关，这一需求引出本文的核心问题：Kronecker 可分模型在何时足够准确，又在何时必须采用联合相关耦合建模才能刻画传播几何？

**A. 贡献**

本文提出一种几何感知的 MIMO 信道老化模型，通过同一传播几何把空间特征模耦合与时间相关联系起来。传播几何受 3GPP 标准化的簇时延线（cluster delay line）信道模型启发。传播环境确实由传播簇构成，其位置随机生成；不过值得一提的是，在实际部署中同一框架也可由射线追踪驱动。我们通过把簇级协方差贡献投影到 BS 与 UE 特征模上，构造 Weischelberger 耦合矩阵。随后推导依赖簇的时间相关系数，其中每个簇的多普勒偏移按其功率、UE 侧角度与多普勒扩展加权。为此，我们提出一种多普勒扩展模型，把角度域中的不确定度直接与多普勒域中的不确定度联系起来。最后，我们在采用显式上行（uplink, UL）与下行（downlink, DL）导频、基于协方差的信道估计以及不完美 CSI 的 SE 表达式的时分双工（time-division duplexing, TDD）MIMO 系统中，评估符号级老化的影响。数值结果识别出 Kronecker 近似准确的区间以及需要几何感知耦合的区间，并表明弥散传播比集中散射引起更强的时间去相关与更大的 SE 损失。

**II. 系统模型**

我们考虑一个多用户 MIMO 系统：位于原点、配备 $M_{\mathrm{BS}}$ 根天线的基站（BS）服务 $K$ 个配备 $M_{\mathrm{UE}}$ 根天线的 UE，其位置为 $\mathbf{e}_k=[e_{k,x},e_{k,y}]^{\top}$。BS 在载波频率 $\overline{f}$ 附近执行正交频分复用

<span id="page-2"></span>

（接上页）（OFDM）传输，使用 $V$ 个有效子载波，子载波间隔为 $\Delta_f$。子载波被划分为 $B$ 个块、每块含 $V_{\mathrm{cho}}$ 个子载波，以块索引 $n$ 标识：假设同一块内各子载波上的信道保持不变。这里 $T=1/\Delta_f+T_{\mathrm{cp}}$ 为符号时长，$T_{\mathrm{cp}}$ 为循环前缀时长。我们定义符号时间索引 $i$，时间单位为 $T$。UE $k$ 与 BS 之间的频域 UL 通信信道记为 $\mathbf{H}_{k,i,n}\in\mathbb{C}^{M_{\mathrm{BS}}\times M_{\mathrm{UE}}}$。假设采用 TDD 与 UL/DL 信道互易，即 $\mathbf{H}_{k,i,n}^{\mathrm{DL}}=\mathbf{H}_{k,i,n}^{\top}$。我们考虑符号时间之间不可忽略的时间相关：相关衰减建模为状态转移矩阵为比例单位阵的一阶自回归（autoregressive, AR）过程[1]。于是信道的时间相关定义为 $\mathbb{E}[\mathbf{h}_{k,i,n}\mathbf{h}_{k,i',n}^{\mathrm{H}}]=\mathbf{C}_k\zeta_k(|i-i'|)$，其中 $\zeta_k(|i-i'|)$ 刻画相关衰减。

BS 在时刻 $i$、块 $n$ 中任一子载波 $v$ 上的频域 UL 观测定义为

$$\mathbf{y}_{i,n}^{\mathrm{UL}}\triangleq\sum_{k=1}^{K}\alpha_k\mathbf{H}_{k,i,n}\mathbf{W}_{k,i,n}\boldsymbol{x}_{k,i,v}+\mathbf{n}_{i,v}, \tag{1}$$

其中 $\mathbf{W}_{k,i,n}\in\mathbb{C}^{M_{\mathrm{UE}}\times M_{\mathrm{UE}}}$ 为 UE $k$ 在时刻 $i$ 对块 $n$ 全部子载波所采用的预编码矩阵。这里 $\alpha_k$ 计入 UE $k$ 的路径损耗与大尺度衰落。$\boldsymbol{x}_{k,i,v}\in\mathbb{C}^{M_{\mathrm{UE}}}$ 为 UE $k$ 在其 UL 传输中采用的发送符号，假设 $\boldsymbol{x}_{k,i,v}\sim\mathcal{CN}(\mathbf{0},\mathbf{I}_{M_{\mathrm{UE}}})$。BS 接收机噪声为 $\mathbf{n}_{i,v}\sim\mathcal{CN}(\mathbf{0},\mathbf{I}_{M_{\mathrm{UE}}}\sigma_{\mathrm{BS}}^2)$。

反之，UE $k$ 处的频域 DL 观测定义为

$$\mathbf{y}_{k,i,n}^{\mathrm{DL}}\triangleq\alpha_k\mathbf{H}_{k,b.n}^{\mathrm{DL}}\mathbf{F}_{i,n}\boldsymbol{x}_{i,v}+\mathbf{n}_{i,v}, \tag{2}$$

其中 $\mathbf{F}_{i,n}=[\mathbf{F}_{1,i,n},\dots,\mathbf{F}_{K,i,n}]\in\mathbb{C}^{M_{\mathrm{BS}}\times KM_{\mathrm{UE}}}$ 为第 $n$ 个块中每个子载波所采用的预编码矩阵。发送符号定义为 $\boldsymbol{x}_{i,v}=[\boldsymbol{x}_{i,v,1},\dots,\boldsymbol{x}_{i,v,K}]^{\top}\in\mathbb{C}^{M_{\mathrm{UE}}K}$，其中 $\boldsymbol{x}_{i,v,k}\sim\mathcal{CN}(\mathbf{0},\mathbf{I}_{M_{\mathrm{UE}}})$。最后，$\mathbf{n}_{i,v,k}\sim\mathcal{CN}(\mathbf{0},\mathbf{I}_{M_{\mathrm{UE}}}\sigma_k^2)$ 为 UE $k$ 的接收机噪声。

**A. Weischelberger 相关模型**

这里我们以 Weichselberger Rayleigh 衰落模型[5]为参照，并用它研究 Kronecker 可分近似在何时准确。该模型引入特征模耦合矩阵，此处记为 $\boldsymbol{\Omega}_k\in\mathbb{R}_+^{M_{\mathrm{BS}}\times M_{\mathrm{UE}}}$，它规定信道功率如何在 BS–UE 特征模对之间分配；而 Kronecker 模型作为可分的特例得到，其中 BS 与 UE 特征模完全解耦。我们定义 UE $k$ 与 BS 之间 UL 信道的单侧相关矩阵为 $\mathbf{C}_{\mathrm{BS},k}=\mathbb{E}[\mathbf{H}_k\mathbf{H}_k^{\mathrm{H}}]\in\mathbb{C}^{M_{\mathrm{BS}}\times M_{\mathrm{BS}}}$ 与 $\mathbf{C}_{\mathrm{UE},k}=\mathbb{E}[\mathbf{H}_k^{\mathrm{DL}}\mathbf{H}_k^{\mathrm{DL},\mathrm{H}}]\in\mathbb{C}^{M_{\mathrm{UE}}\times M_{\mathrm{UE}}}$，其特征分解分别为 $\mathbf{C}_{\mathrm{BS},k}=\mathbf{U}_{\mathrm{BS},k}\mathrm{diag}(\boldsymbol{\lambda}_{\mathrm{BS},k})\mathbf{U}_{\mathrm{BS},k}^{\mathrm{H}}$ 与 $\mathbf{C}_{\mathrm{UE},k}=\mathbf{U}_{\mathrm{UE},k}\mathrm{diag}(\boldsymbol{\lambda}_{\mathrm{UE},k})\mathbf{U}_{\mathrm{UE},k}^{\mathrm{H}}$。UL 信道协方差 $\mathbf{C}_k^{\mathrm{UL}}=\mathbb{E}[\mathrm{vec}(\mathbf{H})\mathrm{vec}(\mathbf{H})^{\mathrm{H}}]$ 定义为

$$\mathbf{C}_k^{\mathrm{UL}}=\left(\mathbf{U}_{\mathrm{UE},k}^{*}\otimes\mathbf{U}_{\mathrm{BS},k}\right)\mathbf{D}_{\Omega,k}\left(\mathbf{U}_{\mathrm{UE},k}^{*}\otimes\mathbf{U}_{\mathrm{BS},k}\right)^{\mathrm{H}}, \tag{3}$$

其中 $\mathbf{D}_{\Omega,k}=\mathrm{diag}(\mathrm{vec}(\boldsymbol{\Omega}_k))$。由互易性可得 DL 信道协方差 $\mathbf{C}_k^{\mathrm{DL}}=\mathbb{E}[\mathrm{vec}(\mathbf{H}^{\mathrm{DL}})\mathrm{vec}(\mathbf{H}^{\mathrm{DL}})^{\mathrm{H}}]$：

$$\mathbf{C}_k^{\mathrm{DL}}=\left(\mathbf{U}_{\mathrm{BS},k}^{*}\otimes\mathbf{U}_{\mathrm{UE},k}\right)\mathbf{D}_{\Omega^{\top},k}\left(\mathbf{U}_{\mathrm{BS},k}^{*}\otimes\mathbf{U}_{\mathrm{UE},k}\right)^{\mathrm{H}}. \tag{4}$$

为简便起见，两个矩阵的迹均归一化为 1。应当注意，耦合矩阵 $\boldsymbol{\Omega}_k^{\mathrm{kron}}=\frac{1}{M_{\mathrm{BS}}M_{\mathrm{UE}}}\boldsymbol{\lambda}_{\mathrm{BS},k}\boldsymbol{\lambda}_{\mathrm{UE},k}^{\top}$ 给出 Kronecker 可分的协方差模型。Kronecker 可分模型与联合相关模型之间的协方差失配度量定义为

$$d_{\Omega}=\max_k\frac{\left\|\boldsymbol{\Omega}_k-\boldsymbol{\Omega}_k^{\mathrm{kron}}\right\|_F^2}{\left\|\boldsymbol{\Omega}_k\right\|_F^2}. \tag{5}$$

**B. 传播几何**

BS 与各 UE 之间的传播环境由 $C$ 个散射簇构成。簇 $c$ 的中心为 $\mathbf{p}_c=[p_{x,c},p_{y,c}]^{\top}$，BS 以角度 $\psi_c$ 观测到它，UE $k$ 以角度 $\varphi_{k,c}$ 观测到它。每个簇所散射射线的角度服从正态分布，其角度扩展与观测侧有关，分别记为 $\varsigma_{\mathrm{BS},c}$ 与 $\varsigma_{\mathrm{UE},k,c}$。假设每个簇的尺寸由其有效半径 $r_c$ 描述，则这些簇的角度扩展计算为

$$\varsigma_{\mathrm{BS},c}=\mathrm{atan}\left(\frac{r_c}{\|\mathbf{p}_c\|}\right),\quad\varsigma_{\mathrm{UE},k,c}=\mathrm{atan}\left(\frac{r_c}{\|\mathbf{p}_c-\mathbf{e}_k\|}\right). \tag{6}$$

该模型背后的理由是：更近的簇在更宽的角度区间内散射射线，而更远的簇则反之。边缘协方差 $\mathbf{C}_{\mathrm{BS},k}$ 与 $\mathbf{C}_{\mathrm{UE},k}$ 按文献[8]中的模型计算：在小角度扩展假设下，可写为 $\mathbf{C}_{\mathrm{BS}}=\sum_{c=1}^{C}\rho_c^{\mathrm{BS}}\mathbf{C}_{\mathrm{BS},c}$，其中

$$\left[\mathbf{C}_{\mathrm{BS},c}\right]_{l,m}\approx e^{-j\pi(l-m)\sin(\psi_c)}e^{-\frac{\pi^2}{2}((l-m)\cos(\psi_c)\varsigma_{\mathrm{BS},c})^2}. \tag{7}$$

$\mathbf{C}_{\mathrm{UE},k}$ 的定义遵循同一模型，为简洁起见从略。这里 $\rho_c^{\mathrm{BS}}$ 表示从 BS 侧看到的簇 $c$ 的功率；反之，$\rho_{c,k}^{\mathrm{UE}}$ 表示 UE $k$ 看到的簇功率，而 $\rho_{c,k}^{\mathrm{J}}$ 表示该簇在耦合矩阵中的功率。这些功率均由对标准化功率时延谱[9]的基于几何的改造生成。簇的 BS 侧、UE 侧与联合时延分别定义为 $\overline{\tau}_c^{\mathrm{BS}}=\|\mathbf{p}_c\|/c_0$、$\overline{\tau}_{c,k}^{\mathrm{UE}}=\|\mathbf{p}_c-\mathbf{e}_k\|/c_0$ 与 $\overline{\tau}_{c,k}^{\mathrm{J}}=(\|\mathbf{p}_c\|+\|\mathbf{p}_c-\mathbf{e}_k\|-\|\mathbf{e}_k\|)/c_0$，其中 $c_0$ 表示光速。

<span id="page-3"></span>

（接上页）随后把每个时延重新归一化，使最近的簇具有零时延，即 $\tau_{c,k}=\overline{\tau}_{c,k}-\min_l\overline{\tau}_{l,k}$。簇功率随后按文献[9, 第 54 页]计算为

$$\rho_{c,k}=\exp\left\{-\tau_{c,k}(r_\tau-1)/(r_\tau DS)\right\}10^{-Z_{c,k}/10}, \tag{8}$$

其中 $DS$ 与 $r_\tau$ 分别为均方根（root mean square, RMS）时延扩展与时延比例因子。逐簇阴影项记为 $Z_{c,k}\sim\mathrm{Lognorm}(0,\sigma_Z^2)$。这些功率随后归一化，使得 $\sum_c\rho_c^{\mathrm{BS}}=\sum_c\rho_{c,k}^{\mathrm{UE}}=\sum_c\rho_{c,k}^{\mathrm{J}}=1,\ \forall k$。我们提出如下耦合矩阵。

**命题 2：** 令 $\mathbf{u}_{\mathrm{BS},l}$ 与 $\mathbf{u}_{\mathrm{UE},k,m}$ 分别表示 $\mathbf{C}_{\mathrm{BS}}$ 的第 $l$ 大特征向量与 $\mathbf{C}_{\mathrm{UE},k}$ 的第 $m$ 大特征向量，则基于几何的耦合矩阵为

$$[\boldsymbol{\Omega}_k]_{l,m}=\sum_{c=1}^{C}\rho_{c,k}^{\mathrm{J}}\nu_{c,l}\upsilon_{k,c,m}, \tag{9}$$

$$\nu_{c,l}=\left(\mathbf{u}_{\mathrm{BS},l}^{\mathrm{H}}\mathbf{C}_{\mathrm{BS},c}\mathbf{u}_{\mathrm{BS},l}\right)/M_{\mathrm{BS}}, \tag{10}$$

$$\upsilon_{k,c,m}=\left(\mathbf{u}_{\mathrm{UE},k,m}^{\mathrm{H}}\mathbf{C}_{\mathrm{UE},k,c}\mathbf{u}_{\mathrm{UE},k,m}\right)/M_{\mathrm{UE}}. \tag{11}$$

该耦合矩阵把传播环境映射到特征模耦合：当两个特征模均被一个或多个高功率簇激励时，$[\boldsymbol{\Omega}_k]_{l,m}$ 较大。某特征模被某簇激励的程度，通过把该簇对边缘协方差的贡献（如 $\mathbf{C}_{\mathrm{BS},k,c}$）投影到相应特征向量（如 $\mathbf{u}_{\mathrm{BS},k,l}$）上度量。我们对 $\boldsymbol{\Omega}$ 施加 Sinkhorn 型缩放[10]，使行和与列和分别与 BS 与 UE 的边缘特征值匹配，从而确保与 $\boldsymbol{\Omega}^{\mathrm{kron}}$ 的公平比较。

**C. 时间相关**

在我们此前的工作中，时间相关系数 $\zeta$ 服从 Jake 模型。该模型在解析上便利，却对不同传播方向取平均，并未考虑 UE 的多普勒偏移并非各向同性这一事实，这意味着位于不同位置的簇以不同速率老化。令 UE $k$ 的速度为 $\boldsymbol{\nu}_k=\|\boldsymbol{\nu}_k\|[\cos(\theta_k),\sin(\theta_k)]$，其中 $\theta_k$ 表示速度方向。因此，簇 $c$ 观测到的多普勒偏移定义为 $f_{\mathrm{D},k,c}=(\overline{f}\|\boldsymbol{\nu}_k\|/c_0)\cos(\varphi_{k,c}-\theta_k)$。参照文献[11, 引理 1]给出的模型，相关系数为

$$\zeta_k(i)=\sum_{c=1}^{C}\rho_{k,c}^{\mathrm{UE}}e^{j2\pi if_{\mathrm{D},k,c}T}e^{-2(\pi T i\varsigma_{\mathrm{D},k,c})^2}, \tag{12}$$

其中 $\varsigma_{\mathrm{D},k,c}$ 表示该簇的多普勒扩展，可按如下引理与传播几何关联。

**引理 1：** 考虑 UE $k$ 以角度 $\varphi_{k,c}$、角度扩展 $\varsigma_{\mathrm{UE},k,c}$ 观测到的簇。假设簇内角度偏差服从高斯分布，则 UE $k$ 观测到的簇多普勒扩展 $\varsigma_{\mathrm{D},k,c}$ 定义为

$$\varsigma_{\mathrm{D},k,c}^2=\overline{f}_{\mathrm{D},k}^2\left[0.5\left(1+A_{k,c}^2\cos(2\epsilon_{k,c})\right)-A_{k,c}\cos^2(\epsilon_{k,c})\right], \tag{13}$$

其中 $A_{k,c}=e^{-\varsigma_{\mathrm{UE},k,c}^2}$、$\overline{f}_{\mathrm{D},k}=\overline{f}\|\boldsymbol{\nu}_k\|/c_0$、$\epsilon_{k,c}=\theta_k-\varphi_{k,c}$。

**证明：** 簇 $c$ 散射的每条射线由 UE $k$ 以角度 $\varphi_{k,c,n}=\varphi_{k,c}+\delta_{\mathrm{UE},k,c,n}$ 观测到，其中 $\delta_{\mathrm{UE},k,c,n}\sim\mathcal{N}(0,\varsigma_{\mathrm{UE},k,c}^2)$ 表示相对标称角度的偏差。于是第 $n$ 条射线的多普勒偏移为 $f_{\mathrm{D},k,c,n}=\overline{f}_{\mathrm{D},k}\cos(\epsilon_{k,c}+\delta_{\mathrm{UE},n})$。考虑到 $\mathbb{E}[\cos(\delta_{\mathrm{UE},k,c,n})]=\exp\{-\varsigma_{\mathrm{UE},k,c}^2/2\}$，并利用三角恒等式 $\cos(a+b)=\cos(a)\cos(b)-\sin(a)\sin(b)$，可算得 $\mathbb{E}[f_{\mathrm{D},k,c,n}]=\overline{f}_{\mathrm{D},k}\exp\{-\varsigma_{\mathrm{UE},k,c}^2/2\}\cos(\epsilon_{k,c})$。进一步利用恒等式 $\cos(a)^2=(1+\cos(2a))/2$，可算得 $\mathbb{E}[f_{\mathrm{D},k,c,n}^2]=0.5\overline{f}_{\mathrm{D},k}^2(1+\exp\{-2\varsigma_{\mathrm{UE},k,c}^2\}\cos(2\epsilon_{k,c}))$。引理由计算 $\varsigma_{\mathrm{D},k,c}^2=\mathbb{E}[f_{\mathrm{D},k,c,n}^2]-\mathbb{E}[f_{\mathrm{D},k,c,n}]^2$ 得证。

**III. 信道估计与频谱效率**

图 1 给出所采用的导频传输图样。UL 与 DL 导频均被调度，以便为 UE 与 BS 提供用于数据检测与预编码的估计 CSI。每个帧由 $\Delta_{\mathrm{UL}}$ 个 UL 数据时隙与 $\Delta_{\mathrm{DL}}$ 个 DL 数据时隙组成，数据时隙总数为 $\Delta=\Delta_{\mathrm{UL}}+\Delta_{\mathrm{DL}}$。导频传输期间采用的预编码矩阵记为 $\mathbf{W}_{0,k,n}$ 与 $\mathbf{F}_{0,n}$，假设其固定且为双方已知[脚注：这避免了引入非高斯等效信道估计[12]，超出本文范围]。现在聚焦 UL 阶段：每个 UE 在 $\tau_{\mathrm{p}}$ 个子载波上发送其导频矩阵 $\boldsymbol{\beth}_k\in\mathbb{C}^{M_{\mathrm{UE}}\times\tau_{\mathrm{p}}}$，这些矩阵相互正交，即 $\boldsymbol{\beth}_k\boldsymbol{\beth}_{k'}^{\mathrm{H}}=\tau_{\mathrm{p}}^{\mathrm{UL}}\mathbf{I}\leftrightarrow k=k'$。后续讨论适用于所有块，因此为简洁起见省略索引 $n$。考虑任一导频时隙 $\iota$，观测到的导频矩阵为 $\mathbf{Y}_{\iota}=\sum_{k=1}^{K}\alpha_k\mathbf{H}_{k,\iota}\mathbf{W}_{0,k}\boldsymbol{\beth}_k+\mathbf{N}_{\iota}\in\mathbb{C}^{M_{\mathrm{BS}}\times\tau_{\mathrm{p}}^{\mathrm{UL}}}$。经导频解扩后，向量化观测定义为

$$\widetilde{\mathbf{y}}_{\iota,k}=\alpha_k\sqrt{\tau_{\mathrm{p}}^{\mathrm{UL}}}\left(\mathbf{W}_{0,k}^{\top}\otimes\mathbf{I}_{M_{\mathrm{BS}}}\right)\mathbf{h}_{k,\iota}+\mathrm{vec}(\widetilde{\mathbf{N}}_{\iota}). \tag{14}$$

接收机使用当前时刻之前的 $p$ 个导频观测，使信道估计所用的观测总数为 $p_{\mathrm{tot}}=p+1$：我们采用文献[13]给出的最小均方误差（minimum mean square error, MMSE）信道估计，即

$$\widehat{\mathbf{h}}_{k,i}=\alpha_k\sqrt{\tau_{\mathrm{p}}^{\mathrm{UL}}}\mathbf{E}_{k,i}\mathbf{W}_{p_{\mathrm{tot}},k}^{\mathrm{H}}\overline{\mathbf{A}}_{k,i}^{-1}\widetilde{\mathbf{y}}_{k}^{p_{\mathrm{tot}}}, \tag{15}$$

其中 $\overline{\mathbf{A}}_{k,i}=\alpha_k^2\tau_{\mathrm{p}}^{\mathrm{UL}}\mathbf{W}_{p_{\mathrm{tot}},k}^{\mathrm{H}}\mathbf{M}_k\mathbf{W}_{p_{\mathrm{tot}},k}^{\mathrm{H}}+\sigma_k^2\mathbf{I}_{p_{\mathrm{tot}}M_{\mathrm{UE}}M_{\mathrm{BS}}}$，$\mathbf{W}_{p_{\mathrm{tot}},k}=\mathbf{I}_{p_{\mathrm{tot}}}\otimes(\mathbf{W}_{0,k}^{\top}\otimes\mathbf{I}_{M_{\mathrm{BS}}})$，$\mathbf{E}_{k,i}=[\zeta(i-\iota),\dots,\zeta(i-\iota+p(\Delta+1))]\otimes\mathbf{C}_k^{\mathrm{UL}}$，$\mathbf{M}_k=\mathcal{T}([\zeta(0),\dots,\zeta(p(\Delta+1))])\otimes\mathbf{C}_k^{\mathrm{UL}}$，$\widetilde{\mathbf{y}}_k^{p_{\mathrm{tot}}}=[\widetilde{\mathbf{y}}_{k,\iota}^{\top},\dots,\widetilde{\mathbf{y}}_{k,\iota-p(\Delta+1)}^{\top}]^{\top}$。信道估计 $\widehat{\mathbf{h}}_{k,i}$ 服从 $\widehat{\mathbf{h}}_{k,i}\sim\mathcal{CN}(\mathbf{0},\widehat{\boldsymbol{\Xi}}_{k,i}=\alpha_k\tau_{\mathrm{p}}^{\mathrm{UL}}\mathbf{E}_k\mathbf{W}_{p_{\mathrm{tot}},k}^{\mathrm{H}}\overline{\mathbf{A}}_{k,i}^{-1}\mathbf{W}_{p_{\mathrm{tot}},k}\mathbf{E}_{k,i}^{\mathrm{H}})$。另一方面，信道估计误差 $\widetilde{\mathbf{h}}_{k,i}=\mathbf{h}_{k,i}-\widehat{\mathbf{h}}_{k,i}$ 的分布为 $\widetilde{\mathbf{h}}_{k,i}\sim\mathcal{CN}(\mathbf{0},\widetilde{\boldsymbol{\Xi}}_{k,i}=\mathbf{C}_k^{\mathrm{UL}}-\widehat{\boldsymbol{\Xi}}_{k,i})$。我们现在在不完美 CSI 与已知预编码器的假设下推导可达 UL 与 DL SE。考虑块 $n$ 中的任一子载波 $v$：BS 为检测 $\boldsymbol{x}_{k,i,v}$ 采用任一合并矩阵 $\mathbf{T}_{k,i,n}\in\mathbb{C}^{M_{\mathrm{BS}}\times M_{\mathrm{UE}}}$，用于检测

<span id="page-4"></span>

（接上页）$\boldsymbol{x}_{k,i,v}$；同时 UE $k$ 采用合并矩阵 $\mathbf{Q}_{k,i,n}\in\mathbb{C}^{M_{\mathrm{UE}}\times M_{\mathrm{UE}}}$ 检测 $\mathbf{x}_{k,i,v}$。假设采用串行干扰消除，UE $k$ 在数据符号时刻 $i$ 的 UL SE 为[6, 推论 1]

$$\mathrm{SE}_{k,i,v}^{\mathrm{UL}}=\mathbb{E}\left\{\log_2\left|\mathbf{I}_{M_{\mathrm{UE}}}+\alpha_k^2\mathcal{H}_{k,i,n}^{\mathrm{H}}\boldsymbol{\Lambda}_{k,i,n}^{-1}\mathcal{H}_{k,i,n}\right|\right\}, \tag{16}$$

其中 $\mathcal{H}_{k,i,n}=\mathbf{T}_{k,i,n}^{\mathrm{H}}\widehat{\mathbf{H}}_{k,i,n}\mathbf{W}_{k,i,n}$，$\boldsymbol{\Lambda}_{k,i,n}$ 由式 (17) 定义：

$$\boldsymbol{\Lambda}_{k,i,n}=\mathbf{T}_{k,i,n}^{\mathrm{H}}\left(\sum\nolimits_{l=1,l\neq k}^{K}\alpha_l^2\widehat{\mathbf{H}}_{l,i,n}\mathbf{W}_{l,i,n}\mathbf{W}_{l,i,n}^{\mathrm{H}}\widehat{\mathbf{H}}_{l,i,n}^{\mathrm{H}}+\sum\nolimits_{l=1}^{K}\alpha_l^2\mathrm{Cov}\left[\widetilde{\mathbf{H}}_{l,i,n}\mathbf{W}_{l,i,n}\right]+\sigma^2\mathbf{I}_{M_{\mathrm{BS}}}\right)\mathbf{T}_{k,i,n}. \tag{17}$$

这里 $\widetilde{\mathbf{H}}_{k,i,n}$ 由把 $\widetilde{\mathbf{h}}_{k,i,n}$ 堆叠成矩阵得到。为简洁起见不显式给出 DL 信道估计器，因为它与式 (15) 采用相同的基于协方差的方法，详见文献[11]。假设 UE 已知 BS 预编码器，DL SE 可建模为

$$\mathrm{SE}_{k,i,v}^{\mathrm{DL}}=\mathbb{E}\left\{\log_2\left|\mathbf{I}_{M_{\mathrm{UE}}}+\alpha_k^2\left(\mathcal{H}_{k,i,n}^{\mathrm{DL}}\right)^{\mathrm{H}}\boldsymbol{\Gamma}_{k,i,n}^{-1}\mathcal{H}_{k,i,n}^{\mathrm{DL}}\right|\right\}, \tag{19}$$

其中 $\mathcal{H}_{k,i,n}^{\mathrm{DL}}=\mathbf{Q}_{k,i,n}^{\mathrm{H}}\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\mathbf{F}_{k,i,n}$，$\boldsymbol{\Gamma}_{k,i,n}$ 由式 (18) 定义：

$$\boldsymbol{\Gamma}_{k,i,n}=\mathbf{Q}_{k,i,n}^{\mathrm{H}}\left(\sum\nolimits_{l=1,l\neq k}^{K}\alpha_k^2\widehat{\mathbf{H}}_{k,i,n,l}^{\mathrm{DL}}\mathbf{F}_{l,i,n}\mathbf{F}_{l,i,n}^{\mathrm{H}}\left(\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\right)^{\mathrm{H}}+\alpha_k^2\mathrm{Cov}\left[\widetilde{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\mathbf{F}_{i,n}\right]+\sigma^2\mathbf{I}_{M_{\mathrm{UE}}}\right)\mathbf{Q}_{k,i,n}. \tag{18}$$

因此，整个帧上对子载波与 UE 聚合的平均 UL SE（DL SE 同理）定义为 $\mathrm{SE}_{\mathrm{UL}}=\sum_{k=1}^{K}\sum_{i=1}^{\Delta_{\mathrm{UL}}}\sum_{v=1}^{V}\mathrm{SE}_{k,i,v}^{\mathrm{UL}}/(\Delta+2)$。

**A. 预编码策略**

所采用的预编码策略在数据时隙（CSI 可用）与导频时隙（先前估计已偏离其真实值过远）之间有所不同。在无 CSI 时，BS 实施特征波束成形，即 $\mathbf{F}_{0,n,k}=[\mathbf{u}_{\mathrm{BS},k,1},\dots,\mathbf{u}_{\mathrm{BS},k,M_{\mathrm{UE}}}]$，而 $\mathbf{W}_{0,k,n}=\mathbf{I}_{M_{\mathrm{UE}}}$。在存在 CSI 时，BS 采用 MMSE 预编码[14, 第 5 章]，而 UE 的预编码器为 $\mathbf{W}_{k,i,n}=\mathbf{U}_{k,i,n}$，其中 $\mathbf{U}_{k,i,n}$ 是 $\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}$ 的左奇异矩阵。预编码器经归一化以保证子载波与流之间的等功率分配。我们在 BS 处比较迫零（zero-forcing, ZF）与 MMSE 合并：ZF 合并矩阵为 $\mathbf{T}_{k,i,n}^{\mathrm{ZF}}=\mathbf{H}_{i,n}^{\dagger}$，其中 $\mathbf{H}_{i,n}=[\alpha_1\mathbf{H}_{1,i,n},\alpha_K\mathbf{H}_{K,i,n}]$，而 MMSE 合并矩阵 $\mathbf{T}_{k,i,n}^{\mathrm{MM}}$ 由式 (20) 定义。UE 采用由式 (18) 定义的合并矩阵 $\mathbf{Q}_{k,i,n}$。

$$\mathbf{T}_{k,i,n}^{\mathrm{MM}}=\left(\sum_{k=1}^{K}\alpha_k^2\left(\widehat{\mathbf{H}}_{k,i,n}\mathbf{W}_{k,i,n}\mathbf{W}_{k,i,n}^{\mathrm{H}}\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{H}}+\mathrm{Cov}[\widetilde{\mathbf{H}}_{k,i,n}^{\top}\mathbf{W}_{k,i,n}]\right)+\sigma^2\mathbf{I}_{M_{\mathrm{BS}}}\right)^{-1}\alpha_k\widehat{\mathbf{H}}_{k,i,n}\mathbf{W}_{k,i,n}, \tag{20}$$

$$\mathbf{Q}_{k,i,n}=\left(\alpha_k^2\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\mathbf{F}_{i,n}\mathbf{F}_{i,n}^{\mathrm{H}}\left(\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\right)^{\mathrm{H}}+\mathrm{Cov}[\widetilde{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\mathbf{F}_{i,n}]+\sigma^2\mathbf{I}_{M_{\mathrm{BS}}}\right)^{-1}\alpha_k\widehat{\mathbf{H}}_{k,i,n}^{\mathrm{DL}}\mathbf{F}_{i,n}. \tag{21}$$

**IV. 数值结果**

仿真参数的默认值列于表 I。有效半径独立地取自表 I 所示的对数正态分布：$r_c$ 被截断在 $2$ 与 $30$ m 之间，以避免不切实际的大半径。由此得到的角度扩展也截断在 $1^{\circ}$ 与 $10^{\circ}$ 之间。簇数被划分为 $C_{\mathrm{dom}}=\lceil\eta C\rceil$ 个主簇与 $C_{\mathrm{back}}=C-C_{\mathrm{dom}}$ 个背景簇：这使我们可通过调节 $\eta$ 控制传播环境。主簇在 UE 间划分为 $C_{\mathrm{dom}}^{k}=\lceil C_{\mathrm{dom}}/K\rceil$，其位置随机生成为 $\mathbf{p}_{c}^{\mathrm{dom},k}=\beta_{k,c}\mathbf{e}_k+\kappa_{k,c}\mathbf{v}_k^{\perp}$。这里 $\beta_{k,c}\sim\mathcal{U}(0.35,0.65)$、$\kappa_{k,c}\sim\mathcal{N}(0,20)$ m，而 $\mathbf{v}_k^{\perp}$ 是与 $\mathbf{e}_k$ 正交的单位向量。另一方面，背景簇位置为 $\mathbf{p}_c^{\mathrm{back}}=[p_{c,x}^{\mathrm{back}},p_{c,y}^{\mathrm{back}}]^{\top}$，其中 $p_{c,x}^{\mathrm{back}}\sim\mathcal{U}(0,225)$、$p_{c,y}^{\mathrm{back}}\sim\mathcal{U}(-300,300)$。所提 Weischelberger 模型记为“Geo”，Kronecker 可分基线记为“Kron”。图 2 给出 Kronecker 可分模型与联合相关模型之间协方差失配的经验累积分布函数：实线为标称几何，虚线为主导簇质心偏移 $30^{\circ}$ 的设置。我们观察到，Kronecker 可分近似的准确度

<span id="page-5"></span>

（接上页）在集中散射环境下得到极大增强（即 $\eta=0.9$），其有 $50\%$ 的概率低于 $25\%$。主导簇质心偏移使 Kronecker 可分近似准确度大幅下降，且更不依赖于 $\eta$，因为点线曲线之间的差距显著缩小。这表明 Kronecker 近似的准确性受益于强集中传播环境，即簇位于 BS 与 UE 之间的连线上。

我们接下来研究 Kronecker 可分近似对可达 SE 的影响：图 3 给出在弥散（即 $\eta=0.1$）与集中（即 $\eta=0.9$）散射条件下，平均 UL 与 DL SE 随 UE 移动性增加的变化。图 3a 与 3b 分别给出采用 MMSE 与 ZF BS 合并时的 UL SE，图 3c 给出 DL SE。增大 $\|\boldsymbol{\nu}\|$ 会使所有 SE 下降，因为信道老化速率增加。集中散射环境产生更高的 SE：集中散射几何产生更小的多普勒扩展，其 $\zeta_k(\cdot)$ 对 UE 移动性更不敏感。图 3c 中的 DL SE 对 $\|\boldsymbol{\nu}\|$ 比 UL 更敏感（UL SE 受益于 BS 侧集中式检测），且呈现低至中等的 Geo–Kron 差距。相反，UL SE 对 UE 移动性较不敏感，并呈现较大的 Geo–Kron 差距。有趣的是，在 ZF BS 合并下，Geo–Kron 差距在集中传播环境中变小。

**图 3：** UL（MMSE (a) 与 ZF (b) BS 合并）与 DL (c) 的平均 SE。图中曲线由 20 次传播环境蒙特卡洛实现平均得到；对每个环境，SE 在 500 次信道与预编码器实现上平均。

**V. 结论**

我们提出一种几何感知的信道模型，其中同一分簇传播环境同时决定 Weischelberger 特征模耦合与时间相关衰减。信道老化现在由 UE 相对散射几何的运动决定，而不仅由其速度幅值决定。利用显式 UL 与 DL 导频，我们评估了信道估计与不完美 CSI 下的 SE。结果表明，Kronecker 可分性在高度集中传播区间是充分近似，但在弥散环境中可能遗漏重要的特征模耦合。此外，弥散传播引起更强的多普勒分集，导致更强的信道老化以及在高 UE 速度下更大的 SE 退化。这为面向移动性敏感的 MIMO 与通感一体化（integrated sensing and communication, ISAC）系统采用特征模耦合模型提供了动机。

## 阅读提示

- 核心问题：Kronecker 可分模型把 MIMO 协方差写成 BS 与 UE 单侧相关矩阵的积，忽略链路两端特征模的联合相关；本文要回答「何时 Kronecker 够用、何时必须用几何感知的 Weischelberger 耦合」。判断依据是式 (5) 的协方差失配 $d_{\Omega}$ 与两种模型下的可达 SE 差距（Geo–Kron gap）。
- 全文最有价值的方法贡献是把空间耦合与时间相关统一到同一簇几何上：命题 2 用簇级协方差投影构造 $\boldsymbol{\Omega}_k$（式 9–11），引理 1 把簇内角度扩展映射为多普勒扩展 $\varsigma_{\mathrm{D},k,c}$（式 13），进而得到簇加权的 $\zeta_k(i)$（式 12）。建议对照第 II-B、II-C 节阅读。
- 关键结论一（空间侧）：图 2 显示集中散射（$\eta=0.9$）下 Kronecker 近似有 50% 概率使失配低于 25%；主导簇质心偏移 30° 后 Kronecker 近似显著变差且几乎不随 $\eta$ 改善——即 Kronecker 可分性依赖「簇位于 BS–UE 连线附近」这一强集中几何。
- 关键结论二（时间/SE 侧）：弥散传播（$\eta=0.1$）产生更大 Doppler 分集，使信道老化更快、SE 损失更大；DL SE 对速度更敏感但 Geo–Kron 差距中等，UL SE 对速度较不敏感却呈现较大 Geo–Kron 差距，ZF 合并在集中环境下差距缩小（图 3）。

# 开放无线数字孪生：基于 OpenAirInterface 与射线追踪的端到端 5G 移动性仿真

**作者：** TETSUYA IYE¹，MASAYA SAKAMOTO²，SHOHEI TAKAYA¹，EISAKU SATO¹，YUKI SUSUKIDA¹，YU NAGAOKA³，KAZUKI MARUTA⁴（IEEE 高级会员），JIN NAKAZATO⁴（IEEE 会员）

**单位：** ¹Kozo Keikaku Engineering Inc.，日本东京；²独立研究者；³拓殖大学工学研究科电子与计算机系统系，日本东京；⁴东京理科大学工学研究科电气工程系，日本东京

**通信作者：** Tetsuya Iye（邮箱：tetsuya-iye@kke.co.jp）

**基金：** 本研发工作部分得到日本总务省“可持续高效无线电波利用基础技术研发项目（FORWARD）”（受理号 JPMI240310001）资助。

**摘要**——本研究提出一个利用开源软件与开放数据构建的端到端无线数字孪生平台，以增强移动通信系统的评估。所提出的开放无线数字孪生（open wireless digital twin，OWDT）集成了用于第五代新空口（5G NR）协议栈仿真的 OpenAirInterface（OAI）与用于高分辨率射线追踪无线传播建模的 NVIDIA Sionna RT。该集成能够在基于 CPU 的 Linux 系统上真实仿真移动场景中的 5G 无线通信，并利用真实建筑物数据弥合理论仿真与实际部署之间的差距。平台还集成了 OAI FlexRIC——一个与 O-RAN 近实时 RAN 智能控制器（near-RT RIC）对齐的实现——以动态监测关键性能指标（key performance indicator，KPI）。通过在城市场景中的大量评估，本研究验证了该仿真框架的有效性，表明其能够高保真地复现真实世界的通信动态。结果凸显了 OWDT 在加速无线系统研发、降低实验成本与优化网络配置方面的潜力。

**索引词**——数字孪生、仿真、SDR、移动性、5G NR、O-RAN、OpenAirInterface、Sionna RT、SUMO、PLATEAU。

## I. 引言

### A. 研究背景

在未来智能交通系统（intelligent transportation system，ITS）的无线辅助网联自动驾驶汽车（connected autonomous vehicle，CAV）研发（R&D）中，通过基于真实使用场景的演示实验来评估关键性能指标（KPI）的动态特性非常重要 [1], [2]。与此同时，演示也是面向工业应用的无线研发中的技术障碍之一。此类演示实验面临的挑战包括：(1) 仿真模型与实际设备之间出现的差异；(2) 某些情况下需要取得无线电台执照，从而增加时间与资金成本；(3) 随着系统日益先进，协议复杂度不断增长；(4) 在演示场景的预评估中难以准确复现无线电传播环境。

为应对挑战 (1) 至 (4)，人们提出了一种方法：在高保真复现真实世界的数字孪生虚拟环境中开展场景测试，从而在现场实验之前完成评估 [3], [4]。数字孪生正在第三代合作伙伴计划（3rd Generation Partnership Project，3GPP）与开放无线接入网（Open Radio Access Network，O-RAN）等标准化项目中得到积极讨论。它们不仅能在现场演示实验之前于虚拟空间中验证新方法，还能复现真实通信系统中难以观测的时变 KPI，并优化部署参数。因此，数字孪生平台的开发及其用于验证

作为弥合理论、仿真与演示实验之间技术鸿沟，并加速研究成果向社会部署转化的有前景的方法论，正日益受到关注 [5]–[15]。此外，数字孪生被视为为无线接入网（RAN）与网络控制所用的人工智能/机器学习（AI/ML）模型生成近乎无限训练数据的有前景手段 [16]–[18]。实现数字孪生的关键技术要素包括：在虚拟空间中保证高保真与实时性能的仿真技术，以及连接虚拟世界与真实世界的、与测量数据的一致性。

特别是关于挑战 (3)，近期无线通信研发在各类开源软件（open-source software，OSS）的发展与开放数据的使用方面取得了显著进展。推动这一开放创新的，是无线通信技术日益增强的复杂性、多样性与复杂度；事实上，单一组织已难以独立完成全栈研发。许多无线技术由标准组织在全球范围内标准化。因此，把这些共同规范实现为 OSS 在全球范围内是一种经济合理的做法。从用户角度看，OSS 可以低成本构建研发环境，同时还能实现商业软件包难以做到的灵活定制。如表 I 所示，已出现执行 RAN、5G 核心网（core network，CN）、用户设备（user equipment，UE）与 O-RAN 相关功能的第五代新空口（5G NR）OSS 实现。其中，OpenAirInterface（OAI）作为研发中广泛使用的 5G OSS 尤为突出，它在 4G 长期演进（LTE）/5G NR 的 CN、RAN、UE 与 O-RAN 方面提供了详细实现，并支持涉及软件定义无线电（software-defined radio，SDR）设备与商用现成（commercial off-the-shelf，COTS）O-RAN 射频单元（O-RAN Radio Unit，O-RU）的空口（over-the-air，OTA）实验 [19], [20]。free5GC、Open5GS 与 Magma 是 5G CN 最著名的三个 OSS 实现 [21]–[23]。由开放网络基金会主导的 AETHER 项目统一了 SD-Core、SD-RAN 以及基于µONOS 构建的 O-RAN 近实时 RAN 智能控制器（near-RT RIC）等子项目 [24]。srsRAN 项目（包括 srsUE）提供独立的 RAN 与 UE 功能，并支持用 SDR 或 O-RU 开展空口实验 [25]。UERANSIM 是提供 RAN 与 UE 功能用于测试的软件仿真器 [26]。NVIDIA Sionna 是面向无线通信系统的 GPU 加速链路级仿真器 [27]。此外，Sionna RT 提供用于确定性无线电传播仿真的可微射线追踪 [28]。O-RAN 软件社区（O-RAN Software Community，O-RAN SC）提供 O-RAN 架构的多个组件，包括 O-CU、O-DU、RIC 与 SMO 框架 [29]。5G-LENA 与 Simu5G 分别是构建在 ns-3 与 OMNeT++ 平台上的离散事件网络仿真器 [30], [31]。另一团队在一篇综述中从 O-RAN 视角对 OSS 项目做了更详细的比较 [32]。

无线电传播建模属于挑战 (4)，人们已用随机方法与确定性方法研究其精度提升。随机方法通过参数拟合构建在统计上近似实验测量结果的信道模型。然而，当具备 3D 建筑物模型与地形数据时，射线追踪等确定性方法可以显式追踪传播路径，并从微观视角进行高保真信道计算。特别地，射线追踪在具有显著多径传播的环境中非常擅长仿真时延谱。虽然多径信号在接收机处被视为衰落效应，但信号的延时节拍数与计算处理成本之间存在权衡。实时处理对于确保数字孪生仿真至关重要。因此，需要高效的计算机制，在保证接收信号实时计算的同时，维持复现真实衰落效应所需的延时节拍数。

### B. 相关工作

在商业领域，一些公司推出了包含专有 AI 技术的网络数字孪生（network digital twin，NDT）解决方案 [33], [34]。这里的“NDT”被定义为“移动网络或其一部分的虚拟副本，捕捉其属性、行为与交互”，其中移动网络在 3GPP 中包括 RAN 与 CN [16]。

已有报道提出一种集成 ns-3 与 Sionna RT、并考虑确定性信道模型的全栈 RAN 仿真环境 [14], [15]。尽管 ns-3 非常适合可扩展的网络性能仿真，但它抽象了物理（PHY）层信号处理，且缺乏亚微秒级的离散时间分辨率。因此，即使应用射线追踪来建模无线电传播，在捕捉延迟多径分量的时域效应方面仍存在固有限制。

Open AI Cellular（OAIC）是一个由美国国家科学基金会（NSF）支持的开源软件平台

，它把用于 RAN/UE 运行的 srsRAN 与 O-RAN SC 组件（near-RT/非实时 RIC 及支撑服务）拼接起来，构建端到端（end-to-end，E2E）、AI 就绪的 5G/6G 研究试验床 [35]。OAIC 支持 SDR 运行，并通过零消息队列（Zero Message Queue，ZeroMQ）进行信道仿真。原则上，如果为基带同相/正交（In-phase and Quadrature，IQ）信号处理实现了高效的信道卷积，就应当能够仿真时变信道。然而，OAIC 目前缺少 5G CN 功能，因此无法实现本研究所需的“E2E”仿真。

Colosseum 是东北大学开发的大规模无线网络仿真器，实现了符合 O-RAN 的数字孪生环境 [8]。其信道仿真在 Massive Channel Emulator（MCHEM）中完成，这是一个由现场可编程门阵列（Field-Programmable Gate Array，FPGA）构成的集群，把信道冲激响应（channel impulse response，CIR）与众多发射/接收节点之间交换的基带信号做卷积。该卷积使用 512 抽头的有限冲激响应（finite impulse response，FIR）滤波器，其中 4 个任意抽头被置为非零值；这种设计保证了高处理速度、轻量数据处理以及对无线节点数目的可扩展性。然而，这种 4 抽头近似限制了每个无线信道的物理保真度，并且被迫省略了原则上应在卷积之前对 CIR 施加的带宽限制滤波。

最近在 OAI 内部也出现了另一项密切相关的工作 [36]。它基于 Godot 实现，通过表征状态转移（representational state transfer，REST）应用编程接口（application programming interface，API）并借助 Sionna 提供的函数 [37] 进行场景控制，从而实现信道生成。利用该实现产生的 CIR，也可以通过 OAIvrtsim（一个固定时间尺度的无线仿真器）在考虑动态信道更新的情况下仿真 5G 通信。我们的实现与之不同之处在于：它在仿真模式下以尽力而为的方式运行在 CPU 上，并仅在 SDR 模式下实时运行。

### C. 贡献与局限

我们把所提出的开放无线数字孪生（Open Wireless Digital Twin，OWDT）架构的贡献总结如下。

1) **与 O-RAN 对齐的 5G E2E 评估环境。** 我们提供了如表 I 底行所示定位的评估环境，它融合 OAI 与 Sionna RT 的优势，以软件方式实现全栈、非抽象的 5G NR 移动通信。这里的“E2E”范围涵盖 5G CN、RAN 与 UE。此外，借助 OAI FlexRIC，可以在 near-RT 中监测 KPI [38]。

2) **完全基于 OSS 的无线数字孪生。** 构建该环境所用的全部软件与数据均为开源软件与开放数据。此外，本研究中在 OAI 上实现的 CIR 卷积与示例场景已作为 OAI 分支发布 [39]。

3) **高保真无线通信仿真。** 通过使用 SDR 对预计算 CIR 执行实时基带卷积，我们实现了由地点特定移动性场景驱动的高保真无线仿真。最多 28 个抽头的实时卷积改进了先前工作 [6], [8]。

4) **低成本、紧凑的试验床。** 作为试验床，OWDT 由一台运行在 CPU 上的标准 Linux 服务器、一个低端 SDR 与一个 COTS UE 模块组成，可实现低成本的实验平台。

这些贡献使得人们能够在实验室环境中对 PHY 与传播的边界进行可控而又贴近实际的研究，从而促进无线数字孪生实验的普及化。

与此同时，当前的 OWDT 具有以下局限，因此仿真仍是近似的：(a) 它不对短于多普勒周期的时变信道建模；(b) 在所有计算出的 CIR 抽头中，它只使用最主要的 28 个抽头——尽管这相对于先前工作已扩展了数倍，但仍是一种约束；(c) 尚未用测量数据对其进行校准；(d) 优先保证 PHY 保真度是以可扩展性为代价的，限制了可同时支持的无线节点数目。

### B. 工作流

OWDT 通过以下五个步骤完成遵循移动性场景的 E2E 无线仿真：1) 准备 3D 建筑物数据；2) 生成移动性场景；3) 使用射线追踪计算信道冲激响应；4) 卷积信道冲激响应；5) 使用 OAI 进行无线通信仿真。在图 1 中，各步骤对应的区段以不同颜色标出。下面先给出各步骤概述，再说明本研究所采用的具体模型与参数。

1) **准备 3D 建筑物数据**

为在无线电传播仿真中获得更高分辨率，必须准备在尺寸与位置上高度详细的 3D 建筑物数据，并进行地点特定的确定性评估。日本国土交通省（MLIT）推动的开放数据项目 PLATEAU 提供的 3D 城市数据 [42] 采用通过航空测量获得的建筑物高度，一般在高度维度上比 OpenStreetMap（OSM）[43] 具有更高精度。这些数据以 CityGML 格式提供，Sionna RT 无法直接处理。因此，使用开源 3D 计算机图形（CG）软件 Blender 4.2 [44] 把数据转换为 PLY 格式。若使用 OSM 作为 3D 建筑物数据，可以借助 Blosm [45] 导入 Blender。随后使用 Mitsuba Blender 插件 [46] 为导入的 3D 模型的多边形表面指定材料。本研究在日本东京评估了两个场景区域：新中野站与涩谷站周边。新中野站区域的 3D 模型以细节层次 1（Level of Detail 1，LOD1）提供，建筑物表示为实体，覆盖实体的所有表面均以多边形元素描述。相比之下，涩谷站区域的 3D 模型以 LOD2 提供，可比 LOD1 表达更精细的结构，能够以不同材料表示墙面、屋顶与地板。对于 LOD1 的新中野模型，包括道路、墙面与屋顶在内的所有材料均指定为混凝土，场景文件以 XML 格式保存。而在 LOD2 的涩谷模型中，建筑墙面指定为玻璃、道路表面指定为混凝土、立交桥表面指定为金属。这些材料由相对介电常数实部与电导率确定，二者按 [47] 中式 $\epsilon_r=a(f\cdot10^{-9})^{b}$、$\sigma_c=c(f\cdot10^{-9})^{d}$ 给出，其中 $f$ 为载频。各材料的具体参数值以及本研究所用频率下的 $\epsilon_r$ 与 $\sigma_c$ 值列于表 III。

2) **生成移动性场景**

移动性评估场景的生成由 SUMO（Simulation of Urban MObility）[48] 完成。SUMO 是一款车辆交通仿真器，能够通过纳入交通信号灯、多车道、各道路限速、渐进加减速以及与其他车辆的交互，真实复现车辆运动。基于 OSM 道路数据，SUMO 可以通过指定行驶车道及其序列来创建车辆移动性场景，并生成车辆位置坐标 $(x,y)$ 的时间序列更新。尽管本研究未使用，移动性场景还可以包含每个快照处车辆的速度矢量，可用于计算作为影响快衰落关键因素的多普勒频移。在新中野与涩谷两个场景中，车辆均在交叉口交通信号灯处短暂停留并左转。此外，在新中野狭窄的居民街道上，交叉口与 T 型路口没有交通信号灯，车辆会在直行或左转前减速或临时停车。

4) **信道冲激响应的卷积**

在 OAI 软件中，可以按照移动性场景的时间推进，把预计算的 CIR 与基带信号实时卷积，从而在收发信号中反映传播环境，实现无线仿真。这一过程使得由移动物体位置变化引起的信道时间演化反映到 OAI 可获得的 KPI 中。

在 OAI 源代码中，与 PHY 层最底层对应的基带 IQ 样本在 nr-ru.c 文件的 tx_rf() 与 rx_rf() 函数中处理。基带 IQ 样本层的 5G NR 帧格式与 CIR 卷积方法如图 3 所示。在 OAI RAN 中，时域信号在每个时隙中被存储为 txData 与 rxData，其中循环前缀正交频分复用（CP-OFDM）的基带信号表示为 $N_s$（=FFT 大小×15）个复 IQ 样本数据。为把某个 CIR 快照的延迟抽头效应纳入基带信号，按 CIR 总抽头数 $L_{\max}$（=146）把基带信号逐样本移位，生成矩阵 $X\in\mathbb{C}^{L_{\max}\times N_s}$。把复 CIR 向量 $\bar{h}\in\mathbb{C}^{L_{\max}}$ 从左侧作用并计算内积，即得到含多径时延分量的接收信号 $y\in\mathbb{C}^{N_s}$。然而在我们的环境中，即使使用了高性能计算库 BLIS（后文述及），对射线追踪得到的 $L_{\max}$ 个抽头时延分量做实时卷积仍不可行。

因此，优先考虑最重要的功率，把 CIR $\bar{h}$ 按降序排序为 $\bar{h}_{\mathrm{sort}}\in\mathbb{C}^{L_{\mathrm{OAI}}}$，并相应重排基带时延矩阵 $X$ 的行以形成 $X_{\mathrm{sort}}\in\mathbb{C}^{L_{\mathrm{OAI}}\times N_s}$。这里，读取的前导抽头数目被参数化为 $L_{\mathrm{OAI}}$，以确定可实时执行的上限。该方法使计算优先反映最重要的多径分量。卷积运算在 OAI gNB 的 rx_rf() 与 tx_rf() 函数内，使用高性能矩阵计算库 BLIS [56] 的 cblas_cgemm 实现。具体而言，对下行（DL）在 gNB 线缆发射之前的基带信号施加卷积，对上行（UL）在 UE 线缆接收之后施加卷积。函数 cblas_cgemm 把两个复矩阵 $A$、$B$ 相乘，并把所得矩阵乘以复常数 $\alpha$；矩阵 $C$ 乘以另一复常数 $\beta$，随后把两个乘积之和存入矩阵 $C$，即 $C\leftarrow\alpha AB+\beta C$。我们使用该函数完成以下计算：

$$
y=s\,\bar{h}X+\sigma w\approx s\,\bar{h}_{\mathrm{sort}}X_{\mathrm{sort}}+\sigma w,
\tag{3}
$$

其中 $s\in\mathbb{R}$ 为信号幅度增益，$\sigma\in\mathbb{R}$ 为噪声幅度增益，$w\in\mathbb{C}^{N_s}$ 为归一化复高斯噪声。为更详细地考察该式，我们在样本时间层把它表示为

$$
y[n]=\sum_{k=0}^{L_{\mathrm{OAI}}-1}s\,\bar{h}[k]\,x_k[n-k]+\sigma w[n],
\tag{4}
$$

其中 $n\in\mathbb{Z}$ 表示采样时间索引。

一般而言，在时不变多径时延环境中，由于不存在多普勒扩展，信道互易性成立 [57]。因此，在该移动性场景中，把同一 CIR 同时叠加到 OAI gNB 的 DL 与 UL 上在理论上是成立的。

为更准确地在收发信号中复现 CIR 的影响，需要考虑多普勒效应，对每个 IQ 样本用随时间变化的 CIR 做卷积。然而从计算

5) **使用 OAI 的无线通信仿真**

OAI 中配置的系统参数汇总于表 IV 下半部分。带宽 BW 设为 40 MHz，这是采样率约束下可达到的最大带宽。子载波间隔设为 30 kHz，对应 numerology $\mu=1$。此处采用的 1536 点 FFT 使用传统 $2^n$ 样本基时钟的四分之三采样频率，从而避免不必要的带宽消耗；这一节能 FFT 选项在 3GPP TR 25.814 [59] 中描述。当在配置为 46.08 Msps 采样率的 USRP B200 上运行 40 MHz 信道时，OAI 支持该 FFT 长度。由于本文重点首先是证明无线通信系统与传播现象能够以同步方式被仿真，我们尽可能简化了问题表述：系统以单输入单输出（SISO）配置运行。双工模式为时分双工（TDD），时隙图样遵循“DDDSU”。特殊时隙格式遵循 6 个 DL 符号、4 个保护符号与 4 个 UL 符号的典型模式。

$$
R_b=10^{-6}\,Q_m R_{\max}\,12\,N_{BW}^{PRB}\,T_{\mathrm{symb}}\,(1-\mathrm{OH})
\tag{5}
$$

$$
=\begin{cases}30.62976\,\eta, & \text{（DL）}\\ 32.76672\,\eta, & \text{（UL）}\end{cases}
\tag{6}
$$

注意该记号已简化：假设 MIMO 层数为 1、聚合载波数为 1、缩放因子为 1。这里，调制阶数 $Q_m$、编码速率 $R_{\max}$ 及其乘积（即频谱效率 $\eta$）由 TS 38.214 表 5.1.3.1-2 [61] 中的 MCS 索引唯一确定。$N_{BW}^{PRB}$ 表示 BW 内的物理资源块（PRB）数目，由频率范围与 numerology 决定；$T_{\mathrm{symb}}$ 是子帧内平均 OFDM 符号持续时间；OH 表示控制信道开销。部分变量由表 IV 的参数决定，在整个场景中保持不变，即 $N_{BW}^{PRB}=106$、$T_{\mathrm{symb}}=3.57$ [µs]，OH 在 DL 为 0.14、在 UL 为 0.08。代入这些具体数值，即得式 (6)。DL（UL）的有效吞吐量 $T_{\mathrm{eff}}^{\mathrm{DL(UL)}}$ 定义为实际接收数据速率，在 TDD 模式下由下式给出

$$
T_{\mathrm{eff}}^{\mathrm{DL(UL)}}=(1-\mathrm{BLER})\,\alpha^{\mathrm{DL(UL)}}\,R_b,
\tag{7}
$$

其中 BLER 表示误块率，定义为错误块数与总发送块数之比；$\alpha^{\mathrm{DL(UL)}}$ 表示由 TDD 时隙图样与特殊时隙格式决定的 DL（UL）时间占用比例。对于表 IV 所示的 TDD 图样，DL 比例为 $\alpha^{\mathrm{DL}}=0.6857$，而

UL 比例为 $\alpha^{\mathrm{UL}}=0.2571$，因此 $T_{\mathrm{eff}}^{\mathrm{DL(UL)}}$ 可表示为

$$
T_{\mathrm{eff}}^{\mathrm{DL}}=21.003264\,(1-\mathrm{BLER})\,\eta
\tag{8}
$$

$$
T_{\mathrm{eff}}^{\mathrm{UL}}=8.425728\,(1-\mathrm{BLER})\,\eta.

因此可以得出结论：有效吞吐量可由与 MCS 索引对应的频谱效率 $\eta$ 与 BLER 计算得到。据此，我们重点关注 MCS 与 BLER 随移动性场景的变化。在所分析的两个场景中，观测到的最大 DL 吞吐量为 150.0778 Mbps，此时 MCS = 27、BLER = 0.001656。利用 (8) 计算得到的有效吞吐量为 155.2989 Mbps，与测量值非常接近。另一方面，观测到的最大 UL 吞吐量为 14.64214 Mbps，此时 MCS = 10、BLER = 0.163917。利用 (9) 计算得到的有效吞吐量为 18.106756 Mbps。UL 吞吐量与 DL 吞吐量的差异可归因于探测参考信号（SRS）占用了 UL 传输中的一部分 PRB。因此，KPM xApp 测得的 KPI 可以认为与理论预期一致。测得的吞吐量在 UE 最接近 gNB 时达到最大，BLER 呈现与吞吐量相反的趋势，MCS 与吞吐量接近成正比变化，这些都表明结果是合理的。比较图 6(b) 与 (c) 中 DL 与 UL 的差异可以明显看出，UL 的变化不如 DL 显著。UL 的 BLER 明显更高，为维持 UL 通信质量，MCS 被自动设得更低以限制调制阶数，导致 UL 吞吐量更低。误差的潜在原因包括：(i) 调制与解调方法，(ii) 调制符号周期，(iii) 带宽限制滤波器的特性，(iv) 信道特性，以及 (v) 周跳导致的定时偏移。这些误差既源于系统因素，也源于无线电传播问题。若只关注传播方面，相关因素是 (iv) 与 (v)。由于本研究不考虑车辆的速度矢量，由快衰落引起周跳的可能性被排除。因此，由不同到达时间的多径传播导致的符号间干扰（ISI）误差仍是主要关注点。5G NR 所用 CP-OFDM 中的循环前缀（CP）正是为缓解 ISI 而设计的技术。在我们的通信系统参数中，分配给第一个 OFDM 符号的长 CP 含 132 个样本，对应 2.86 µs；后续的短 CP 含 106 个样本，对应 2.30 µs。如果在本研究使用的 146 个 CIR 抽头中，超过 132 个样本的抽头处存在显著的复幅度，吞吐量就可能受到影响。在我们的环境中，实时处理上限为 $L_{\mathrm{OAI}}=28$ 个抽头，且未观测到超过 2.30 µs 的延迟抽头索引。因此可以认为，在这些场景中多径传播引起的 ISI 不是问题，UL 中观测到的误差被认为源自系统。如表 V 所示，UL 的 BLER 在基线测量时就已接近 10%，这可能与 gNB 上接收信号处理的实现有关。

为评估 OAI 所用 CP-OFDM 波形对移动性场景中预期最大多普勒频移的鲁棒性，我们依据可靠 OFDM 传输必须满足的一组著名条件 [57]：

$$
\sigma_\tau\ll T_{\mathrm{GI}}\ll T_{\mathrm{OFDM}}\ll T_f\left(=\frac{1}{f_D}=\frac{c}{fv}\right),
$$

其中 $\sigma_\tau$ 为 RMS 时延扩展，$T_{\mathrm{GI}}$ 为保护间隔（CP）长度，$T_{\mathrm{OFDM}}$ 为有效 OFDM 符号持续时间（不含 CP），$T_f$ 为衰落（相位变化）周期，$f_D$ 为最大多普勒频率，$c$ 为光速，$v$ 为 UE 最大速度。首先，如上文所述，未观测到时延超过短 CP 长度 $T_{\mathrm{GI}}=2.30$ [µs] 的多径分量，因此 $\sigma_\tau\ll T_{\mathrm{GI}}$ 成立，ISI 得以避免。其次，比值 $T_{\mathrm{GI}}/T_{\mathrm{OFDM}}$（2.30 µs / 33.3 µs）符合 5G NR 标准，意味着 $T_{\mathrm{GI}}\ll T_{\mathrm{OFDM}}$ 且保持高频谱效率。第三，在最大车速 $v=11.78$ [m/s] 下，

$$
T_f=\frac{c}{fv}=\frac{2.998\times10^{8}}{4.01916\times10^{9}\times11.78}=6.332\,[\mathrm{ms}],
$$

其远长于 $T_{\mathrm{OFDM}}$，因此相位相干条件 $T_{\mathrm{OFDM}}\ll T_f$ 也满足。由于三个不等式均成立，多普勒频移 $f_D=158$ [Hz] 在本研究设定参数下对 CP-OFDM 传输的链路质量影响可忽略。在更高载频（例如 FR2）与高速移动场景（例如列车）中，这些条件会严苛得多，预计会出现严重的 ISI 或快衰落。由于最短衰落周期为 $T_f=6.332$ [ms]，CIR 快照间隔原则上应不大于 $T_f$。一种高效做法是大约每 20 ms（不超过 $T_f$ 的若干倍）计算一次快照，然后使用 Sionna RT 的 apply_doppler() 函数在更细的时间分辨率上插值出受多普勒影响的 CIR。要捕捉 6.332 ms 的周期性，只需以约 1 ms 的步长插值即可，因此 CIR 数据可以离线预生成。剩下的问题是在实时地把这些时变 CIR 与基带信号卷积。随着有效 CIR 间隔缩短，实时处理中的数据加载开销会增大，需要额外的加速技术。

### C. 未来展望

在讨论未来智能交通系统时，需要考虑在动态无线电环境中信道统计特性随时间快速变化的移动性场景的恰当评估方法。尽管射线追踪在静态信道建模中取得了高分辨率结果，但在涉及高速移动车辆的动态场景中会变得显著更

<span id="page-12"></span>

（接上页）

复杂，此时广义平稳（wide-sense stationary，WSS）假设被破坏。一般而言，多径环境中的移动实体必须考虑频率选择性衰落与时间选择性衰落。然而，要真实地把两类衰落的影响纳入基带信号处理并执行实时 E2E 无线通信，因计算负载而极具挑战。为应对该挑战，我们计划在未来研究中探索借助 FPGA 与 GPU 等加速技术、包含多普勒效应支持的实时处理。

从覆盖多个 gNB/UE 节点与 MIMO 仿真的可扩展性角度看，我们认为最有前景的方法是把卷积运算卸载到插入 gNB 与 UE 之间线缆链路的 FPGA 板上。在这种配置中，FPGA 充当信道仿真器，最多可处理[板上射频端口数 / 2]路同时信道（每路信道对应一对 TX/RX）。相应地，只要满足

$$
\frac{[\#\mathrm{RF\ 端口数}]}{2}\ge[\#\mathrm{gNB}]\times[\#\mathrm{UE}]\times[\#\mathrm{MIMO\ 层数}],
$$

就具备可扩展性。由于卷积非常适合 FPGA 的低时延并行架构，我们认为硬件卸载是实现可扩展仿真的有效手段。

面向 FR2 等更高频段的波束成形还需要跟踪移动目标，这可能导致频繁切换。由于射线追踪仿真器可以同时考虑 gNB 的波束图样与 UE 的天线方向图，因此可以构建波束动态跟踪移动 UE 的 FR2 移动性场景。一旦生成此类场景，OWDT 就能支持开发面向整个系统的切换管理方案。

为实现这些目标，需要以下扩展：与更高精度的 3D 模型及移动性场景集成；在 gNB 与 UE 数目方面的可扩展性；利用 GPU 与 FPGA 等加速技术以支撑增加的计算复杂度；以及通过与实验数据比较进行验证，以建立真正具有代表性的数字孪生。

## IV. 结论

本研究提出了 OWDT，一个可作为 O-RAN 生态部署的 E2E 5G 移动性仿真框架。通过把用于协议栈仿真的 OAI 与用于基于射线追踪的射频建模的 Sionna RT 相结合，OWDT 能够在车辆移动性场景中实现高保真性能评估。为实现实时仿真，我们实现了一种把预计算的时变 CIR 施加到基带 IQ 信号上的卷积方法。该方法在商用硬件约束下保证实时处理的同时，有效复现了多径衰落效应。该框架借助 FlexRIC 利用 near-RT RIC 监测 RSRP、MCS、BLER 与吞吐量等 KPI，为理解无线通信系统的行为提供了有价值的洞察。实验验证表明，OWDT 能够有效复现真实信道条件，以极少的物理部署支撑高效的网络性能分析与优化。该方法显著降低成本并加速无线通信系统的开发。本研究的一个关键特点是，所有工作流与系统架构完全使用 OSS 与开放数据构建。我们构建的 OWDT 架构可作为参考架构，其中每个组件都可以替换为任何专有产品或替代的 OSS 实现。

## 阅读提示

- 核心贡献：用全开源栈把 5G NR 协议栈（OAI）与确定性射线追踪（Sionna RT）在真实移动性场景下打通，形成可在 CPU 服务器 + 低端 SDR 上实时运行的 E2E 无线数字孪生，并接入 OAI FlexRIC 实现 near-RT KPI 监测。
- 五个工作流步骤：3D 建筑数据准备（PLATEAU/OSM → Blender → PLY + 材质）→ SUMO 移动性场景 → 射线追踪计算 CIR → CIR 与基带 IQ 信号实时卷积 → OAI 5G 通信仿真；关键数字：n77 频段 4.01916 GHz、46.08 Msps、40 MHz、30 kHz SCS、1536 FFT、SISO、TDD DDDSU。
- 卷积实现要点：把基带信号逐样本移位构造 $L_{\max}=146$ 行的时延矩阵，按功率降序排序后只取前 $L_{\mathrm{OAI}}=28$ 个抽头，用 BLIS 的 cblas_cgemm 实时做复数矩阵乘（式 (3)(4)）；CIR 每 100 ms 更新一次。
- 两个城市场景：新中野（LOD1）与涩谷（LOD2）；实验表明 RT 路径增益与 OAI 的 RSRP 趋势一致，但在红灯停留平台、短期 20 dB 波动等细节上因 KPI 平均与 AGC 存在差异。
- 吞吐量核算：按 3GPP 公式（式 (5)–(9)）由 MCS/BLER 推算有效吞吐量；最大 DL 观测 150.0778 Mbps（MCS 27、BLER 0.001656，理论 155.2989 Mbps），最大 UL 14.64214 Mbps（MCS 10，理论 18.106756 Mbps），UL 偏低主要归因于 SRS 占用 PRB。
- 局限与展望：不考虑 100 ms 内的多普勒时变、只用 28 个抽头、未用实测校准、可扩展性受限；未来用 FPGA/GPU 卸载卷积、支持 FR2 波束跟踪与多节点 MIMO。

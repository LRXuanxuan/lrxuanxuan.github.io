# DeepTelecom：动态异构无线环境中用于信道孪生的可微多模态框架

**原题：** DeepTelecom: A Differentiable Multimodal Framework for Channel Twinning in Dynamic Heterogeneous Wireless Environments  
**作者：** Bohao Wang、Tianen Yuan、William Yen、Zehua Jiang、Chongwen Huang、Li Wei、Chen Zhu、Jiguang He、Hang Zou、Lina Bariah、Brahim Mefgouda、Anis Bara、Yongliang Shen、Zhaoyang Zhang、Mérouane Debbah。  
**原文：** https://arxiv.org/pdf/2610.14545v1（2026 年 10 月 10 日，13 页）。  
**翻译范围：** 摘要、引言及框架概述；场景重建与材料参数部分的公式和说明。**第 V–X 节、全部图表与参考文献尚待补译，非全文译稿，qa_complete=false。**

## 摘要

大规模多模态数据是将大型生成式人工智能模型融入无线网络的重要基础。然而，现有无线数据集对异构环境的支持有限，尤其缺乏可复用的高保真场景、可扩展的可微射线追踪以及同步的多模态数据。在环境和信道随时间变化的移动与空中场景中，这些局限性更加突出。为解决上述问题，本文提出 DeepTelecom：一种面向包含无人机和可重构智能表面网络的、具有材料感知能力的高保真多模态信道数据集和可复现生成框架。DeepTelecom 对室内外粗略重建场景进行精细化处理，并利用大语言模型将分割后的表面映射到随频率变化的电磁参数，获得具有材料感知能力的细节层级 3（LoD3）数字孪生体。随后，基于 GPU 加速的可微 Sionna 射线追踪器，对 sub-6 GHz、毫米波和亚太赫兹频段的传播进行仿真，并专门捕获具有不同俯仰角和平移速度的静止或运动无人机所产生的旋翼微多普勒特征。框架同步生成信道张量、覆盖图、传播视频、多视角图像和受天气条件控制的渲染结果，并支持利用稀疏信道锚点进行可微材料校准。公开数据集包含 10 个具有材料感知能力的室内外场景和 50,000 个同步无人机样本；框架支持针对用户自定义场景和系统配置可扩展地生成额外数据。在无人机三维定位任务中，与仅考虑信道状态信息的方案相比，DeepTelecom 将第 90 百分位定位误差从 31.05 米降低至 2.43 米，体现了其对人工智能赋能无线系统的重要价值。

**关键词：** 数字孪生；多模态数据集；射线追踪；无人机；无线信道建模。

## I. 引言

大型多模态模型的快速发展正在推动人工智能（AI）融入第六代（6G）无线网络 [2]–[7]。在物理层，大型 AI 模型已用于多种核心任务，包括利用视觉和传感器辅助信息进行多天线波束成形 [8]、信道估计与均衡 [9]–[11]、大规模 MIMO 信道状态信息（CSI）反馈 [12]、无线感知与定位 [13]，以及端到端学习收发机 [14]、[15] 等。这些任务均依赖数据，其精度与泛化能力取决于能否以多种模态联合表征无线信道及其物理环境。因此，生成大规模、高保真、多模态的信道数据，是实现原生 AI 无线通信的基础条件之一。

然而，通过实际测量获取此类数据集十分困难。在真实三维环境中，对密集采样的收发机位置对进行信道探测，需要昂贵的信道探测仪、机器人平台或大规模道路测试，还需要精确同步和大量人工标注工作。以实际测量获得广泛空间覆盖和丰富场景类型的成本因此极高 [16]。

为应对这一挑战，研究界广泛采用基于射线追踪（RT）的数字孪生，将其作为生成大规模多模态信道数据集的主要手段 [17]–[22]。确定性射线追踪器从三维环境模型出发，结合几何光学与电磁传播规律，合成与具体布局、频段和天线配置相关联的逐路径信道。场景建模完成后，RT 可为任意虚拟收发机部署生成可控、可复现的信道，大幅减少对穷尽式实地测量的依赖。

但现有 RT 数据集仍不足以满足原生 AI 6G 系统的需求。首先，具有一致几何与材料保真度的可复用场景仍然受限。早期 DeepMIMO、ViWi 主要提供固定商业 RT 场景生成的预计算信道，虽然支持标准化学习基准，但在可编辑几何、材料属性和同步多模态数据生成流水线方面存在局限 [17]、[18]。DeepMIMOv4 纳入几何、材料元数据、动态链路和多普勒信息，并提供包括 Sionna RT 在内的多种射线追踪器转换工具 [23]，但仍缺少用于构建与校准材料分割的 LoD3 室内外孪生体，并同步产生视觉观测和无线信道数据的端到端流程。WAIR-D、DataAI-6G 和 BUPTCMCC-6G-DataAI+ 等数据集将频率覆盖扩展至亚太赫兹，但公开场景比材料分割的 LoD3 孪生体粗略得多，所提供的表面级电磁语义也较为有限 [19]–[21]。

其次，规模化 RT 与可微材料校准尚未充分结合。基于 Sionna RT 的 GPU 方法能够从稀疏测量中学习材料参数，但主要面向特定场所的校准或信道预测 [22]、[28]–[33]；基于 CPU 的商业射线追踪器 NYURay、Ranplan 虽具有丰富的材料库，但手工流程、运行时间和访问限制不利于大规模数据生成 [34]、[35]。

第三，已有数据集的同步模态日益丰富，但公开的数据产品通常局限于原任务。实际测量数据集 DeepSense 6G、WiWorld-RealData 和 Multimodal-NF 将无线信道与相机、GPS/GNSS、LiDAR、雷达等数据同步，却受固定测量活动限制 [16]、[36]、[37]。合成数据集 SynthSoM、Multimodal-Wireless 和 SynthSoM-Twin 扩展了深度图像、IMU、天气数据和无人机轨迹等模态，但通常公开任务专用样本而非可复用场景资源 [38]–[40]。即使提供无人机轨迹，往往也缺少精细的无人机几何、旋翼运动及微多普勒特征，使得数据难以用于新的载频、阵列、RIS 部署、无人机动力学或传播环境。

为弥合这些能力之间的缺口，DeepTelecom 从 LiDAR、Google 3D Tiles、程序化布局以及 CAD/BIM 资源构建室内外孪生体，在 Blender 中细化几何并分离表面。大语言模型将语义标签映射到可编辑的频率相关介电常数、磁导率和电导率，覆盖 sub-6 GHz、毫米波及亚太赫兹。基于 Sionna 的可微 GPU RT 引擎支持每个场景数千万条射线、RIS、移动终端和无人机 [22]、[28]，并通过显式建模平移、俯仰与旋翼运动产生微多普勒特征。固定射线拓扑的可微校准循环利用稀疏路径损耗测量调整材料参数。在统一数据模式下，框架同步信道张量、逐路径表格、覆盖图、传播视频、多视角图像和天气条件渲染结果。

本文的贡献包括：（1）开发大语言模型辅助的统一流水线，将异构三维数据源转化为材料感知 LoD3 室内外孪生体；（2）构建支持 RIS、移动终端、无人机、微多普勒和材料可微校准的可扩展 Sionna RT 框架；（3）发布可复用的同步多模态数据集，验证融合 CSI、相机和路径损耗图像对无人机定位性能的改善。

## II. 框架概述

图 1 所示的 DeepTelecom 通过六个阶段将三维场景转化为高保真、多模态、LoD3 信道数据集：

1. **场景初始化。** 使用开放地理空间数据和 LiDAR 扫描重建室内外粗略 LoD3 几何结构，并导出为标准三维格式 [24]–[26]。
2. **材料参数化。** 将粗略场景分割为命名表面，利用大语言模型为其分配随频率变化的电磁材料参数，得到每个表面都带有材料属性的结构化描述。
3. **补充场景元素。** 加入 RIS 面板产生可控反射，给移动终端赋予速度以产生时变信道；进一步模拟不同俯仰角与平移速度下无人机旋翼产生的微多普勒特征。
4. **射线追踪与信道提取。** 使用 NVIDIA Sionna 和 OptiX 支持的可微 GPU RT 引擎，提取信道冲激响应（CIR）、信道频率响应（CFR）及角度统计量 [22]、[28]、[29]。
5. **校准。** 最小化仿真与实测路径损耗之间的鲁棒损失，在固定射线拓扑的条件下反向传播场计算梯度，校准材料参数。
6. **可视化和打包。** 在可选校准之后，GPU 生成快照、传播视频、覆盖图和天气条件渲染结果，并以统一场景模式组织所有模态。

**图 1：** 前向流程为“场景初始化 → 材料参数化 → 补充 RIS、移动终端和无人机运动 → 可微 RT → 可视化与数据集”；校准循环利用稀疏路径损耗目标及自动微分更新材料参数。

## III. 初始化数字孪生：粗略场景获取

第一阶段构建作为数字孪生起点的粗略 LoD3 几何结构。两条并行流水线分别从开放地理空间数据重建室外环境、从 LiDAR 数据重建室内环境。两条流水线都通过统一接口输出粗略几何模型，供下一阶段进行精细化处理和材料参数化。

### A. 室外粗略场景重建

对室外环境，使用专业三维建模工具，根据开放地理空间数据构建 LoD3 城市场景。图 2 给出了具体流水线。实现中，通过 Blender-blosm 插件导入 Google 3D Tiles 提供的真实世界模型，并选择日本某处建筑密集的城区作为测试地点。导入的模型包含建筑物外形、纹理和地形高程，但依然比较粗略，存在表面不均匀、不同构件合并等问题。为了更高效地编辑，将模型以 .gltf 格式导出到 SketchUp。在 SketchUp 中，以 Google 3D Tiles 为参照重新构造关键结构元素，按照类别组织对象，并为它们分配玻璃、混凝土等符合实际的材料名称。输入 GPS 坐标后，这套流程即可重建包含地形和建筑物的室外孪生体。

**图 2：** 室外数字场景重建流水线，依次为选择目标区域、加载原始模型、在 SketchUp 中建模、在 Blender 中调整。

### B. 室内粗略场景重建

对于室内环境，通过信息物理数字孪生系统，以 LoD3 粒度重建复杂场景。装有三维 LiDAR 扫描器的四足机器人在环境中测绘 [24]、[25]、[41]。LiDAR 既记录几何距离，又测量反射强度，因此能够推断材料类型、颜色等表面特征。先对原始点云去噪和滤波，再采用基于无迹卡尔曼滤波器（UKF）的 HDL 定位算法 [42]，将点云转换到统一三维坐标系。如果 UKF 在扫描获取时间 $t$ 提供旋转矩阵 $R(t)$ 和位姿平移向量 $d(t)$，机器人坐标系中的点 $p_{\mathrm{local}}$ 对应的全局坐标为

$$
p_{\mathrm{global}}(t)=R(t)p_{\mathrm{local}}+d(t).
\tag{1}
$$

其中 $p_{\mathrm{global}}(t)$ 是变换至全局坐标系后的点。该变换将所有扫描结果对齐至公共坐标系。汇总点云可以揭示墙壁、家具等室内结构的几何形状与布局 [26]、[43]。图 3 展示室内数字场景重建流水线。

随后，三维建模模块把点云转换为多边形网格。通过网格提取与简化，在保留必要细节的同时减少冗余几何；并根据对象类型组合实体建模、表面建模和线框建模，使不同对象得到适合的重建表达。再执行纹理烘焙与光照烘焙，将表面纹理和照明预计算到网格上，形成照片级逼真外观。粗略室内模型以 .obj、.fbx 等标准格式导出，交由下一阶段处理。

通过统一接口，LiDAR 或 RGB-D 传感器采集的室内点云可形成 LoD3 室内模型，而 GPS 坐标可形成室外孪生体。两者均进入同一材料参数化阶段；此时模型只有几何信息，还缺乏传播仿真所需的电磁语义。

**图 3：** 室内数字场景重建流水线，包含实际建筑照片、LiDAR 扫描建模结果和两种虚拟孪生场景示例。

## IV. 数字孪生参数化：从粗略几何到材料感知表面

第二阶段通过将粗略几何转换为具有材料感知能力的孪生体，补充缺少的电磁语义。首先将场景划分为带名称的表面，再利用大语言模型（LLM）为每种材料分配频率相关的电磁参数。这种材料分配能力把 DeepTelecom 与不可微的 LoD1 数据集区分开来，后者通常只有拉伸得到的简单块体，材料语义有限。

### A. 使用 Blender 进行区域分割与标注

Blender 在同一平台整合室内和室外流水线。无论重建模型来自 LiDAR 扫描还是地理空间数据，都通过 .obj、.fbx、.gltf 等标准格式导入 Blender [25]。Blender 执行以下三项功能。

- **几何清理与简化。** 修复非流形边、删除重复顶点，确保获得适于射线追踪的水密几何结构。在保留影响电磁传播的重要结构细节的同时，优化三角面片数量。
- **材料标注。** 按严格的命名约定给每个对象分配描述性名称，例如 wall_concrete、window_glass、door_wood 和 road_asphalt。该命名约定把材料类别编码进对象名称，驱动下一处理步骤。
- **纹理坐标映射与保存。** 在导入、导出过程中保留纹理坐标与贴图，使场景快照和视频保持照片级逼真度。

处理后，场景导出为自定义 XML 表示，其中包含对象层次、三角网格几何、顶点坐标与材料标签。其结构示例为

~~~xml
<scene>
  <object id="1" name="wall_concrete">
    <mesh>
      <vertices> ... </vertices>
      <faces> ... </faces>
    </mesh>
  </object>
  ...
</scene>
~~~

LLM 材料模块与 Sionna 射线追踪器均解析这一文件格式。

### B. LLM 辅助的材料分配

LLM 分析结构化 XML 场景，修正和验证材料标注。具体包括四个步骤。

1. **提取对象名称。** XML 解析器读取每个对象的 name 属性，例如 window_glass 或 wall_brick，沿用 Blender 建模阶段的命名约定。
2. **LLM 材料映射。** 使用本地部署的 LLM（例如 Qwen3-4B）读取对象名称，并查询基于 IEEE 标准和相关文献编制的电磁材料数据库。模型将对象描述与材料条目进行语义匹配，例如将 window_glass 映射到工作频率下钠钙玻璃的介电参数。
3. **参数赋值。** 为每种材料赋予 RT 所需的电磁参数，包括相对介电常数实部 $\varepsilon'_r$、非磁性材料取值为 1 的相对磁导率 $\mu_r$、单位为 S/m 的电导率 $\sigma$，以及表征漫散射的表面粗糙度系数。所有这些参数可以随频率变化，在仿真中心频率处插值得到实际使用值。对复杂材料可采用多层模型。
4. **一致性验证。** LLM 检查可能形成非物理边界的不一致现象，例如相邻对象的介电属性差异极大。检测到这类情形后，模型提出修正建议，或标记对象供人工复查。

材料参数通过有效复介电常数、菲涅耳反射系数，以及对粗糙表面适用的相干反射衰减进入射线追踪器。令 $s$ 为表面，$m(s)$ 为其材料类别。在 $e^{j2\pi ft}$ 相量约定下，材料类别 $m$ 在频率 $f$ 处的有效复相对介电常数为 [44]

$$
\bar{\varepsilon}_{r,m}(f)
=\varepsilon'_{r,m}(f)-j\frac{\sigma_m(f)}{2\pi f\varepsilon_0}.
\tag{2}
$$

这里 $j=\sqrt{-1}$，$\varepsilon'_{r,m}(f)$ 为相对介电常数的实部，$\varepsilon_0$ 为真空介电常数，$\sigma_m(f)$ 为材料 $m$ 的电导率。考虑从自由空间入射至局部平坦、非磁性表面的电磁波，令 $\theta_i$ 表示相对表面法线测量的入射角。对于电场极化分别平行和垂直于入射面的情况，菲涅耳反射系数为 [44]

$$
\begin{aligned}
\Gamma_{\parallel,m}(f,\theta_i)
&=\frac{\bar{\varepsilon}_{r,m}(f)\cos\theta_i-\sqrt{\bar{\varepsilon}_{r,m}(f)-\sin^2\theta_i}}
{\bar{\varepsilon}_{r,m}(f)\cos\theta_i+\sqrt{\bar{\varepsilon}_{r,m}(f)-\sin^2\theta_i}},\\
\Gamma_{\perp,m}(f,\theta_i)
&=\frac{\cos\theta_i-\sqrt{\bar{\varepsilon}_{r,m}(f)-\sin^2\theta_i}}
{\cos\theta_i+\sqrt{\bar{\varepsilon}_{r,m}(f)-\sin^2\theta_i}}.
\end{aligned}\tag{3}
$$

对粗糙表面 $s$，使用瑞利粗糙度因子 [45] 衰减相干镜面反射：

$$
\rho_s(f,\theta_i)=
\exp\left[-2\left(\frac{2\pi\sigma_{h,s}\cos\theta_i}{\lambda_0(f)}\right)^2\right],
\qquad \lambda_0(f)=\frac{c}{f}.
\tag{4}
$$

其中 $\sigma_{h,s}$ 是表面高度标准差，$\lambda_0(f)=c/f$ 是自由空间波长，$c$ 为光速。对于极化 $\chi\in\{\parallel,\perp\}$，追踪器最终采用的有效反射系数为 [45]

$$
\widetilde{\Gamma}_{\chi,s}(f,\theta_i)
=\rho_s(f,\theta_i)\Gamma_{\chi,m(s)}(f,\theta_i).
\tag{5}
$$


## V. 补充场景元素：RIS、移动性与无人机

除了静态几何结构与材料之外，DeepTelecom 还添加了三类会影响实际部署中传播行为的元素。RIS 面板产生可控反射，移动终端（MT）通过平移运动使信道随时间变化，旋转无人机的旋翼又在平移运动之上引入微多普勒调制。在射线追踪前配置上述三类元素，它们将共同改变引擎生成的信道。

### A. RIS

首先在场景中添加 RIS 面板，通过可编程相位控制重新定向信号反射。每块面板均被放置在场景中，并支持两种波束成形模式。

**单波束聚焦。** 对于点对点高吞吐量回传链路，根据路径长度差采用相位梯度策略。若 RIS 位于 $xy$ 平面，为使波束指向 $(\theta_0,\phi_0)$，相位分布为

$$
\Phi(x,y)=-\frac{2\pi}{\lambda}
\left(x\sin\theta_0\cos\phi_0+y\sin\theta_0\sin\phi_0\right).
\tag{6}
$$

其中 $(x,y)$ 为 RIS 坐标，$\lambda$ 为波长，$\theta_0$ 与 $\phi_0$ 分别是目标俯仰角和方位角。表面上的线性相位梯度将波束引导至目标方向。

**多波束优化。** 对于同时服务多个用户的场景，使用随机梯度下降等迭代方法设计相位码本 [46]，使辐射方向图近似目标多波束形状。

### B. MT 移动性

为每个移动终端分配速度向量，使终端运动时信道响应发生变化，从而生成时变信道冲激响应（CIR）。同时加入时变噪声，以体现更真实的信道动力学。运动路径产生的多普勒频移为

$$
f_{D,\ell}=\frac{v}{\lambda}\cos\psi_\ell.
\tag{7}
$$

其中 $\ell\in\{1,\ldots,L\}$ 索引该链路保留的 $L$ 条传播路径；$v$ 为相对速度，$\lambda$ 为波长，$\psi_\ell$ 为路径方向与速度向量之间的夹角。第 VI 节的射线追踪器逐路径记录这一频移，第 VI-B 节的二阶统计量将其汇总为多普勒扩展。这种逐路径频移刻画了平移效应，但无法刻画旋翼转动产生的更快速调制。

### C. 无人机建模与微多普勒

无人机的飞行状态耦合了平移速度、俯仰角和旋翼频率，三者影响多普勒谱的不同部分。式（7）描述单程通信链路的多普勒频移。下文考虑的无人机感知回波属于单站形式，往返传播相位会使平移多普勒频移加倍。令速度向量与视线（LoS）夹角为 $\psi$，回波中心频移为 $f_D^{\mathrm{mono}}=(2v/\lambda)\cos\psi$。俯仰角改变机身及旋翼平面相对于 LoS 的姿态，而旋翼频率 $f_{\mathrm{rot}}$ 决定叶片周期性运动。它们共同决定旋翼微多普勒特征（MDS）的中心、频率范围与周期结构。

用一个点散射体代表无人机机身，将每个旋翼叶片离散成围绕旋翼轴转动的点。处于半径 $\rho$ 的叶片点以角速度 $\omega=2\pi f_{\mathrm{rot}}$ 旋转，其投影速度呈正弦变化，于是产生瞬时微多普勒频移 [47]、[48]：

$$
f_{\mathrm{mD}}(t)=\frac{2\omega\rho}{\lambda}
\cos\theta\cos(\omega t+\phi_0-\phi_{\mathrm{LoS}}).
\tag{8}
$$

其中 $t$ 为连续观测时间，$\lambda$ 为波长，$\theta$ 为从旋翼平面测量的 LoS 仰角/观测角，$\phi_0$ 为叶片初始相位，$\phi_{\mathrm{LoS}}$ 为旋转平面内的 LoS 方位角。等价地，LoS 与旋翼轴的夹角为 $\pi/2-\theta$。机身俯仰角与 $\theta$ 并不相同：机身俯仰使旋翼平面及轴在世界坐标系内旋转，从而针对当前无人机与基站（BS）的几何关系改变 $\theta$。在叶尖位置 $\rho=R$，最大频移为

$$
f_{\mathrm{mD}}^{\max}=\frac{4\pi f_{\mathrm{rot}}R}{\lambda}\cos\theta.
\tag{9}
$$

其中 $R$ 为叶片半径，$\lambda=c/f_c$，$f_c$ 为载频。微多普勒谱宽因而随 $f_{\mathrm{rot}}$、$R$ 与 $f_c$ 线性增长，并受到姿态相关投影因子 $\cos\theta$ 的调节。

令 $x(t)$ 为单片叶片的复回波。利用 Jacobi–Anger 恒等式 [47]、[48] 对周期性相位调制展开，可得离散多普勒边带：

$$
x(t)=A\sum_{\nu=-\infty}^{\infty}
J_\nu(\beta)
e^{j[2\pi(f_D^{\mathrm{mono}}+\nu f_{\mathrm{rot}})t+
\nu(\phi_0-\phi_{\mathrm{LoS}})]}.
\tag{10}
$$

这里 $A$ 为回波幅度，$\nu\in\mathbb Z$ 为边带阶数，$J_\nu$ 是 $\nu$ 阶贝塞尔函数，$\beta=4\pi R\cos\theta/\lambda$ 为调制指数。机身速度通过 $f_D^{\mathrm{mono}}$ 移动单站回波谱梳中心；旋翼频率设置单叶片边带间隔 $f_{\mathrm{rot}}$；俯仰相关的 $\theta$ 通过 $J_\nu(\beta)$ 控制包络。对 $B$ 片等角间隔叶片，相干相加后保留的边带阶数间隔对应 $Bf_{\mathrm{rot}}$，从而将可观测周期与叶片数量联系起来。

DeepTelecom 在第 VI 节的可微射线追踪器内部生成 MDS。令 $\mathcal K$ 为无人机点散射体的有限集合，$k\in\mathcal K$ 索引单个散射体。每个旋翼快照更新机身与叶片点的位置，追踪器得到 BS 至第 $k$ 个散射体的单程复信道系数 $h_k(t)$，并据此构造近似单站回波 [48]：

$$
s(t)=\sum_{k\in\mathcal K}w_kh_k(t)^2+\eta(t).
\tag{11}
$$

其中 $w_k$ 是无量纲散射体权重，$\eta(t)$ 为加性复噪声。对 $h_k(t)$ 平方近似了基站—散射体—基站的往返传播。对所得快照序列执行短时傅里叶变换（STFT）得到 MDS，同时保留周围场景中的多径效应。

## VI. 射线追踪引擎与信道提取

场景完成参数化，并加入第 V 节的补充元素后，第四阶段执行传播追踪和信道数据提取。本文基于 NVIDIA 的 Sionna RT 构建：它将高性能射线追踪和完整可微性相结合，使场景参数能够通过梯度进行优化 [22]、[28]、[29]。追踪器在包含发射机、接收机、RIS 面板及 MT 的精细三维场景上运行，因此一次追踪即可传播信号并捕获这些元素导致的多径效应。

### A. 射线追踪

射线追踪从先前阶段布置的设备出发。每个 BS 和 MT 都有位置、姿态、发射功率和天线阵列，而系统带宽决定信道的时延分辨率。对于每个发射机，利用斐波那契球面采样发射大量射线，实现近似均匀的方向覆盖；同时加入自适应重要性采样，对可能包含接收机的区域投射更密集的射线。NVIDIA OptiX 并行追踪大批射线并检测它们与几何结构的相交，从而在不产生不切实际延迟的条件下，支持每场景数千万条射线 [28]。射线达到最大交互深度或功率低于阈值时停止追踪，且丢弃交互序列重复的路径。

每次交互都使用物理传播模型并更新复幅度。反射和透射遵从几何光学，采用式（3）的菲涅耳系数和式（2）的材料介电常数；衍射遵从一致性衍射理论；自由空间传播则计入其余损耗。对于保留的路径拓扑，Sionna RT 允许材料相关场计算对连续场景参数求导。第 VII 节将利用这些导数进行校准。

### B. 信道数据产品

可微追踪器不仅生成信道，还形成信号如何抵达接收机的结构化记录。对于每对收发机，引擎把多跳传播路径记录为带交互标签的坐标点序列。每条路径都具有顶点、交互类型、材料标识、复增益 $\alpha_\ell$、时延 $\tau_\ell$、到达角 $\Omega_{r,\ell}$、离开角 $\Omega_{t,\ell}$ 及式（7）的多普勒频移。再根据这些路径合成标准信道响应。

在物理观测时间 $t$，令 $\mathcal P(t)=\{1,\ldots,L(t)\}$ 为保留路径集合，$\tau$ 为超额时延变量。对于 MIMO 系统，时变 CIR 为

$$
\mathbf H_{\mathrm{CIR}}(t,\tau)=
\sum_{\ell\in\mathcal P(t)}
\alpha_\ell(t)\,
\mathbf a_r(\Omega_{r,\ell}(t))
\mathbf a_t^{H}(\Omega_{t,\ell}(t))
\delta_D(\tau-\tau_\ell(t)).
\tag{12}
$$

其中 $\mathbf a_r$、$\mathbf a_t$ 分别为接收和发射阵列响应，$(\cdot)^H$ 为共轭转置，$\delta_D(\cdot)$ 为狄拉克 $\delta$ 函数。相应 CFR 是 CIR 对时延 $\tau$ 的傅里叶变换：

$$
\mathbf H_{\mathrm{CFR}}(t,f)=
\int_{-\infty}^{\infty}
\mathbf H_{\mathrm{CIR}}(t,\tau)e^{-j2\pi f\tau}\,d\tau.
\tag{13}
$$

其中 $f$ 为频率。$t$ 标识观察信道的时间，$\tau$ 仅是 CIR 的时延坐标。式（11）中的标量 $h_k(t)$ 为基站到散射体链路在载频 $f_c$ 处的 CFR 系数。还计算信道色散的二阶统计量。在固定时间 $t$，省略显式时间依赖，令 $L=L(t)$，均方根（RMS）时延扩展为

$$
\tau_{\mathrm{rms}}=
\sqrt{
\frac{\sum_{\ell=1}^L|\alpha_\ell|^2\tau_\ell^2}
{\sum_{\ell=1}^L|\alpha_\ell|^2}
-\left(
\frac{\sum_{\ell=1}^L|\alpha_\ell|^2\tau_\ell}
{\sum_{\ell=1}^L|\alpha_\ell|^2}
\right)^2}.
\tag{14}
$$

离开角和到达角的角度扩展为

$$
\sigma_{\mathrm{AS}}=
\sqrt{\frac{\sum_{\ell=1}^L|\alpha_\ell|^2(\Delta\phi_\ell)^2}
{\sum_{\ell=1}^L|\alpha_\ell|^2}}.
\tag{15}
$$

其中 $\Delta\phi_\ell$ 为相对平均方向的角偏差。多普勒扩展对各路径多普勒频移采用相同的功率加权形式。对于指定平面，将数值覆盖图栅格化，位置 $r$ 的接收功率由链路预算给出：

$$
P_{\mathrm{rx}}(r)=P_{\mathrm{tx}}+G_{\mathrm{tx}}+G_{\mathrm{rx}}-\mathrm{PL}(r)\quad[\mathrm{dBm}].
\tag{16}
$$

其中 $r$ 是覆盖图栅格位置，$P_{\mathrm{tx}}$ 以 dBm 表示，$G_{\mathrm{tx}}$ 和 $G_{\mathrm{rx}}$ 以 dBi 表示，$\mathrm{PL}(r)$ 为来自所有到达位置 $r$ 的路径所聚合得到的路径损耗（dB）。可视化阶段渲染该栅格。过滤不可达路径与无效链路后，DeepTelecom 将场景几何与材料映射至信道，为时频域 MIMO 行为的分析提供基于物理的基础。所有数据起初采用材料表中的初值，下一阶段通过稀疏路径损耗目标进行校准。



## VII. 校准

材料表提供具有物理意义的参数初值，但这些数值未必准确复现目标信道响应。因此将校准表述为固定拓扑下的可微逆问题。给定稀疏的路径损耗目标锚点，在保留的传播路径上重放材料相关电磁场，最小化鲁棒失配，并诊断这些锚点能否对待训练参数形成约束。如果具有配准信息，目标也可以采用实测路径损耗值。

### A. 固定拓扑可微前向模型

在校准载频 $f_c$（Hz）处计算式（2）的材料模型。为简洁起见，省略频率自变量，写作 $\varepsilon_{r,m}=\varepsilon'_{r,m}(f_c)$，并用 $\sigma_m$ 表示在 $f_c$ 处评价的电导率。改变这两个实数参数，将影响追踪器使用的材料相关菲涅耳系数。

设 $\mathcal I$ 为校准锚点集合，$i\in\mathcal I$。在文献 [28]、[30] 的可微 RT 形式中，路径发现与场计算发挥不同作用。对于接收机位置 $\mathbf r_i$ 的锚点，路径求解器首先发现离散的路径索引集合：

$$
\mathcal P_i=\operatorname{TracePaths}(\mathcal G,\mathbf p_{\mathrm{tx}},\mathbf r_i).
\tag{17}
$$

其中 $\operatorname{TracePaths}$ 为离散路径发现算子，$\mathcal G$ 是场景几何结构，$\mathbf p_{\mathrm{tx}}$ 为发射机位置。可见性检测与路径选择是离散操作。令 $\mathbf z$ 为无约束校准变量，$\boldsymbol\theta(\mathbf z)$ 为对应的材料参数，其具体映射由式（21）给出。于是先追踪 $\mathcal P_i$，然后仅对固定拓扑上的连续场重放求导：

$$
\{\alpha_{i\ell}(\boldsymbol\theta(\mathbf z)),\tau_{i\ell}\}_{\ell\in\mathcal P_i}
=\mathcal F(\mathcal P_i,\boldsymbol\theta(\mathbf z)).
\tag{18}
$$

其中 $\mathcal F$ 是可微场重放算子，$\ell$ 索引保留路径，$\alpha_{i\ell}$ 是归一化的无量纲复信道系数，$\tau_{i\ell}$ 为其时延。在几何结构与路径拓扑固定时，时延不变，材料交互则改变各路径系数的权重。采用相位鲁棒的路径增益观测量

$$
\widehat g_i(\boldsymbol\theta)
=\sum_{\ell\in\mathcal P_i}|\alpha_{i\ell}(\boldsymbol\theta)|^2+\epsilon_g,
\tag{19}
$$

其中 $\widehat g_i$ 与 $\epsilon_g>0$ 均无量纲。预测路径损耗为

$$
\widehat{\mathrm{PL}}_i(\boldsymbol\theta)
=C_i-10\log_{10}\widehat g_i(\boldsymbol\theta).
\tag{20}
$$

$C_i$ 为已知且固定的 dB 偏置，用于将信道增益归一化约定换算为锚点 $i$ 的目标路径损耗约定。它不依赖材料参数，可以包含与锚点有关的已知链路预算项。

### B. 鲁棒目标与物理重参数化

令 $\mathcal M_{\mathrm{cal}}$ 为待校准材料类别集合，$M_{\mathrm{cal}}=|\mathcal M_{\mathrm{cal}}|$，并固定材料顺序 $(m_1,\ldots,m_{M_{\mathrm{cal}}})$。为每类材料 $m$ 分配无量纲、无约束变量 $u_m$、$v_m$，映射到允许的材料参数域，并按照固定顺序构造变量向量：

$$
\begin{aligned}
\mathbf z&=[u_{m_1},v_{m_1},\ldots,u_{m_{M_{\mathrm{cal}}}},v_{m_{M_{\mathrm{cal}}}}]^\top,\\
\varepsilon_{r,m}(u_m)&=\varepsilon_{\min}
+(\varepsilon_{\max}-\varepsilon_{\min})\operatorname{sigmoid}(u_m),\\
\sigma_m(v_m)&=\sigma_{\mathrm{ref}}\exp(v_m),\\
\boldsymbol\theta_m(u_m,v_m)
&=[\,\varepsilon_{r,m}(u_m),\ \sigma_m(v_m)/\sigma_{\mathrm{ref}}\,]^\top,\\
\boldsymbol\theta(\mathbf z)&=
[\boldsymbol\theta_{m_1}^{\top},\ldots,\boldsymbol\theta_{m_{M_{\mathrm{cal}}}}^{\top}]^\top
\in\mathbb R^{2M_{\mathrm{cal}}}.
\end{aligned}\tag{21}
$$

这里 $\varepsilon_{\min}$、$\varepsilon_{\max}$ 分别为无量纲介电常数下界和上界，$\sigma_{\mathrm{ref}}=1$ S/m。因而介电常数有界，电导率为正并采用 S/m 单位，而 $\boldsymbol\theta$ 使用固定的无量纲电导率坐标 $\sigma_m/\sigma_{\mathrm{ref}}$。实验仅校准大理石材料，即 $M_{\mathrm{cal}}=1$。

令 $\mathcal I_{\mathrm{tr}}\subseteq\mathcal I$ 为训练锚点，$\mathrm{PL}_i^{\mathrm{tar}}$ 为其目标路径损耗（dB），定义残差 $e_i(\mathbf z)=\widehat{\mathrm{PL}}_i(\boldsymbol\theta(\mathbf z))-\mathrm{PL}_i^{\mathrm{tar}}$。使用 Huber 数据目标 [49]：

$$
\mathcal L_{\mathrm{data}}(\mathbf z)=
\frac1{|\mathcal I_{\mathrm{tr}}|}
\sum_{i\in\mathcal I_{\mathrm{tr}}}\rho_{\delta_H}(e_i(\mathbf z)).
\tag{22}
$$

其中

$$
\rho_{\delta_H}(e)=
\begin{cases}
\frac12e^2,&|e|\le\delta_H,\\
\delta_H(|e|-\frac12\delta_H),&|e|>\delta_H.
\end{cases}\tag{23}
$$

残差与过渡阈值 $\delta_H>0$ 均以 dB 表示，因此 Huber 惩罚和 $\mathcal L_{\mathrm{data}}$ 的数值量纲为 dB 的平方。二次区间为最优解附近提供平滑目标，线性区间限制具有较大残差的锚点的影响。利用弱先验对锚点约束不足的方向进行正则化：

$$
\mathcal L_{\mathrm{total}}(\mathbf z)=
\mathcal L_{\mathrm{data}}(\mathbf z)+
\lambda_{\mathrm{prior}}\|\mathbf z-\mathbf z_0\|_2^2.
\tag{24}
$$

其中 $\mathbf z_0$ 是把材料表初值按式（21）进行逆变换得到的无约束初值。当初值严格位于介电常数允许区间内且电导率大于零时，逆映射有限。初始化 $\mathbf z^{(0)}=\mathbf z_0$。优化器根据链式法则，对 $\mathbf z\mapsto\boldsymbol\theta(\mathbf z)$ 与固定拓扑场重放共同反向传播。对于 $q\in\{0,\ldots,Q-1\}$，Adam [50] 执行

$$
\mathbf z^{(q+1)}
=\operatorname{Adam}\!\left(
\mathbf z^{(q)},\nabla_{\mathbf z}
\mathcal L_{\mathrm{total}}(\mathbf z^{(q)})
\right).
\tag{25}
$$

### C. 梯度检验与可辨识性

在同一 $\mathbf z$ 处，使用中心有限差分验证反向模式自动微分梯度。对坐标 $a\in\{1,\ldots,2M_{\mathrm{cal}}\}$，令 $\mathbf e_a$ 为对应单位向量，$\Delta_{\mathrm{FD}}>0$ 为无量纲有限差分步长：

$$
\begin{aligned}
\mathbf g_{\mathrm{AD}}(\mathbf z)
&=\nabla_{\mathbf z}\mathcal L_{\mathrm{total}}(\mathbf z),\\
[\mathbf g_{\mathrm{FD}}(\mathbf z)]_a
&=\frac{
\mathcal L_{\mathrm{total}}(\mathbf z+\Delta_{\mathrm{FD}}\mathbf e_a)
-\mathcal L_{\mathrm{total}}(\mathbf z-\Delta_{\mathrm{FD}}\mathbf e_a)
}{2\Delta_{\mathrm{FD}}}.
\end{aligned}\tag{26}
$$

两种梯度的相对差异为

$$
e_{\mathrm{grad}}(\mathbf z)=
\frac{
\|\mathbf g_{\mathrm{AD}}(\mathbf z)-\mathbf g_{\mathrm{FD}}(\mathbf z)\|_2
}{
\|\mathbf g_{\mathrm{FD}}(\mathbf z)\|_2+\epsilon_{\mathrm{grad}}
}.
\tag{27}
$$

这里 $\epsilon_{\mathrm{grad}}>0$ 防止除零。进一步考察在式（21）无量纲材料坐标中的训练锚点雅可比矩阵

$$
\mathbf J=
\frac{
\partial[\,\widehat{\mathrm{PL}}_i(\boldsymbol\theta)\,]_{i\in\mathcal I_{\mathrm{tr}}}
}{
\partial\boldsymbol\theta^\top
}
\in\mathbb R^{|\mathcal I_{\mathrm{tr}}|\times2M_{\mathrm{cal}}}.
\tag{28}
$$

没有被保留路径接触的材料，对应雅可比列为零；列之间近乎共线，则对应参数在局部难以区分。因此材料覆盖、雅可比秩和条件数共同决定锚点对所选变量的局部约束能力。改变参数归一化尺度可能改变奇异值与条件数，但不改变秩。这些诊断仅说明局部敏感性，不能保证全局解唯一。

## VIII. 数据集格式与打包

数据集采用统一层次结构组织所有模态，使视觉、几何与无线表示在时间和空间上对齐。每个场景是自包含目录，结构如下：

~~~text
scenario_name/
|- model/       # 三维模型与 XML 场景描述
|- config/      # 仿真配置文件
|- snapshots/   # 渲染图像与视频
|- paths/       # 传播路径数据（CSV/HDF5）
|- heatmaps/    # 覆盖图（NPY/MAT）
|- channel/     # CIR/CFR 张量（HDF5）
'- metadata.json # 场景级元数据
~~~

这样既可独立加载每个场景的几何、配置、信道和可视化结果，也能通过新增子目录扩展新的数据模态。

## IX. 仿真与分析

DeepTelecom 从四个相互补充的角度评价：包含 RIS 的室内外场景生成、无人机微多普勒建模、基于留出合成锚点的材料校准，以及多模态三维定位。

### A. 场景生成与 RIS 辅助传播

室外地理空间模型和室内点云被统一转换为材料感知的 LoD3 表示，并使用一致的 BS、MT 与 RIS 接口。图 4(a) 展示室内结果：墙面、家具和隔断提供精细的交互表面，追踪路径连接 BS、RIS 和 MT。突出显示的 BS–RIS–MT 路径说明室内 RT 场景已集成 RIS 辅助传播。图 4(b) 展示室外街道场景：建筑物产生不同的多径结构，但 RIS 辅助路径仍通过相同设备和信道接口表示。这两种情况证明异构场景来源能够汇聚到统一的仿真流程。

### B. 无人机仿真

在室外射线追踪场景中，考虑一个四旋翼无人机和固定的屋顶 BS，载频为 28 GHz。无人机沿贝塞尔轨迹以恒定 10 m/s 的速度飞行，分别测试 $0^\circ$、$30^\circ$ 和 $45^\circ$ 的俯仰角。对于每个样本，旋翼频率与叶片半径分别在标称值的 $\pm10\%$ 范围内随机变化。表 I 列出了用户可配置的无人机与采样参数。

| 参数 | 本文设置 |
|---|---|
| 载频 $f_c$ | 28 GHz |
| 飞行轨迹 | 贝塞尔曲线 |
| 平移速度 $v$ | 恒定 10 m/s |
| 俯仰角 | 0°、30°、45° |
| 旋翼频率 $f_{\mathrm{rot}}$ | 25 Hz，每样本 ±10% |
| 叶片半径 $R$ | 0.02 m，每样本 ±10% |
| 旋翼与叶片布局 | 四个旋翼，每个旋翼两片叶片 |
| 完整无人机离散化 | 每叶片三点、机身一点，共 25 个点 |
| 单叶片参考 | 一个叶尖点 |
| 相机/无人机采样率 $f_s$ | 共享且用户可配置 |
| 每个样本的快照数量 $N_{\mathrm{snap}}$ | 用户可配置 |
| 快照间隔 $\Delta t_{\mathrm{snap}}$ | 用户可配置 |
| 快照窗口 $T_w$ | 不长于局部相干时间 |

令 $b\in\{0,\ldots,N_{\mathrm{out}}-1\}$ 索引 $N_{\mathrm{out}}$ 个同步输出样本。在 $t_b=b/f_s$ 时刻，渲染器记录相机图像 $I_b$，仿真器记录相同时间戳的无人机状态和无线数据，因此相机帧与无人机/无线样本一一对应。为在输出样本内部解析旋翼运动，需要更高采样率的复快照向量 $\mathbf s_b$：

$$
\begin{aligned}
t_{b,n}&=t_b+n\Delta t_{\mathrm{snap}},\\
\mathbf s_b&=[s(t_{b,0}),\ldots,s(t_{b,N_{\mathrm{snap}}-1})]^\top
\in\mathbb C^{N_{\mathrm{snap}}},\\
T_w&=(N_{\mathrm{snap}}-1)\Delta t_{\mathrm{snap}}\le T_c(t_b).
\end{aligned}\tag{29}
$$

其中 $n$ 索引旋翼快照，$T_c(t_b)$ 为局部相干时间，$N_{\mathrm{snap}}$ 与 $\Delta t_{\mathrm{snap}}$ 可由用户设置。将全部快照限制在一个相干时间之内，使宏观传播几何在局部近似静止，同时解析形成 MDS 所需的旋翼相位变化。

图 5 展示同一无人机状态在晴、雨、雪条件下的同步相机图像。晴天与雪天只提供视觉变化；雨天还采用 ITU-R P.838-3 比衰减模型 [51]，其中雨衰比衰减为

$$
\gamma_{\mathrm{rain}}=
k_R(f_c,p_{\mathrm{pol}})
r_{\mathrm{rain}}^{\alpha_R(f_c,p_{\mathrm{pol}})}
\quad[\mathrm{dB/km}].
\tag{30}
$$

其中 $f_c$ 以 GHz 表示，$r_{\mathrm{rain}}$ 是 mm/h 单位的降雨率，$p_{\mathrm{pol}}$ 表示极化和路径几何配置。对散射体 $k$，令 $d_k$ 为 BS 到散射体的单程雨中路径长度（km），则雨衰后的单程信道为

$$
h_k^{\mathrm{rain}}(t)=10^{-\gamma_{\mathrm{rain}}d_k/20}h_k(t).
\tag{31}
$$

这个正实数因子改变回波幅度，但不改变微多普勒频率。由于式（11）对单程信道平方，单站回波中的往返衰减为 $10^{-\gamma_{\mathrm{rain}}d_k/10}$。当前实验不加入雪天的 RF 衰减，降雪只改变渲染图像的外观。

对式（29）的快照序列执行 STFT，得到图 6 的射线追踪微多普勒时频图，其中实线和虚线分别表示独立计算的平移与叶尖多普勒预测。所有完整机身样本虽然均以 10 m/s 飞行，但由于沿曲线运动时速度在 LoS 上的投影不同，平移频移不同。因此，所选择 $0^\circ$ 俯仰样本具有接近零的径向速度，而非飞行速度为零。俯仰改变旋翼平面的 LoS 投影 $\cos\theta$，从而改变边带包络。两个叶片在标称旋翼频率下产生约 $Bf_{\mathrm{rot}}\approx50$ Hz 的边带间隔。单叶片参考展示了式（8）预测的正弦频率脊线。图 7 对应 25 点完整无人机与一个叶尖点的单叶片模型。

### C. 校准结果

在 28 GHz 室外场景中，利用 48 个低空非视距（NLoS）无人机锚点进行校准评价，其中 24 个用于训练、12 个用于验证、12 个作为留出集。路径审计共保留 97 条传播路径（每锚点 1–3 条），记录 142 次与大理石表面的交互。所有锚点都对所选材料参数具有非零敏感性。

使用指定的大理石材料配置生成目标信道，但不把该配置提供给优化器。然后把场景重置为 ITU-R 材料初值，仅利用 24 个训练路径损耗目标，通过式（24）优化大理石相对介电常数和电导率。其他材料、散射及链路预算项保持不变。实现使用 Sionna RT 2.0.1，每个锚点只追踪一次，此后重放材料相关电磁场，执行 $Q=200$ 次式（25）的更新。

图 8 表明路径损耗平均绝对误差（MAE）在 200 次迭代中持续降低，验证集与留出集变化跟随训练趋势，说明收敛稳定，并具有一致的泛化表现。报告的式（27）相对梯度差异为 $2.08\times10^{-3}$。在式（21）的无量纲坐标下，训练锚点对应的 24×2 雅可比矩阵秩为 2，数值奇异值分别为 399.94 和 6.36，条件数为 62.9。这两个参数因而在这些锚点下局部可观测，但敏感性不均匀，局部结果不意味着全局解唯一。

**表 II：12 个留出室外无人机锚点上的校准性能。**

| 材料模型 | PL MAE（dB） | PL RMSE（dB） | 时延扩展 RAE |
|---|---:|---:|---:|
| ITU-R 初始化 | 3.429 | 3.601 | 0.194 |
| 校准 $\varepsilon_r$ 和 $\sigma$ | 0.343 | 0.435 | 0.066 |

对留出锚点 $i$，式（14）RMS 时延扩展的相对绝对误差（RAE）为

$$
\operatorname{RAE}_{\tau,i}=
\frac{|\widehat\tau_{\mathrm{rms},i}-\tau_{\mathrm{rms},i}^{\mathrm{tar}}|}
{\tau_{\mathrm{rms},i}^{\mathrm{tar}}+\epsilon_\tau}.
\tag{32}
$$

其中 $\widehat\tau_{\mathrm{rms},i}$ 和 $\tau_{\mathrm{rms},i}^{\mathrm{tar}}$ 为预测和目标时延扩展，$\epsilon_\tau>0$ 与时延使用相同单位，用于稳定分母。RAE 均值由 0.194 降至 0.066，虽然优化损失并未显式包含时延扩展。这是因为学习到的材料参数重新调整了保留路径的权重，改变它们对信道色散的相对贡献。图 9 用信道增益绝对对数误差（ALE）和 RMS 时延扩展 RAE 的经验累积分布函数（CDF）展示全部留出误差。校准使两者向合成真值靠近，并显著收缩信道增益误差尾部。

### D. 下游应用

为了验证 DeepTelecom 在下游感知中的实用性，研究利用单站蜂窝通感一体化（ISAC）系统，对无设备协作的被动无人机目标进行三维定位。这里“被动”描述无人机目标，而非感知基础设施：固定屋顶 BS 发射感知波形并接收单站回波，无人机既不与 BS 通信，也不携带定位设备。

使用四种无人机运动类别的 6,620 个样本，按照 8:1:1 划分为训练集（5,296）、验证集（662）和测试集（662）。将式（29）的有序复回波向量表示为实值网络输入：

$$
\mathbf X_b=
\begin{bmatrix}
\operatorname{Re}\{\mathbf s_b\}^\top\\
\operatorname{Im}\{\mathbf s_b\}^\top
\end{bmatrix}\in\mathbb R^{2\times N_{\mathrm{snap}}}.
\tag{33}
$$

因此 $\mathbf X_b$ 是单站回波的实部与虚部有序表示，而非矩阵值的 $\mathbf H_{\mathrm{CIR}}$ 或 $\mathbf H_{\mathrm{CFR}}$。本实验把任务级“CSI”定义为 $\mathbf X_b$，并采用 $N_{\mathrm{snap}}=2048$。每个样本包含 $\mathbf X_b\in\mathbb R^{2\times2048}$、相机图像 $I_b\in\mathbb R^{3\times180\times320}$ 和路径损耗图像 $P_b\in\mathbb R^{3\times180\times320}$，以无人机中点坐标 $\mathbf p_b=(x_b,y_b,z_b)$ 作为回归目标。两个模型都使用八组 GroupNorm，对标准化坐标优化 Smooth L1 损失。

**表 III：无人机定位的主要训练参数。**

| 参数 | 仅 CSI | 多模态 |
|---|---|---|
| 输入模态 | CSI | CSI、相机、路径损耗 |
| 信道张量大小 | 2×2048 | 2×2048 |
| 图像尺寸 | 不使用 | 每幅 3×180×320 |
| 优化器 | AdamW | AdamW |
| 学习率 | 3×10⁻⁴ | 8×10⁻⁴ |
| 权重衰减 | 10⁻⁴ | 10⁻³ |
| 批量大小 | 256 | 64 |

仅 CSI 模型利用三个一维卷积神经网络（CNN）模块编码 $\mathbf X_b$ 的实部与虚部行，并将池化特征传给多层感知机（MLP）回归头。多模态模型采用一维信道编码器与两个独立的二维图像编码器分别处理相机和路径损耗图像；利用双向特征线性调制（FiLM）交换信道与相机上下文，再通过秩为 16 的双线性融合模块组合特征。将融合表示与路径损耗特征拼接，经 MLP 映射到三维位置预测。每个样本还公开由 STFT 得到的 MDS 时频图，但两个定位模型均未使用这一输入。

图 10(a) 对比 50 轮训练期间的标准化 Smooth L1 损失。第 50 轮时，多模态验证损失为 0.160，仅 CSI 为 0.318，降低了 49.5%。较低的训练与验证曲线表明补充模态为位置回归提供了更充分的信息。图 10(b) 展示定位误差分布：结合相机与路径损耗图像后，中位误差从 6.96 米降至 0.72 米，第 90 百分位误差从 31.05 米降至 2.43 米。可视模态减少了仅依赖 CSI 定位的空间歧义。这些结果验证了所构建合成无人机场景中的下游应用价值；实地验证与仿真到现实的评估仍属未来研究。

## X. 结论与未来工作

DeepTelecom 提供面向 6G 无线 AI 的统一材料感知 LoD3 数字孪生框架和多模态数据集。它将粗略室内外场景转化为可编辑的表面级模型，分配频率相关电磁属性，并利用可微 GPU RT，在包含 RIS、MT 与动态无人机的场景中生成同步的信道、视觉和天气条件数据。无人机模型还刻画平移速度、俯仰角和旋翼微多普勒。在 28 GHz 室外实验中，固定拓扑校准将留出路径损耗 MAE 从 3.429 dB 降至 0.343 dB，将 RMS 时延扩展 RAE 从 0.194 降至 0.066。对于下游三维定位，组合 CSI、相机图像和路径损耗图像，将第 90 百分位误差从 31.05 米降至 2.43 米。结果共同证明在所评估的合成场景中，信道级校准与多模态学习具有价值。

用户还可针对自身的材料、场景和部署配置生成数据。未来工作将研究闭环数字孪生，其中可微 RT 用于优化材料参数、RIS 配置和无人机轨迹控制，并通过持续校准、实地验证以及仿真到现实的迁移，覆盖更多材料和轨迹。还将丰富信号级表示与感知模态，并通过改进场景几何、环境渲染以及物体动力学、运动散射体和旋转平台的建模，进一步完善数据集生成。

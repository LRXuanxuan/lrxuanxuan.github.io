## 摘要

离散流匹配通过迭代地把噪声 token 变换为连贯语言来生成文本，但可能需要数百次前向传播。蒸馏利用多步轨迹来训练一个学生模型，使其在少数几步内复现这一过程。当学生模型表现不佳时，通常的解释是容量不足。我们则主张相反的判断：瓶颈在轨迹，而不在学生模型。每条训练轨迹都是通过一连串盲目的随机跳转构建的，其中从不对序列质量进行评估；在早期中点处的一个糟糕决策会通过后续步骤传播，而学生模型却必须模仿这一结果。轨迹塑形离散流匹配（Trajectory-Shaped Discrete Flow Matching, TS-DFM）用引导式导航取代这些盲目跳转：一个轻量级的能量罗盘在每个中点评估候选续步，并选出最连贯的一个。所有塑形都只在训练阶段进行；推理开销不变。在 170M 参数的语言建模上，塑形后的学生模型在 8 步时达到的困惑度比 1024 步的教师模型低 32%，同时速度快 128 倍；这一增益在多种源分布以及三个规模递增的评估器上保持一致。在我们比较的所有离散生成基线中，TS-DFM 取得了最佳困惑度，其中包括用 6 倍数据训练的方法或使用 5 倍大模型的方法。

## 1 引言

离散流匹配（discrete flow matching, DFM）模型通过数百乃至数千个细化步骤，迭代地把一个无信息量的源序列（例如均匀随机 token 或掩码 token）变换为连贯语言，从而生成文本（Gat et al., 2024; Campbell et al., 2024; Nie et al., 2026; Ye et al., 2025）。尽管其质量与其他 LLM 相当，但由于每生成一个 token 都需要一次完整的前向传播，它比自回归 LLM 慢了几个数量级。

蒸馏压缩了这一过程：学生模型学会用少数几步复现迭代过程在许多步中完成的事情（例如 FS-DFM（Monsefi et al., 2026））。学生模型从不接触训练数据，而是完全从轨迹中学习——所谓轨迹，就是迭代过程从源状态出发、穿过 token 空间、通向成文文本的具体路径。当蒸馏出的学生模型表现不佳时，标准的解释是模型容量不足。本文则认为，这一解释忽视了轨迹，真正的瓶颈是轨迹，而不是学生模型。

轨迹的构建需要在每个中间步骤把连续的速度 logits 转换为具体的 token 序列。由于 token 是离散的，这种转换在每个位置上都要求一个硬性的随机决策。对所得序列从不进行任何评估：该过程只会确定一个随机的实现，然后继续前进。

<span id="page-2"></span>

此后的每个步骤都以这个可能已经退化的状态为条件，因此一个糟糕的采样会向前传播，并污染所有下游计算。在 FS-DFM 的 RK-4 估计器中（Monsefi et al., 2026），三个这样的盲目跳转被串联起来；在第一个中点引入的误差会使第二个中点处的速度评估发生偏移，进而使第三个中点退化，最终目标则吸收了累积的漂移。学生模型忠实地模仿这个漂移后的目标，因为这是它唯一能获得的监督信号。

我们提出轨迹塑形离散流匹配（Trajectory-Shaped Discrete Flow Matching, TS-DFM），这是一个通过我们称为"导航塑形"（navigation shaping）的机制来塑造训练轨迹、以最大化其教学价值的框架。在标准方法只做一次盲目随机跳转的每个中点处，我们生成多个候选续步，并使用一个轻量级的能量罗盘（energy compass）——一个在生成感知负样本（generation-aware negatives）上训练得到的标量能量模型——来选出质量最高的一个。在实验中，该罗盘在区分真实流状态与生成相关的损坏（generation-relevant corruptions）方面达到 98.5% 的准确率。一个"序列到 token"（Sequence-to-Token）策略先在序列层面全局选出最佳候选，再利用速度置信度作为免费代理在 token 层面进行精修。时间阈值 $\tau$ 补全了整个设计：在流时间较早的阶段，序列的信息量太少，罗盘无法在候选之间做出区分，因此导航只在充分的语言结构已经浮现之后才激活（图 2）。

在 170M 参数的语言建模上，8 步的 TS-DFM 在使用均匀源时达到 56.1 的 GPT-2 困惑度——相对 FS-DFM 降低 36%，比完整的 1024 步教师模型还低 32%，同时速度快 128 倍（图 1）。对于掩码源，改进幅度甚至更大（8 步时相对 FS-DFM 为 5.6 倍）。

**图 1.** 跨步预算、评估器与源分布的生成质量。从左到右依次为：在三个评估器下的下一 token 预测准确率与困惑度。TS-DFM 取得最低的困惑度，且在低 NFE（函数评估次数）处增益最大，而这正是少步生成最重要的区间。

**图 2.** 训练期间，标准的轨迹构建会通过盲目的随机跳转累积误差。导航塑形则通过能量罗盘在候选中进行选择，并在 $t \ge \tau$ 时激活。

**图内文字与图例。** 图 1：横轴为 NFE，纵轴为 Accuracy (%)／Perplexity；图例为 DFM、FS-DFM、TS-DFM，以及掩码源（Mask）与均匀源（Uniform）。图 2：罗盘未激活（源主导）、导航激活（信号丰富）、$t=\tau$、生成进度、序列质量、源文本、理想情形、盲目跳转、误差累积、标准轨迹、能量罗盘选出最佳、塑形轨迹（本文）、塑形差距。

<span id="page-3"></span>

TS-DFM 优于 Duo（Sahoo et al., 2025）与 SDTT（Deschenaux and Gulcehre, 2025），在少步离散生成方法中取得了最先进的困惑度。这一改进在三个规模递增的评估器（GPT-2、LLaMA-2、LLaMA-3）上均成立。所有塑形都只在训练阶段进行，带来 2.0–2.4 倍的一次性开销；推理过程不变。

据我们所知，这是首个把离散流轨迹的中间状态——而不仅是端点——作为蒸馏过程中质量优化目标的工作。导航塑形与蒸馏机制本身正交，可以叠加在任何基于轨迹的蒸馏框架之上。我们的贡献如下：

- **轨迹质量是蒸馏的瓶颈**：我们表明，少步 DFM 的性能上限由轨迹质量决定，而不是由学生容量决定。RK-4 中点处的盲目随机跳转引入了复合误差，从而降低监督质量；优化这些中点状态即可突破该上限。
- **序列到 token 的导航塑形**：一个两阶段策略，先在序列层面从 $K$ 个候选续步中选出最佳者，再在 token 层面进行精修，并由时间阈值 $\tau$ 控制是否启用。
- **生成感知的能量罗盘**：一个轻量级能量模型，用速度近失负样本（velocity near-miss negatives）训练，在部分揭示的流状态上达到 98.5% 的损坏检测准确率。
- **无推理开销**：所有塑形都只在训练阶段进行；推理保持不变。

## 2 相关工作

离散扩散（discrete diffusion）（Austin et al., 2021; He et al., 2023; Xie et al., 2025; Song et al., 2025; Arriola et al., 2025; Yang et al., 2026; Ye et al., 2024）已在 LLaDA（Nie et al., 2026）与 Dream（Ye et al., 2025）等模型中被用于文本生成。这些模型从源分布出发、通过迭代细化来生成文本，但当采样步数减少时质量会急剧下降。

一种自然的补救办法是蒸馏：在连续设定下，渐进蒸馏（progressive distillation）（Salimans and Ho, 2022）、一致性模型（consistency models）（Song et al., 2023）以及单步方法（Meng et al., 2023; Frans et al., 2025）都已被用于把多步采样器压缩为少步学生模型。

在离散设定下，SDTT（Deschenaux and Gulcehre, 2025）通过多轮迭代自蒸馏来蒸馏掩码扩散模型（MDLM（Sahoo et al., 2024）、SEDD（Lou et al., 2024）），获得了很强的少步质量，但需要多轮训练以及一个较大的基座模型。ReMDM（Wang et al., 2026）在推理阶段通过重掩码策略（cap、conf、rescale、loop）改进少步掩码扩散，避免了重新训练，但增加了每步开销。Duo（Sahoo et al., 2025）在高斯态与均匀态离散扩散之间建立了对偶性，使一致性蒸馏可以在离散设定下进行，取得了有竞争力的少步生成效果，代价是要多得多的训练数据。FS-DFM（Monsefi et al., 2026）把蒸馏引入离散流匹配，并带有步长条件化与 RK-4 轨迹估计。T3D（Zhang et al., 2026）同期提出了带反向 KL 目标的轨迹自蒸馏，鼓励模式寻求行为，它是通过改变蒸馏损失而非改变轨迹构建来弥合少步差距的。

本文建立在 FS-DFM 的蒸馏机制之上，但处理的是一个正交的问题：不是"如何"蒸馏，而是学生"从什么"中学习。训练信号的质量对蒸馏很重要，这一点早已确立——在知识蒸馏中，教师容量与温度会塑造学生表现（Hinton et al., 2015）；在扩散蒸馏中，轨迹采样策略会影响结果（Yin et al., 2024）——然而此前针对离散序列的工作并未尝试优化轨迹本身。与在同一批轨迹上通过多轮蒸馏改进学生的 SDTT（Deschenaux and Gulcehre, 2025）、以及在推理阶段纠正错误的 ReMDM（Wang et al., 2026）不同，TS-DFM 从源头介入：在训练期间塑造轨迹，使学生从一开始就获得更高质量的监督。

为了塑造轨迹，我们引入一个能量模型，对部分揭示的流状态打分，并选出

<span id="page-4"></span>

每一步中质量最高的候选。能量模型在生成建模中有着悠久的历史（LeCun et al., 2006; Song and Kingma, 2021）：在连续扩散中，它们构成了无分类器引导与基于分类器的引导的基础（Dhariwal and Nichol, 2021; Du et al., 2023; Liu et al., 2022; Bansal et al., 2023）；而在文本领域，它们已被用于对完整序列进行重排序与受控生成（Deng et al., 2020; Khalifa et al., 2021）。我们的用法有三点不同：(i) 能量模型作用于部分状态——即由有意义的 token 与源 token 混合而成的状态——而不是完整序列或向量；(ii) 它作为离散的选择准则起作用，而不是提供梯度；(iii) 它只在训练阶段参与，不产生任何推理开销。

## 3 背景与动机

离散流匹配（DFM）（Gat et al., 2024; Campbell et al., 2024）通过沿轨迹从源状态行进到文本来生成文本。速度场 $v_\theta$ 在 $N$ 步内迭代地把源序列 $x_0$ 变换为连贯文本 $x_1$，其中 $x_0$ 从源分布（词汇表上的均匀分布，或掩码 token）中抽取。在中间时刻 $t \in [0,1]$，状态 $x_t$ 是源 token 与目标 token 的逐位置混合：每个位置 $j$ 独立地保持目标 token 或源 token，

$$x_t[j] = \begin{cases} x_1[j] & \text{以概率 } \alpha(t), \\ x_0[j] & \text{以概率 } 1-\alpha(t), \end{cases} \tag{3.1}$$

其中 $\alpha(t)$ 是单调递增的调度，满足 $\alpha(0)=0$、$\alpha(1)=1$。这一插值既定义了训练时的前向采样路径，也定义了能量罗盘必须评估的部分成形序列。

少步离散流匹配框架（Few-Step Discrete Flow-Matching）（Monsefi et al., 2026）使用三个模型把长的教师轨迹压缩为少步的学生轨迹。教师模型 $v_\theta(x_t, t)$ 是一个冻结的预训练 DFM 速度模型。学生模型 $s_\psi(x_t, t, h)$ 与教师共享架构，但增加了一个步长条件化机制，并由教师初始化。半教师模型 $\tilde{v}_\omega(x_t, t, h)$ 是学生权重的 EMA。对小步长，直接使用教师的单步速度；对大步长，半教师通过四阶 Runge–Kutta（fourth-order Runge-Kutta, RK-4）积分来估计速度，从而构造出教师单独一次评估无法提供的多步目标：

$$k_1 = \tilde{v}_\omega\left(x_t, t, \tfrac{h}{2}\right),\qquad k_{i+1} = \tilde{v}_\omega\left(x_{\mathrm{mid},i}, t_{\mathrm{mid},i}, \tfrac{h}{2}\right),\quad i=1,2,3, \tag{3.2}$$

其中 $t_{\mathrm{mid},1}=t_{\mathrm{mid},2}=t+\tfrac{h}{2}$、$t_{\mathrm{mid},3}=t+h$，并且每个中点 $x_{\mathrm{mid},i}$ 都是通过一次随机 CTMC 跳转、由上一阶段的速度构造出的具体 token 序列。最终的 RK-4 目标 $v_{\mathrm{RK\text{-}4}} = \tfrac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$ 是标准的加权组合，学生最小化 $\mathcal{L}_{\mathrm{KL}} = \mathrm{KL}\left(s_\psi(x_t, t, h) \,\|\, v_{\mathrm{RK\text{-}4}}\right)$。学生模型的全部训练信号都来自这些 RK-4 目标：半教师在每个训练步所构造的轨迹就是它的课程。学生无法独立访问数据，没有其他样本，也没有"匹配这个目标"之外的误差信号。

**轨迹为何是糟糕的教师。** 为了构造 RK-4 链中的每个中点 $x_{\mathrm{mid},i}$，必须把速度 logits 转换为具体的 token 序列。由于 token 是离散的，这要求一次随机跳转：一个 Poisson 率过程决定每个位置 $j$ 是否发生转移，再由一次类别采样选出新的 token。具体而言，给定时刻 $t$ 的当前状态 $x$ 与速度 logits $k$、子步长 $h'$：

$$x_{\mathrm{mid}}[j] = \begin{cases} \hat{x}_1[j] \sim \mathrm{Cat}\big(k[j]\big) & \text{以概率 } p_{\mathrm{jump}}(j), \\ x[j] & \text{否则，} \end{cases} \tag{3.3}$$

其中 $\hat{x}_1[j]$ 从速度在位置 $j$ 处的类别分布中采样，$p_{\mathrm{jump}}(j)$ 是由 CTMC 速率与子步长 $h'$ 导出的转移概率。该过程在 RK-4 的三个内部阶段各执行一次。每次执行都产生一个具体的实现，而不进行任何质量评估，于是问题沿链条不断累积。糟糕的第一次采样会影响后续步骤的速度评估，每一步都加剧退化：

$$k_1 \xrightarrow{\ \text{采样}\ } \underbrace{x_{\mathrm{mid},1}}_{\text{退化}} \rightarrow k_2 \xrightarrow{\ \text{采样}\ } \underbrace{x_{\mathrm{mid},2}}_{\text{更差}} \rightarrow k_3 \xrightarrow{\ \text{采样}\ } \underbrace{x_{\mathrm{mid},3}}_{\text{最差}} \rightarrow k_4. \tag{3.4}$$

<span id="page-5"></span>

最终目标 $v_{\mathrm{RK\text{-}4}} = \tfrac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$ 吸收了来自所有中点的复合误差，导致轨迹漂移（图 2）。由于学生模型学习模仿的就是这条漂移后的轨迹，它无法恢复轨迹构建过程中损失的质量，只能把复合误差一并学进去。

## 4 方法：导航塑形

我们提出轨迹塑形离散流匹配（TS-DFM），这是一个建立在 FS-DFM 之上、但用引导式导航取代盲目随机跳转的框架。图 3 展示了 TS-DFM 的训练流程及其三个新组件：能量罗盘、序列到 token 的导航过程，以及控制引导何时激活的时间阈值。

### 4.1 能量罗盘

导航的核心工具是一个标量能量模型 $E_\phi(x): \mathcal{V}^L \to \mathbb{R}$，它评估 token 序列的质量，但不带时间条件——只对原始 token 序列打分。序列质量是内容本身的内在属性。一个已经出现连贯 token 的部分揭示序列，无论出现在 $t=0.3$ 还是 $t=0.7$，都应当得到较好的分数。

罗盘必须能够区分部分揭示的流状态之间细微的质量差异，而不是给干净文本打分。扩散中标准的损坏策略——随机替换 token——产生的是平凡负样本，无法代表轨迹导航过程中实际出现的那些决策。为了得到一个表现良好的能量罗盘 $E_\phi$，我们在生成感知负样本上使用噪声对比目标进行训练，使真实流状态被赋予更低的能量。

我们利用速度近失来构造负样本。给定一个正样本 $x_t$，沿流反向走一步得到 $x_{t-h}$，再用冻结的教师速度模型前向重建得到 $\hat{x}_t$，并把 $\hat{x}_t$ 作为负样本。该结果与正样本直接竞争——二者在时刻 $t$ 都是合理的序列——但 $\hat{x}_t$ 在尚未揭示的位置上带有教师的重建误差。这正是罗盘在轨迹构建期间比较 CTMC 跳转候选时必须检测的那类细微错误。总训练损失为：

$$\mathcal{L}_{\mathrm{energy}} = \mathcal{L}_{\mathrm{NCE}} + \lambda_{\mathrm{reg}} \cdot \mathcal{L}_{\mathrm{reg}} + \lambda_{\mathrm{order}} \cdot \mathcal{L}_{\mathrm{order}}, \qquad \lambda_{\mathrm{reg}} = \lambda_{\mathrm{order}} = 1.0 \tag{4.1}$$

其中 $\mathcal{L}_{\mathrm{NCE}}$ 训练罗盘给真实流状态分配比损坏状态更低的能量，$\mathcal{L}_{\mathrm{reg}}$ 惩罚能量尺度漂移，$\mathcal{L}_{\mathrm{order}}$ 施加时间序约束。附录 A 给出了完整的训练细节、额外的负样本策略，以及一个对每个样本 $x_t$ 强制能量随 $t$ 增大而单调下降的时间序损失。在留出的 FineWeb-Edu 上，训练好的罗盘在区分真实流状态与生成相关的损坏时达到 98.5%–99.8% 的准确率，并且对两种源分布都呈现出随 $t$ 增大而完全单调的分箱级能量（附录 B）。

### 4.2 序列到 token 的导航

罗盘提供的是序列级分数，但轨迹质量取决于 token 级的决策。给整个候选打分开销可接受，但过于粗糙——一个序列可能整体得分不错，却含有糟糕的 token。

**图 3.** TS-DFM 训练概览。对小步长，冻结的教师直接提供目标。对大步长，半教师通过 RK-4 构造目标，其中每个中点都由能量罗盘 $E_\phi$ 引导。TS-DFM 特有的组件位于虚线框内；其余部分继承自 FS-DFM。

（图中文字：学生模型 $s_\psi(x_t,t,h)$；半教师 $\tilde{v}_\omega$（学生模型的 EMA），EMA 更新 $\omega \leftarrow \mu\omega + (1-\mu)\psi$；教师 $v_\theta(x_t,t)$；导航 RK-4 $\hat{v}_{\mathrm{RK\text{-}4}}$；罗盘 $E_\phi: \mathcal{V}^L \to \mathbb{R}$，当 $t \ge \tau$ 时激活；导航步 $\nabla_\psi \hat{k}_i$；虚线框标注"TS-DFM 新增"；❄ 标识参数冻结。）

<span id="page-6"></span>

如果把引导作用到每个单独的位置上，每个中点将需要 $|\mathcal{V}| \times L$ 次能量评估，这是无法承受的。为此我们提出 Navigate，一个引导式的两阶段方法：

1. **序列阶段（序列级）。** 从当前状态出发，通过温度多样化的 CTMC 转移生成 $K$ 个候选下一状态。用一次批量的前向传播把它们送入 $E_\phi$ 评估，选出能量最低的候选。这确保轨迹进入序列空间中全局低能量的区域。
2. **token 阶段（token 级）。** 利用速度网络自身的置信度作为每个 token 质量的免费代理，在单个位置上精修选中的候选——这些 logits 在 RK-4 速度评估时已经计算过。若某位置所选中的 token 与一个高置信度的速度预测不一致，该位置就是可替换的候选，替换由随 $t$ 衰减的自适应引导系数调制。对精修结果再做一次能量评估作为保障：只有当精修没有使能量增加超过容差 $\epsilon_{\mathrm{safe}}$ 时，才接受该精修。

序列阶段保证全局轨迹的连贯性，token 阶段保证局部 token 级的准确性——两者结合即可覆盖两种粒度，而无需逐 token 的能量评估。二者缺一不可：序列选择无法修复隐藏在好序列中的个别坏 token，而 token 精修也无法挽回一开始就选错候选的情况。候选多样性足以让选择产生实际影响：在 $t=\tau=0.2$ 时，从同一中点出发的 $K$ 次独立 CTMC 跳转平均在 1024 个位置中的约 147 个位置（14%）上互不相同（附录 E.2）。保障机制接受至少 94.7% 的精修，而被拒绝的精修平均而言会使能量升高（附录 D.2）。一项推理期消融验证了二者的互补性：在 64 步时，完整策略（38.0 PPL）比仅用序列阶段（52.0）和仅用 token 阶段（47.6）高出至少 20%（附录 D.1）。附录 C 与 D 给出了完整细节与消融。

用 Navigate 替换每一次盲目跳转，就把标准的 RK-4 估计变成了导航式估计。半教师 $\tilde{v}_\omega$ 仍像以前那样计算速度 logits；唯一的改变是如何从这些 logits 构造中点状态。我们用帽子标记导航后的速度（$\hat{k}_i$），用星号标记经过质量检查的中点（$x^*_{\mathrm{mid},i}$），以区别于盲目版本：

$$\hat{k}_1 =  \tilde{v}_\omega\left(x_t, t, \tfrac{h}{2}\right), \qquad x^*_{\mathrm{mid},1} = \mathrm{Navigate}\left(x_t, \hat{k}_1, t, \tfrac{h}{2}, E_\phi\right), \tag{4.2}$$

$$\hat{k}_2 =  \tilde{v}_\omega\left(x^*_{\mathrm{mid},1}, t+\tfrac{h}{2}, \tfrac{h}{2}\right), \qquad x^*_{\mathrm{mid},2} = \mathrm{Navigate}\left(x^*_{\mathrm{mid},1}, \hat{k}_2, t+\tfrac{h}{2}, \tfrac{h}{2}, E_\phi\right), \tag{4.3}$$

$$\hat{k}_3 =  \tilde{v}_\omega\left(x^*_{\mathrm{mid},2}, t+\tfrac{h}{2}, \tfrac{h}{2}\right), \qquad x^*_{\mathrm{mid},3} = \mathrm{Navigate}\left(x^*_{\mathrm{mid},2}, \hat{k}_3, t+\tfrac{h}{2}, \tfrac{h}{2}, E_\phi\right), \tag{4.4}$$

$$\hat{k}_4 = \tilde{v}_\omega\left(x^*_{\mathrm{mid},3}, t+h, \tfrac{h}{2}\right), \qquad \hat{v}_{\mathrm{RK\text{-}4}} = \tfrac{1}{6}\left(\hat{k}_1 + 2\hat{k}_2 + 2\hat{k}_3 + \hat{k}_4\right). \tag{4.5}$$

与标准链条中盲目跳转产生带复合误差的中点相比，导航式跳转产生的中点具有经过质量检查的转移。这种优势会以乘性方式累积：若每次引导跳转相对于盲目跳转把误差缩小 $\rho < 1$ 倍，那么经过三个中点后，整体目标大约改善 $\rho^3$ 倍。

### 4.3 时间阈值激活

罗盘需要信号才能导航。在流时间 $t$ 较小时，只有比例为 $\alpha(t)$ 的少部分位置携带了有意义的 token——序列远离自然语言的流形，所有候选看起来都同样缺乏信息量。此时激活罗盘只会增加计算开销而无收益，并且可能通过"在噪声上做选择"引入偏差。因此我们只在时间阈值 $\tau$ 以上激活导航：

$$x'_{\mathrm{mid}} = \begin{cases} \mathrm{Jump}(x_t, k, t, h) & \text{若 } t < \tau \text{（标准盲目跳转）}, \\[2pt] \mathrm{Navigate}(x_t, k, t, h, E_\phi) & \text{若 } t \ge \tau \text{（罗盘引导选择）}. \end{cases} \tag{4.6}$$

在源主导的区域（$t < \tau$），轨迹自由探索。在信号丰富的区域（$t \ge \tau$），语言结构——局部连贯性、语法依赖、主题一致性——已经充分浮现，罗盘足以做出有依据的选择，于是导航接管。

<span id="page-7"></span>

在一次 RK-4 估计之内，不同中点可能会自然地跨过阈值。例如取 $t=0.3$、$h=0.25$、$\tau=0.5$：位于 $t=0.3$ 的第一个中点不受引导，而位于 $t_{\mathrm{mid}}=0.55$ 的中点则接受导航。随着序列逐步逼近数据流形，轨迹会自动从探索过渡到引导式导航。如图 3 所示，学生模型的目标与 FS-DFM 蒸馏时保持不变——仍是同一个 KL 散度，只是针对导航后的目标：$L = \mathrm{KL}\left(s_\psi(x_t, t, h) \,\|\, \hat{v}_{\mathrm{RK\text{-}4}}\right)$，其中 $\hat{v}_{\mathrm{RK\text{-}4}}$ 来自式 (4.5)。学生模型、训练循环与推理流程都与 FS-DFM 相同；唯一的改动是 RK-4 目标估计期间中点状态的构造方式。推理时并不使用罗盘——所有质量改进都被编码进学生模型的权重中。

### 5.1 设置

DFM 教师与 FS-DFM/TS-DFM 学生模型都是 170M 参数的 DDiT transformer（Gat et al., 2024）。能量罗盘 $E_\phi$ 是一个 6 个 block 的 transformer，先在 FineWeb-Edu（Penedo et al., 2024）上以噪声对比估计与生成感知负样本进行预训练，随后在学生训练全程冻结。能量罗盘的训练与评估细节见附录 A 和 B。我们在两种源分布上评估：(i) Uniform：从 GPT-2 词表（$|\mathcal{V}|=50\,257$）中均匀抽取 token；(ii) Mask：所有位置都初始化为专用的 [MASK] token。

所有模型都在 FineWeb-Edu（Penedo et al., 2024）上训练。每种源分布各有自己的 DFM 教师（65.5B tokens）与 FS-DFM 学生（额外 13.2B 微调 tokens），二者都可作为 TS-DFM 的初始化（额外 6.4B 塑形 tokens）。默认配置：每个中点 $K=5$ 个候选、时间阈值 $\tau=0.2$。

### 5.2 主要结果

表 1 给出了核心结果：在两种源分布上，轨迹塑形都使学生模型大幅优于 FS-DFM 基线，并且仅用 8 个推理步就超过了 1024 步的 DFM 教师。

**均匀源。** 以 FS-DFM 初始化时，TS-DFM 在 8 步达到 56.1 的 GPT-2 PPL——相对 FS-DFM 基线（87.6）降低 36%，比 1024 步教师（82.8）低 32%。这一改进在三个评估器上一致成立，并在 16 步与 32 步继续保持，TS-DFM 分别达到 47.2 与 46.7。即便采用 DFM 初始化（没有经过先前的蒸馏），8 步的 TS-DFM（79.0）也已经超过 1024 步教师，这证实增益来自轨迹塑形，而不仅仅是初始化。

**掩码源。** 对掩码源而言，DFM 初始化比 FS-DFM 初始化更有效。带 DFM 初始化的 TS-DFM 在 8 步达到 91.4 的 GPT-2 PPL，在 16 步达到 61.9——两者都超过 1024 步的掩码教师（93.6）。掩码源对少步生成而言明显更难：FS-DFM 基线在 8 步仅达到 516.6 PPL，使 TS-DFM 的 5.6 倍改进尤为突出。这直接回应了 FS-DFM 的一个关键局限：它只在均匀源上报告了强结果，并指出掩码源蒸馏仍是一个开放问题；TS-DFM 表明，轨迹塑形同样能让掩码源的少步蒸馏变得有效。

**时间阈值 $\tau$ 的影响。** 时间阈值 $\tau$ 控制导航塑形何时激活。我们对两种源分布分别训练了 $\tau \in \{0.02, 0.2, 0.4\}$ 的 TS-DFM 学生，每种都有两种初始化：从 DFM 教师初始化（DFM init）与从 FS-DFM 学生初始化（FS-DFM init）。表 2 报告了 8 步与 16 步的 GPT-2 困惑度与生成熵。第一，$\tau=0.2$ 对两种源都给出最佳的质量–多样性权衡：它在保持熵高于 7.0 的同时取得很强的困惑度。最低阈值（$\tau=0.02$）给出更好的原始困惑度，但使熵降到 6.5 以下，说明多样性崩塌。第二，两种源偏好不同的初始化：均匀源从 FS-DFM 初始化中获益（$\tau=0.2$ 时 8 步为 56.1 对 79.0），而掩码源从 DFM 初始化中获益（91.4 对 188.7）——这提示掩码源的 FS-DFM 学生已经收敛到更难被轨迹塑形重新引导的速度模式。我们在全文中采用这些默认设置。第三，训练开销不大：从 $\tau=0.4$ 时的 2.0 倍到 $\tau=0.02$ 时的 2.4 倍，我们默认的 $\tau=0.2$ 为 2.2 倍。更多分析见附录 C.7 与 E.1。

## 6 结论

我们提出了 TS-DFM，其出发点是这样一个观察：少步离散流蒸馏的性能上限由训练轨迹决定，而不是由学生模型决定。RK-4 中点处的盲目随机跳转会累积误差，而学生模型会忠实地模仿这些误差。TS-DFM 只在训练阶段，用一个轻量级能量罗盘和一个两阶段的"序列到 token"策略，以引导式导航取代这些跳转。在 170M 参数上，TS-DFM 在均匀源与掩码源上都达到少步离散生成方法中的最先进水平。在 1.3B 上，由同一个轻量级罗盘引导，塑形后的学生模型仅用 8 步就击败其 1024 步教师，实现 128 倍加速且质量更好；在这一步数预算下，相对 FS-DFM 基线的差距随规模扩大（从 170M 到 1.3B，PPL 的降低幅度由 36% 提升到 41%），而不是缩小。

**局限性。** 罗盘只训练一次然后冻结；随着学生模型不断改进，其流状态分布会发生偏移，可能降低罗盘的有效性（迭代式精修或许有帮助，但存在共同适应（co-adaptation）的风险）。激活阈值 $\tau$ 在训练全程固定；自适应或退火调度尚未探索。

## A 能量罗盘训练细节

第 4.1 节描述了能量罗盘的作用、训练目标与关键设计选择。本节给出完整的训练规范，包括目标分解、负样本构造细节、源分布处理与优化配置。

我们为每个源族分别训练一个能量罗盘：一个用于均匀源分布（$x_0$ 在 $\mathcal{V}$ 上均匀采样），一个用于掩码源分布（$x_0 = [\mathrm{Mask}]^L$）。两个罗盘共享相同的架构与训练流程（表 6 与表 8）；它们仅在构造正、负样本时用于填充未揭示位置的源 token 上不同。附录 B 中的验证结果在适用时都报告了两个变体。

### A.1 架构

**表 6.** 能量罗盘架构。

| 组件 | 配置 |
|---|---|
| Transformer 层数 | 6 |
| 隐藏维度 | 768 |
| 注意力头数 | 12 |
| 池化方式 | 注意力池化（学习到的 query→标量） |
| 时间条件化 | 无（仅序列） |
| 参数量 | ∼90M |

能量罗盘是一个带注意力池化的 transformer 编码器，把 token 序列映射为一个标量能量。它与速度模型共享相同的 tokenizer（GPT-2，$|\mathcal{V}|=50\,257$）与块大小（$L=1\,024$），但规模小得多（表 6）。没有时间条件化是刻意做出的设计选择：罗盘给序列的内在质量打分，而不是给"相对于时间步的质量"打分。作为时间嵌入的替代，模型使用一个学习到的常量缓冲区（constant buffer），从而在架构上与时间条件化变体保持完全一致（以保证检查点兼容），但不接收任何时间信息。

### A.2 训练目标

总损失是三个分量的加权和，每个分量针对一个不同的训练挑战：

$$\mathcal{L}_{\mathrm{energy}} = \mathcal{L}_{\mathrm{NCE}} + \lambda_{\mathrm{reg}} \cdot \mathcal{L}_{\mathrm{reg}} + \lambda_{\mathrm{order}} \cdot \mathcal{L}_{\mathrm{order}}, \qquad \lambda_{\mathrm{reg}} = \lambda_{\mathrm{order}} = 1.0$$

**噪声对比损失（$\mathcal{L}_{\mathrm{NCE}}$）**：对每个正样本流状态 $x_t$，我们通过附录 A.3 中的策略生成 $N_{\mathrm{neg}}=12$ 个损坏负样本 $\{\tilde{x}_t^{(j)}\}$，并最小化：

$$\mathcal{L}_{\mathrm{NCE}} = -\log \frac{\exp\left(-E_\phi(x_t)\right)}{\exp\left(-E_\phi(x_t)\right) + \sum_{j=1}^{N_{\mathrm{neg}}} \exp\left(-E_\phi\left(\tilde{x}_t^{(j)}\right)\right)}, \tag{A.1}$$

从而训练罗盘给真实流状态分配比任何损坏状态都更低的能量。

**正则化损失（$\mathcal{L}_{\mathrm{reg}}$）**：防止训练期间能量尺度漂移——平均能量在不同的评估检查点之间可能浮动数个单位，从而破坏 NCE 梯度的稳定性并淹没时间序信号。我们惩罚其偏离零的程度，这在不约束样本之间相对排序的前提下锚定能量尺度：

$$\mathcal{L}_{\mathrm{reg}} = E_\phi(x_t)^2 \tag{A.2}$$

**时间序损失（$\mathcal{L}_{\mathrm{order}}$）**：NCE 目标教会的是同一时间步内的判别（固定 $t$ 时损坏 vs. 干净），但并不协调跨时间步的能量水平。为强制能量随更多 token 被揭示而单调下降，我们使用同一个 $(x_0, x_1)$ 对，构造一个揭示程度更低的版本 $x_{t'}$，其中 $t' = \max(t-\delta, 0.01)$、$\delta \sim \mathrm{Uniform}(0.05, 0.5)$，并施加基于 margin 的 hinge 损失：

$$\mathcal{L}_{\mathrm{order}} = \max\left(0,\ E_\phi(x_t) - E_\phi(x_{t'}) + \gamma \cdot \delta\right), \tag{A.3}$$

其中比例 margin 取 $\gamma = 0.3$。margin 随 $\delta$ 缩放，因此时间间隔越大就要求越大的能量差，从而为单调性提供平滑的梯度信号。

<span id="page-17"></span>

### A.3 负样本策略

负样本只通过损坏已揭示位置来构造——即 $x_t$ 中已经携带来自 $x_1$ 的目标 token 的位置。未揭示位置保留其源 token（均匀随机 token 或 [Mask]），因为损坏它们没有信息价值。

我们使用两大类负样本，各自针对罗盘必须检测的一种不同失效模式：

- **生成逼真负样本（generation-realistic negatives）** 模拟离散流匹配过程中实际出现的误差——教师重建错误（velocity_step）与揭示不足的流状态（time_downstep）。这些是最难的负样本，也最直接地代表了罗盘在轨迹导航期间所做的比较。
- **token 损坏负样本（token-corruption negatives）** 用错误或重复的替换来退化已揭示的 token（random_replace、frequency_replace、token_repeat）。它们构造起来更便宜，教会罗盘拒绝那些与流动力学无关的内容层面损坏。

每个负样本从表 7 的五种策略之一抽取，按表中列出的概率采样。生成逼真负样本合计约占训练负样本的 45%。在该组内，velocity_step 产生的负样本最逼真，但采样频率较低（9.1%），以限制它所需的冻结教师前向传播开销；其余所有策略都不需要额外的模型推理。

**表 7.** 能量模型训练的负样本策略，按类别分组。损坏率范围仅适用于 token 级策略。

| 策略 | 概率 | 损坏率范围 | 说明 |
|---|---|---|---|
| **生成逼真负样本（generation-realistic negatives）** | | | |
| time_downstep | 36.4% | $\delta \in [0.025, 0.5]$ | **时间维度。** 由同一个 $(x_0, x_1)$ 在更低的 $t' < t$ 处构造 $x_{t'}$。这是一个真实但揭示程度更低的流状态。 |
| velocity_step | 9.1% | — | **近失。** 先反向再正向经过教师，产生逼真的重建误差负样本（见下文）。 |
| **token 损坏负样本（token-corruption negatives）** | | | |
| random_replace | 18.2% | [0.05, 0.25] | **错误 token。** 用词表中均匀随机的项替换已揭示 token。 |
| frequency_replace | 18.2% | [0.03, 0.20] | **错误 token。** 用同一 unigram 频率箱中的 token 替换——仅凭频率统计无法检测。 |
| token_repeat | 18.2% | [0.05, 0.50] | **重复。** 在已揭示位置上重复同一个 token。模拟退化式重复。 |

#### A.3.1 速度近失构造

velocity_step 策略产生的负样本最逼真，值得进一步说明。给定时刻 $t$ 的正样本 $x_t$：

1. 从覆盖 $[\sim 0.001, 0.0625]$ 的一组离散选项中采样步长 $h$。
2. 通过概率性地"反揭示"位置来构造 $x_{t-h}$：$x_t$ 中每个已揭示位置以概率 $\alpha(t-h)/\alpha(t)$ 被保留，否则被替换为一个源 token（均匀罗盘用均匀随机 token，掩码罗盘用 [Mask]）。这样得到揭示比例约为 $\alpha(t-h)$ 的序列——与时刻 $t-h$ 的流动力学一致。

<span id="page-18"></span>

（接续第 17 页的步骤列表）3. 在 $(x_{t-h}, t-h)$ 上运行冻结的教师速度模型得到 logits，然后做一个前向 Euler 步回到时刻 $t$，得到 $\hat{x}_t$。
4. 返回 $\hat{x}_t$ 作为负样本，与同一时刻 $t$ 的正样本 $x_t$ 配对。

所得负样本与正样本直接竞争：二者在时刻 $t$ 都是合理的序列，但 $\hat{x}_t$ 在第 2 步中未被揭示的位置上带有教师的重建误差。这正是罗盘在轨迹构建期间比较 CTMC 跳转候选时必须检测的那类误差。

**教师速度模型。** velocity_step 策略需要一个冻结的教师速度模型来生成逼真的近失负样本。每个罗盘变体使用与之匹配的 DFM 教师（170M 参数）——均匀罗盘用均匀源训练的教师，掩码罗盘用掩码源训练的教师——与 TS-DFM 和 FS-DFM 蒸馏中使用的教师完全相同。教师以 eval 模式加载、梯度关闭；只有在对某个批元素采样到 velocity_step 时才会产生其前向传播开销。

#### A.3.2 损坏率采样

对 token 级策略（random_replace、frequency_replace、token_repeat），损坏率从 $[\mathrm{rate}_{\min}, \mathrm{rate}_{\max}]$ 上的 $\mathrm{Beta}(1,3)$ 分布中采样。$\mathrm{Beta}(1,3)$ 的均值位于其区间的 0.25 处，偏向低损坏率，因而偏向更难的负样本——即只有少数 token 与正样本不同的情形。已揭示位置的 10% 下限确保即便在 $t$ 很大、可损坏的已揭示位置很少时，负样本仍与正样本有足够差异，从而提供有意义的梯度信号。

### A.4 正样本构造

正样本是由 $(x_0, x_1)$ 对经标准插值路径（式 (3.1)）构造的流状态 $x_t$，其中 $x_1$ 是来自 FineWeb-Edu（Penedo et al., 2024）的真实文本序列。源 $x_0$ 从相应的源分布中抽取：均匀罗盘用 $\mathcal{V}$ 上的均匀随机 token，掩码罗盘用 $[\mathrm{Mask}]^L$。时刻 $t$ 从 $(0,1)$ 中均匀采样。

为锚定能量尺度，10% 的训练正样本直接使用干净目标 $x_1$（即 $t=1$），而不是路径插值得到的 $x_t$。这确保罗盘学到完全揭示的真实文本应当得到最低能量——从而为能量景观提供一个稳定的参考点。

**检查点选择。** 能量罗盘必须满足两个性质：同一时间步内的判别能力（每种策略上的高 NCE 准确率，附录 B.2）与跨时间步的单调性（能量随 $t$ 平滑下降，附录 B.1）。二者可能冲突：更强的 NCE 梯度会拉大逐时间步的能量差，却不协调跨时间步的绝对能量水平。我们用一个复合分数来选取最佳检查点，该分数把各策略上的总体 NCE 准确率与能量正确下降的相邻时间箱对所占比例（smooth_pct）相加：

<span id="page-19"></span>

$$\mathrm{score} = \mathrm{strategy\_acc} + \mathrm{smooth\_pct} \tag{A.4}$$

等权相加反映了这两个性质对可靠导航都是必要的：高判别力而缺乏单调性，会产生一个在单个时间步内排序很好、却在跨时间步时给出不一致绝对能量的罗盘；而单调性缺乏判别力，则无法区分候选中细微的质量差异。

## B 能量罗盘验证

在用能量罗盘引导轨迹构建之前，我们必须验证两个性质：(1) 它对揭示 token 更多的序列分配单调更低的能量（反映沿流路径质量递增）；(2) 它对真实流状态分配的能量低于对损坏版本分配的能量，且这些损坏版本体现出离散流匹配生成过程中出现的特定失效模式——而不只是任意噪声。我们在 FineWeb-Edu 的留出序列上、用冻结的预训练能量模型验证这两个性质。由于我们为每个源族分别训练一个罗盘（附录 A），下面同时报告均匀与掩码两个变体的结果。

### B.1 时间–能量单调性

在离散流匹配中，时刻 $t$ 的序列 $x_t$ 大约有 $\alpha(t)$ 比例的位置被揭示（与目标 $x_1$ 一致），其余位置保持为源噪声。随着 $t$ 增大，$\alpha(t)$ 增大，序列在内在质量上变得越来越好。要使能量罗盘成为可靠的导航器，其分数必须反映这种序关系：$E_\phi(x_t)$ 应随 $t$ 单调下降。形式上，对由同一个 $(x_0, x_1)$ 对在 $t > t'$ 处构造的任意两个流状态：

$$E_\phi(x_t) < E_\phi(x_{t'}) \qquad (\text{更高的 } t = \text{更多揭示} = \text{更低能量}). \tag{B.1}$$

### B.2 生成相关损坏检测

一个只给干净文本分配低能量的罗盘是不够的；它必须给那些体现出离散流匹配生成过程中出现的特定损坏的序列分配**更高**的能量。我们在四类损坏上评估两个能量模型变体，看它们能否正确地把真实流状态排在损坏版本之下；这些损坏按所模拟的失效模式组织。形式上，对真实流状态 $x_t$ 与施加任一生成相关损坏策略得到的损坏版本 $\tilde{x}_t$：

$$E_\phi(x_t) < E_\phi(\tilde{x}_t) \qquad (\text{真实流状态} = \text{能量低于损坏版本}). \tag{B.2}$$

我们在留出数据上、跨四种损坏策略衡量训练好的罗盘多一致地满足该准则：

- **随机替换（random_replace）**：用词表中均匀随机的项替换已揭示 token（平均约改动 99 个 token）。检验基本的质量检测能力。
- **频率匹配替换（frequency_replace）**：用同一 unigram 频率箱中的 token 替换已揭示 token（平均改动约 104 个 token）。一个更难的变体，仅凭频率统计无法检测。
- **token 重复（token_repeat）**：在已揭示位置上重复同一个 token（约改动 93–103 个 token）。模拟离散扩散中常见的退化式重复失效模式。

<span id="page-21"></span>

- **时间降步（time_downstep）**：由同一组 $(x_0, x_1)$ 构造 $t'<t$ 时刻的 $x_{t'}$（约 116 个 token 被改变）。这是同一段文本"揭示得更少"的版本——用来检验罗盘能否分辨同一真实流轨迹在两个不同时刻的状态之间的质量差异。

对每一种源分布，我们在每种策略下评估 1130 个留出的（正例，负例）对（每个变体合计 4520 对），并统计满足 $E_\phi(\text{real}) < E_\phi(\text{corrupted})$（即式 (B.2)）的比例。

两种罗盘变体在全部四种策略上都近乎完美地满足式 (B.2)。均匀罗盘的平均准确率为 98.5%，没有任何策略低于 98%；掩码罗盘的平均准确率为 99.8%，在四种策略中的三种上完全正确，在 token 重复上为 99.4%。

掩码罗盘总体更高的准确率似乎与表 9 中更弱的单调性指标相矛盾；然而二者度量的是不同的性质。损坏检测比较的是同一时间步上的真实流状态与显式退化版本——这是一个时间步内的判别任务，质量差距很大。单调性则要求区分相邻时间步上的真实流状态——这是精细得多的比较，哪怕只有几个 token 的差异也可能落在估计噪声之内。掩码罗盘擅长前者，而在后者上更吃力，这与其被压缩的能量取值范围是一致的。

|---|---|---|
| random_replace | 98.6 | 100.0 |

对于两种变体，频率匹配替换的准确率与随机替换几乎相同（均匀罗盘为 98.4% 对 98.6%；掩码罗盘两者均为 100%）。由于频率匹配的负例保留了原序列的一元 token 分布，能量模型无法依赖简单的频率线索——它必须评估上下文连贯性，才能把真实流状态与损坏状态区分开。

我们有意在训练和评估中都排除对顺序敏感的损坏（token 打乱、片段反转、相邻交换）。在离散流匹配生成过程中，速度模型是在正确位置上揭示 token 的——它从不会把正确的 token 置换到错误位置。基于顺序的损坏检验的是与下游用途无关的能力，会把训练信号浪费在一个小型 Transformer 难以胜任的任务上。把训练预算集中在与生成相关的损坏上，可以让罗盘在其实际职责上校准得更好。

## C 序列到 token 罗盘导航

我们在本节对第 4.2 节加以扩展，给出导航塑形过程中每个 RK-4 中点所使用的 Navigate 过程的完整规范。

### C.1 动机：离散引导中的粒度困境

回顾：能量罗盘 $E_\phi(x_t)$ 给出对全局序列质量的标量评估。要用它来引导 CTMC 的中点跳转，就必须把全局信号转换为逐位置的转移决策。数学上理想的引导速率按每个单 token 转移的能量差分对其进行修正：

$$\tilde{u}_t(y,x) = u_\theta^t(y,x)\cdot \exp\!\Big(-\beta_t\big[E_\phi(y)-E_\phi(x)\big]\Big), \tag{C.1}$$

其中 $y=x^{[i\to v]}$ 与 $x$ 仅在位置 $i$ 处相差一个 token。对全部位置和全部词表项逐一计算需要每个中点 $|V|\times L$ 次能量前向传播，这是不可行的。

<span id="page-22"></span>

**图 4 内部标注。** 左：仅序列级——"$K$ 次能量调用——选出全局最优"；"$c_2$：$E=-1.8$"；"$c^*$：o1 o2 o3 o4 o5 o6 o7 o8，$E=-2.1$ ✓"；"坏 token 藏在全局最优序列中"；"→ 误差在下一个中点处累积"。中：位置因子化——"$|V|\times L$ 次能量调用——不可行"；"50257×1024≈5100 万次能量调用 / 每个中点"。右：序列到 token（本文）——阶段一：序列，"$K$ 个候选在一次批量调用中打分，选出全局最优续写，开销：$K$ 次能量调用"；阶段二：token，"速度对齐修正单个 token，免费的代理信号——logits 已计算完毕，开销：0 次额外前向 + 1 次保护性检查"；能量保护，"仅当 $E_\phi(x_{\text{refined}})\le E_{\text{best}}+\epsilon$ 时才接受精修，防止局部修正损害全局质量"。

**图 4.** 粒度困境。左：序列级打分选出全局最优候选，却无法修正个别坏 token（红色）。位置因子化引导能修正每个 token，代价是每个中点数百万次能量评估。右：序列到 token 导航化解了这一矛盾——阶段一通过 $K$ 次能量调用找到最优续写；阶段二以零模型推理开销、借助速度对齐精修单个 token；能量保护则确保精修永不损害全局质量。

近似式 (C.1) 的两种朴素策略处于粒度谱系的两个极端，二者对于轨迹构造都不令人满意：

| 朴素策略 | 每个中点的开销 | 失效模式 |
|---|---|---|
| 仅序列级 | $K$ 次能量调用 | 无法修正个别坏 token |
| 位置因子化 | $\lvert V\rvert\cdot L$ 次调用 | 假设 $E(x)\approx\sum_i e_i(x_i)$；该假设很少成立 |

人们可以对整条候选序列打分并选出最好者（序列级），这种做法开销可接受但粗糙：能量函数是整体地评估序列的，因此一个候选可能尽管包含个别很差的 token 仍然胜出，仅仅因为序列的其余部分把它补偿了。另一种做法是假设能量在各位置上可分解（位置因子化），从而支持逐 token 引导，但 token 独立的假设与能量模型的目的——刻画全局连贯性——相抵触。

图 4 展示了这一困境，以及序列到 token 导航如何通过把引导分解为两个在不同粒度上运作的互补阶段来绕开它：

1. **序列阶段（序列级）**：生成 $K$ 个多样的候选跳转，用一次能量调用为每个候选打分，并选出全局最优的候选。这确保轨迹进入序列空间的低能量区域。
2. **token 阶段（细粒度）**：利用速度网络自身的置信度作为逐 token 质量的**免费代理信号**来精修选中的候选（不增加能量调用）。对精修结果做一次能量评估，作为防止性能退化的保护性检查。

token 阶段的关键洞见是：速度模型 $v_\theta$ 已经在每个位置上编码了合理 token 上的分布。选中候选与高置信度速度预测不一致的位置很可能次优；已经与速度的 top 预测对齐的位置则很可能正确。速度对齐信号是零成本可得的，因为 logits 已经计算完毕；它提供了一个有原则的位置级精修判据，与序列级能量信号互补。

### C.2 阶段一：通过多样化候选打分进行序列探索

**温度多样化候选生成。** 为确保 $K$ 个候选覆盖轨迹空间中一个有意义的范围，我们让每个候选在不同的温度下采样 (Zhang et al., 2024; Du et al., 2025)。基准温度通过逐位置熵，随速度当前的不确定性自适应调整。

<span id="page-23"></span>

$$T_{\text{base}} = T_{\min} + \Delta T\cdot(1-\tilde{H}), \tag{C.2}$$

其中 $\tilde{H}\in[0,1]$ 是速度分布在批次内归一化后的平均熵，$T_{\min}$（$=0.8$）设定基准温度的下限，$\Delta T$（$=0.4$）控制随熵变化的范围，因此 $T_{\text{base}}\in[T_{\min},T_{\min}+\Delta T]$。取 $T_{\min}=0.8$ 与 $\Delta T=0.4$，是为了让基准温度保持在接近 1 的区间：远低于 1.0 的温度会使候选之间的多样性坍缩，而远高于 1.0 的温度会给 CTMC 跳转引入过多噪声，产生多样却一致地差的候选。区间 $[0.8,1.2]$ 使采样既贴近速度学到的分布，又保留有意义的波动。

这一调度看似反直觉：当速度**自信**（$\tilde{H}$ 低）时，我们略微提高温度，以确认不存在更好的备选；当速度**不确定**（$\tilde{H}$ 高）时，我们降低温度，把注意力集中在高概率 token 上，而不是放大噪声。$K$ 个候选中的每一个都在温度

$$T_c = T_{\text{base}}\cdot\Big(\lambda_{\min}+(\lambda_{\max}-\lambda_{\min})\cdot\frac{c-1}{K-1}\Big),\quad c=1,\dots,K, \tag{C.3}$$

下采样，其中逐候选乘子覆盖 $[\lambda_{\min},\lambda_{\max}]$（$=[0.7,1.3]$），产生的有效温度位于 $[\lambda_{\min}T_{\text{base}},\lambda_{\max}T_{\text{base}}]$。低温候选（$\lambda_{\min}$）利用速度的众数预测；高温候选（$\lambda_{\max}$）探索分布的尾部。围绕 $T_{\text{base}}$ 的 $\pm30\%$ 对称展宽体现了一种平衡：更窄的展宽会产生几乎相同的候选，浪费多候选预算；更宽的展宽则把高温候选推入采样 token 实际上近乎随机的区间，对基于能量的选择贡献甚微。每个采样得到的预测 $\hat{x}_1^{(c)}$ 都在标准 CTMC 跳转动力学下演化，得到候选中点状态 $x^{(c)}=\text{CTMCJump}(x_t,\hat{x}_1^{(c)},h)$。

**基于能量的选择。** 能量罗盘在单个批次中为所有候选打分，以找出能量为 $E_{\text{best}}$ 的最优候选 $x_{\text{best}}=x^{(c^*)}$：

$$c^* = \arg\min_{c\in\{1,\dots,K\}} E_\phi(x^{(c)}). \tag{C.4}$$

序列阶段保证被选中的候选具有更低的全局能量。由于能量函数整体地评估序列，一条序列可能尽管包含一些弱 token 仍然胜出。这些弱 token 可能在后续 RK-4 中点中导致误差累积，却得不到修正（图 4 左侧的红色 token）。

### C.3 阶段二：通过速度对齐的 token 修正进行 token 精修

token 阶段利用速度网络自身的预测作为精修信号，修正 $x_{\text{best}}$ 中个别的 token 级弱点——无需任何逐 token 的能量调用。

**速度对齐作为 token 质量的免费代理。** 速度网络在 $x_t$ 处的 logits 已作为 RK-4 速度评估的一部分计算完毕——不需要额外的前向传播。我们复用这些 logits 采样一个新的预测 $\hat{x}_1^{\text{ref}}\sim p_\theta^{1|t}(\cdot\,|\,x_t)$，并提取速度的 argmax 预测 $x_{\text{top}}^{(i)}=\arg\max_v p_{1|t}^{(i)}(v\,|\,x_t)$ 及其置信度 $\text{conf}_i=\max_v p_{1|t}^{(i)}(v\,|\,x_t)$。这三个量——精修样本、top 预测与置信度——都通过廉价的类别操作（采样、argmax 与取最大值）从同一份缓存 logits 中得到，模型推理代价为零。对齐信号在每个位置上比较精修提议与选中的候选：

$$\Delta_{\text{align}}^{(i)}=\mathbb{1}\big[\hat{x}_{1,i}^{\text{ref}}=x_{\text{top}}^{(i)}\big]-\mathbb{1}\big[x_{\text{best}}^{(i)}=x_{\text{top}}^{(i)}\big]\in\{-1,0,+1\}. \tag{C.5}$$

其解释很直接：$\Delta_{\text{align}}^{(i)}=+1$ 表示精修提议与速度最有信心的预测一致，而当前 token 不一致——这是替换的强信号。$\Delta_{\text{align}}^{(i)}=-1$ 表示当前 token 已经一致，而提议不一致——保留不动。$\Delta_{\text{align}}^{(i)}=0$ 表示没有对齐差异——回退到基础跳转率。

**为什么速度对齐可以作为代理。** 速度网络是在数据分布上训练的，刻画了给定当前流状态下每个 token 的条件概率。在速度高度自信的位置（$\text{conf}_i$ 大），其 top 预测是数据分布下"正确"token 的强指示。与高置信度速度预测不一致的候选 token，在统计上更可能是随机 CTMC 跳转的产物，而不是目标序列的真实特征。利用这一零额外前向传播的信号，我们得到位置级引导，与能量模型的序列级评估互补。图 5 在一个具体例子上说明了该机制，展示置信度门控如何避免覆盖不确定的位置。

**自适应引导强度。** token 精修使用引导系数 $\beta_{\text{adp}}$ 调制跳转概率，该系数控制速度对齐信号对 token 替换决策的影响强度。在整个流轨迹上使用固定系数是次优的：在低 $t$（以噪声为主）时，速度网络的预测不确定，对齐信号应当拥有更大权重；在高 $t$（文本大部分已揭示）时，速度本身越来越可靠，用力过猛的调制有覆盖校准良好的局部预测的风险。因此我们让引导强度衰减：

$$\beta_{\text{adp}}=\beta_0\cdot(1-\alpha_\beta t), \tag{C.6}$$

其中 $\alpha_\beta$（$=0.5$）控制衰减速率，在 $t=0$ 时得到满强度 $\beta_0$，在 $t=1$ 时为 $\beta_0/2$。线性形式是最简单的单调调度，取 $\alpha_\beta=0.5$ 可确保引导从不完全关闭——即便在序列大部分已揭示的晚时间步，适度的能量信号也有助于避免剩余未揭示位置上的"最后一公里"错误。

**置信度调制的跳转概率。** 基础 CTMC 跳转概率 $p_{\text{base}}^{(i)}=1-\exp(-h\cdot\lambda_{\text{base}})$（其中 $\lambda_{\text{base}}=\dot{\kappa}_t/(1-\kappa_t)$，且只在精修提议了不同 token 的位置上施加）被对齐信号调制：

$$p_{\text{jump}}^{(i)}=\text{clamp}\Big(p_{\text{base}}^{(i)}\cdot\exp\big(\Delta_{\text{align}}^{(i)}\cdot\text{conf}_i\cdot\beta_{\text{adp}}\cdot\alpha_{\text{soft}}\big),0,p_{\max}\Big), \tag{C.7}$$

其中 $\alpha_{\text{soft}}$（$=0.5$）是软化因子，$p_{\max}$（$=0.95$）为跳转概率的上限。式 (C.7) 中的三项设计值得解释：

- **置信度门控（$\text{conf}_i$）**：调制幅度随速度在该位置上的确定性缩放。在不确定的位置，对齐信号不可靠，调整量会被自动

<span id="page-25"></span>

被抑制，从而避免对含糊 token 进行过度自信的精修（图 5 中位置 5 给出一个具体例子）。

- **软化因子 $\alpha_{\text{soft}}$（$=0.5$）**：如果不做软化（$\alpha_{\text{soft}}=1$），指数调制会产生极端的调整——一个 $\text{conf}_i=0.9$、$\beta_{\text{adp}}=1$ 的位置会把跳转率缩放 $\exp(\pm0.9)\approx2.5\times$ 或 $0.4\times$。因子 $\alpha_{\text{soft}}=0.5$ 把指数减半，使速率调整保持在温和范围内（$\exp(\pm0.45)\approx1.6\times$ 或 $0.6\times$），既能引导，又不至于压过基础动力学。
- **上限 $p_{\max}$（$=0.95$）**：把上限设在 1.0 以下可以保留随机性。确定性跳转（$p=1$）有在相邻中点之间于竞争 token 选择之间振荡的风险，并会去掉 CTMC 动力学所需的随机性。$0.95$ 是离散采样中常用的近确定性上限；$[0.9,0.99]$ 中的任何取值都能起到同样的作用。

随后，token 按调整后的概率被随机替换：

$$x_{\text{refined}}^{(i)} = \begin{cases}\hat{x}_{1,i}^{\text{ref}} & \text{以概率 } p_{\text{jump}}^{(i)},\\ x_{\text{best}}^{(i)} & \text{否则}.\end{cases} \tag{C.8}$$

### C.4 能量保护

阶段二的 token 级精修由速度对齐引导，而速度对齐只是序列级能量的代理——并不等同于它。一组各自对齐良好的 token 替换，合起来可能产生能量更高的序列（尽管在实践中不常见）。对精修后的序列做一次能量评估，可以提供安全网：

$$x'_{\text{mid}} = \begin{cases} x_{\text{refined}} & \text{若 } E_\phi(x_{\text{refined}})\le E_{\text{best}}+\epsilon_{\text{safe}},\\ x_{\text{best}} & \text{否则},\end{cases} \tag{C.9}$$

其中容差 $\epsilon_{\text{safe}}$（$=0.1$）。该容差容纳能量估计噪声：使估计能量略微升高的精修仍可能确实有益（例如在估计器误差范围内以可忽略的能量增加换取速度对齐的改善）。$\epsilon_{\text{safe}}=0.1$ 相对于候选间典型的能量范围（在我们实验中跨越数个能量单位）很小，因此它只允许边缘性的退化，同时避免在带噪标量上做精确 $\le$ 检查的脆弱性。在我们的实验中，保护机制在少于 8% 的中点上被触发，这证实速度对齐的精修与能量改善高度相关。

### C.5 完整算法

算法 1 汇总了前几小节描述的完整 Navigate 过程。阶段一（第 4–12 行）生成 $K$ 个温度多样的候选，并通过一次批量能量调用选出能量最低者。阶段二（第 13–19 行）通过速度对齐的 token 替换精修胜出者，其强度由自适应引导系数 $\beta_{\text{adp}}$（式 (C.6)）与速度的逐位置置信度调制。能量保护（第 20–24 行）仅当精修不会显著增加能量时才接受它，否则回退到阶段一的胜出者。所有符号与超参数汇总于表 13。

**超参数选择。** 我们没有对导航常数做超参数搜索。对质量有实质影响的两个值 $K$ 与 $\tau$ 在正文中做了消融。其余取值由方法的结构性要求决定——使采样保持在速度分布附近、确保引导永不彻底关闭、把跳转概率上限设在确定性之下以保留随机性——并在所有实验设置下固定不变：170M 与 1.3B、均匀源与掩码源、两种初始化。同样的常数在两种模型规模与两种源分布下都不加修改地适用，这是我们能提供的最强证据，说明它们不是调参的产物。

**仅阶段一（序列）不够。** 用能量做 best-of-$K$ 选择强大但粗放。能量函数整体地给序列打分：一个候选可以在包含个别弱 token 的情况下仍然胜出，只要序列其余部分足以补偿。这些未被修正的弱 token 会通过后续 RK-4 中点变成累积误差——这正是导航塑形要解决的"盲导航"问题。序列选择降低了这类错误的频率，但无法消除它们。

**仅阶段二（token）不够。** 通过速度对齐进行的 token 级精修廉价而细粒度，但它接触不到能量景观。速度置信度是逐 token 质量的有用代理，却不能替代能量：速度是被训练来预测数据分布的，而不是来最小化罗盘能量的。没有阶段一给出的良好起点，局部精修只会打磨错误候选——一条在每个位置局部连贯、但全局不连贯的轨迹。

**合起来：全局选择 + 局部修正。** 阶段一确保轨迹进入序列空间中全局低能量的区域。阶段二则在该区域内做有针对性、按置信度加权的修正——修复整体能量得分无法单独定位的 token 级弱点。能量保护（式 (C.9)）确保局部精修永远不会使阶段一识别出的全局低能量状态退化。这种序列到 token 的分解应用了一个自然的两阶段原则：先选出最好的全局续写，再在局部精修它。

## D 导航策略的经验验证

能量罗盘与序列到 token（S2T）导航策略在我们主实验中都只在训练时使用。为了独立于训练动力学来验证这些组件，我们在推理时应用它们——直接引导基线 FS-DFM 学生的生成过程。推理时引导对实际部署来说太慢（附录 C.7），但它提供了一个受控试验台：学生的权重保持固定，因此任何改善都可完全归因于罗盘与导航策略。本节所有实验都使用同一个 170M 参数的基线 FS-DFM 学生，该学生在均匀源分布与无轨迹塑形的条件下训练。

能量罗盘本身在附录 B 中单独验证：它在两种源分布上都达到 98.5–99.8% 的损坏检测准确率，并具有完美的分箱级单调性。下面的实验关注的是：在罗盘之上构建的导航策略——序列选择、token 精修及其组合——能否把这些性质转化为实际的生成改善。

**关键观察。**（1）**在 8 步时，差异不大。** 在学生的目标推理预算（8 步）下，所有导航策略产生的困惑度相近：无引导与最佳策略之间的差距在 GPT-2 Large 上约为 9%（89.6→81.2），在 LLaMA-2 7B 上约为 10%（58.2→52.2）。步数如此之少时，每一步都覆盖流轨迹的很大一部分，留给逐步引导累积改善的空间很小。在这一区间，仅序列选择提供了最大的收益，因为它避免了在少数可用决策点上出现最坏的随机实现。

<span id="page-29"></span>

（2）**在更高步数下，S2T 占优。** 从 16 步开始，S2T 在三个评估器上都持续取得最佳或接近最佳的困惑度。优势随步数增长：在 32 步时，S2T 相对无引导把 GPT-2 Large 的困惑度降低 39%（70.6→43.1），并优于仅序列（53.3）与仅 token（fine-only，46.8）。在 64 步——与 RK-4 中点构造最相关的区间——S2T 达到 38.0 的 GPT-2 Large 困惑度，相对无引导基线降低 49%，比仅 token（47.6）好 20%。这印证了附录 C.6 中的互补性论证：任何单独一个阶段都无法与它们的组合相比。

（3）**无引导生成在更高步数下退化。** 与直觉相反，无引导基线的困惑度从 32 步到 64 步反而变差（GPT-2 Large：70.6→75.0）。更多步数意味着更多随机跳转，每一次都引入误差；没有引导时，误差累积，最终超过更细粒度积分带来的收益。所有引导策略都完全避免了这种退化，S2T 从 32 步到 64 步仍在继续改善（GPT-2 Large 上 43.1→38.0）。这一分化恰好凸显了为什么在 RK-4 目标构造过程中需要导航塑形：训练所处的盲跳转区间，正是累积误差危害最大的地方。

（4）**两个阶段在不同步数区间各有优势。** 在 8 步时，序列选择占主导：决策点很少时，从 $K$ 个选项中挑出全局最优候选，比被大步长稀释的 token 级修正更有影响。到 16 步时，随着 token 精修累积起足够多的小修正，S2T 开始超过仅序列。到 32–64 步时，组合已具有决定性：序列选择确保每个中点都从低能量区域出发，token 精修则修正序列打分无法单独定位的个别 token 级错误——带来任何单一阶段都无法取得的改善。这正是训练中 RK-4 中点构造的工作区间，也是 S2T 设计带来最大优势之处。

**与训练时动力学的联系。** 16–64 个推理步下的行为不只是一次压力测试——它还是 S2T 在训练中运行于 RK-4 目标构造内部时行为的代理。训练一个用于 8 步生成（$h=0.125$）的学生，需要在 $h/2=0.0625$ 的子步长上构造 RK-4 中点，这对应 16–32 步的区间，而 S2T 在每个中点都会被调用。因此，16–64 步的推理时结果反映的正是 S2T 塑造学生训练信号时实际所处的区间。在此视角下，上述两个模式直接提供了信息：S2T 随步数增长而扩大的优势（观察 2）预示其收益会在 RK-4 链内部累积；而无引导基线在高步数下的退化（观察 3）正好展示了导航塑形所防止的失效模式。

### D.2 不同步数下的 token 精修行为

为了理解 token 精修阶段究竟做了什么，我们在每个步数下对 504 条序列收集精修统计。回顾：在每个被引导的中点，token 阶段基于速度对齐提出 token 级替换（附录 C.3），随后能量保护决定接受还是拒绝精修后的序列（附录 C.4）。我们度量四个量：

- **接受率（Accept %）**：能量保护接受精修序列的中点比例，即精修没有使能量超出容差 $\epsilon_{\text{safe}}$ 的比例。接受率高说明速度对齐的修正与能量改善高度相关。
- **token/步（Tokens / step）**：token 阶段在每个中点替换的 token 平均数量（总计 1024 个位置中）。它衡量精修的激进程度——数值越低表示修正越有针对性。
- **$\Delta E_{\text{acc}}$**：被接受精修的平均能量变化。负值证实被接受的精修确实改善了序列质量。
- **$\Delta E_{\text{rej}}$**：被拒绝精修的平均能量变化。正值证实保护机制正确地拦截了那些会降低质量的修改。

表 16 报告了各步数下的这些指标。结果揭示出一致的规律：随着步数增加、每一步覆盖的轨迹比例变小，精修变得更加选择性、更加可靠，幅度也更小。

**表 16.** token 精修统计（每个步数 504 条序列）。

### E.1 时间阈值 $\tau$ 的影响：补充细节

阈值消融的主要结果与表格见第 5.2 节。本节提供进一步分析。

**为什么取 $\tau=0.02$ 而不是 $\tau=0$。** 我们取 $\tau=0.02$ 作为最低阈值而不是 $\tau=0$，原因有二。其一，在 $t=0$ 时序列是纯源噪声——$\alpha(0)=0$，没有任何位置被揭示——能量罗盘收到的序列没有可打分的有意义内容；所有候选都是无法区分的噪声，基于能量的选择等价于随机选择。其二，在极早的流时刻，CTMC 转移率涉及比值 $\dot{\kappa}_t/(1-\kappa_t)$，当 $\kappa_t\approx0$ 时可能产生数值不稳定。取 $\tau=0.02$ 可确保在调用罗盘之前至少有约 2% 的位置（1024 个中的约 20 个）携带已揭示 token，为候选比较提供最小但非零的信号，同时避开数值边界情形。

**观察（均匀源）。** 均匀源的结果显示出清晰的趋势。第一，**FS-DFM 初始化在每个阈值与每个步数下都持续优于 DFM 初始化**——例如在 $\tau=0.2$、8 步时，FS-DFM 初始化达到 56.1 PPL，而 DFM 初始化为 79.0——这证实轨迹塑形与更强的起点是叠加关系，而不是替代关系。第二，**更低的阈值带来更好的困惑度，但以多样性为代价。** 最低阈值（$\tau=0.02$）在两种初始化下都取得最佳原始 PPL（例如 FS-DFM 初始化在 8 步时为 43.5），但其生成熵在 8 步时降到 6.4——低于 6.5 这一阈值，在离散扩散模型中低于此值时 token 重复与词汇多样性下降会变得普遍。这表明在几乎每个中点都激活罗盘，会使模型过度优化能量目标，把分布坍缩到高能量（低困惑度）但重复的序列上。第三，**$\tau=0.2$ 为均匀源提供了最佳的质量–多样性权衡**：它取得很强的困惑度（FS-DFM 初始化下 8 步为 56.1、16 步为 47.2），同时保持高于 7.0 的健康熵，表明生成的文本保留了自然的词汇多样性。默认的 $\tau=0.4$ 更保守，产生最高熵（7.2–7.5），但牺牲了困惑度。

**观察（掩码源）。** 掩码源在两个方面表现出与均匀源明显不同的模式。第一，**DFM 初始化持续优于 FS-DFM 初始化**——与均匀源设定相反。在 8 步、$\tau=0.02$ 时，DFM 初始化达到 92.9 PPL，而 FS-DFM 初始化只达到 137.0；在 16 步、$\tau=0.2$ 时，差距更大（61.9 对 109.9）。这表明在掩码源下蒸馏出的 FS-DFM 学生已收敛到难以用轨迹塑形重新引导的速度模式，而 DFM 教师提供了更灵活的起点，塑形可以更有效地塑造它。第二，**掩码源从低 $\tau$ 中获益少于均匀源**。虽然 $\tau=0.02$ 配 DFM 初始化在 8 步给出合理的 PPL（92.9），但其熵降到 6.2——远低于 6.5 的多样性阈值——而且相对 $\tau=0.2$（91.4）的 PPL 改善可以忽略。在 16 步时，$\tau=0.2$ 配 DFM 初始化取得总体最佳结果（61.9 PPL，7.6 熵），这证实 $\tau=0.2$ 也是掩码源的首选阈值。

### E.2 中点多样性分析

导航塑形的一个关键假设是：在中间流时刻所做的随机 CTMC 跳转会产生有实质差异的续写——如果无论跳转如何，所有候选都收敛到相同输出，那么在 $K$ 个候选之间做基于能量的选择就没有可用的材料。我们通过测量从共享中点状态生成多条独立补全时还保留多少多样性，直接检验这一假设。

<span id="page-32"></span>

**设置。** 我们使用以均匀源分布训练的 170M 参数 TS-DFM 学生。对每次试验，我们采样一个源序列 $x_0$，运行流求解器从 $t=0$ 到中点时刻 $t_{\text{mid}}$，得到共享状态 $x_{t_{\text{mid}}}$。从这个共享状态出发，我们启动 $N=10$ 个独立补全直到 $t=1$，每个补全对所有随机跳转都使用新的随机种子。我们对 48 个独立前缀重复这一过程，并报告所有补全上的平均多样性指标。

**步数分配。** 给定总预算 $S$ 步，前缀阶段使用 $S_{\text{pre}}=\max(1,\lfloor S\cdot t_{\text{mid}}\rfloor)$ 步到达 $t_{\text{mid}}$，每个补全使用 $S_{\text{comp}}=\max(1,\lfloor S\cdot(1-t_{\text{mid}})\rfloor)$ 步完成剩余部分。由于舍入，$S_{\text{pre}}+S_{\text{comp}}$ 可能不等于 $S$，因此各阶段的有效步长（$t_{\text{mid}}/S_{\text{pre}}$ 与 $(1-t_{\text{mid}})/S_{\text{comp}}$）与训练中使用的均匀步长 $1/S$ 略有不同。例如取 $S=8$、$t_{\text{mid}}=0.3$：前缀使用 2 步（步长 0.15），每个补全使用 5 步（步长 0.14），合计 7 步。这一不匹配很小，且不影响定性结论，因为多样性指标在不同步数下是一致的（表 18）。

**指标。** 我们从三个互补的方面度量每个共享中点所产生 $N$ 个补全之间的多样性。

**Self-BLEU** (Zhu et al., 2018) 通过把每个补全与其余 $N-1$ 个补全比较来度量 n-gram 重叠：

$$\text{Self-BLEU}=\frac{1}{N}\sum_{i=1}^{N}\text{BLEU}\Big(x^{(i)},\{x^{(j)}\}_{j\ne i}\Big). \tag{E.1}$$

得分接近 1.0 意味着各补全共享相同的措辞；接近 0 则意味着完全不同的词序列。它刻画的是短语级多样性：候选可能在一些零散位置上不同，却仍然产出实质相同的文本（高 Self-BLEU），或者代表真正不同的续写（低 Self-BLEU）。

**成对编辑距离**统计两条补全不一致的位置比例，并在所有配对上取平均：

$$\text{EditDist}=\frac{1}{\binom{N}{2}}\sum_{i<j}\frac{1}{L}\sum_{\ell=1}^{L}\mathbb{1}\big[x_\ell^{(i)}\ne x_\ell^{(j)}\big]. \tag{E.2}$$

它直接量化了有多少 token 位置被随机跳转影响——这正是能量罗盘用于候选选择的"材料"。

**token 一致度**通过计算在每个位置上共享最流行 token 的补全比例，度量逐位置的共识：

$$\text{Agree}=\frac{1}{L}\sum_{\ell=1}^{L}\frac{1}{N}\max_{v\in\mathcal{V}}\sum_{i=1}^{N}\mathbb{1}\big[x_\ell^{(i)}=v\big]. \tag{E.3}$$

它通过揭示分歧的分布来补充编辑距离：一致度低的位置正是随机跳转真正不确定的位置，也正是 token 精修阶段必须决定是否介入的位置（附录 C.3）。

表 18 报告了七个中点时刻在 8 步与 64 步（覆盖我们实验所用步数范围的两端）下的这些指标。不同步数下的多样性剖面几乎相同，说明中点多样性是流结构的性质，而不是求解器粒度的性质。

**对导航塑形的含义。** 结果证实中点多样性是逐渐衰减而非突然坍缩的，这验证了序列选择阶段的核心假设。在 $t_{\text{mid}}=0.2$——我们主实验所使用的激活阈值（$\tau=0.2$）——从共享中点出发的独立补全在 1024 个 token 位置中约有 147 个不同（编辑距离 14.4%）。在 $t_{\text{mid}}=0.3$ 时，补全仍约有 98 个位置不同（编辑距离 9.6%）。这意味着从同一中点生成的 $K=5$ 个候选，会在约 100–150 个位置上给出真正不同的选项，为能量罗盘提供有实质意义的选择材料。

即便在 $t_{\text{mid}}=0.5$ 时，序列已有约一半被揭示，仍有约 32 个位置在各补全之间变化。这些剩余的易变位置恰恰是最容易在后续中点产生累积误差的位置：它们是未揭示的 token，随机跳转在此做出有后果的选择。导航塑形瞄准的正是这些位置——序列阶段在所有易变位置上选出全局最优候选，token 阶段则修正胜出者内部的个别错位。

在 $t_{\text{mid}}$ 较高时残留的多样性（$t=0.7$ 时约 13 个位置，$t=0.9$ 时约 4 个）看似可以忽略，但在一条接近完成的序列中，即使少数 token 放错位置，也可能传播到后续 RK-4 阶段。token 精修阶段正是为这一区间设计的：它以速度置信度门控在单个位置上操作，在随机跳转最可能引入错误的地方做有针对性的修正（附录 C.3）。

### E.3 扩展到更大的模型

第 5 节的主实验使用 170M 参数的学生。一个自然的问题是：随着模型规模增大，轨迹塑形是否仍然有效，还是更大的速度模型本身就能产生质量足够高的轨迹，使导航塑形变得多余。为回答这一问题，我们用一个 1.3B 参数的学生重复均匀源比较——它比正文模型大约 $7.6\times$。

这一设定有一个值得注意之处：1.3B 学生由与 170M 时相同的约 90M 能量罗盘引导。因此罗盘比它所监督的学生小约 $14\times$。如果轨迹塑形只有在罗盘与学生在容量上匹配时才有用，那么这个比例将极为不利。因此，1.3B 上的任何增益也说明了该方法的一个实际扩展性质：轻量罗盘可以引导大得多的学生。

该实验的主要数字与表格见第 5.2 节与表 5；本节补充正文未能容纳的细项与讨论。

**TS-DFM 相对 FS-DFM 的优势随规模增大。** 在 1.3B 上，8 步的 TS-DFM 达到 48.0 GPT-2 Large PPL，而 FS-DFM 为 81.5——降低 41%，大于 170M 上观察到的 36%（56.1 对 87.6）。同样的模式也出现在其他步数：16 步时这一差距从 170M 的 35%（47.2 对 73.2）变为 1.3B 的 33%（33.1 对 49.5），32 步时从 31% 变为 30%。更大的学生并不会让轨迹塑形变得多余；如果说有什么区别，它扩大了盲轨迹构造与引导轨迹构造之间的差距。

**TS-DFM 从 8 步起就胜过 1024 步的 DFM 教师，且在全部评估器上成立。** 仅用 8 步，TS-DFM 就取得 48.0 的 GPT-2 Large PPL——低于 1024 步 DFM 教师的 57.5——同时快 $128\times$。同样的次序在 LLaMA-2 7B（26.6 对 32.1）与 LLaMA-3 8B（46.7 对 54.5）上成立。在 16 步时优势进一步扩大（GPT-2 Large 上 33.1 对 57.5，相对教师降低 42%），在 32 步时 TS-DFM 达到 31.5——在步数少 $32\times$ 的情况下相对 1024 步教师降低 45%。从 8 步起的每个 TS-DFM 单元在三个评估器上都超过全步教师。170M 上展示的少步质量优势不是小规模蒸馏的假象；它会随规模扩展。

（3）**一个 90M 的罗盘可以有效引导 1.3B 的学生——且相对开销只占很小一部分。** 能量罗盘在两种规模下都保持约 90M 参数，因此罗盘与学生的比例从 170M 时的约 1:2 变为 1.3B 时的约 1:14。尽管存在这种不对称，罗盘仍提供了足够的判别信号来引导

<span id="page-34"></span>

更大的学生轨迹，而且质量增益实际上超过 170M 时（1.3B 上相对 FS-DFM 的 8 步降低为 41%，170M 为 36%）。这一比例变化还大幅降低了相对训练开销：在 170M 时，每次能量前向传播的开销约为一次速度传播的 $1/1.9\approx53\%$，而在 1.3B 时仅为 $90/1300\approx7\%$。换言之，同一套在 170M 时带来约 $2.2\times$ 训练时开销的导航塑形流程（表 3），在更大规模下按比例便宜得多——导航的 FLOPs 开销由罗盘主导，而每步 FLOPs 的大部分转移到（更大的）速度模型上。因此，模型越大，应用该方法越划算：质量增益更高，相对开销更低。

（4）**多样性在规模扩展后得以保留。** 1.3B 上 TS-DFM 的生成熵从 7.0（4 步）到 7.6（32 步），远高于 6.5——低于该阈值时，离散扩散模型中的 token 重复与词汇多样性下降会变得普遍（附录 E.1）。因此，规模扩展后的困惑度改善反映的是真实的质量提升，而不是熵向重复的高概率序列坍缩。

这些结果把论文的主要结论推广到一个大得多的模型：少步离散流匹配的瓶颈是轨迹质量，而不是学生容量。在 1.3B 上，用塑形轨迹训练的学生从仅 8 步起就胜过其 1024 步教师——推理加速 $128\times$ 而质量反而更好——并且使用的是与 170M 时相同的轻量 90M 能量罗盘。放大学生会令轨迹塑形**更有效**（相对 FS-DFM 的质量增益更大），并在相对意义上**更便宜**（罗盘与学生的 FLOPs 比例更小）。该方法的实用性与其监督信号的容量干净地解耦。

（3）**以一小部分参数量获得质量。** TS-DFM（0.17B）在 16 步时达到 PPL 54 与 MAUVE 0.71；在相同步数下，Dream（7B）与 LLaDA（8B）的 PPL 至少为 432，MAUVE 不超过 0.005。规模悬殊并不是需要克服的小模型劣势，而是一个正面结果：小 $40\times$–$47\times$ 的蒸馏学生能生成更大的未蒸馏模型在此步数预算下无法企及的文本。决定少步质量可用与否的杠杆是轨迹塑形，而不是参数量。

**少步 TS-DFM 超过全步教师。** 最主要的结果是：在极低步数下，TS-DFM 在 pass@8 上超过了教师全步（256 步）的准确率：TS-DFM 在 4 步时达到 9.61、在 8 步时达到 9.17，两者都高于教师全步的 9.12，而推理计算少 $32\times$–$64\times$。这正是少步蒸馏需要用来证明自身价值的核心主张。步数预算很小的蒸馏学生不应只是**接近**全步教师；它应当达到或超过教师。TS-DFM 在 pass@8 上跨过了这一门槛，并在更难的 pass@32 指标上达到教师全步质量的 92–93%（TS-DFM 4 步：25.47；教师 256 步：27.52）。同步数下的差距更为醒目：在 8 步时，TS-DFM（9.17，15.79，25.19）在 pass@8、pass@16、pass@32 上分别以 +61%、+35%、+20% 超过同样 8 步的教师（5.68，11.69，20.92）——这是尚未收敛的教师与已内化少步生成的学生之间的差距。

**轨迹塑形在低步数下持续扩展 FS-DFM 的优势。** 表中每个单元格里，TS-DFM 都在相同步数与 pass@$k$ 指标下优于 FS-DFM。差距在最重要的地方最大——即最低的步数预算。在 4 步时，TS-DFM 相对 FS-DFM 在 pass@8 上提升 +0.20，在 pass@16 上提升 +0.14，在 pass@32 上提升 +2.42；在 8 步时，增益分别为 +0.18、+0.31、+0.25。4 步时 pass@32 的提升（23.05→25.47）尤其有信息量：教师要在 pass@32 上取得可比幅度的提升，需要从 4 步增加到 32 步（18.49→22.16，$8\times$ 计算下 +3.67），或从 32 步增加到 256 步（22.16→27.52，$8\times$ 计算下 +5.36）。TS-DFM 以比教师全步设定少 $64\times$ 的推理计算，取得了后一项增益的大约一半。轨迹塑形实际上把推理步计算转换为一次性训练步计算——而这种转换是有利的。

**为什么轨迹塑形在推理任务上取胜。** 数学推理区间中，每一个 token 决策都承载着不同寻常的分量：一个错误数字、一个放错位置的运算符、一个颠倒的比较符，都可能翻转整个答案。这与无条件语言建模在结构上相反：后者的局部错误可以被周围上下文吸收。TS-DFM 背后的假设——轨迹中间中点处的累积误差会污染学生的训练信号——预测：在轨迹错误会传播为结果错误（而非表面瑕疵）的任务上，增益应当更大。4 步时的 pass@32 增益（此时整个 32 token 答案必须足够连贯，才能被验证器接受）印证了这一点：轨迹塑形防止了那种把"48"变成"84"、把"+"变成"−"的生成中途漂移。能量罗盘与序列到 token 策略从未见过 GSM8K 题目——罗盘是在无条件文本上训练的——然而同一套塑形机制在 1.3B 参数上干净地迁移到了推理任务。这就是我们所说的瓶颈在轨迹、而不在学生的含义。

**泛化结论。** 由此可得三点。第一，轨迹塑形可以迁移到指令跟随任务：同一套在 170M 参数上改善无条件生成的能量导航 RK-4 过程，在 1.3B 上改善了少步数学推理——没有方法修改，没有任务专用罗盘，没有逐任务调参。第二，少步区间正是塑形最重要的地方：在 4 步与 8 步时，TS-DFM 在 pass@8 上超过全步教师，并在最多 $64\times$ 更少的计算下恢复到全步 pass@32 准确率的 92–93%。第三，少步推理的瓶颈与少步语言建模相同：轨迹质量，而不是学生容量。同一种杠杆在两个区间都起作用。

**利用生长数据与应用技术：**

为说明确定土壤 Hollis 上光照质量的重要性，让我们考察不同的开花过程检测技术与应用方法。主要步骤之一是检测开花品种，以测量氮与磷的具体用量。这些检测提供的数据将帮助植物根据所涉及的多种因素——如温度、湿度、土壤质地、土壤水分与土壤温度——为每个品种与应用调整营养液。此外，还可以收集关于施肥条件与相关生根激素补充的生长数据，确保营养液到达特定的生长阶段。通过降低这些因素的风险，植物能够确定特定花生长的最佳营养液，并相应调整其施用。

**土壤 Hollis 的准备：**

对土壤颜色的考虑对于改善花的光照质量与外观至关重要。一些步骤包括：

- **检测 pH 水平**：对土壤养分需求进行检测可以防止活性，并确定高于 ppm 的 pH 是否最有利于植物生长发展或衰退。这可能涉及施用平衡的 pH 溶液，如温和硫，它可以提高蔬菜、水果和花的 pH。
- **使用适当技术**：施用高质量肥料会增加养分流失与水处理的风险。这也可能导致根部损伤，必须加以管理以防止过度浇水。
- **监测 pH 水平**：营养液应通过局部显色水平进行监测。pH 水平、定期检测与维护以确定生长的理想范围；并加入检测溶液（如 eremosiloba）以维持平衡的 pH，有助于根系发育、健康的根与纤维生长。
- **理解颜色深度分布**：在根系（包括叶片与茎）之间维持平衡的深度有助于防止损伤，因为叶片促进空气循环并确保光吸收。通过确保向根系的适当分配，植物衡量其养分需求并支持根系生长与发育。

## 摘要

贝叶斯反问题既需要信息量充足的先验模型，也需要在计算上可行的后验推断。基于分数的扩散模型（score-based diffusion models）能够提供表达力强的学习型先验，但将其用于反演会引入一个条件化问题：加噪后验的分数一般无法仅由先验分数得到。本选择性综述回顾了处理该问题的主要方法，包括似然引导、谱方法与投影方法、序贯蒙特卡洛校正，以及摊销式条件训练。我们按各方法在离线准备与在线推断之间如何拆分计算代价来组织这些方法，并比较它们的假设、优势与局限，重点关注计算加速。文末汇集了一些进行中的方向与开放问题。

**关键词：** 贝叶斯反问题；基于分数的扩散模型；后验采样；摊销式推断；不确定性量化

**MSC2020：** 62F15；65C40；65N21；68T07。

## 1 引言

### 1.1 无穷维贝叶斯反问题

反问题关注从间接观测中恢复状态、系数或源的任务，例如在 CT 成像中由 X 射线测量重建人体内部结构，或由偏微分方程（PDE）解的观测识别系数。由于反问题具有不适定性（ill-posed，即解可能不存在、不唯一且不稳定），通常需要引入额外信息。贝叶斯反演用先验测度（prior measure）表示这类信息，并以观测为条件得到后验（posterior）[30]。这里采用无穷维框架，允许未知量取值于（例如）Hilbert 空间。这样可以在离散化之前研究适定性与逼近性质，从而推动离散化不变算法的发展，使其收敛性可在网格加密下进行研究。

设 $X$ 取值于可分 Hilbert 空间 $H$，先验为 $\mu$，考虑观测模型

$$Y = G(X) + \varepsilon, \quad \varepsilon \sim N(0,\Gamma), \tag{1}$$

其中 $G : H \to \mathbb{R}^m$ 可测，$\Gamma$ 正定，且 $\varepsilon$ 与 $X$ 独立。后验 $\mu^y$ 满足

$$\frac{d\mu^y}{d\mu}(x) = \frac{\exp[-\Phi(x;y)]}{Z(y)}, \qquad \Phi(x;y) = \frac{1}{2}\|G(x)-y\|_{\Gamma}^{2},$$

其中 $\|v\|_{\Gamma}^{2} = v^{\top}\Gamma^{-1}v$，且 $Z(y) = \int \exp[-\Phi(x;y)]\,\mu(dx) > 0$。后验蕴含了关于未知量及其不确定性的信息。

<span id="page-2"></span>

然而，后验计算可能十分昂贵。马尔可夫链蒙特卡洛（MCMC）在适当条件下给出渐近精确的推断，函数空间方法则可避免网格加密带来的一些退化 [6]。采样探索缓慢与似然评估代价高仍会限制有效样本量，尤其当 $G$ 需要求解 PDE 时。代理模型（surrogate）与传输映射（transport map）提供了替代途径 [7, 22]。

去噪扩散概率模型 [15] 与连续的基于分数的表述 [29] 学习加噪分布，并通过反转加噪过程生成样本。用于反演时还需引入似然。早期医学成像工作展示了可复用的无条件分数 [28]，此后的条件化方法在精度与代价上各有特点。近期进展可参见综述 [8, 17] 与即将出版的书 [20]。

### 1.2 扩散先验与后验条件化

考虑 Ornstein–Uhlenbeck（OU）过程

$$dX_t = -\frac{1}{2}X_t\,dt + dW_t, \quad X_0 \sim \nu, \tag{2}$$

其中 $W$ 是与 $X_0$ 独立的 $C$-Wiener 过程，$C$ 为单射、正、自伴的迹类算子。则依分布有 $X_t = e^{-t/2}X_0 + \sqrt{1-e^{-t}}\,Z$，其中 $Z \sim N(0,C)$ 且与 $X_0$ 独立。对具有有限二阶矩的分布 $\nu$，定义协方差加权分数（covariance-weighted score）[23]

$$s(x,t;\nu) = -\frac{x - e^{-t/2}\,\mathbb{E}[X_0 \mid X_t = x]}{1 - e^{-t}}. \tag{3}$$

在有限维情形下它等于 $C\nabla \log p_t(x)$，其中 $p_t$ 是 $X_t$ 的密度。去噪分数匹配（denoising score matching）无需 $\nu$ 的显式密度即可学习该场 [23]。

在函数空间中不存在 Lebesgue 密度，(3) 给出了一个有用的概率式定义。在适当的支撑集与可积性假设下，以 $C$-Wiener 过程 $W$ 进行时间反演具有如下形式

$$dZ_u = \left[\frac{1}{2}Z_u + s(Z_u, T-u;\nu)\right] du + dW_u, \quad 0 \le u < T. \tag{4}$$

以精确的终端分布作为初始化时，该过程反转了 (2)。详细推导与证明见 [23]。

对于后验采样，所需的初始分布为 $\nu = \mu^y$。在有限维情形下，记 $p_t$ 为加噪先验密度，$p_t^y$ 为加噪后验密度。由 Bayes 公式可得

$$\nabla \log p_t^y(x) = \nabla \log p_t(x) + \nabla \log h_t(x;y), \qquad h_t(x;y) = \mathbb{E}\left[e^{-\Phi(X_0;y)} \mid X_t = x\right]. \tag{5}$$

该期望基于先验的加噪过程。由于似然依赖于 $X_0$，即便已知似然与先验分数，(5) 中的第二项通常仍不可得。已有工作提出了不同的方式来估计 (5)，由此形成了多种后验采样策略。

## 2 高效后验采样的途径

下文给出使用扩散模型的后验采样方法的一个样本$^{1}$。这些方法在如何融入观测、以及如何在离线准备与在线推断之间分配计算上各不相同。离线工作可包括先验训练、模拟观测对以及依赖算子的预处理；在线工作则针对每个新数据集执行，包含条件化与样本生成。

$^{1}$ 本列表远非穷尽；更全面的综述请参见 [8]。

<span id="page-3"></span>

### 2.1 复用预训练先验模型

这类方法复用预训练的先验模型，并在推断阶段引入观测模型。扩散后验采样（diffusion posterior sampling, DPS）[5] 利用去噪估计 $\hat{x}_0(x,t) = \mathbb{E}[X_0 \mid X_t = x]$ 近似中间似然。对高斯观测，所得引导项基于 $-\nabla_x \Phi(\hat{x}_0(x,t);y)$。该方法可容纳可微的非线性映射，配合其他似然也可处理非高斯噪声，且无需在参数—观测对上联合训练。然而，引导需要对去噪器与前向模型求导，通常还需要调参。即便先验分数精确，在去噪均值处评估似然仍是一种近似。

Tweedie 矩投影扩散（Tweedie moment projected diffusions, TMPD）[3] 同时保留去噪的协方差与均值。对 $X_0 \mid X_t = x$ 的矩近似为线性—高斯观测给出可处理的中间似然，并以额外的导数或协方差代价刻画条件分布的离散程度。对非高斯先验，所得的矩近似一般仍带有条件化偏差。Feynman–Kac 分析 [10] 刻画了 DPS 及相关引导方法在先验分数精确时的偏差，并分析了强引导下的离散化不稳定性。

去噪扩散恢复模型（denoising diffusion restoration models, DDRM）[19] 通过在奇异向量坐标中的噪声感知更新来利用线性结构。它们能以可复用的先验和少量去噪步实现高效恢复，但要求谱表示易于处理。去噪扩散零空间模型（denoising diffusion null-space models, DDNM）[31] 使用值域—零空间分解来强制数据一致性，同时由先验决定未观测分量。两者都利用了算子结构，但重建质量或无噪声一致性并不能确立经过校准的后验采样。

同样的预训练先验也可借助序贯蒙特卡洛（sequential Monte Carlo, SMC）进行条件化：SMC 用加权粒子、重采样与变异（mutation）来近似中间分布。MCGDiff [4] 构造一系列中间线性问题，其后验随扩散噪声减小而逼近目标后验。滤波式后验采样（filtering posterior sampling）[11] 将条件化与贝叶斯滤波联系起来，并通过 SMC 获得渐近准确的推断。解耦扩散 SMC（decoupled diffusion SMC, DDSMC）[14] 允许更大的生成式更新，并对线性—高斯观测是渐近精确的。

粒子校正为近似引导提供了一种有原理依据的替代方案。有限粒子数下的权重退化会损害精度，而粒子会增加分数评估、似然计算与内存开销。它们共同采用的中间分布“扭转”（twisting）技术综述于 [17]。

### 2.2 学习后验条件化

条件训练把观测的融入转移到学习阶段。在 $(X,Y)$ 的联合样本上训练的网络 $s_\theta(x,t,y)$ 直接学习加噪后验分数，从而无需重复的前向或伴随（adjoint）评估即可生成样本。Baldassari 等 [2] 论证了无穷维线性反问题中条件去噪估计的合理性，包括其短时行为。这种在线节省需要具有代表性的联合训练数据。若要在不同算子、噪声统计或传感器几何之间复用，则需要训练覆盖这些设置，或通过自适应加以处理。

一条相关策略是学习 PDE 参数与解之间的关系。FunDPS 的主要实现 [32] 训练这些函数上的联合扩散模型，并通过掩码与梯度引导融入稀疏观测；其另一种表述只对参数设先验并配合显式 PDE 求解器，在采样过程中保留经该求解器求导。这些表述说明，学习前向关系如何改变离线仿真与在线计算之间的平衡。

只学习引导项则提供了一种折中方案。Baker 等 [1] 在适当的 Cameron–Martin 支撑或高斯绝对连续性假设下建立了无穷维 Doob $h$-变换，并提出有监督的引导训练。这样便可在复用

<span id="page-4"></span>

现有先验网络的同时，额外训练一个用于条件化的模型。不过，其基于似然信息的参数化在采样过程中仍保留观测模型的梯度，因此计算收益取决于条件化中哪些部分是被学习得到的。

### 2.3 减少逆时间评估次数

降低在线代价的另一条互补途径是减少分数或去噪器的评估次数。DDIM [26] 允许用更少的去噪步采样，DPM-Solver [21] 则采用高阶扩散 ODE 积分。两者都可直接使用已有的训练模型而无需重新训练。一致性模型（consistency models）[27] 通过训练或蒸馏支持一步或少步生成，从而把额外的计算投入转移到离线准备阶段。

对于后验采样，评估这些节省时必须同时考虑条件化误差与数值积分误差。Posterior-DDIM [18] 在奇异方向上采用随噪声变化的更新，并在其假设下证明了后验收敛性。把此类保证推广到非线性反问题与函数空间表述仍是一个重要方向。

## 3 任务相关的摊销：UCoS 与正则化变体

条件分数的无条件表示（unconditional representation of the conditional score, UCoS）[24] 将一种与具体测量无关的去噪表述同一种避免重复物理（physics）评估的后验采样相结合。其训练针对特定的观测模型，所得网络可在该模型的新数据集之间复用。

假设如 (1) 中那样，$G = A : H \to \mathbb{R}^m$ 为有界线性算子，且观测噪声为高斯噪声（先验不必为高斯）。对 $t>0$，令 $q_t = e^{t}-1$，并定义

$$C_t = \Gamma + q_t A C A^{*}, \qquad R_t = q_t I - q_t^{2} C A^{*} C_t^{-1} A, \qquad \Sigma_t = R_t C.$$

令 $\tilde{X}_t = \tilde{X}_0 + \eta_t$，其中 $\tilde{X}_0 \sim \mu$ 与 $\eta_t \sim N(0,\Sigma_t)$ 相互独立，并置

$$r(z,t) = \mathbb{E}[\tilde{X}_0 \mid \tilde{X}_t = R_t z], \qquad \lambda(t) = (e^{t/2}-e^{-t/2})^{-1}.$$

将高斯似然与高斯加噪核通过“配方”（completing the square）结合，可得恒等式

$$s(x,t;\mu^y) = \lambda(t)\left[r\left(C A^{*}\Gamma^{-1}y + \lambda(t)x,\ t\right) - e^{t/2}x\right].$$

在函数空间中，该式在 Cameron–Martin 支撑假设 $\mu(C^{1/2}(H)) = 1$ 下几乎必然成立 [24]。该恒等式精确表示条件分数，而无需对似然作近似。

近似 $r$ 的网络在先验样本上训练，其扰动依赖于 $(A, \Gamma, C)$，与具体实现的观测无关。训练需要算子运算，但可采用无矩阵（matrix-free）实现，无需构造完整算子矩阵或其 SVD。一旦计算出 $b_y = C A^{*}\Gamma^{-1}y$，逆时间采样便只需使用 $b_y$、标量运算与网络，无需再应用 $A$ 或 $A^{*}$。于是，UCoS 既避免了完整条件训练所需的单独测量向量输入，又消除了重复的在线物理评估。观测算子或噪声模型发生变化时，通常仍需重新训练或自适应。

[25] 中 UCoS 的正则化变体将学习得到的条件分数与一个高斯参考后验的分数结合，

$$s_{\alpha} = (1-\alpha)s_{\mathrm{learned}} + \alpha\, s_{\mathrm{Gaussian}}, \qquad 0 \le \alpha \le 1. \tag{6}$$

这在严重不适定的情形（包括有限视角扩散光学层析成像）中为学习到的信息提供补充。

为解释这种正则化，考虑 $C = I$ 的有限维情形下的精确分量分数。记 $P_t^{*}$ 为 OU 密度演化算子，$p_1, p_2$ 为初始后验密度，它们分别对应

<span id="page-5"></span>

学习分数与高斯分数。理想的分数混合等于 $\nabla\log\left[(P_t^{*}p_1)^{1-\alpha}(P_t^{*}p_2)^{\alpha}\right]$。它一般不同于将几何混合 $p_1^{1-\alpha}p_2^{\alpha}$ 加噪后所得的分数 $\nabla\log P_t^{*}\left(p_1^{1-\alpha}p_2^{\alpha}\right)$。在正则性与局部正性假设下 [25]，当 $t \downarrow 0$ 时，该差异在任意有界区域上为 $O(t)$。这一结果给出了理想分数混合的局部短时解释。但需注意，它并不能证明学习到的正则化采样器精确采样了该几何混合。

## 4 结论与展望

可复用的先验引导灵活但通常是近似的。粒子校正以额外代价提供渐近一致性。条件训练与任务相关训练对条件化进行摊销，而快速的逆时间求解器减少网络评估次数。它们的相对优势取决于算子结构、训练数据、复用情况以及所需的后验精度。作为一个简单示例，令 $C_{\mathrm{off}}$ 表示可复用的训练与准备代价，$C_{\mathrm{on}}$ 表示在给定后验精度下每个新数据集的代价。把这一准备在 $N$ 个数据集上复用，则每次反演的平均代价约为 $C_{\mathrm{off}}/N + C_{\mathrm{on}}$。若方法 $A$ 的离线代价高于 $B$、但在线代价低于 $B$，则其总代价更小的条件为

$$N > \left(C_{\mathrm{off}}^{A} - C_{\mathrm{off}}^{B}\right)\Big/\left(C_{\mathrm{on}}^{B} - C_{\mathrm{on}}^{A}\right).$$

上述讨论引出以下开放问题。

**非线性与非高斯条件化。** 似然引导与学习型 Doob 变换为超出线性—高斯设定的条件化提供了途径 [5, 1]。能否在减少 PDE 与伴随求解次数的同时，以可控偏差近似中间似然或引导项？特别值得关注的，是对多峰后验或高度集中后验仍然有效的保证。近期工作 [13] 将扩散先验与无导数似然采样相结合，用于 LWR 交通模型的初始条件识别，并有可能推广到基于轨迹的前向模型 [9, 12]。推广到其他非线性模型还需要新的思路。

**学习与模型误差。** 近期分析定量刻画了生成先验的近似如何影响后验 [16]。能否把这些结果与有限数据下的分数估计、条件化以及数值误差结合起来，从而对感兴趣的后验量给出定量保证？理解这些界对观测噪声与模型误设的依赖尤为重要。分数正则化的统计上合理的选择是一个相关问题。

**离散化与观测。** 函数空间扩散理论在适当假设下给出维数无关的界 [23]，而条件化表述揭示了扩散时间接近零时额外的困难 [2]。能否在网格加密、传感器变化与观测噪声很小的情况下，一致地得到条件分数界与数值界？此外，混合分数 (6) 的几何解释限于有限维与小扩散时间。把这一解释推广到函数空间，需要适当的绝对连续性、可积性与分数正则性假设。

**保持后验的加速。** 高阶扩散求解器与一致性模型降低了生成代价 [21, 27]。在条件化之后，类似的加速能否保持可量化的后验精度？针对特定线性构造的后验收敛结果 [18] 提供了起点，但推广到非线性 PDE 模型仍然重要。粒子校正提供了另一条路径 [4, 14]，不过其精度与效率取决于权重是否可计算、粒子退化程度以及似然评估的代价。

| Bayesian inverse problem | 贝叶斯反问题 | 用先验测度与观测似然得到后验分布的反问题求解框架 |

| likelihood guidance | 似然引导 | 在逆时间采样中用似然的梯度修正先验分数，以把观测信息注入采样 |
| conditional score | 条件分数 | 加噪后验分布的对数密度梯度，即引导采样所需的目标分数 |
| sequential Monte Carlo (SMC) | 序贯蒙特卡洛 | 用加权粒子、重采样与变异近似一族中间分布，从而对条件化做粒子校正 |
| amortization | 摊销 | 把每次推断都要重复的计算前移到离线训练或准备阶段，以降低在线代价 |

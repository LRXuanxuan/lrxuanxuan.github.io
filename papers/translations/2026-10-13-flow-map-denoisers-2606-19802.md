## 摘要

图像恢复面临根本性的权衡：最小化误差的方法往往产生模糊重建，而最大化感知质量的方法虽然生成清晰的图像，却不一定忠实于原图。现有方法或者只选择失真—感知（Distortion–Perception，DP）前沿上的一个工作点，或者必须依赖成对数据监督、辅助模型或采样器的超参数调节，才能访问不同工作点。

本文指出，流映射模型（Flow Map Model）——近期扩展流匹配、通过学习平均速度场实现少步采样的一类模型——隐式定义了一族由单个参数索引的去噪器，能够在 DP 平面上连续移动。**前瞻参数（Lookahead Parameter）\(t\)** 可作为控制最小均方误差（MMSE）区域与感知区域之间权衡的旋钮。对于各向同性高斯目标，本文证明改变 \(t\) 可以精确恢复最优 DP 前沿；对于自然图像，实验观察到类似行为。

将其嵌入即插即用（Plug-and-Play，PnP）求解器后，同一机制可扩展至一般逆问题。此时前瞻参数作为正则化参数，控制感知对齐与数据一致性之间的权衡。虽然在该设置下不再具有严格最优性保证，但一个训练好的流映射就可以遍历 DP 权衡，在两个端点上均与专用基线相竞争，也能与无需训练的 DP 遍历方法相竞争。在 CelebA（128×128）、AFHQ（256×256）上，针对多个线性及非线性逆任务的广泛实验验证了上述结果。代码：https://github.com/nzilberstein/Flow-map-denoisers。

## 1. 引言

图像恢复是高度不适定的逆问题：单个退化观测可能对应大量看似合理的干净图像。标准的监督回归方法通过最小化均方误差（MSE），逼近条件期望（Ongie et al., 2020），实现最小失真，却往往过度平滑，缺少精细细节。相比之下，后验采样方法（Kawar et al., 2021）可以产生看起来真实的解，但通常伴随更高失真。这种内在折衷可由失真—感知（DP）权衡理论形式化（Blau & Michaeli, 2018; Freirich et al., 2021）。由于低失真和高感知质量之间的理想平衡严格依赖使用者偏好，设计能够在推理期间遍历 DP 平面的单一模型，仍是计算成像领域的核心挑战。

多数现有方法只选择 DP 平面中的一个工作点：或者用有监督回归寻求最小失真（Dong et al., 2015; Terris et al., 2026），或者利用生成先验（Pokle et al., 2024; Chung et al., 2023; Kadkhodaie & Simoncelli, 2021），从后验抽样以实现最佳感知质量。少数基于数据依赖 Flow 的工作尝试遍历 DP 平面（Ohayon et al., 2025; Delbracio & Milanfar, 2023; Albergo et al., 2024; Zhu et al., 2026），通常显式地在依赖测量的估计量（例如条件均值）和干净图像之间进行插值。另一些无需额外训练的方法，通过调整采样器遍历 DP 平面，例如缩放注入噪声（Zhu et al., 2023; Wang et al., 2025）、在引导项之间插值（Garber & Tirer, 2024），或对 MAP 估计重新加噪后进行后验采样（Zhang et al., 2026）。不同于上述需要插值、求解器超参数或重新训练等外部机制的方法，本文表明这一权衡本来就隐含于流映射的动力学之中。

本文提出基于流映射（Boffi et al., 2025a,b; Geng et al., 2025; Sabour et al., 2025b）的统一方法，在一个模型中涵盖 DP 平面上的全部工作点。之前研究主要把流映射用于加速采样（Gülle et al., 2026; Sabour et al., 2025a; Spagnoletti et al., 2025），而我们使用它来遍历 DP 平面。关键观察在于：前瞻参数 \(t\) 从单个训练流映射中隐含的一系列估计器——称为**平均去噪器**（Average Denoisers）——中选择工作点，因此成为控制恢复图像特性的旋钮。这个角度说明 DP 控制是流映射内部学习所得的性质，无须多个模型、辅助网络或启发式求解器选择。

对于各向同性高斯目标，我们证明该去噪器族跨越整个最优 DP 前沿，一端是 MMSE 估计量，另一端是完美感知估计量，精确描绘最优 DP 曲线（Freirich et al., 2021）。这一对应关系严格只对高斯去噪问题成立，自然图像的类似行为由实验观察得到。在推广至非高斯的一般逆问题时，调整前瞻参数只是对真实 DP 前沿的近似遍历；此时它更应被理解为控制感知对齐与数据一致性效应的正则化参数，而不能声称精确复现去噪中的最优 DP 前沿。通过嵌入 PnP 框架（Venkatakrishnan et al., 2013; Romano et al., 2017），本文将这种性质用于广泛的逆问题。图 1 以二维高斯混合模型说明其效果。

本文贡献包括：

1. **流映射作为 DP 估计量的连续统。** 将流映射解释成按前瞻参数 \(t\) 索引的去噪器族，让单个模型连续遍历 DP 平面。
2. **高斯情况下的精确最优性。** 证明各向同性高斯目标下该族恰好恢复最优 DP 曲线，建立流映射与 DP 理论的直接联系。
3. **具有连续控制能力的 PnP 重建。** 将去噪器嵌入即插即用框架，无需重新训练便能在 DP 平面上移动，并以显著低于后验采样的成本生成高感知质量结果。
4. **实验验证。** 在 CelebA 和 AFHQ 的修复、运动去模糊、超分辨率和高斯去模糊任务中，单个流映射在两个 DP 端点都具有竞争力，并在其间绘制平滑曲线，无需重新训练、辅助网络或为每个工作点重新调节求解器。

**符号。** 粗体小写（如 \(\mathbf x\)）表示向量，粗体大写（如 \(\mathbf H\)）表示矩阵。流映射 \(X_{s,t}\) 和去噪器 \(D_{s,t}\) 等映射记为普通非粗体。

## 2. 背景

### 2.1 流匹配与流映射

**随机插值过程（Stochastic Interpolants）。** 随机插值过程（Albergo et al., 2025; Lipman et al., 2023）定义从源分布 \(p_0\)（一般取 \(\mathcal N(0,I)\)）到目标分布 \(p_1\)（数据分布）的一族随机过程：

\[
\mathbf x_t=\alpha_t\mathbf x_0+\beta_t\mathbf x_1. \tag{1}
\]

其中 \(\alpha,\beta:[0,1]\to\mathbb R\) 连续可微，满足 \(\alpha_0=1,\alpha_1=0,\beta_0=0,\beta_1=1\)。常用线性选择 \(\alpha_t=1-t,\beta_t=t\)，即 \(\mathbf x_t=(1-t)\mathbf x_0+t\mathbf x_1\)。边缘速度场

\[
v(\mathbf x,t)=\mathbb E[\dot{\mathbf x}_t\mid\mathbf x_t=\mathbf x]
\]

定义 ODE \(\dot{\mathbf x}_t=v_t(\mathbf x_t)\)，它将源分布连续传输到目标分布，可用于从 \(p_1\) 采样。实践中，神经网络 \(v_\theta(\mathbf x,t)\) 以均方误差拟合目标速度：

\[
\mathbb E_{t,\mathbf x_0,\mathbf x_1}
\left[\left\|v_\theta(\mathbf x_t,t)-(\dot\alpha_t\mathbf x_0+\dot\beta_t\mathbf x_1)\right\|_2^2\right]. \tag{2}
\]

在扩散模型（Song et al., 2021）中，它的角色类似去噪得分匹配（Vincent, 2011）。对于线性插值，通过 Tweedie 公式（Robbins, 1956; Miyasawa et al., 1961），速度场与最小均方误差（MMSE）**瞬时去噪器**直接联系：

\[
D_t(\mathbf x):=\mathbb E[\mathbf x_1\mid\mathbf x_t=\mathbf x]
=\mathbf x+(1-t)v(\mathbf x,t). \tag{3}
\]

**流映射。** 从 \(p_1\) 采样时，求解学习速度场 ODE 通常需要多次函数评估。流映射（Boffi et al., 2025a,b; Geng et al., 2025）则直接学习有限时间区间 \([s,t]\) 的平均速度，绕过完整积分：

\[
X_{s,t}(\mathbf x)=\mathbf x+(t-s)\bar v(\mathbf x,s,t). \tag{4}
\]

平均速度 \(\bar v\) 在对角线上退化为瞬时速度 \(\bar v(\mathbf x,t,t)=v(\mathbf x,t)\)。使用同一网络 \(v_\theta(\mathbf x,s,t)\) 学习平均速度，同时以当前时间 \(s\) 和目标时间 \(t\) 为条件。作为流映射的自蒸馏目标之一（Boffi et al., 2025b），本文采用**拉格朗日自蒸馏损失**（Lagrangian Self-Distillation，LSD），包含对角线上的式（2）及非对角线项：

\[
\mathcal L_{\rm LSD}(\theta)=
\int_0^1\int_0^t
\mathbb E_{\mathbf x_0,\mathbf x_1}
\left[\left\|
\partial_t\widehat X_{s,t}(\mathbf x_s)
-v_\theta(\widehat X_{s,t}(\mathbf x_s),t,t)
\right\|_2^2\right]\,ds\,dt, \tag{5}
\]

其中 \(\widehat X_{s,t}(\mathbf x)=\mathbf x+(t-s)v_\theta(\mathbf x,s,t)\)。右侧速度使用**同一网络**的对角线切片，无须预训练教师。作者在尝试过的自蒸馏目标中选择 LSD，因为它带来最稳定的训练和最好的视觉质量。其他背景见附录 A.1。

### 2.2 逆问题与即插即用方法

考虑

\[
\mathbf y=f(\mathbf x)+\mathbf n, \tag{6}
\]

其中 \(f\) 是已知的退化算子，可非线性，\(\mathbf n\) 是加性噪声，典型地 \(\mathbf n\sim\mathcal N(0,\sigma^2I)\)。结合 Flow／扩散先验与数据一致性更新的主要方法分为两类（Daras et al., 2024; Chung et al., 2025; Zheng et al., 2025）：引导式方法（Zhang et al., 2024; Pokle et al., 2024; Chung et al., 2023; Song et al., 2022）与即插即用的优化式方法（Ben-Hamu et al., 2024; Martin et al., 2025）。本文聚焦后者，引导式方法讨论见附录 A.2。

**即插即用方法。** PnP 算法（Venkatakrishnan et al., 2013; Romano et al., 2017）起源于处理 \(\min_{\mathbf x}g(\mathbf x)+h(\mathbf x)\) 的近端优化。特别地，前向—后向分裂（FBS）交替执行数据保真项上的梯度下降

\[
\mathbf z^k=\mathbf x^k-\lambda\nabla g(\mathbf x^k)
\]

以及正则项上的近端步骤

\[
\mathbf x^{k+1}=\operatorname{prox}_{\lambda h}(\mathbf z^k),\quad
\operatorname{prox}_{\lambda h}(\mathbf z):=
\arg\min_{\mathbf x}\frac12\|\mathbf x-\mathbf z\|_2^2+\lambda h(\mathbf x).
\]

求解近端算子相当于一个去噪问题。

**Flow／扩散模型作为 PnP 先验。** 近年的 PnP 方法用学习得到的去噪器 \(D_t\) 替代近端步骤，得到 \(\mathbf x^{k+1}=D_t(\mathbf z^k)\)（Zhu et al., 2023; Martin et al., 2025; Mardani et al., 2024; Zilberstein et al., 2025; Renaud et al., 2024; Laumont et al., 2022, 2023; Hu et al., 2024）。这种方法借助生成先验，仍保留 PnP 面向任意正向算子的灵活性。但由于 PnP 源于近端分裂，其输出偏向最大后验（MAP）类解，偏重低失真而牺牲感知质量，造成过度平滑。第 3 节将说明，用流映射的平均去噪器替代瞬时去噪器，可连续控制这一折衷。

### 2.3 失真—感知权衡

图像恢复常用平均失真 \(D=\mathbb E[\Delta(\mathbf x,\widehat{\mathbf x})]\)（如 MSE、LPIPS）度量估计和真实值间的差距。但重建还应在人眼看来自然，因此常另用感知质量指标。形式上，可用真实分布 \(p_x\) 与恢复结果边缘分布 \(p_{\widehat x}\) 的距离 \(P=d(p_x,p_{\widehat x})\) 衡量，例如 Wasserstein 距离，并用 FID（Heusel et al., 2017）、KID（Binkowski et al., 2018）等代理统计指标估计。

Blau & Michaeli（2018）形式化了失真与感知间的根本冲突。DP 函数定义为指定感知水平下任一估计器可达到的最小失真：

\[
D(P)=\min_{p_{\widehat x|y}}\mathbb E\|\mathbf x-\widehat{\mathbf x}\|_2^2
\quad\text{s.t.}\quad
W_2(p_x,p_{\widehat x})\le P.
\]

本文选 MSE 为失真、二阶 Wasserstein 距离为感知；\(D(P)\) 的图形为最优 DP 曲线。Freirich et al.（2021）证明，这一设置下有

\[
D(P)=D^\star+\bigl(\max\{P^\star-P,0\}\bigr)^2,
\]

其中 \(D^\star=\mathbb E\|\mathbf x-\mathbf x^\star\|_2^2\) 为 MMSE 失真，\(P^\star=W_2(p_x,p_{x^\star})\) 为后验均值 \(\mathbf x^\star=\mathbb E[\mathbf x|\mathbf y]\) 的感知差距。这里感知约束的是**重建结果边缘分布**，这也是 FID 和 KID 实际衡量的对象。指定感知水平的最优估计量是两个端点的插值：

\[
\widehat{\mathbf x}_P=
\left(1-\frac{P}{P^\star}\right)\widehat{\mathbf x}_0+
\frac{P}{P^\star}\mathbf x^\star. \tag{7}
\]

其中 \(\widehat{\mathbf x}_0\) 为完美感知估计器。结果说明整个 DP 前沿可由 MMSE 与最佳感知两个端点插值得到。以往方法通过插值独立估计器、任务特定训练（Delbracio & Milanfar, 2023; Ohayon et al., 2025）或调采样器（Wang et al., 2025; Zhang et al., 2026）访问中间点；本文追求由单一模型的条件输入直接参数化这条连续曲线。

**图 1：** 二维高斯混合逆问题中的 PnP 平均去噪器。观测为 \(\mathbf y=\mathbf H\mathbf x+\sigma\epsilon\)，\(\mathbf H\) 含旋转与缩放，\(\sigma=0.3\)。在 \(t=s\) 时，MMSE 去噪器使 PnP 重建集中在双峰后验的均值（位于两模态之间），失真较低但感知质量较差；当 \(t\to1\)，逐渐恢复双峰结构，输出分布在两个模态附近，代价是更高失真。细节见附录 B.4。[原图第 3 页](https://arxiv.org/pdf/2606.19802v2#page=3)

## 3. 平均去噪器：遍历 DP 平面

本节定义并分析流映射对应的平均去噪器及其与 DP 权衡的联系。

### 3.1 流映射作为去噪器

目标是用一个模型参数化估计器族，在 \(P=P^\star\)（最小失真）与 \(P=0\)（最佳感知）之间插值。自然候选是第 2.1 节流映射隐含的去噪器。相同对象曾由 Lee et al.（2026）及 Lu et al.（2026）独立地用于离散数据上的单步语言建模；本文研究连续情形，证明其可以参数化 DP 前沿。

**定义 1（平均去噪器）。** 给定具有平均速度 \(v(\cdot,s,t)\) 的流映射，定义平均去噪器（亦称双时间去噪器）：

\[
D_{s,t}(\mathbf x):=\mathbf x+(1-s)v(\mathbf x,s,t). \tag{8}
\]

它与式（3）的瞬时去噪器形式相同，但用区间 \([s,t]\) 上的平均速度替代时刻 \(s\) 的瞬时速度。关键区别是参数 \(t\) 控制 \(D_{s,t}\) 位于 DP 平面的什么位置：当 \(t=s\)，\(D_{s,s}\) 为失真最低的 MMSE 去噪器；当 \(t=1\)，有 \(D_{s,1}(\mathbf x)=X_{s,1}(\mathbf x)\)，它将含噪输入送至流的终点，因此输出服从数据分布、感知质量最好；中间的 \(t\) 对两者插值。因为 \(s,t\) 都是 \(v_\theta(\mathbf x,s,t)\) 的输入，一个训练好的模型就包含特性不同的一整族去噪器。

### 3.2 使用流映射遍历 DP 平面

#### 3.2.1 高斯情况的预备分析：一维

先研究可求闭式表达的高斯情形。推导在标量 \(x\in\mathbb R\) 下进行，对各向同性目标 \(\mathcal N(0,\sigma_p^2 I)\) 可逐分量推广。令 \(p_1=\mathcal N(0,\sigma_p^2)\)，取 \(\sigma_p^2\le1\) 只是一种归一化习惯，而非必需条件（见附录 D.2）。由第 2.1 节随机插值，噪声水平 \(t\) 的边缘方差为

\[
\sigma_t^2=t^2\sigma_p^2+(1-t)^2.
\]

瞬时去噪器为线性映射：

\[
\mathbb E[x_1|x_t=x]=a_t x,\quad a_t=\frac{t\sigma_p^2}{\sigma_t^2}.
\]

据式（3）的 Tweedie 关系，瞬时速度场也为线性映射 \(v(x,t)=b_t x\)，其中

\[
b_t=\frac{t(\sigma_p^2+1)-1}{\sigma_t^2}.
\]

**流映射与平均去噪器。** 由于速度线性，积分 \(\int_s^t b_\tau\,d\tau=\log(\sigma_t/\sigma_s)\) 得到标量流映射 \(x_t=\Phi(t,s)x_s\)，\(\Phi(t,s)=\sigma_t/\sigma_s\)。定义 1 给出 \(D_{s,t}(x_s)=\Lambda(s,t)x_s\)，增益为

\[
\Lambda(s,t)=\frac{(1-s)\sigma_t-(1-t)\sigma_s}{\sigma_s(t-s)}. \tag{9}
\]

当 \(t=s\) 时，\(\Lambda(s,s)=a_s\)，即 MMSE 增益；当 \(t=1\) 时，\(\Lambda(s,1)=\sigma_p/\sigma_s\)，刚好把 \(x_s\sim\mathcal N(0,\sigma_s^2)\) 变换为 \(p_1\)，达到最佳感知；并且增益随 \(t\) 严格递增（证明见附录 D.2）。

**高斯情况下的最优 DP 估计量。** 式（7）中的最优估计器仍是线性增益 \(\widehat x_P=\Gamma_s(\alpha)x_s\)，其中

\[
\Gamma_s(\alpha)=\alpha a_s+(1-\alpha)\frac{\sigma_p}{\sigma_s}. \tag{10}
\]

\(\alpha=P/P^\star\in[0,1]\) 表示感知水平，在 MMSE 增益 \(a_s\) 和完美感知增益 \(\sigma_p/\sigma_s\) 之间线性插值；它们都取决于噪声水平 \(s\)。

**定理 1（精确最优性）。** 设 \(p_1=\mathcal N(0,\sigma_p^2)\)，\(\sigma_p^2\le1\)，\(\Lambda(s,t)\) 是真实流映射对应的式（9）平均去噪器增益。则对每个 \(s\in(0,1)\) 和 \(t\in[s,1]\)，均存在感知水平

\[
\alpha(s,t)=
\frac{\sigma_p/\sigma_s-\Lambda(s,t)}
{\sigma_p/\sigma_s-a_s}\in[0,1], \tag{11}
\]

使 \(\Lambda(s,t)=\Gamma_s(\alpha(s,t))\)。此外，当 \(t\) 从 \(s\) 增至 1，\(\alpha(s,t)\) 从 1（MMSE，\(P=P^\star\)）单调降至 0（完美感知，\(P=0\)）。因此，\(D_{s,t}\) 在 \(t\in[s,1]\) 变化时**精确描绘最优 DP 曲线**。

证明见附录 D.2。其核心是 \(\Lambda(s,t)\) 和 \(\Gamma_s(\alpha)\) 都是连续单调函数，具有相同的两个端点：MMSE 的 \(a_s\) 和完美感知的 \(\sigma_p/\sigma_s\)。对 \(\Gamma_s(\alpha)=\Lambda(s,t)\) 求反函数，便得到前瞻参数与感知水平之间的一一对应。对于非各向同性的高斯目标 \(\mathcal N(0,\Sigma)\)，两端点仍严格最优，但中间 \(t\) 只有在谱平坦时才严格最优（附录 D.2.3）。

### 3.3 超越高斯情况：图像去噪实验

一般图像分布下，平均去噪器不再有闭式表达，严格 DP 最优性也不能保证。不过定理 1 的结构性直觉仍应成立：\(t\) 从 \(s\) 增至 1，\(D_{s,t}\) 的输出应平滑地从低失真、低感知质量的 MMSE 估计，过渡到更高失真、更佳感知对齐的估计。因此，我们预期：（i）由 \(t\) 参数化的平滑、单调 DP 曲线；（ii）与最优 DP 函数形状一致的凸轨迹。下面用图像实验检验，并在附录 D.3 的二维高斯混合中进一步验证。

**设置。** 在 CelebA 128×128 上训练流映射网络 \(v_\theta(x,s,t)\)（附录 B），对多个 \(t\in[s,1]\) 计算 \(D_{s,t}(x_s)\)。当 \(t=s\) 时得到 MMSE 去噪器，当 \(t=1\) 时到达流终点。由于 \(x_s=sx_1+(1-s)\epsilon\)、\(\epsilon\sim\mathcal N(0,I)\)，对 \(x_s\) 应用平均去噪器等价于从幅度为 \(s\) 的干净信号、标准差为 \(1-s\) 的噪声观测中恢复 \(x_1\)。将噪声级别参数化为 \(\xi:=1-s\in(0,1)\)，越大表示噪声越强。

**DP 遍历。** 图 2(a) 在 \(\xi\in\{0.1,0.3,0.5,0.7\}\) 四种噪声水平下，将前瞻 \(t\) 从 \(s\) 扫至 1，绘制经验 DP 曲线。平均去噪器确实给出平滑、单调轨迹：增大 \(t\) 会改善感知（FID 下降），但同时提高失真（RMSE 上升）。所得曲线呈最优 DP 函数所预言的凸形；但最大噪声级别下接近直线，作者将此归因于跨度较长的 \([s,1]\) 上流映射近似误差（附录 C.9）。一个训练模型即可实现平滑连续的 DP 参数化。

噪声越强，可遍历范围越宽。对于 \(\xi=0.1\)，由于 MMSE 估计已经接近真实数据分布，范围较窄；\(\xi=0.7\) 时前瞻覆盖更宽的工作点。这与 Freirich et al.（2021）一致：噪声增大，感知差距 \(P^\star\) 也增大，失真与感知之间可权衡的空间更大。图 35 直观展示，随 \(t\) 增大，恢复图像从平滑平均值逐渐变得清晰、细节丰富。

**图 2：** CelebA 128×128 去噪的 DP 权衡与方差恢复。（a）不同噪声级别下 RMSE 对 FID 曲线，均由单模型改变 \(t\) 得到；（b）重建方差比与 FID 的关系，各噪声级别曲线近似重合，提示方差恢复与感知质量之间存在共同关系。[原图第 6 页](https://arxiv.org/pdf/2606.19802v2#page=6)

**方差恢复。** 为什么增大 \(t\) 可以改善感知质量？全方差公式提供了部分解释：

\[
\operatorname{Var}(x_1)=
\operatorname{Var}(\mathbb E[x_1|x_s])+
\mathbb E[\operatorname{Var}(x_1|x_s)].
\]

由于第二项严格为正，MMSE 估计器 \(D_s(x_s)=\mathbb E[x_1|x_s]\) 的方差小于真实数据：\(\operatorname{Var}(D_s(x_s))<\operatorname{Var}(x_1)\)。这一方差缺口会使对比度下降、图像过度平滑；式（7）的最优 DP 估计器恰好通过插值修复此缺口。随着前瞻 \(t\) 增大，平均去噪器逐步恢复方差，从而在同一个模型中完成权衡遍历。

不过单纯匹配方差并不足够：添加独立噪声也能恢复方差，却会破坏重建。对于高斯目标，最优的完美感知估计器实际上是**不额外加入噪声的确定性传输映射**（Freirich et al., 2021，定理 4、推论 2），而 \(D_{s,1}\) 正好与其对应。图 2(b) 实验显示方差比和 FID 共同改善，并在不同噪声水平下遵循近乎相同的关系，支持方差恢复解释。

## 4. 使用平均去噪器的即插即用求解

现在将式（8）嵌入第 2.2 节 PnP 框架，求解一般逆问题，并连续控制 DP。须强调：DP 解释首先适用于去噪器 \(D_{s,t}\)；整体 PnP 输出还受到正向模型交互的影响。所以在一般逆问题中，前瞻是同时影响感知对齐与数据一致性的正则化参数，而不是严格生成去噪理论中的同一条 DP 前沿。

**算法。** 给定训练流映射 \(v_\theta(\cdot,s,t)\)、观测 \(\mathbf y\) 和指定前瞻，交替执行数据保真项 \(g(\mathbf x)=\frac12\|\mathbf y-f(\mathbf x)\|_2^2\) 的梯度下降，以及使用平均去噪器的近端步骤。参照 Martin et al.（2025），在去噪前额外执行重新加噪：将梯度更新后的变量重新投影到噪声水平 \(s_k\) 对应分布的支撑区域，保证 \(D_{s_k,t_k}\) 接收其设计噪声水平下的输入。噪声水平不被直接调参，而遵循欧拉离散 \(s_k=k/N\)，\(k=0,\ldots,N-1\)，\(N\) 是 PnP 迭代次数。前瞻采取常数偏移 \(\Delta\)：

\[
t_k=\min(s_k+\Delta,1).
\]

**算法 1：基于流映射去噪器的 PnP。** 输入训练好的 \(v_\theta(\cdot,s,t)\)、观测 \(\mathbf y\)、正向模型 \(f\)、迭代次数 \(N\)、\(s_k=k/N\)、\(t_k\in[s_k,1]\)、步长 \(\lambda_k\)。初始化 \(\mathbf x^0\)。对 \(k=0,\ldots,N-1\)：

\[
\begin{aligned}
\mathbf z^k&=\mathbf x^k-\lambda_k\nabla g(\mathbf x^k)
&&\text{（数据保真梯度步）},\\
\epsilon&\sim\mathcal N(0,I),\\
\widetilde{\mathbf z}^k&=(1-s_k)\epsilon+s_k\mathbf z^k
&&\text{（重新加噪至 }s_k\text{）},\\
\mathbf x^{k+1}&=\widetilde{\mathbf z}^k+(1-s_k)
v_\theta(\widetilde{\mathbf z}^k,s_k,t_k)
&&\text{（平均去噪器）}.
\end{aligned}
\]

循环结束返回 \(\mathbf x^N\)。

**重新加噪的作用。** 该随机步骤是前瞻参数能够成为逆问题 DP 控制旋钮的关键：它使 \(D_{s,t}\) 工作于其理论设计噪声水平 \(s\)，从而处于定理 1 的适用状态。注入的噪声 \((1-s_k)\epsilon\) 本身不是待优化超参数，因此可调自由度只有前瞻。不使用重新加噪且高斯先验时，迭代退化成固定点 Tikhonov 估计器，前瞻仅成为偏差—方差旋钮，见附录 D.5。一般情况下，迭代仍偏向 MAP，改变前瞻相当于改变隐式正则项，其收敛依赖退火调度而非收缩性（附录 D.4、D.5）。

**成本和与 PnP-Flow 的关系。** 算法 1 每轮只需调用速度网络一次，当 \(t_k=s_k\) 时退化为 PnP-Flow（Martin et al., 2025）。由于前瞻 \(t\) 仅作为条件输入，不增加计算成本，因此相比需要 ODE 反向传播或迹运算的方法保持较高效率。

## 5. 相关工作

**逆问题的相容性模型与流映射。** 相容性模型（Consistency Models；Song et al., 2023b）学习将概率流 ODE 上任意点映射到同一轨迹的原点，实现单步生成。相容性轨迹模型（Kim et al., 2025）和流映射（Boffi et al., 2025a）通过学习 ODE 解算子，将其拓展至任意时间对 \((s,t)\)。近期工作将它们用于受控生成，或作为引导采样器（Sabour et al., 2025a; Spagnoletti et al., 2025; Garber & Tirer, 2025; Holderrieth et al., 2026），或作为先验（Gülle et al., 2026），或用于优化初始噪声（Mammadov et al., 2026）。与本文并行的 Huang et al.（2026）也使用流映射进行引导，将基于奖励的生成描述为最优控制问题，并用流映射快速执行引导采样。不过，这些方法主要关注在固定工作点上加速采样，未显式提供恢复权衡控制。本文则将 \(t\) 看成连续参数，使单个流映射成为遍历 DP 平面的估计器族。

**遍历 DP 平面的其他方法。** 近年来有方法学习退化分布到干净分布之间的数据依赖流，以控制 DP。Inversion by Direct Iteration（InDI；Delbracio & Milanfar, 2023）与随机插值（Albergo et al., 2024）学习测量到干净图像的流；Posterior-Mean Rectified Flow（PMRF；Ohayon et al., 2025）把源分布替换为后验均值的近似；OFTSR（Zhu et al., 2026）把一步超分辨率流蒸馏成带可调保真—真实度参数的模型。不过，这些方法依赖成对 \((y,x)\) 数据的监督；PMRF 和 OFTSR 还需要辅助模型或教师模型。相比之下，本文只用干净图像训练单个**无条件流映射**，前瞻参数自然构成连续去噪器族，并通过 PnP 推理适用于任意正向算子。

更接近本文设置的无需额外训练方案，通常针对预训练模型改变采样器：DiffPIR（Zhu et al., 2023）缩放每步注入噪声；DDPG（Garber & Tirer, 2024）在反投影和最小二乘引导之间插值；Wang et al.（2025）缩放反向 SDE 注入噪声；MAP-RPS（Zhang et al., 2026）在后验采样前对 MAP 估计重新加噪。更多方法见附录 C.5。

旋钮作用的位置决定实际被控制的对象。上述方法由于逐观测地控制输出，遍历的是**条件 DP 平面**，一般要求随机估计器。而本文固定求解器，只改变去噪器：通过确定性地传输估计器本身，遍历 **边缘 DP 平面**，后者恰是 FID 衡量的对象；其最优估计器已被证明可以是确定性的（Freirich et al., 2021）。与 Wang et al. 和 MAP-RPS 的比较见附录 C.5。

## 6. 数值实验

实验有两个目标：（i）在最新方法中取得有竞争力的性能；（ii）表明单个训练模型可连续遍历 DP 平面。

**设置。** 在 CelebA 128×128 和 AFHQ 256×256 两个数据集上分别从头训练流映射 \(v_\theta(x,s,t)\)。使用 Song U-Net 架构（Song et al., 2020; Ronneberger et al., 2015），以第 2.1 节的 LSD 目标训练，包括对角线与非对角线项，细节见附录 B.1。不同采样器的重建质量使用 MSE 转换得到的 PSNR（\(\mathrm{PSNR}=-10\log_{10}\mathrm{MSE}\)）及两个感知指标 LPIPS（Zhang et al., 2018）、DISTS（Ding et al., 2020）；另外在测试图像和采样样本集合上计算 FID（Heusel et al., 2017）、KID（Binkowski et al., 2018）。评价采用 100 个样本的均值。全部方法在大多数任务下使用标准差 \(\sigma=0.05\) 的高斯噪声，90% 随机修复任务采用 \(\sigma=0.01\)；附录 C.2.2 还考虑泊松噪声。

比较最近使用预训练流模型的方法：OT-ODE（Pokle et al., 2024）、Flow Priors（Zhang et al., 2024）、D-Flow（Ben-Hamu et al., 2024）、DPS-ODE（Chung et al., 2023）及 PnP-Flow（Martin et al., 2025），后者相当于本文方法的 \(t=s\) 情形。对所有模型使用相同的训练网络作为先验／正则器，执行超参数网格搜索，以各方法本身追求的指标为目标：后验采样器对感知指标调参，优化式方法对 PSNR 调参。细节见附录 B.2；附录 C.4 还比较仅使用对角线损失训练的普通流匹配先验。

### 6.2 DP 权衡分析

现在研究前瞻 \(t\) 如何在 DP 平面内移动并控制重建特性。在 PnP 求解器中，对多个前瞻偏移 \(\Delta\) 计算去噪器族 \(D_{s,t}\)，报告 RMSE（失真）与 FID（感知），其他超参数在各任务内保持固定、所有前瞻共享；方框修复采用 80×80 遮挡区域。

结果见图 3。两个观察尤为突出。第一，改变 \(t\) 产生平滑、近乎单调的 DP 轨迹：较小前瞻给出最低 RMSE，较大前瞻给出最低 FID，中间工作点平滑插值。这与第 3.2.1 节理论一致，说明此行为扩展到了自然图像和一般退化。第二，尽管正向算子截然不同，五种逆问题——高斯、运动去模糊；随机、方框修复；超分辨率——都表现相同的定性趋势，提示由 \(t\) 产生的 DP 控制不依赖具体退化类型。唯一明显例外是 \(t\) 接近 1 时的方框修复，原因见附录 C.13。对于 JPEG 恢复、彩色化等非线性任务，也观察到类似表现（附录 C.2.1）。

## 7. 讨论与局限性

本文引入流映射去噪器，对标准瞬时去噪器进行推广，使其能够无需任务特定训练而连续遍历 DP 权衡。把流映射重新理解为由前瞻 \(t\) 索引的平均去噪器连续统后，流映射便与最优 DP 估计量的理论关联起来。该遍历对各向同性高斯目标严格最优，在自然图像上也被实验观察到。在 PnP 求解器中，本文方法可以在推理阶段针对多种退化连续控制恢复质量，无须重新训练、成对数据或辅助模型。

但方法也有局限。第一，严格最优性结果只在高斯情形成立，本文没有提供 PnP 迭代的收敛保证。某些退化甚至产生非单调 DP 行为，例如图 3 的方框修复，作者认为由具有空间相干性的零空间造成；相位恢复的非单调性则可能来自非凸数据保真项（附录 C.13）。第二，流映射的训练成本高于普通流匹配：在 8 张 A100 GPU 上大约分别需要 10 天与 4 天，并且在 PSNR 等纯失真指标上可能不占优。第三，虽然增加 \(t\) 通常推动重建向 DP 平面的感知端移动，\(t=1\) 也不总是取得最佳感知指标。这表明前瞻的核心定位应是**遍历 DP 权衡的机制**，而不是保证每项恢复任务达到感知最优点的方法。

未来方向包括直接使用基于 Stein 无偏风险估计 SURE 或相容性损失训练平均去噪器（Raphan & Simoncelli, 2011; Daras et al., 2025; Tachella et al., 2025）。此外，实验只采用像素空间模型（CelebA 128、AFHQ 256），扩展到潜空间和文本生成图像仍是重要方向。

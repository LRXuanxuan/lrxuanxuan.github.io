## 摘要

本文研究大规模多输入多输出系统中的移动性问题，该问题会给第五代移动通信网络的实际部署带来显著性能损失。本文提出基于多维矩阵束（MDMP）的新型信道预测方法，利用宽带信道在角度–频率域和角度–时间域中的结构估计路径参数。根据角度估计的超分辨率特性，还设计了一种将时延与多普勒配对的新方法。所提方法能处理用户移动造成的路径时延变化这一实际约束，以往文献尚未考虑该约束。本文从理论上证明，在路径时延随时间变化的场景中，只需已知任意两个信道样本，随着基站天线数增加，预测误差趋于零。本文还推导了取得令人满意性能所需基站天线数的下界。采用 3GPP 工业信道模型的仿真表明，即使用户速度达到 120 km/h、信道状态信息时延达到 16 ms，所提 MDMP 方法也可以接近静止场景的性能。

**关键词** 大规模 MIMO、移动性、信道预测、CSI 时延、矩阵束、MDMP 预测方法、信道结构。

## I. 引言

大规模多输入多输出（MIMO）技术对提升第五代（5G）移动通信系统的频谱效率发挥关键作用 [2]。相较于传统 MIMO，大规模 MIMO 通过在基站（BS）部署更多阵元，大幅提高移动通信系统的容量与可靠性 [3]。

在理论上，大规模 MIMO 的性能取决于信道状态信息（CSI）的准确性。实际中，导频污染 [4]、频分双工（FDD）模式下的非理想 CSI 反馈 [2]、移动性问题 [5]（或称“移动性诅咒”）等均会使 CSI 不准确。已有许多工作研究 FDD 下的导频污染及 CSI 反馈问题，例如 [6]–[9]。相比之下，移动性问题迄今受到的关注相对较少，仍是待解决的难题。它主要由用户设备（UE）的移动性和 CSI 时延造成 [5]。UE 运动使 CSI 估计过时，难以用于多用户预编码，尤其是在 CSI 时延较大的高移动性场景中。一些研究关注 CSI 时延的影响，证明其会损害大规模 MIMO 的频谱效率 [10]–[13]。

一种解决办法是信道预测，已有文献对此展开研究。文献 [14] 提出用时空基展开模型（ST-BEM）预测下行（DL）信道。文献 [15] 提出压缩感知信道预测方法，文献 [16] 提出高效的近似最大似然估计器。但上述文献通常假设信道参数随时间不变，这在实际移动场景中可能难以成立。文献 [17] 研究 Wi-Fi 通信场景中的时变时延，并提出一种迭代信道估计器，其利用离散长椭球（DPS）序列张成的二维子空间。DPS 序列比离散傅里叶变换（DFT）序列的频谱泄漏更小。然而，DPS 序列在应用中需要满足 $\omega_{\max}T\ll1$ 和 $\tau_{\max}\Delta f\ll1$ 两个特定条件，其中 $\omega_{\max}$ 为最大多普勒，$\tau_{\max}$ 为最大时延，$T$ 为样本的持续时间，$\Delta f$ 为子载波间隔。在实际中这些条件不易满足。

近年来，机器学习（ML）和神经网络（NN）算法，如循环神经网络、常规神经网络及深度神经网络，已通过用历史数据训练的网络来预测信道 [18]–[21]。文献 [21] 采用复值神经网络算法，提出数据驱动的信道预测方法。然而，这些算法通常需要大量数据，在实际系统中不易采集。此外，算法在静态和低移动场景中的表现或许良好，但因训练时间长，在高移动场景中可能无法取得预期效果。由于网络泛化存在挑战，在变化环境中训练好的网络也可能无法达到理想性能。

将宽带信道变换至角度–时延<a id="page-2"></a>域后，文献 [5] 提出了基于 Prony 法的角度–时延域（PAD）预测方法，并证明其可缓解 CSI 老化问题。但该方法未考虑时变路径时延的影响，并假定 CSI 时延为导频间隔的整数倍。据作者所知，现有文献大多忽略了时变路径时延这一现实影响。它使路径时延难以跟踪，并造成传统时域多径信道结构失真。

为突破上述限制并解决移动性问题，本文提出一种基于矩阵束（MP）的新型超分辨率信道预测方法。超分辨率特性来自 MP 算法对参数的极高估计精度。已有一些研究采用 MP 算法估计信道参数。文献 [22] 采用二维 MP 算法估计二维频率，文献 [23] 在 IEEE 802.11ac 场景中估计路径角度和时延，文献 [24] 估计离开仰角（EOD）、离开方位角（AOD）与时延。与多重信号分类（MUSIC）[25]、旋转不变技术的信号参数估计（ESPRIT）[26] 等传统超分辨率算法相比，MP 算法有其优势，无需在参数空间中搜索峰值，所需信道样本也较少。但受时变路径时延和宽带大规模 MIMO 信道多维结构的影响，传统 MP 算法无法直接解决大规模 MIMO 的移动性问题。

为提高信道预测准确性，本文将传统 MP 方法推广为可同时提取 EOD、AOD、时变时延与多普勒的多维算法。具体而言，先用三维（3-D）MP 算法在角度–频率域估计 EOD、AOD 和时延，再用另一种三维 MP 算法在角度–时间域估计 EOD、AOD 和多普勒。根据所估 EOD 和 AOD 的超分辨率特性，设计路径间的时延–多普勒配对算法，然后用估计参数重构未来的 CSI。据作者所知，本文的多维矩阵束（MDMP）方法是在多个路径上同时估计 EOD、AOD、多普勒和时变时延的首次尝试。

本文的贡献如下。

- 提出超分辨率 MDMP 预测方法，以解决时变路径时延下的移动性问题。通过利用信道的角度–时间域和角度–频率域结构，同时估计多径 EOD、AOD、时延及多普勒。仿真结果证实，所提方法相较传统方法具有显著增益。
- 证明当基站天线数和带宽足够大时，在具有任意 CSI 时延的移动场景中，MDMP 方法的预测误差趋于零，突破了 PAD 方法对 CSI 时延须为导频间隔整数倍的限制。
- 还证明当基站天线数足够大时，只需已知任意两个样本，预测误差即趋于零。MDMP 方法对两个样本是否相邻没有要求，而多数现有工作作此假设。
- 推导在宽带信道中使 MDMP 方法达到令人满意性能所需基站天线数的下界。下界与样本数相关，且随样本数增加而降低。

本文结构如下。第 II 节介绍信道模型，第 III 节提出 MDMP 预测方法，第 IV 节分析 MDMP 方法的性能，第 V 节给出仿真结果，第 VI 节总结全文。

**记号** 用粗体表示向量和矩阵。$\mathbf 0_{M_1\times N_1}$、$\mathbf I_{M_2}$、$\Upsilon_{M_3}$、$\mathbf1_{M_4\times N_5}$ 分别表示 $M_1\times N_1$ 零矩阵、$M_2\times M_2$ 单位矩阵、$M_3\times M_3$ 反单位矩阵和 $M_4\times N_5$ 全一矩阵。$(\mathbf X)^T$、$(\mathbf X)^*$、$(\mathbf X)^H$、$(\mathbf X)^{-1}$ 和 $(\mathbf X)^\dagger$ 分别表示矩阵 $\mathbf X$ 的转置、共轭、共轭转置、逆与 Moore–Penrose 伪逆。$\operatorname{card}(\cdot)$ 表示集合元素数量，$r\{\cdot\}$ 表示矩阵的秩，$\|\cdot\|_F$ 表示 Frobenius 范数。$\mathrm{Re}\{\cdot\}$ 和 $\mathrm{Im}\{\cdot\}$ 分别取得复数实部和虚部，$E\{\cdot\}$ 为期望运算。$\operatorname{diag}\{\cdot\}$ 表示矩阵的对角操作。$[\mathbf X:\mathbf Y]$ 是 $\mathbf X$ 和 $\mathbf Y$ 的扩展矩阵。$\mathbf X\odot\mathbf Y$ 与 $\mathbf X\otimes\mathbf Y$ 分别表示 Hadamard 积与 Kronecker 积。

## II. 信道模型

考虑宽带时分双工（TDD）大规模 MIMO 系统，其中一个基站服务多个 UE。在此类系统中，基站根据上行（UL）导频估计 CSI，并基于信道互易性获得下行 CSI。

**图 1：** 基站与 UE 之间的多径信道。

图 1 展示了基站与 UE 之间的信道。在多数商用 5G 系统中，基站配备由 $N_h^{\mathrm{BS}}$ 列和 $N_v^{\mathrm{BS}}$ 行天线阵元构成的均匀面阵（UPA）。

<a id="page-3"></a>

基站天线数和 UE 天线数分别为 $N_t=N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}$ 和 $N_r^{\mathrm{UE}}$。共有 $M_{\mathrm{cluster}}$ 个不同的簇，记为 $S_i$，$i=1,2,\ldots,M_{\mathrm{cluster}}$。每个簇包含许多散射射线。上行与下行信道共用同一带宽，由 $N_f$ 个间隔为 $\Delta f$ 的子载波构成。

基站到 UE 的下行 MIMO 信道可表示为 $\mathbf H(t,f)=[h_{u,s_h,s_v}(t,f)]_{N_r^{\mathrm{UE}}\times N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}}$。其中 $h_{u,s_h,s_v}(t,f)$ 表示基站面阵第 $s_h$ 列、第 $s_v$ 行阵元与 UE 第 $u$ 根天线之间的信道频率响应，模型为 [27]

$$
\begin{array}{l}
\!\!\!{h_{u,{s_h},{s_v}}}(t,f)\\
\!\!\!= \sum\limits_{p = 1}^P {} {\beta _p}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_p^{ {\mathrm{rx}}}})^T}{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_p^{ {\mathrm{tx}}}})^T}{\mathbf{\bar d}}_{ {s_h},{s_v}}^{ {\mathrm{tx}}}}}{ { {\lambda _0}}}}}{e^{j2\pi {\omega _p}t}}{e^{-j2\pi f{\tau _p}(t)}}
\end{array},
\tag{1}
$$

其中 $P$ 是路径数，$\beta_p$ 为第 $p$ 条路径的复幅度。$\lambda_0=c/f_c$ 为波长，其中 $f_c$ 是中心载频，$c$ 是光速。$\hat{\mathbf r}_p^{\mathrm{rx}}$ 和 $\hat{\mathbf r}_p^{\mathrm{tx}}$ 分别表示 UE 和基站处的球面单位向量，表达式为

$$
\begin{array}{l}
{\mathbf{\hat r}}_p^{ {\mathrm{rx}}} = \left[ \begin{array}{l}
\cos {\theta _{p,{\mathrm{EOA}}}}\cos {\phi _{p,{\mathrm{AOA}}}}\\
\cos {\theta _{p,{\mathrm{EOA}}}}\sin {\phi _{p,{\mathrm{AOA}}}}\\
\ \ \ \ \ \ \ \sin {\theta _{p,{\mathrm{EOA}}}}
\end{array} \right],
\end{array}
\tag{2}
$$

$$
\begin{array}{l}
{\mathbf{\hat r}}_p^{ {\mathrm{tx}}} = \left[ \begin{array}{l}
\cos {\theta _{p,{\mathrm{EOD}}}}\cos {\phi _{p,{\mathrm{AOD}}}}\\
\cos {\theta _{p,{\mathrm{EOD}}}}\sin {\phi _{p,{\mathrm{AOD}}}}\\
\ \ \ \ \ \ \ \sin {\theta _{p,{\mathrm{EOD}}}}
\end{array} \right],
\end{array}
\tag{3}
$$

其中 $\theta_{p,\mathrm{EOA}}$、$\phi_{p,\mathrm{AOA}}$、$\theta_{p,\mathrm{EOD}}$ 和 $\phi_{p,\mathrm{AOD}}$ 分别表示到达仰角（EOA）、到达方位角（AOA）、EOD 和 AOD。另外，$\bar{\mathbf d}_{s_h,s_v}^{\mathrm{tx}}$ 和 $\bar{\mathbf d}_u^{\mathrm{rx}}$ 分别为基站和 UE 的天线位置向量：

$$
{\mathbf{\bar d}}_{ {s_h},{s_v}}^{ {\mathrm{tx}}} = {\left[ {\begin{array}{cccccccccccccccccccc}{0,}&{d_h^{ {\mathrm{tx}}}({s_h} - 1),}&{d_v^{ {\mathrm{tx}}}({s_v} - 1)} \end{array}} \right]^T},
\tag{4}
$$

其中 $d_h^{\mathrm{tx}}$ 是水平天线间距，$d_v^{\mathrm{tx}}$ 是垂直天线间距。此外，$\omega_p=(\hat{\mathbf r}_p^{\mathrm{rx}})^T\mathbf v/\lambda_0$ 表示多普勒，$\mathbf v$ 为 UE 的速度向量：

$$
{\mathbf{v}} = v{\left[ {\begin{array}{cccccccccccccccccccc}{\cos {\theta _v}\cos {\phi _v},}&{\cos {\theta _v}\sin {\phi _v},}&{\sin {\theta _v}} \end{array}} \right]^T},
\tag{5}
$$

其中 $v$ 为速率，$\theta_v$ 与 $\phi_v$ 分别是速度的仰角与方位角。第 $p$ 条路径的时延 $\tau_p(t)$ 随时间变化，模型为 [27]

$$
{\tau _p}(t) = {\tau _{p,0}} + {k_{ {\tau _p}}} t = {\tau _{p,0}} - \frac{ {({\mathbf{\hat r}}{ {_p^{ {\mathrm{rx}}}})^T}{\mathbf{v}}}}{ {\mathrm{c}}} t = {\tau _{p,0}} - \frac{ { {\omega _p}}}{ { {f_c}}} t,
\tag{6}
$$

其中 $\tau_{p,0}$ 为初值，$k_{\tau_p}$ 是路径时延的变化率。多普勒除了影响时域，也会影响频域。

三维导向向量 $\mathbf a^{\mathrm{tx}}(\theta_p,\phi_p)$ 可表示为

$$
\begin{array}{l}
{ {\mathbf{a}}^{ {\mathrm{tx}}}}({\theta _{p}},{\phi _{p}})= {\left[ {\begin{array}{cccccccccccccccccccc}{ {(a_h^{ {\mathrm{tx}}})}^0,}&{ {(a_h^{ {\mathrm{tx}}})}^1,}&{\cdots,}&{ {(a_h^{ {\mathrm{tx}}})}^{(N_h^{ {\mathrm{BS}}} - 1)}} \end{array}} \right]^T}\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \otimes {\left[ {\begin{array}{cccccccccccccccccccc}{ {(a_v^{ {\mathrm{tx}}})}^0,}&{ {(a_v^{ {\mathrm{tx}}})}^1,}&{\cdots,}&{ {(a_v^{ {\mathrm{tx}}})}^{(N_v^{ {\mathrm{BS}}} - 1)}} \end{array}} \right]^T},
\end{array}
\tag{7}
$$

为简便起见，用 $\theta_p$ 和 $\phi_p$ 表示 $\theta_{p,\mathrm{EOD}}$ 和 $\phi_{p,\mathrm{AOD}}$。此外，$a_h^{\mathrm{tx}}$ 和 $a_v^{\mathrm{tx}}$ 分别表示 $\cos(\theta_p)\sin(\phi_p)$ 及 $\sin(\theta_p)$ 方向的空间特征：

$$
a_h^{ {\mathrm{tx}}} = {\mathrm{exp}}({\frac{ {j2\pi d_h^{ {\mathrm{tx}}}\cos ({\theta _p})\sin({\phi _p})}}{ { {\lambda _0}}}}),
\tag{8}
$$

$$
a_v^{ {\mathrm{tx}}} = {\mathrm{exp}}({\frac{ {j2\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _p})}}{ { {\lambda _0}}}}).
\tag{9}
$$

将所有基站天线与 UE 第 $u$ 根天线之间在时刻 $t$、频率 $f$ 处的信道记为 $\mathbf h_u(t,f)$：

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!\!{ {\mathbf{h}}_u}(t,f) \!=\!\! \sum\limits_{p = 1}^P {} \!\!{\beta _p}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_p^{ {\mathrm{rx}}}}})^T{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}}\!\!{e^{j2\pi {\omega _p}t}}{e^{-j2\pi f{\tau _p}(t)}}{ {\mathbf{a}}^{ {\mathrm{tx}}}}({\theta _{p}},{\phi _{p}}).\!\!
\!\!\!\end{array}
\tag{10}
$$

在时域，各子载波上的信道表示为

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!\!{ {\mathbf{H}}_u}(t) = [{\begin{array}{cccccccccccccccccccc}{ {\mathbf{h}}_u^T(t,{f_1}),}&{ {\mathbf{h}}_u^T(t,{f_2}),}&{\cdots,}&{ {\mathbf{h}}_u^T(t,{f_{ {N_f}}})} \end{array}}],
\!\!\!\end{array}
\tag{11}
$$

其中 $f_{n_f}$ 为第 $n_f$ 个子载波的频率：

$$
{f_{ {n_f}}} = {f_1} + ({n_f} - 1)\Delta f,{\mathrm{ }}{n_f} = 1,2, \cdots {N_f}.
\tag{12}
$$

根据角度–频率域信道结构，$\mathbf H_u(t)$ 可改写为

$$
{ {\mathbf{H}}_u}(t) = {\mathbf{A}}_u^{ {\mathrm{tx}}}{ {\mathbf{C}}_u}{ {\mathbf{B}}_u},
\tag{13}
$$

其中 $\mathbf A_u^{\mathrm{tx}}$ 包含各路径的三维导向向量：

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!\!\!{\mathbf{A}}_u^{ {\mathrm{tx}}} = [{\begin{array}{cccccccccccccccccccc}{ { {\mathbf{a}}^{ {\mathrm{tx}}}}({\theta _{1}},\!{\phi _{1}}),}&{\cdots,}&{ { {\mathbf{a}}^{ {\mathrm{tx}}}}({\theta _{P}},\!{\phi _{P}})} \end{array}}].
\!\!\!\!\!\!\!\end{array}
\tag{14}
$$

频域矩阵 $\mathbf B_u$ 表示为

$$
{ {\mathbf{B}}_u} = \left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{b}}({f_1}),}&{ {\mathbf{b}}({f_2}),}&{\cdots,}&{ {\mathbf{b}}({f_{ {N_f}}})} \end{array}} \right],
\tag{15}
$$

其中 $\mathbf b(f_{n_f})$ 表示第 $n_f$ 个子载波上的时延响应向量：

$$
{\mathbf{b}}({f_{ {n_f}}}) = {\left[ {\begin{array}{cccccccccccccccccccc}{e^{ - j2\pi {f_{ {n_f}}} {\tau _1}(t)},}&{\cdots,}&{ {e^{ - j2\pi {f_{ {n_f}}} {\tau _P}(t)}}} \end{array}} \right]^T}.
\tag{16}
$$

对角矩阵 $\mathbf C_u$ 可表示为

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!{ {\mathbf{C}}_u}\\
\!\!\!\!\!\!\!=\! {\mathrm{diag}}\!\!\left\{\! { {\beta _1}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_1^{ {\mathrm{rx}}}}})^T{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}}\!{e^{j2\pi {\omega _1}t}}, \!\cdots \!,{\beta _P}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_P^{ {\mathrm{rx}}}}})^T{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}}\!{e^{j2\pi {\omega _P}t}}} \!\right\}\!\!.
\!\!\end{array}
\tag{17}
$$

根据角度–时间域信道结构，$\mathbf H_u(t)$ 还可改写为

$$
{ {\mathbf{H}}_u}(t) = {\mathbf{A}}_u^{ {\mathrm{tx}}}{ {\mathbf{D}}_u}({ {\mathbf{E}}_u} \odot { {\mathbf{F}}_u}),
\tag{18}
$$

其中 $\mathbf D_u$ 是一个对角矩阵：

$$
{ {\mathbf{D}}_u} = {\mathrm{diag}}\left\{ {\begin{array}{cccccccccccccccccccc}{ {\beta _1}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_1^{ {\mathrm{rx}}}}})^T{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}},}&{\cdots,}&{ {\beta _P}{e^{\frac{ {j2\pi ({\mathbf{\hat r}}{ {_P^{ {\mathrm{rx}}}}})^T{\mathbf{\bar d}}_u^{ {\mathrm{rx}}}}}{ { {\lambda _0}}}}}} \end{array}} \right\}.
\tag{19}
$$

矩阵 $\mathbf E_u$ 由各子载波的初始时延响应向量组成：

$$
{ {\mathbf{E}}_u} = \left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{e}}({f_1}),}&{ {\mathbf{e}}({f_2}),}&{\cdots,}&{ {\mathbf{e}}({f_{ {N_f}}})} \end{array}} \right],
\tag{20}
$$

其中 $\mathbf e(f_{n_f})$ 对应第 $n_f$ 个子载波：

$$
{\mathbf{e}}({f_{ {n_f}}}) = {\left[ {\begin{array}{cccccccccccccccccccc}{e^{ - j2\pi {f_{ {n_f}}} {\tau _{1,0}}},}&{\cdots,}&{e^{ - j2\pi {f_{ {n_f}}} {\tau _{P,0}}}} \end{array}} \right]^T}.
\tag{21}
$$

时域矩阵 $\mathbf F_u$ 表示为

$$
{ {\mathbf{F}}_u} = {\left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{f}}({f_1}),}&{ {\mathbf{f}}({f_2}),}&{\cdots,}&{ {\mathbf{f}}({f_{ {N_f}}})} \end{array}} \right]^T},
\tag{22}
$$

<a id="page-4"></a>

其中对 $1\leq n_f\leq N_f$，$\mathbf f(f_{n_f})$ 定义为

$$
\!{\mathbf{f}}({f_{ {n_f}}}) = {\left[ {\begin{array}{cccccccccccccccccccc}{e^{j2\pi ({\omega _1} - {f_{ {n_f}}} {k_{ {\tau _1}}})t},}&{\cdots,}&{e^{j2\pi ({\omega _P} - {f_{ {n_f}}} {k_{ {\tau _P}}})t}} \end{array}} \right]^T}\!\!\!.
\tag{23}
$$

由于这里同时考虑多普勒对时域和频域的影响，式 (18) 与文献 [5] 的结果不同。接下来用所提 MDMP 方法联合估计多径时延、角度与多普勒。

## III. 所提 MDMP 预测方法

本节介绍所提用于信道预测的 MDMP 超分辨率方法。该方法先利用信道的角度–频率域和角度–时间域结构估计 EOD、AOD、时延和多普勒，再通过路径配对确定对应的各路径参数。最后，基站用估计参数重构未来信道，从而预测 CSI。

为便于理解，下面简述第 III-A 节和第 III-B 节的推导。两节推导相似，以第 III-A 节为例，主要包含五步：根据信道生成三维 MP 矩阵，将三维复数 MP 矩阵转换为实矩阵，确定路径数，估计路径时延，以及估计 EOD 和 AOD。

### A. 三维角度–时延估计

先生成三维 MP 矩阵。为便于说明，先介绍一维矩阵束，再推广到二维和三维情形。具体而言，首先沿基站面阵水平方向开窗，生成仅包含 $\cos\theta_p\sin\phi_p$ 信息的一维 MP 矩阵。随后在基站面阵的垂直方向增加第二个窗口，生成同时包含 $\sin\theta_p$ 信息的二维 MP 矩阵。最后，在二维 MP 矩阵的基础上在频域增加第三个窗口，生成包含路径时延信息的三维 MP 矩阵。下文给出细节。

根据角度–频率域信道结构，在基站面阵中滑动水平窗口生成一维 MP 矩阵 $\mathbf G_{u,r}(t,n_f)\in\mathbb C^{L\times(N_h^{\mathrm{BS}}-L+1)}$，定义为

$$
{ {\mathbf{G}}_{u,r}}(t,{n_f}) \!=\!\! \left[\!\! \begin{array}{l}
{h_{u,1,r}}(t,{n_f}), \cdots \!,{h_{u,(N_h^{ {\mathrm{BS}}} \!-\! L \!+\! 1),r}}(t,{n_f})\\
 \ \ \ \ \ \ \vdots \ \ \ \ \ \ \ \ \ \ddots \ \ \ \ \ \ \ \ \vdots \\
{h_{u,L,r}}(t,{n_f}), \cdots ,\ \ {h_{u,N_h^{ {\mathrm{BS}}},r}}(t,{n_f})
\end{array} \!\!\!\right]\!\!,
\tag{24}
$$

该矩阵由第 $n_f$ 个子载波上 UE 第 $u$ 根天线与基站面阵第 $r$ 行全部水平天线间的信道组成。$L$ 是满足 $P<L<N_h^{\mathrm{BS}}-P+1$ 的矩阵束尺寸。根据式 (13)，一维 MP 矩阵可改写为

$$
{ {\mathbf{G}}_{u,r}}(t,{n_f}) = { {\mathbf{X}}_{\theta ,\phi ,1}}{ {\mathbf{Z}}_{\theta}^{r}}{\mathbf{Y}}{ {\mathbf{Z}}_{\tau}^{ {n_f}-1}}{ {\mathbf{X}}_{\theta ,\phi ,2}},
\tag{25}
$$

其中 $\mathbf X_{\theta,\phi,1}\in\mathbb C^{L\times P}$ 的第 $p$ 列和 $\mathbf X_{\theta,\phi,2}\in\mathbb C^{P\times(N_h^{\mathrm{BS}}-L+1)}$ 的第 $p$ 行，分别为基站面阵中尺寸为 $1\times L$ 与 $1\times(N_h^{\mathrm{BS}}-L+1)$ 的两个子阵列的导向向量。两个矩阵定义如下：

$$
{ {\mathbf{X}}_{\theta ,\phi ,1}} = \left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{a}}_{h,L-1}^{ {\mathrm{tx}}}({\theta _{1}},{\phi _{1}}),}&{\cdots,}&{ {\mathbf{a}}_{h,L-1}^{ {\mathrm{tx}}}({\theta _{P}}\!,\!{\phi _{P}})} \end{array}} \right],
\tag{26}
$$

$$
\!\!\!\!\!\!{ {\mathbf{X}}_{\theta ,\phi ,2}} = {\left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{a}}_{h,N_h^{ {\mathrm{BS}}} - L}^{ {\mathrm{tx}}}({\theta _{1}},{\phi _{1}}),}&{\cdots,}&{ {\mathbf{a}}_{h,N_h^{ {\mathrm{BS}}} - L}^{ {\mathrm{tx}}}({\theta _{P}},{\phi _{P}})} \end{array}} \!\!\right]^T}\!\!,
\tag{27}
$$

其中 $\mathbf a_{h,l_1}^{\mathrm{tx}}(\theta_p,\phi_p)=[(a_h^{\mathrm{tx}})^0,(a_h^{\mathrm{tx}})^1,\ldots,(a_h^{\mathrm{tx}})^{l_1}]^T$，$l_1\in\{L-1,N_h^{\mathrm{BS}}-L\}$。矩阵 $\mathbf Z_\tau$ 包含各路径在相邻两个子载波之间的相位差：

$$
{ {\mathbf{Z}}_\tau} = {\mathrm{diag}}\left\{ {\begin{array}{cccccccccccccccccccc}{e^{ - j2\pi \Delta f{\tau _1}(t)},}&{\cdots,}&{e^{ - j2\pi \Delta f{\tau _P}(t)}} \end{array}} \right\}.
\tag{28}
$$

类似地，$\mathbf Z_\theta$ 为各路径在基站垂直方向相邻两根天线之间的相位差矩阵：

$$
{ {\mathbf{Z}}_\theta} = {\mathrm{diag}}\left\{ {\begin{array}{cccccccccccccccccccc}{e^{\frac{ {j2\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _{1}})}}{ { {\lambda _0}}}},}&{\cdots,}&{e^{\frac{ {j2\pi d_v^{ {\mathrm{tx}}}\sin({\theta _{P}})}}{ { {\lambda _0}}}}} \end{array}} \right\}.
\tag{29}
$$

矩阵 $\mathbf Y$ 定义为

$$
{\mathbf{Y}} = {\mathrm{diag}}\left\{ { { {\mathbf{C}}_u} {\mathbf{b}}({f_1})} \right\},
\tag{30}
$$

其中 $\mathbf b(f_1)$ 与 $\mathbf C_u$ 分别定义于式 (16) 和式 (17)。

沿基站面阵垂直方向增加一个窗口，引入二维 MP 矩阵 $\mathbf G_u(t,n_f)\in\mathbb C^{LR\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)}$：

$$
{ {\mathbf{G}}_u}(t,{n_f}) \!=\!\!\! \left[\!\! \begin{array}{l}
{ {\mathbf{G}}_{u,1}}(t,{n_f}), \cdots\! ,\ { {\mathbf{G}}_{u,(N_v^{ {\mathrm{BS}}}\! - \!R + 1)}}(t,{n_f})\\
 \ \ \ \ \vdots \ \ \ \ \ \ \ \ \ \ \ddots \ \ \ \ \ \ \ \ \ \ \ \vdots \\
{ {\mathbf{G}}_{u,R}}(t,{n_f}), \cdots ,\ \ \ \ { {\mathbf{G}}_{u,N_v^{ {\mathrm{BS}}}}}(t,{n_f})
\end{array} \!\right]\!,
\tag{31}
$$

该矩阵由第 $n_f$ 个子载波上 UE 第 $u$ 根天线与全部基站天线间的信道组成，并包含路径角度信息。相应的矩阵束尺寸记为 $R$，满足 $P<R<N_v^{\mathrm{BS}}-P+1$。把式 (25) 代入式 (31)，可将 $\mathbf G_u(t,n_f)$ 改写为

$$
{ {\mathbf{G}}_u}(t,{n_f}) = { {\check{\mathbf{E}}}_{1}}{\mathbf{Y}}{ {\mathbf{Z}}_{\tau}^{ {n_f}-1}}{ {\check{\mathbf{F}}}_{1}},
\tag{32}
$$

其中 $\check{\mathbf E}_1\in\mathbb C^{LR\times P}$ 的第 $p$ 列和 $\check{\mathbf F}_1\in\mathbb C^{P\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)}$ 的第 $p$ 行，分别是基站面阵中尺寸为 $R\times L$ 和 $(N_v^{\mathrm{BS}}-R+1)\times(N_h^{\mathrm{BS}}-L+1)$ 的两个子阵列的三维导向向量。定义如下：

$$
{ {\check{\mathbf{E}}}_{1}} = {\left[ {\begin{array}{cccccccccccccccccccc}{({ {\mathbf{X}}_{\theta ,\phi ,1}}{ {\mathbf{Z}}_{\theta}^{0}})^T,}&{\cdots,}&{({ {\mathbf{X}}_{\theta ,\phi ,1}}{ {\mathbf{Z}}_{\theta}^{R - 1}})^T} \end{array}} \right]^T},
\tag{33}
$$

$$
{ {\check{\mathbf{F}}}_{1}} = \left[ {\begin{array}{cccccccccccccccccccc}{ { {\mathbf{Z}}_{\theta}^0}{ {\mathbf{X}}_{\theta ,\phi ,2}},}&{\cdots,}&{ { {\mathbf{Z}}_{\theta}^{N_v^{ {\mathrm{BS}}} - R}}{ {\mathbf{X}}_{\theta ,\phi ,2}}} \end{array}} \right].
\tag{34}
$$

在频域中增加第三个窗口，从 $\mathbf G_u(t,n_f)$ 生成三维 MP 矩阵 $\mathbf G_u(t)\in\mathbb C^{LRK\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)(N_f-K+1)}$，表示为

$$
{ {\mathbf{G}}_u}(t) \!=\!\! \left[ \!\!\begin{array}{l}
{ {\mathbf{G}}_u}(t,1), \ \cdots ,{ {\mathbf{G}}_u}(t,{N_f} \!-\! K\! +\! 1)\\
 \ \ \ \ \ \vdots \ \ \ \ \ \ \ddots \ \ \ \ \ \ \ \ \ \ \ \vdots \\
{ {\mathbf{G}}_u}(t,K), \cdots ,\ \ \ \ { {\mathbf{G}}_u}(t,{N_f})
\end{array} \right]\!\!,
\tag{35}
$$

其中矩阵束尺寸 $K$ 满足 $P<K<N_f-P+1$。矩阵 $\mathbf G_u(t)$ 由所有子载波上<a id="page-5"></a>UE 第 $u$ 根天线与全部基站天线间的信道组成，并包含路径的角度和时延信息。为简化记号，定义 $\mu_1=LRK$、$\mu_2=(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)(N_f-K+1)$。根据式 (13) 中信道的角度–频率域结构，$\mathbf G_u(t)$ 可改写为

$$
{ {\mathbf{G}}_u}(t) = { {\check{\mathbf{E}}}_{2}}{\mathbf{Y}}{ {\check{\mathbf{F}}}_{2}},
\tag{36}
$$

其中 $\check{\mathbf E}_2\in\mathbb C^{\mu_1\times P}$ 和 $\check{\mathbf F}_2\in\mathbb C^{P\times\mu_2}$ 定义为

$$
{ {\check{\mathbf{E}}}_{2}} = {\left[ {\begin{array}{cccccccccccccccccccc}{({ {\check{\mathbf{E}}}_{1}}{ {\mathbf{Z}}_{\tau}^{0}})^T,}&{\cdots,}&{({ {\check{\mathbf{E}}}_{1}}{ {\mathbf{Z}}_{\tau}^{K - 1}})^T} \end{array}} \right]^T},
\tag{37}
$$

$$
{ {\check{\mathbf{F}}}_{2}} = \left[ {\begin{array}{cccccccccccccccccccc}{ { {\mathbf{Z}}_{\tau}^{0}}{ {\check{\mathbf{F}}}_{1}},}&{\cdots,}&{ { {\mathbf{Z}}_{\tau}^{ {N_f} - K}}{ {\check{\mathbf{F}}}_{1}}} \end{array}} \right].
\tag{38}
$$

$\check{\mathbf E}_1\mathbf Z_\tau^{k_1}$（$k_1=0,\ldots,K-1$）的物理意义为基站面阵中尺寸为 $R\times L$ 的子阵列在第 $k_1+1$ 个子载波上的路径 EOD–AOD 导向向量。类似地，$\mathbf Z_\tau^{k_2}\check{\mathbf F}_1$（$k_2=0,\ldots,N_f-K$）为尺寸为 $(N_v^{\mathrm{BS}}-R+1)\times(N_h^{\mathrm{BS}}-L+1)$ 的子阵列在第 $k_2+1$ 个子载波上的路径 EOD–AOD 导向向量。如果三维 MP 矩阵 $\mathbf G_u(t)$ 的秩满足 $r(\mathbf G_u(t))=P$，它就包含多径信息。此时三个矩阵束尺寸满足

$$
\left\{ \begin{array}{l}
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ LR(K - 1) \ge P\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ LK(R - 1) \ge P\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ RK(L - 1) \ge P\\
(N_h^{ {\mathrm{BS}}} - L + 1)(N_v^{ {\mathrm{BS}}} - R + 1)({N_f} - K + 1) \ge P
\end{array} \!\!\!\!\right..
\tag{39}
$$

随后使用酉矩阵束（UMP）方法 [28] 将三维 MP 矩阵 $\mathbf G_u(t)$ 变换为实矩阵 $\mathbf G_{\mathrm{re}}(t)\in\mathbb C^{\mu_1\times2\mu_2}$。这样可在不损失精度的情况下减少计算复杂度。实矩阵 $\mathbf G_{\mathrm{re}}(t)$ 由下式得到：

$$
{ {\mathbf{G}}_{\mathrm{re}}}(t) = {\mathbf{Q}}_{\mu_1}^H{ {\mathbf{G}}_{\mathrm{ex}}}(t){ {\mathbf{Q}}_{2{\mu_2}}},
\tag{40}
$$

其中

$$
{ {\mathbf{G}}_{\mathrm{ex}}}(t) = \left[ { { {\mathbf{G}}_u}(t):{\Upsilon_{\mu_1}} { {\mathbf{G}}_u^*(t)}{\Upsilon_{ {\mu_2}}} } \right].
\tag{41}
$$

定义两个分别取决于尺寸 $\mu_1$、$2\mu_2$ 的酉矩阵 $\mathbf Q_{\mu_1}$ 与 $\mathbf Q_{2\mu_2}$。以 $\mathbf Q_{\mu_1}$ 为例，当 $\mu_1$ 为偶数时，

$$
{ {\mathbf{Q}}_{\mu_1} } = \frac{1}{ {\sqrt 2 }}\left[ \begin{array}{l}
{ {\mathbf{I}}_{\frac{ {\mu_1} }{2}}}\ \ \ \ \ j{ {\mathbf{I}}_{\frac{ {\mu_1} }{2}}}\\
{\Upsilon _{\frac{ {\mu_1} }{2}}}\  -j{\Upsilon _{\frac{ {\mu_1} }{2}}}
\end{array} \right],
\tag{42}
$$

当 $\mu_1$ 为奇数时，

$$
{ {\mathbf{Q}}_{\mu_1} } = \frac{1}{ {\sqrt 2 }}\left[ \begin{array}{l}
\ { {\mathbf{I}}_{\frac{ { {\mu_1}  - 1}}{2}}}\ \ \ \ { {\mathbf{0}}_{(\frac{ { {\mu_1}  - 1}}{2}) \times 1}}\ \ \ j{ {\mathbf{I}}_{\frac{ { {\mu_1}  - 1}}{2}}}\\
{ {\mathbf{0}}_{1 \times (\frac{ { {\mu_1}  - 1}}{2})}}\ \ {\sqrt 2} \ \ \ \ \ \ \ \ { {\mathbf{0}}_{1 \times (\frac{ { {\mu_1}  - 1}}{2})}}\\
\ {\Upsilon _{\frac{ { {\mu_1}  - 1}}{2}}}\ \ \ { {\mathbf{0}}_{(\frac{ { {\mu_1}  - 1}}{2}) \times 1}}\ -j{\Upsilon _{\frac{ { {\mu_1}  - 1}}{2}}}
\end{array} \right].
\tag{43}
$$

随后对 $\mathbf G_{\mathrm{re}}(t)$ 作奇异值分解（SVD），以确定路径数。记 $\mathbf G_{\mathrm{re}}(t)=\mathbf U_\tau\mathbf S_\tau\mathbf V_\tau^H$，其中 $\mathbf U_\tau=[\mathbf u_1,\ldots,\mathbf u_{\mu_1}]$，$\mathbf S_\tau=\operatorname{diag}\{s_1,\ldots,s_{M_\tau}\}$，$M_\tau=\min(\mu_1,2\mu_2)$。不失一般性，假设 $\mathbf S_\tau$ 的对角元素按非递增顺序排列。为确定不能忽略的路径数，定义集合

$$
\begin{array}{l}
{\mathfrak{M}} = \{ {m_\tau }|\lvert { {s_{ {m_\tau }}}} \rvert \ge {\gamma _1},1 \le {m_\tau } \le {M_\tau }\} \\
\ \ \ \ = \{ {\begin{array}{cccccccccccccccccccc}{m_1,}&{\cdots,}&{m_P} \end{array}} \},
\end{array}
\tag{44}
$$

其中正阈值 $\gamma_1$ 接近于零。不可忽略的路径数为 $P=\operatorname{card}(\mathfrak M)$。

随后估计路径时延，共有两个子步骤，即生成实矩阵和特征值分解（EVD）。首先，定义由 $\mathbf U_\tau$ 中选择的 $P$ 列构成的矩阵 $\mathbf U_s=[\mathbf u_{m_1},\ldots,\mathbf u_{m_P}]$。定义与路径时延相关的实矩阵：

$$
{ {\mathbf{\Psi }}_\tau } = {\left[ { {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{\mu_3 }^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1 }^{}){ {\mathbf{U}}_s}} \right]^\dagger }{\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ {\mathbf{U}}_s},
\tag{45}
$$

其中 $\mu_3=KRL-RL$，$\mathbf J_1=[\mathbf I_{\mu_3}:\mathbf 0_{\mu_3\times RL}]$。酉矩阵 $\mathbf Q_{\mu_3}$ 只取决于尺寸 $\mu_3$，按式 (42) 或式 (43) 表示。另引入包含时延信息的矩阵 $\hat{\mathbf Z}_\tau$：

$$
{ {\mathbf{\hat Z}}_\tau} = {\mathrm{diag}}\left\{\!\! {\begin{array}{cccccccccccccccccccc}{\tan \left( {\pi \Delta f{\tau _1}(t)} \right),}\!\!&\!\!{\cdots,}\!\!&\!\!{\tan \left( {\pi \Delta f{\tau _{ {P}}}(t)} \right)} \end{array}} \!\!\right\}.
\tag{46}
$$

$\boldsymbol\Psi_\tau$ 和 $\hat{\mathbf Z}_\tau$ 是具有相同特征值的相似矩阵 [28]。随后通过对 $\boldsymbol\Psi_\tau$ 作 EVD 估计路径时延。令 $\boldsymbol\Psi_\tau=\mathbf W_\tau\hat{\mathbf Z}_\tau\mathbf W_\tau^{-1}$，其中 $\mathbf W_\tau$ 汇集 $\boldsymbol\Psi_\tau$ 的特征向量。由两者相似，可用 $\hat{\mathbf Z}_\tau=\mathbf W_\tau^{-1}\boldsymbol\Psi_\tau\mathbf W_\tau$ 计算 $\hat{\mathbf Z}_\tau$。根据式 (13) 的角度–频率域信道结构，$\hat{\mathbf Z}_\tau$ 的估计对角元素可以反映相邻两个子载波之间的多径时延相位差。因此，第 $p$ 条路径时延 $\hat{\tau}_p(t)$ 的估计为

$$
{\hat \tau _p}(t) = \frac{ { { {\tan }^{ - 1}}\left( { { {\hat z}_{\tau,p}}} \right)}}{ {\pi \Delta f}},
\tag{47}
$$

其中 $\hat z_{\tau,p}$ 为 $\hat{\mathbf Z}_\tau$ 中第 $p$ 个估计对角元素。此外，用两个不同时刻的样本来估计时延变化率 $\hat k_{\tau_p}$：

$$
{\hat k_{ {\tau _p}}} = \frac{ { { {\hat \tau }_p}({t_2}) - { {\hat \tau }_p}({t_1})}}{ { {t_2} - {t_1}}}.
\tag{48}
$$

至此已估计多径时延。接下来分两步估计多径 EOD 和 AOD，即引入若干置换矩阵，以及生成与 EOD 和 AOD 相关的两个实矩阵。由于 $\mathbf G_u(t)$ 已含路径角度信息，只需对 $\mathbf G_u(t)$ 作置换即可生成两个新的三维 MP 矩阵 $\mathbf G_h(t)$、$\mathbf G_v(t)$。首先，引入四个置换矩阵 $\mathbf S_{\mathrm{left},h}$、$\mathbf S_{\mathrm{right},h}$、$\mathbf S_{\mathrm{left},v}$ 和 $\mathbf S_{\mathrm{right},v}$：

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!{ {\mathbf{S}}_{ {\mathrm{left}},h}}\! =\! [{\mathbf{s}}(1),\! \cdots\! ,{\mathbf{s}}(1\! +\! \mu_1\! -\! L),{\mathbf{s}}(2), \cdots ,\\
\ \ {\mathbf{s}}(2 \!+\! \mu_1\! -\! L),\! \cdots\! ,{\mathbf{s}}(L),\! \cdots\! {\mathbf{s}}(\mu_1){]^T},
\end{array}
\tag{49}
$$

$$
\begin{array}{l}
\!\!\!\!\!{ {\mathbf{S}}_{ {\mathrm{right}},h}}\! =\! [{\mathbf{s}}(1),\! \cdots\! ,{\mathbf{s}}(\mu_2\! -\! (N_h^{ {\mathrm{BS}}} - L)),{\mathbf{s}}(2), \cdots ,\\
\ \ \ \ \ \ \ {\mathbf{s}}(\mu_2\! -\! (N_h^{ {\mathrm{BS}}} \!-\! L \!-\! 1)),\! \cdots\! ,{\mathbf{s}}(N_h^{ {\mathrm{BS}}} \!-\! L \!+\! 1),\! \cdots\! {\mathbf{s}}(\mu_2){]^T},
\end{array}
\tag{50}
$$

$$
\begin{array}{l}
\!\!\!\!\!\!{ {\mathbf{S}}_{ {\mathrm{left}},v}} \!=\!\! [{\mathbf{s}}(1),\! \cdots\! ,\!{\mathbf{s}}(L),\! \cdots\! ,{\mathbf{s}}(1\!\! +\!\! \mu_1\!\! -\!\! LR), \!\cdots\! ,{\mathbf{s}}(L\!\! +\!\! \mu_1\!\! -\!\! LR),\! \cdots\! ,\\
\ \ \ \ \ {\mathbf{s}}(1\!\! +\!\! (R\!\! -\!\! 1)L),\! \cdots\! ,{\mathbf{s}}(L\!\! +\!\! (R\!\! -\!\! 1)L),\! \cdots\! ,\\
\ \ \ \ \ {\mathbf{s}}(1\!\! +\!\! (R\!\! -\!\! 1)L\!\! +\!\! (K\!\! -\!\! 1)LR),\! \cdots\! ,{\mathbf{s}}(\mu_1){]^T},
\end{array}
\tag{51}
$$

$$
\begin{array}{l}
\!\!\!\!\!\!{ {\mathbf{S}}_{ {\mathrm{right}},v}} \!=\!\! [{\mathbf{s}}(1),\! \cdots\! ,\!{\mathbf{s}}(N_h^{ {\mathrm{BS}}} \!\!-\!\! L\!\! +\!\! 1),\! \cdots\! ,\\
\ \ \ \ \ {\mathbf{s}}((N_v^{ {\mathrm{BS}}}\!\! -\!\! R\!\! +\!\! 1)(N_h^{ {\mathrm{BS}}} \!\!-\!\! L \!\!+\!\! 1) \!\!-\!\! (N_h^{ {\mathrm{BS}}} \!\!-\!\! L)), \!\cdots\!,\\ 
\ \ \ \ \ {\mathbf{s}}((N_v^{ {\mathrm{BS}}} - R + 1)(N_h^{ {\mathrm{BS}}} - L + 1)),\! \cdots\! ,\\
\ \ \ \ \ {\mathbf{s}}(1\!\! -\!\! (N_h^{ {\mathrm{BS}}} \!\!-\!\! L \!\!+\!\! 1) \!\!+\!\! \mu_2),\! \cdots\! ,{\mathbf{s}}(\mu_2){]^T},
\end{array}
\tag{52}
$$

其中 $\mathbf s(m)$（$m=1,\ldots,LRK$）是一个 $LRK\times1$ 单位向量，其第 $m$ 个元素为一。

通过置换 $\mathbf G_u(t)$，两矩阵分别表示为 $\mathbf G_h(t)=\mathbf S_{\mathrm{left},h}\mathbf G_u(t)\mathbf S_{\mathrm{right},h}^H$ 和 $\mathbf G_v(t)=\mathbf S_{\mathrm{left},v}\mathbf G_u(t)\mathbf S_{\mathrm{right},v}^H$。实际中，无需显式构造这两个三维 MP 矩阵，也无需构造 $\mathbf S_{\mathrm{right},h}$ 与 $\mathbf S_{\mathrm{right},v}$。实际上，只需引入 $\mathbf S_{\mathrm{left},h}$ 与 $\mathbf S_{\mathrm{left},v}$ 即可估计 EOD 和 AOD。

接下来生成与 EOD 和 AOD 相关的两个实矩阵。沿用从 $\mathbf G_u(t)$ 生成 $\boldsymbol\Psi_\tau$ 的过程，即式 (40) 至式 (45)，分别从 $\mathbf G_h(t)$ 和 $\mathbf G_v(t)$ 生成两个实矩阵 $\boldsymbol\Psi_\phi$ 和 $\boldsymbol\Psi_\theta$，定义为

$$
\begin{array}{l}
{ {\mathbf{\Psi }}_{\phi }} = {\left( { {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{\mu_4}^H{ {\mathbf{J}}_2}{\mathbf{Q}}_{\mu_1}^{}){\mathbf{Q}}_{\mu_1}^{}{ {\mathbf{S}}_{ {\mathrm{left}},h}}{\mathbf{Q}}_{\mu_1}^H{ {\mathbf{U}}_s}} \right)^\dagger }\\
\ \ \ \ \ \ \ \ \ {\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{\mu_4}^H{ {\mathbf{J}}_2}{\mathbf{Q}}_{\mu_1}^{}){\mathbf{Q}}_{\mu_1}^{}{ {\mathbf{S}}_{ {\mathrm{left}},h}}{\mathbf{Q}}_{\mu_1}^H{ {\mathbf{U}}_s},
\end{array}
\tag{53}
$$

$$
\begin{array}{l}
{ {\mathbf{\Psi }}_\theta } = {\left( { {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{\mu_5}^H{ {\mathbf{J}}_3}{\mathbf{Q}}_{\mu_1}^{}){\mathbf{Q}}_{\mu_1}^{}{ {\mathbf{S}}_{ {\mathrm{left}},v}}{\mathbf{Q}}_{\mu_1}^H{ {\mathbf{U}}_s}} \right)^\dagger }\\
\ \ \ \ \ \ \ {\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{\mu_5}^H{ {\mathbf{J}}_3}{\mathbf{Q}}_{\mu_1}^{}){\mathbf{Q}}_{\mu_1}^{}{ {\mathbf{S}}_{ {\mathrm{left}},v}}{\mathbf{Q}}_{\mu_1}^H{ {\mathbf{U}}_s},
\end{array}
\tag{54}
$$

其中 $\mu_4=KRL-KR$、$\mu_5=KRL-KL$，$\mathbf J_2=[\mathbf I_{\mu_4}:\mathbf0_{\mu_4\times KR}]$，$\mathbf J_3=[\mathbf I_{\mu_5}:\mathbf0_{\mu_5\times KL}]$。两个酉矩阵 $\mathbf Q_{\mu_4}$ 与 $\mathbf Q_{\mu_5}$ 根据各自尺寸 $\mu_4$ 与 $\mu_5$ 按式 (42) 或式 (43) 定义。

定义包含角度信息的两个实对角矩阵 $\hat{\mathbf Z}_\phi$ 与 $\hat{\mathbf Z}_\theta$：

$$
\begin{array}{l}
{ { {\mathbf{\hat Z}}}_{\phi }} = {\mathrm{diag}}\{ \tan (\frac{ {\pi d_h^{ {\mathrm{tx}}}\cos ({\theta _1})\sin({\phi _1})}}{ { {\lambda _0}}}), \\
\ \ \ \ \ \ \ \ \cdots ,\tan (\frac{ {\pi d_h^{ {\mathrm{tx}}}\cos ({\theta _{ {P}}})\sin({\phi _{ {P}}})}}{ { {\lambda _0}}})\},
\end{array}
\tag{55}
$$

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!{ {\mathbf{\hat Z}}_\theta } = {\mathrm{diag}}\{ \!{\begin{array}{cccccccccccccccccccc}{\tan (\frac{ {\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _1})}}{ { {\lambda _0}}}),}\!&\!{\cdots,}\!&\!{\tan (\frac{ {\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _{ {P}}})}}{ { {\lambda _0}}})} \end{array}}\!\}.
\end{array}
\tag{56}
$$

$\hat{\mathbf Z}_\phi$ 中的对角元素反映各路径在基站面阵水平方向相邻两阵元间的相位差。类似地，$\hat{\mathbf Z}_\theta$ 反映各路径在基站面阵垂直方向相邻两阵元间的相位差。

最后按如下方式估计 EOD 和 AOD。两个实矩阵 $\boldsymbol\Psi_\phi$ 与 $\boldsymbol\Psi_\theta$ 分别与 $\hat{\mathbf Z}_\phi$ 和 $\hat{\mathbf Z}_\theta$ 相似，即各自与对应的实对角矩阵拥有相同的特征值。因此，可以对 $\boldsymbol\Psi_\phi$ 与 $\boldsymbol\Psi_\theta$ 作 EVD 得到 $\hat{\mathbf Z}_\phi$ 和 $\hat{\mathbf Z}_\theta$。由于 $\mathbf G_h(t)$ 与 $\mathbf G_v(t)$ 是 $\mathbf G_u(t)$ 的置换，$\boldsymbol\Psi_\phi$、$\boldsymbol\Psi_\theta$ 与 $\boldsymbol\Psi_\tau$ 共享同一组特征向量。具体而言，$\boldsymbol\Psi_\phi=\mathbf W_\tau\hat{\mathbf Z}_\phi\mathbf W_\tau^{-1}$，$\boldsymbol\Psi_\theta=\mathbf W_\tau\hat{\mathbf Z}_\theta\mathbf W_\tau^{-1}$，其中 $\mathbf W_\tau$ 包含 $\boldsymbol\Psi_\tau$ 的特征向量。因此，$\hat{\mathbf Z}_\phi=\mathbf W_\tau^{-1}\boldsymbol\Psi_\phi\mathbf W_\tau$，$\hat{\mathbf Z}_\theta=\mathbf W_\tau^{-1}\boldsymbol\Psi_\theta\mathbf W_\tau$。EOD 和 AOD 的估计为

$$
{\hat \theta _p} = {\sin ^{ - 1}}\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\theta,p}}) {\lambda _0}}}{ {\pi d_v^{ {\mathrm{tx}}}}}} \right),
\tag{57}
$$

$$
{\hat \phi _p} = {\sin ^{ - 1}}\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\phi,p}}) {\lambda _0}}}{ {\pi d_h^{ {\mathrm{tx}}} \cos \left( { { {\sin }^{ - 1}}\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\theta,p}}) {\lambda _0}}}{ {\pi d_v^{ {\mathrm{tx}}}}}} \right)} \right)}}} \right),
\tag{58}
$$

其中 $\hat z_{\phi,p}$ 和 $\hat z_{\theta,p}$ 分别为 $\hat{\mathbf Z}_\phi$ 和 $\hat{\mathbf Z}_\theta$ 的第 $p$ 个估计对角元素。至此，所提三维角度–时延估计方案已经给出 EOD、AOD 与时延，见算法 1。算法 1 的输入 $\mathbf H_u(t)$ 是由上行探测参考信号（SRS）获得的历史样本。通过算法 1 估计用于重构和预测未来下行信道的参数。

下面从时间与存储两方面分析该算法的计算复杂度。时间复杂度主要由第 3–8 步决定。第 3 步的复杂度为 $\mathcal O(2\mu_1^2\mu_2)+\mathcal O(4\mu_1\mu_2^2)$。第 4 步主要开销为 SVD，即 $\mathcal O(4\mu_1\mu_2^2)$。第 5 步包含矩阵求逆与相乘，复杂度为 $\mathcal O(\mu_3^2\mu_1)+\mathcal O(\mu_3\mu_1^2)+\mathcal O(P^{2.37})$。第 6 步主要由 EVD 决定，即 $\mathcal O(P^3)$。第 7 步主要为矩阵求逆和相乘，复杂度为 $\mathcal O(\mu_4^2\mu_1)+\mathcal O(\mu_4\mu_1^2)+\mathcal O(\mu_1^3)+\mathcal O(P^{2.37})$。与第 6 步类似，第 8 步的复杂度为 $\mathcal O(P^3)$。根据式 (39) 中矩阵束尺寸条件，算法 1 总体时间复杂度为 $\mathcal O(2\mu_1^2\mu_2)+\mathcal O(4\mu_1\mu_2^2)+\mathcal O(\mu_1^3)$。算法 1 的存储复杂度主要由第 3 步决定，即该步的两个矩阵 $\mathbf Q_{\mu_1}$ 和 $\mathbf Q_{\mu_2}$，总存储复杂度为 $\mathcal S(\mu_1^2)+\mathcal S(4\mu_2^2)$。

**算法 1：** 所提三维角度–时延估计方案。

**输入** $\mathbf H_u(t)$、$L$、$R$、$K$、$\gamma_1$。

1. 对 $t\in\{t_1,t_2\}$ 循环。
2. 按式 (24) 至式 (36) 的过程构造三维 MP 矩阵 $\mathbf G_u(t)$。
3. 由式 (40) 和式 (41) 将 $\mathbf G_u(t)$ 变换为三维实矩阵 $\mathbf G_{\mathrm{re}}(t)$。
4. 由式 (44) 确定路径数。
5. 由式 (45) 构造实矩阵 $\boldsymbol\Psi_\tau$。
6. 通过对 $\boldsymbol\Psi_\tau$ 作 EVD，按式 (47) 估计时延 $\hat\tau_p(t)$。
7. 按式 (49) 和式 (51) 定义两个置换矩阵，并用式 (53) 和式 (54) 生成 $\boldsymbol\Psi_\phi$、$\boldsymbol\Psi_\theta$。
8. 分别按式 (57) 和式 (58) 估计 EOD $\hat\theta_p$ 及 AOD $\hat\phi_p$。
9. 结束循环。
10. 按式 (48) 估计参数 $\hat k_{\tau_p}$。

**输出** $\hat\tau_p(t)$、$\hat\theta_p$、$\hat\phi_p$、$\hat k_{\tau_p}$，其中 $p\in\{1,\ldots,P\}$。

### B. 三维角度–多普勒估计

根据第 III-A 节获得的角度和时延信息，本节估计多径角度与多普勒。信道样本的持续时间为 $T$，因此将第 $n_s$ 个样本时刻记为 $t=n_sT$。类似第 III-A 节，首先定义三维 MP 矩阵 $\boldsymbol{\mathcal G}_u(f_1)\in\mathbb C^{LRQ\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)(N_s-Q+1)}$：

$$
{ {\boldsymbol{\mathcal G}}_u}({f_1}) = \left[ \begin{array}{l}
{ {\boldsymbol{\mathcal G}}_u}(1,{f_1}), \ \cdots ,{ {\boldsymbol{\mathcal G}}_u}({N_s} \!-\! Q \!+\! 1,{f_1})\\
 \ \ \ \ \vdots \ \ \ \ \ \ \ \ \ddots \ \ \ \ \ \ \ \ \ \vdots \\
{ {\boldsymbol{\mathcal G}}_u}(Q,{f_1}), \cdots ,\ \ \ \ { {\boldsymbol{\mathcal G}}_u}({N_s},{f_1})
\end{array} \right],
\tag{59}
$$

其中 $N_s$ 为样本数，$Q$ 为矩阵束尺寸，满足 $P<Q<N_s-P+1$。矩阵 $\boldsymbol{\mathcal G}_u(f_1)$ 由第一个子载波上所有采样时刻的<a id="page-7"></a>UE 第 $u$ 根天线与全部基站天线之间的信道组成。为简便起见，定义 $\omega_{\mu_1}=LRQ$、$\omega_{\mu_2}=(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)(N_s-Q+1)$。二维 MP 矩阵 $\boldsymbol{\mathcal G}_u(n_s,f_1)\in\mathbb C^{LR\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)}$，$n_s=1,\ldots,N_s$，由 UE 第 $u$ 根天线与所有基站天线之间在第一个子载波、第 $n_s$ 个样本时刻的信道构成。将它改写为

$$
{ {\boldsymbol{\mathcal G}}_u}({n_s},{f_1}) = { {\check{\mathbf{E}}}_{1}}{ {\mathbf{Y}}_w}{\mathbf{Z}}_{w_\tau}^{ {n_s}}{ {\check{\mathbf{F}}}_{1}},
\tag{60}
$$

其中 $\mathbf Z_{\omega_\tau}$ 表示各路径在相邻两个样本间的相位差：

$$
{\mathbf{Z}}_{\omega_\tau} = {\mathrm{diag}}\left\{ {\begin{array}{cccccccccccccccccccc}{e^{j2\pi {\omega_{\tau _1}} {T}},}&{\cdots,}&{e^{j2\pi {\omega_{\tau _P}} {T}}} \end{array}} \right\},
\tag{61}
$$

其中

$$
{\omega_{\tau _p}} = {\omega_p} - {f_1} {k_{ {\tau _p}}}.
\tag{62}
$$

矩阵 $\mathbf Y_\omega$ 定义为

$$
{ {\mathbf{Y}}_\omega} = {\mathrm{diag}}\left\{ { { {\mathbf{D}}_u}{\mathbf{e}}({f_1})} \right\},
\tag{63}
$$

其中 $\mathbf D_u$ 和 $\mathbf e(f_1)$ 分别见式 (19) 和式 (21)。根据式 (18) 的角度–时间域信道结构，$\boldsymbol{\mathcal G}_u(f_1)$ 可改写为

$$
{ {\boldsymbol{\mathcal G}}_u}({f_1}) = { {\check{\mathbf{E}}}_{\omega,2}}{ {\mathbf{Y}}_\omega}{ {\check{\mathbf{F}}}_{\omega,2}},
\tag{64}
$$

其中 $\check{\mathbf E}_{\omega,2}\in\mathbb C^{\omega_{\mu_1}\times P}$ 和 $\check{\mathbf F}_{\omega,2}\in\mathbb C^{P\times\omega_{\mu_2}}$ 定义为

$$
{ {\check{\mathbf{E}}}_{\omega,2}} = {\left[\! {\begin{array}{cccccccccccccccccccc}{({ {\check{\mathbf{E}}}_{1}}{\mathbf{Z}}_{\omega_\tau}^{0})^T,}\!&\!{\cdots,}\!&\!{({ {\check{\mathbf{E}}}_{1}}{\mathbf{Z}}_{\omega_\tau}^{Q - 1})^T} \end{array}} \!\right]^T},
\tag{65}
$$

$$
{ {\check{\mathbf{F}}}_{\omega,2}} = \left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{Z}}_{\omega_\tau}^{0}{ {\check{\mathbf{F}}}_{1}},}&{\cdots,}&{ {\mathbf{Z}}_{\omega_\tau}^{ {N_s} - Q}{ {\check{\mathbf{F}}}_{1}}} \end{array}} \right].
\tag{66}
$$

$\check{\mathbf E}_1\mathbf Z_{\omega_\tau}^{q_1}$（$q_1=0,\ldots,Q-1$）表示基站面阵中尺寸为 $R\times L$ 的子阵列在第 $q_1+1$ 个样本时的三维导向向量。类似地，$\mathbf Z_{\omega_\tau}^{q_2}\check{\mathbf F}_1$（$q_2=0,\ldots,N_s-Q$）表示尺寸为 $(N_v^{\mathrm{BS}}-R+1)\times(N_h^{\mathrm{BS}}-L+1)$ 的子阵列在第 $q_2+1$ 个样本时的三维导向向量。$\boldsymbol{\mathcal G}_u(f_1)$ 的三个矩阵束尺寸满足

$$
\left\{ \begin{array}{l}
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ LR(Q - 1) \ge P\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ LQ(R - 1) \ge P\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ RQ(L - 1) \ge P\\
(N_h^{ {\mathrm{BS}}} - L + 1)(N_v^{ {\mathrm{BS}}} - R + 1)({N_s} - Q + 1) \ge P
\end{array} \right.\!\!\!\!\!\!.
\tag{67}
$$

沿用第 III-A 节的估计流程，将 $\boldsymbol{\mathcal G}_u(f_1)$ 变换为实矩阵 $\boldsymbol{\mathcal G}_{\mathrm{re}}(f_1)$。路径数已在第 III-A 节确定，无需再次确定。接下来通过生成实矩阵与作 EVD 来估计 $\hat\omega_{\tau_p}$。具体而言，与多普勒相关的实矩阵为

$$
\ \!\!{ {\mathbf{\Psi }}_{\omega_\tau}} \!\!=\!\! {\left( \!{ {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{ {\omega}_{\mu_3}}^H{ {\mathbf{J}}_{\omega,1}}{ {\mathbf{Q}}_{ {\omega}_{\mu_1}}}){ {\mathbf{U}}_{\omega,s}}} \!\right)^\dagger }\!\mathrm{Im}({\mathbf{Q}}_{ {\omega}_{\mu_3}}^H{ {\mathbf{J}}_{\omega,1}}{ {\mathbf{Q}}_{ {\omega}_{\mu_1}}}){ {\mathbf{U}}_{\omega,s}},
\tag{68}
$$

其中 $\omega_{\mu_3}=QRL-RL$，$\mathbf J_{\omega,1}=[\mathbf I_{\omega_{\mu_3}}:\mathbf0_{\omega_{\mu_3}\times RL}]$。两个酉矩阵 $\mathbf Q_{\omega_{\mu_1}}$ 与 $\mathbf Q_{\omega_{\mu_3}}$ 取决于相应的尺寸 $\omega_{\mu_1}$ 及 $\omega_{\mu_3}$，可写成式 (42) 或式 (43) 的形式。对 $\boldsymbol{\mathcal G}_{\mathrm{re}}(f_1)$ 进行 SVD：

$\boldsymbol{\mathcal G}_{\mathrm{re}}(f_1)=\mathbf U_\omega\mathbf S_\omega\mathbf V_\omega^H$。用第 III-A 节确定 $\mathbf U_s$ 的类似步骤，从 $\mathbf U_\omega$ 选择 $P$ 列组成 $\mathbf U_{\omega,s}$。

矩阵 $\boldsymbol\Psi_{\omega_\tau}$ 与实对角矩阵 $\hat{\mathbf Z}_{\omega_\tau}$ 相似，具有相同的特征值。定义包含多普勒信息的 $\hat{\mathbf Z}_{\omega_\tau}$：

$$
{ { {\mathbf{\hat Z}}}_{ {\omega _\tau }}} = {\mathrm{diag}}\{\! {\begin{array}{cccccccccccccccccccc}{- \tan ({\omega _{ {\tau _1}}}\pi T),}\!&\!{\cdots,}\!&\!{- \tan ({\omega _{ {\tau _{ {P}}}}}\pi T)} \end{array}} \!\}.
\tag{69}
$$

$\hat{\mathbf Z}_{\omega_\tau}$ 的对角元素反映各路径的两个样本之间的相位差。至此，已构造出实矩阵 $\boldsymbol\Psi_{\omega_\tau}$，接下来对其作 EVD，即 $\boldsymbol\Psi_{\omega_\tau}=\mathbf W_{\omega_\tau}\hat{\mathbf Z}_{\omega_\tau}\mathbf W_{\omega_\tau}^{-1}$，其中 $\mathbf W_{\omega_\tau}$ 由 $\boldsymbol\Psi_{\omega_\tau}$ 的特征向量构成。计算 $\hat{\mathbf Z}_{\omega_\tau}=\mathbf W_{\omega_\tau}^{-1}\boldsymbol\Psi_{\omega_\tau}\mathbf W_{\omega_\tau}$，得到参数 $\hat\omega_{\tau_p}$ 的估计：

$$
{\hat \omega_{\tau _p}} =  - \frac{ { { {\tan }^{ - 1}}({ {\hat z}_{\omega_\tau,p}})}}{ {\pi {T}}},
\tag{70}
$$

其中 $\hat z_{\omega_\tau,p}$ 为 $\hat{\mathbf Z}_{\omega_\tau}$ 第 $p$ 个估计对角元素。类似地，按以下方式估计 EOD 和 AOD。两个与 EOD、AOD 相关的实矩阵为

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!{ {\mathbf{\Psi }}_{\omega_\tau,\phi }} \!=\!\! {\left( \!{ {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{ {\omega}_{\mu_4}}^H\!{ {\mathbf{J}}_{\omega,2}}{ {\mathbf{Q}}_{ {\omega}_{\mu_1}}}\!){\mathbf{Q}}_{ {\omega}_{\mu_1}}\!{ {\mathbf{S}}_{ {\mathrm{left}},\omega,h}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^H\!\!{ {\mathbf{U}}_{\omega,s}}} \!\right)^\dagger }\\
\ \ \ \ \ \ \ {\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{ {\omega}_{\mu_4}}^H\!{ {\mathbf{J}}_{\omega,2}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^{}\!){\mathbf{Q}}_{ {\omega}_{\mu_1}}^{}\!\!{ {\mathbf{S}}_{ {\mathrm{left}},\omega,h}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^H{ {\mathbf{U}}_{\omega,s}},

\tag{71}
$$

$$
\begin{array}{l}
\!\!\!\!\!\!\!{ {\mathbf{\Psi }}_{\omega_\tau,\theta }} \!=\!\! {\left( \!{ {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{ {\omega}_{\mu_5}}^H{ {\mathbf{J}}_{\omega,3}}{ {\mathbf{Q}}_{ {\omega}_{\mu_1}}}\!){\mathbf{Q}}_{ {\omega}_{\mu_1}}{ {\mathbf{S}}_{ {\mathrm{left}},\omega,v}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^H{ {\mathbf{U}}_{\omega,s}}} \!\right)^\dagger }\\
\ \ \ \ \ \ {\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{ {\omega}_{\mu_5}}^H{ {\mathbf{J}}_{\omega,3}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^{}\!){\mathbf{Q}}_{ {\omega}_{\mu_1}}^{}{ {\mathbf{S}}_{ {\mathrm{left}},\omega,v}}{\mathbf{Q}}_{ {\omega}_{\mu_1}}^H{ {\mathbf{U}}_{\omega,s}},
\end{array}
\tag{72}
$$

其中 $\omega_{\mu_4}=QRL-QR$、$\omega_{\mu_5}=QRL-QL$，$\mathbf J_{\omega,2}=[\mathbf I_{\omega_{\mu_4}}:\mathbf0_{\omega_{\mu_4}\times QR}]$，$\mathbf J_{\omega,3}=[\mathbf I_{\omega_{\mu_5}}:\mathbf0_{\omega_{\mu_5}\times QL}]$。将 $\mathbf S_{\mathrm{left},\omega,h}$ 与 $\mathbf S_{\mathrm{left},\omega,v}$ 定义为两个新置换矩阵，其形式与式 (49) 及式 (51) 中的 $\mathbf S_{\mathrm{left},h}$ 与 $\mathbf S_{\mathrm{left},v}$ 类似，由将两式中的 $K$ 替换为 $Q$ 得到。

$$
\begin{array}{l}
\!\!\!\!\!\!\!\!\!\!\!\!\!\!{ { {\mathbf{\hat Z}}}_{ {\omega _\tau },\theta }}\! =\! {\mathrm{diag}}\{ \tan (\frac{ {\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _{\omega ,1}})}}{ { {\lambda _0}}}), \cdots \!,\tan (\frac{ {\pi d_v^{ {\mathrm{tx}}}\sin ({\theta _{\omega ,{ {P}}}})}}{ { {\lambda _0}}})\},

$$

\begin{array}{l}
{ { {\mathbf{\hat Z}}}_{ {\omega _\tau },\phi }} = {\mathrm{diag}}\{ \tan (\frac{ {\pi d_h^{ {\mathrm{tx}}}\cos ({\theta _{\omega ,1}}){\mathrm{sin}}({\phi _{\omega ,1}})}}{ { {\lambda _0}}}),\\
 \ \ \ \ \ \ \ \ \ \ \cdots ,\tan (\frac{ {\pi d_h^{ {\mathrm{tx}}}\cos ({\theta _{\omega ,{ {P}}}}){\mathrm{sin}}({\phi _{\omega ,{ {P}}}})}}{ { {\lambda _0}}})\},
\end{array}
\tag{74}
$$

其中 $\hat{\mathbf Z}_{\omega_\tau,\phi}=\mathbf W_{\omega_\tau}^{-1}\boldsymbol\Psi_{\omega_\tau,\phi}\mathbf W_{\omega_\tau}$，$\hat{\mathbf Z}_{\omega_\tau,\theta}=\mathbf W_{\omega_\tau}^{-1}\boldsymbol\Psi_{\omega_\tau,\theta}\mathbf W_{\omega_\tau}$。EOD 和 AOD 的估计如下：

{\hat \theta _{\omega,p}} = {\sin ^{ - 1}}\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\omega_\tau,\phi,p}}) {\lambda _0}}}{ {\pi d_v^{ {\mathrm{tx}}}}}} \right),

\ {\hat \phi _{\omega,p}} \!=\! {\sin ^{ - 1}}\!\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\omega_\tau,\theta,p}}) {\lambda _0}}}{ {\pi d_h^{ {\mathrm{tx}}} \cos \left( {\sin{^{ - 1}}\left( {\frac{ { {\tan ^{-1}}({ {\hat z}_{\omega_\tau,\phi,p}}) {\lambda _0}}}{ {\pi d_v^{ {\mathrm{tx}}}}}} \right)} \right)}}} \right),
\tag{76}
$$

其中 $\hat z_{\omega_\tau,\phi,p}$ 和 $\hat z_{\omega_\tau,\theta,p}$ 分别为 $\hat{\mathbf Z}_{\omega_\tau,\phi}$ 与 $\hat{\mathbf Z}_{\omega_\tau,\theta}$ 的第 $p$ 个估计对角元素。算法 2 概述了所提三维角度–多普勒估计方案的步骤。类似算法 1 的时间与存储复杂度分析，算法 2 的时间复杂度为 $\mathcal O(2\omega_{\mu_1}^2\omega_{\mu_2})+\mathcal O(4\omega_{\mu_1}\omega_{\mu_2}^2)+\mathcal O(\omega_{\mu_1}^3)$，存储复杂度为 $\mathcal S(\omega_{\mu_1}^2)+\mathcal S(4\omega_{\mu_2}^2)$。

虽然已在算法 1 中得到路径的<a id="page-8"></a>角度–时延信息，在算法 2 中得到路径的角度–多普勒信息，但仍需将各路径的角度、时延和多普勒配对，以重构信道。

**算法 2：** 所提三维角度–多普勒估计方案。

**输入** $\mathbf H_u(t)$、$L$、$R$、$Q$、$N_s$、$P$。

1. 按式 (59) 至式 (64) 的过程生成 $\boldsymbol{\mathcal G}_u(f_1)$。
2. 将 $\boldsymbol{\mathcal G}_u(f_1)$ 变换为实矩阵 $\boldsymbol{\mathcal G}_{\mathrm{re}}(f_1)$。
3. 由式 (68) 生成矩阵 $\boldsymbol\Psi_{\omega_\tau}$。
4. 通过对 $\boldsymbol\Psi_{\omega_\tau}$ 作 EVD，由式 (70) 估计 $\hat\omega_{\tau_p}$。
5. 由式 (71) 与式 (72) 生成 $\boldsymbol\Psi_{\omega_\tau,\phi}$ 和 $\boldsymbol\Psi_{\omega_\tau,\theta}$。
6. 由式 (75) 与式 (76) 分别估计 EOD $\hat\theta_{\omega,p}$ 及 AOD $\hat\phi_{\omega,p}$。

**输出** $\hat\omega_{\tau_p}$、$\hat\theta_{\omega,p}$、$\hat\phi_{\omega,p}$，其中 $p\in\{1,\ldots,P\}$。

### C. 所提角度–时延–多普勒配对方案

利用角度估计的超分辨率特性，对各路径的角度、时延及多普勒进行配对。令 $P\times1$ 向量 $\hat{\boldsymbol\theta}$、$\hat{\boldsymbol\phi}$、$\hat{\boldsymbol\tau}(t)$、$\hat{\boldsymbol k}_{\tau}$、$\hat{\boldsymbol\theta}_{\omega}$、$\hat{\boldsymbol\phi}_{\omega}$ 及 $\hat{\boldsymbol\omega}_{\tau}$ 分别表示相应的多径参数估计。定义配对矩阵 $[\mathbf s_{\mathrm{pair},1},\ldots,\mathbf s_{\mathrm{pair},P}]$，建立 $[\hat{\boldsymbol\theta},\hat{\boldsymbol\phi}]$ 和 $[\hat{\boldsymbol\theta}_\omega,\hat{\boldsymbol\phi}_\omega]$ 之间的映射关系：

$$
[\boldsymbol{\hat \theta },\boldsymbol{\hat \phi }] = {[{ {\mathbf{s}}_{ {\mathrm{pair}},1}}, \cdots ,{ {\mathbf{s}}_{ {\mathrm{pair}},{P}}}]}[\boldsymbol{\hat \theta _\omega},\boldsymbol{\hat \phi _\omega}],
\tag{77}
$$

其中 $\mathbf s_{\mathrm{pair},p}=[s_{p,1},\ldots,s_{p,P}]^T$，$p=1,\ldots,P$，是一个仅有一个元素为 1 的 $P\times1$ 单位向量。将 $[\hat{\boldsymbol\theta}_w,\hat{\boldsymbol\phi}_w]$ 的第 $p$ 行记为 $[\hat\theta_{w,p},\hat\phi_{w,p}]$。求解如下最小化问题可得 $\mathbf s_{\mathrm{pair},p}$：

$$
{ {\mathbf{s}}_{ {\mathrm{pair}},p}} = \arg \mathop {\min }\limits_{ { {\mathbf{s}}_{ {\mathrm{pair}},p}}} (\lvert { { {\hat \theta }_{w,p}}{ {\mathbf{1}}_{ {P} \times {1}}} - \boldsymbol{\hat \theta }} \rvert + \lvert { { {\hat \phi }_{w,p}}{ {\mathbf{1}}_{ {P} \times {1}}} - \boldsymbol{\hat \phi }} \rvert),
\tag{78}
$$

具体而言，$|\hat\theta_{w,p}\mathbf1_{P\times1}-\hat{\boldsymbol\theta}|$ 是 $\hat\theta_{w,p}$ 与 $\hat{\boldsymbol\theta}$ 的误差向量，$|\hat\phi_{w,p}\mathbf1_{P\times1}-\hat{\boldsymbol\phi}|$ 是 $\hat\phi_{w,p}$ 与 $\hat{\boldsymbol\phi}$ 的误差向量。使两误差向量之和最小的行索引，为 $\mathbf s_{\mathrm{pair},p}$ 中唯一非零元素的行索引。

用配对结果重排 $\hat{\boldsymbol\omega}_{\tau}$ 的元素，得到多普勒 $\hat{\boldsymbol\omega}$：

$$
\boldsymbol{\hat \omega} = {({[{ {\mathbf{s}}_{ {\mathrm{pair}},1}}, \cdots ,{ {\mathbf{s}}_{ {\mathrm{pair}},{P}}}]})}\boldsymbol{\hat \omega_{\tau}} + {f_1}{\boldsymbol{\hat k_\tau }}.
\tag{79}
$$

现在，$\hat{\boldsymbol\tau}(t)$ 与 $\hat{\boldsymbol\omega}$ 已正确配对，并与相应路径关联。利用估计参数可重构时刻 $t$ 的未来信道 $\hat{\mathbf H}_u(t)$。

**算法 3：** 所提 MDMP 信道预测方法。

1. 用算法 1 估计 $\hat{\boldsymbol\theta}$、$\hat{\boldsymbol\phi}$、$\hat{\boldsymbol\tau}(t)$ 和 $\hat{\boldsymbol k}_\tau$。
2. 用算法 2 估计 $\hat{\boldsymbol\theta}_\omega$、$\hat{\boldsymbol\phi}_\omega$ 和 $\hat{\boldsymbol\omega}_{\tau_p}$。
3. 对 $p=1:P$ 循环。
4. 求解式 (78) 的最小化问题，找到配对矩阵 $[\mathbf s_{\mathrm{pair},1},\ldots,\mathbf s_{\mathrm{pair},P}]^T$。
5. 结束循环。
6. 由式 (79) 计算多普勒 $\hat{\boldsymbol\omega}$。
7. 用估计参数预测未来信道 $\hat{\mathbf H}_u(t)$。

所提 MDMP 方法归纳于算法 3。算法 3 第 3–6 步的时间复杂度为 $\mathcal O(P^2)$，存储复杂度为 $\mathcal S(P^2)$。第 7 步信道重构的时间复杂度为 $\mathcal O(N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}N_fP)$，存储复杂度为 $\mathcal S(N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}N_f)$。MDMP 方法的时间和存储复杂度主要取决于算法 1 与算法 2。因此，MDMP 方法的总体时间复杂度为 $\mathcal O(2\mu_1^2\mu_2)+\mathcal O(4\mu_1\mu_2^2)+\mathcal O(\mu_1^3)+\mathcal O(2\omega_{\mu_1}^2\omega_{\mu_2})+\mathcal O(4\omega_{\mu_1}\omega_{\mu_2}^2)+\mathcal O(\omega_{\mu_1}^3)$，总体存储复杂度为 $\max(\mathcal S(\mu_1^2)+\mathcal S(4\mu_2^2),\mathcal S(\omega_{\mu_1}^2)+\mathcal S(4\omega_{\mu_2}^2))$。

文献 [5] 的 PAD 方法复杂度为 $\mathcal O(NN_tN_f\log(N_tN_f))+\mathcal O(N_pN^{2.37})+\mathcal O(N_dN_pN)$，其中 $N_p\ll N_tN_f$，$N$ 与 $N_d$ 分别为 PAD 方法的预测阶数及预测样本数。MDMP 方法的时间复杂度可能高于 PAD 方法，但其性能更好，且适用于更一般的设置，允许 CSI 时延不等于导频间隔的整数倍，也不要求历史信道样本相邻。详细证明见下一节。

## IV. MDMP 预测方法的性能分析

本节对所提 MDMP 预测方法作性能分析。记时刻 $t$ 的观测样本为 $\tilde{\mathbf H}_u(t)$。将 $\mathbf H_u(t)$、$\tilde{\mathbf H}_u(t)$ 和 $\hat{\mathbf H}_u(t)$ 的向量化形式分别记为 $\mathbf h_u(t)$、$\tilde{\mathbf h}_u(t)$ 与 $\hat{\mathbf h}_u(t)$，即 $\mathbf h_u(t)=\operatorname{vec}(\mathbf H_u(t))$，$\tilde{\mathbf h}_u(t)=\operatorname{vec}(\tilde{\mathbf H}_u(t))$，$\hat{\mathbf h}_u(t)=\operatorname{vec}(\hat{\mathbf H}_u(t))$。在进行渐近性能分析之前，引入一个假设。

**假设 1** 观测样本满足

$$
{ {\mathbf{\tilde h}}_u}(t) = { {\mathbf{h}}_u}(t) + {\mathbf{n}},
\tag{80}
$$

其中 $\mathbf n=[n_1,\ldots,n_{N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}N_f}]^T\in\mathbb C^{N_h^{\mathrm{BS}}N_v^{\mathrm{BS}}N_f\times1}$ 是均值为零、各元素方差为 $\sigma^2$ 的独立同分布高斯白噪声。随 $N_h^{\mathrm{BS}}$、$N_v^{\mathrm{BS}}$ 和 $N_f$ 趋于无穷，方差 $\sigma^2$ 趋于零，从而有

$$
\mathop {\lim }\limits_{N_v^{ {\mathrm{BS}}},N_h^{ {\mathrm{BS}}},{N_f} \to \infty } \frac{ {\left\| { { { {\mathbf{\tilde h}}}_u}(t) - { {\mathbf{h}}_u}(t)} \right\|_2^2}}{ {\left\| { { {\mathbf{h}}_u}(t)} \right\|_2^2}} = 0.
\tag{81}
$$

**说明** 这一技术性假设指，当基站天线数和带宽增大时，归一化的信道样本误差趋于零。实际上，即使在受导频污染的多用户多小区场景中，也可以利用某些非线性信号处理技术 [29] 达到式 (81) 的条件。为简便起见，再引入定义 1 中的向量。

**定义 1** 定义包含各路径参数的向量：

$$
{\mathbf{\Omega}}(t) = {\left[ { { {\mathbf{\Omega }}_1}(t), \cdots ,{ {\mathbf{\Omega }}_P}(t)} \right]^T},
\tag{82}
$$

其中 $\boldsymbol\Omega_p(t)=[\cos\theta_p\sin\phi_p,\sin\theta_p,\omega_p,\tau_p(t)]$，$p=1,\ldots,P$。

<a id="page-9"></a>

**定理 1** 在假设 1 下，对任意 CSI 时延 $t_\tau$，若矩阵束尺寸满足 $N_h^{\mathrm{BS}}-P+1>L>P$、$N_v^{\mathrm{BS}}-P+1>R>P$、$N_f-P+1>K>P$ 及 $N_s-P+1>Q>P$，则 MDMP 预测方法的渐近性能满足

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty }\!\!\!\!\!\! \frac{ {\left\| { { { { {\mathbf{\hat h}}}_u}(t + {t_\tau })} \!-\! { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}}{ {\left\| { { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}} = 0,
\!\!
\tag{83}
$$

**证明** 见附录 A。

**说明** 定理 1 表明，基站天线数和带宽足够大时，信道预测误差趋于零。定理 1 中的 CSI 时延无需为导频间隔的整数倍，这意味着所提 MDMP 方法比文献 [5] 的 PAD 方法更一般，因为 PAD 在 CSI 时延为信道采样间隔整数倍时达到渐近无误差。

若 $Q=P+1$，定理 1 所需的最少样本数应满足 $N_s=2P+1$。在散射丰富的环境中，路径数 $P$ 可能很大。这时定理 1 表明，达到渐近无误差预测可能需要大量样本 $N_s$。下面给出仅已知任意两个样本时预测误差的渐近性能。

**定理 2** 在假设 1 下，若 EOD 和 AOD 满足 $(\theta_p,\phi_p)\neq(\theta_q,\phi_q)$ 对任意 $p\neq q$ 成立，子载波数满足 $N_f\geq2$，且基站天线配置满足 $N_h^{\mathrm{BS}}-P+1>L>P$ 和 $N_v^{\mathrm{BS}}-P+1>R>P$，则仅已知两个任意样本 $\tilde{\mathbf h}_u(n_{s_1}T)$ 与 $\tilde{\mathbf h}_u(n_{s_2}T)$ 时，MDMP 预测方法的渐近性能满足

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}} \to \infty } \frac{ {\left\| { { { { {\mathbf{\hat h}}}_u}(t+ {t_\tau })} \!-\! { { {\mathbf{h}}_u}(t+ {t_\tau })}} \right\|_2^2}}{ {\left\| { { { {\mathbf{h}}_u}(t+ {t_\tau })}} \right\|_2^2}} = 0.
\tag{84}
$$

**证明** 见附录 B。

**说明** 定理 2 要求任意两条路径的角度不同，该假设强于定理 1。但所得结论只需两个样本。这两个样本无需相邻，条件同样比 PAD 方法更一般。

在定理 1 和定理 2 中，基站天线条件，例如 $N_h^{\mathrm{BS}}-P+1>L>P$ 与 $N_v^{\mathrm{BS}}-P+1>R>P$，保证三维 MP 矩阵的秩满足 $r(\mathbf G_{\mathrm{re}}(t+t_\tau))=r(\boldsymbol{\mathcal G}_u(f_1))=P$。若 $L=P+1$ 且 $R=P+1$，基站天线数至少为 $N_t=(2P+1)^2$，似乎偏大。下面假定已知 $r(\mathbf G_{\mathrm{re}}(t+t_\tau))=r(\boldsymbol{\mathcal G}_u(f_1))=P$，推导达到令人满意性能所需基站天线数的下界。为此，引入两个函数。

**定义 2** 定义两个函数 $F_1(L,R)$ 和 $F_2(R)$。第一个为

$$
{F_1}(L,R) = \frac{ {\mathcal{N}}_s}{ {N_v^{ {\mathrm{BS}}} - R + 1}} + L - 1,
\tag{85}
$$

其中 $L$ 与 $R$ 满足

$$
\left\{ \begin{array}{l}
LR \ge \mathcal{Q}\\
L \ge 2\\
N_v^{ {\mathrm{BS}}} \ge R \ge 2
\end{array} \right.,
\tag{86}
$$

$\mathcal N_s=\max(Q/(N_s-Q+1),1)$，$\mathcal Q=\max(P/(Q-1),4)$。另一函数 $F_2(R)$ 定义为

$$
{F_2}(R) \!=\! \frac{P}{ {({N_s} \!-\! Q \!+\! 1)(N_v^{ {\mathrm{BS}}} \!-\! R \!+\! 1)}} \!+\! \frac{P}{ {(R \!-\! 1)Q}} \!-\! 1,
\tag{87}
$$

并满足

$$
\left\{ \begin{array}{l}
LQ \ge { {\max \left( {\frac{P}{ {R - 1}},4} \right)}}\\
N_v^{ {\mathrm{BS}}} \ge R \ge 2
\end{array} \right..
\tag{88}
$$

接下来在命题 1 中推导取得令人满意性能所需基站天线数的下界。对于任意给定的 $N_v^{\mathrm{BS}}$，推导基站总天线数 $N_t$ 的下界。在宽带系统中，$N_f$ 与 $N_s$ 通常满足 $N_f>N_s$。根据式 (39) 和式 (67)，基站天线数的下界由式 (67) 中的 $N_s$ 决定。$N_t$ 的下界由两个子下界 $f_{N_v^{\mathrm{BS}},N_s,1}$ 与 $f_{N_v^{\mathrm{BS}},N_s,2}$ 构成。前者由估计多普勒时的三维 MP 矩阵导出，后者由估计角度时的三维 MP 矩阵导出。

**命题 1** 在宽带信道中，对于给定的 $N_v^{\mathrm{BS}}$，基站天线数 $N_t$ 的下界为

$$
N_t \ge \max ({f_{N_v^{ {\mathrm{BS}}},{N_s},1}},{f_{N_v^{ {\mathrm{BS}}},{N_s},2}}),
\tag{89}
$$

其中

$$
\begin{array}{l}
\!\!\!\!\!{f_{N_v^{ {\mathrm{BS}}},{N_s},1}}=\!\! \max (\!{N_v^{ {\mathrm{BS}}}}{F_1}({L_1},\!{R_1}),\!{N_v^{ {\mathrm{BS}}}}{F_1}({L_2},\!{R_2}),\\
\!{N_v^{ {\mathrm{BS}}}}{F_1}({L_3},\!{R_3}),{N_v^{ {\mathrm{BS}}}}{F_1}({L_4},\!{R_4}),\!{N_v^{ {\mathrm{BS}}}}{F_1}({L_5},\!{R_5})),\!\!\!
\end{array}
\tag{90}
$$

且 $(L_{n_1},R_{n_1})$，$n_1=1,2,3,4,5$，定义为

$$
\begin{array}{l}
{R_1} = \frac{ {\sqrt {\mathcal{Q}} }}{ {\sqrt { {\mathcal{N}}_s}  + \sqrt {\mathcal{Q}} }}(N_v^{ {\mathrm{BS}}} + 1)\\
{L_1} = \frac{ {\sqrt {\mathcal{Q}} (\sqrt { {\mathcal{N}}_s}  + \sqrt {\mathcal{Q}} )}}{ {N_v^{ {\mathrm{BS}}} + 1}}
\end{array},
\tag{91}
$$

$$
\begin{array}{l}
{R_2} = \frac{ {\sqrt {\mathcal{Q}} }}{ {\sqrt {\mathcal{Q}}  - \sqrt { {\mathcal{N}}_s} }}(N_v^{ {\mathrm{BS}}} + 1)\\
{L_2} = \frac{ {\sqrt {\mathcal{Q}} (\sqrt {\mathcal{Q}}  - \sqrt { {\mathcal{N}}_s} )}}{ {N_v^{ {\mathrm{BS}}} + 1}}
\end{array},
\tag{92}
$$

并且 $(R_3=\mathcal Q/2,L_3=2)$、$(R_4=2,L_4=\mathcal Q/2)$、$(R_5=N_v^{\mathrm{BS}},L_5=\mathcal Q/N_v^{\mathrm{BS}})$。$f_{N_v^{\mathrm{BS}},N_s,2}$ 定义为

$$
\begin{array}{l}
\!\!{f_{N_v^{ {\mathrm{BS}}},{N_s},2}} \!\!=\\
\!\!\left\{ \begin{array}{l}
\!\!\!\!\!{N_v^{ {\mathrm{BS}}}}(\frac{1}{ {({N_s} - 1)}} + 1),\ \ \!\!\!\!\!{\mathrm{if}}\ \!N_v^{ {\mathrm{BS}}} \!-\! P \!+\! 1 \!\ge\! R \!\ge\! \frac{P}{4} \!+\! 1\\
\!\!\!\!\!{N_v^{ {\mathrm{BS}}}}(\frac{1}{ {({N_s} - Q + 1)}} \!+\! \frac{P}{Q} \!-\! 1),
\!{\mathrm{if}}\ \!\min (N_v^{ {\mathrm{BS}}} \!-\!\! P\! \!+\! 1,\!\frac{P}{4} \!\!+\! 1) \!\ge\! R\! \ge\! 2\\
\!\!\!\!\!{N_v^{ {\mathrm{BS}}}}(\frac{P}{ {({N_s} - 1)}} + 1),\!{\mathrm{if}}\ \!N_v^{ {\mathrm{BS}}} \!\!\ge\!\! R \!\!\ge\!\! \max (N_v^{ {\mathrm{BS}}} \!\!-\! P \!\!+\! 1,\frac{P}{4} \!+\!\! 1,2)\\
\!\!\!\!\!{N_v^{ {\mathrm{BS}}}}{F_{2,\mathrm{max}}}(R),\!{\mathrm{if}}\ \!P \!>\! R \!\ge\! \max (N_v^{ {\mathrm{BS}}} \!-\! P \!+\! 1,2)
\end{array} \right.\!\!\!\!\!\!,
\end{array}
\tag{93}
$$

其中

$$
\begin{array}{l}
\!\!{F_{2,\mathrm{max}}}(R) \!\!=\\
\!\!\left\{ \begin{array}{l}
\!\!\!\!\max (\!{F_2}(\max (2,\!{R_6})),\!{F_2}(\max (2,\!{R_7})),\\
\!{F_2}(N_v^{ {\mathrm{BS}}})),\; \!{\mathrm{if}} \; Q < \frac{ { {N_s} + 1}}{2}\\
\!\!\!\!\max ({F_2}(\max (2,{R_6})),{F_2}(\max (2,{R_7}))),{\mathrm{if}}\; Q > \frac{ { {N_s} + 1}}{2}\\
\!\!\!\!{F_2}({\frac{(N_v^{ {\mathrm{BS}}} + 1)}{2}}),\; {\mathrm{if}}\ \!Q = \frac{ { {N_s} + 1}}{2}
\end{array} \right.\!,
\end{array}
\tag{94}
$$

<a id="page-10"></a>

且 $R_6$ 和 $R_7$ 分别为

$$
{R_6} = \frac{ {\sqrt { {N_s} - Q + 1} (N_v^{ {\mathrm{BS}}} + 1)}}{ {\sqrt { {N_s} - Q + 1}  + \sqrt Q }},
\tag{95}
$$

$$
{R_7} = \frac{ {\sqrt { {N_s} - Q + 1} (N_v^{ {\mathrm{BS}}} + 1)}}{ {\sqrt { {N_s} - Q + 1}  - \sqrt Q }}.
\tag{96}
$$

**证明** 见附录 C。

**说明** 命题 1 针对给定的 $N_v^{\mathrm{BS}}$ 推导 $N_t$ 的下界。若基站天线配置无法满足该下界，MDMP 方法就不能工作。作为补救，可以增加信道样本数 $N_s$ 来减小下界，使天线配置满足要求。若给定的是 $N_h^{\mathrm{BS}}$，也可以推导 $N_t$ 的下界，具体推导省略。

## VI. 结论

本文研究了工业信道模型中具有时变路径时延的大规模 MIMO 移动性挑战，提出一种新的多维矩阵束信道预测方法，利用宽带大规模 MIMO 信道的角度–时间域和角度–频率域结构，同时估计角度、时延及多普勒。还利用角度估计的超分辨率特性提出配对方法，将估计出的角度、时延与多普勒关联到各路径。在理论分析中证明，只需已知任意两个样本，所提 MDMP 方法在任意 CSI 时延下可以达到渐近无误差。还推导了该方法正常工作所需基站天线数的下界，增加信道样本数可以减小该下界。仿真表明，在 CSI 时延较大的高移动性场景中，所提 MDMP 方法的性能非常接近静止设置。

### A. 定理 1 的证明

为便于说明，先根据观测信道样本计算参数估计，再证明估计趋于精确取值。先按如下方法估计信道参数。任意 CSI 时延 $t_\tau$ 后，将 $t$ 更新为 $t+t_\tau$，将式 (13) 中的信道改写为

$$
{ {\mathbf{\tilde H}}_u}(t + {t_\tau }) = { {\mathbf{A}}_u}{ {\mathbf{C}}_u}{ {\mathbf{\bar C}}_u}\left( { { {\mathbf{\bar B}}_u} \odot { {\mathbf{B}}_u}} \right) + {\mathbf{N}},
\tag{97}
$$

其中 $\mathbf N$ 为样本噪声矩阵。矩阵 $\bar{\mathbf C}_u$ 由 UE 在 $t_\tau$ 期间的运动产生，表示为

$$
{ {\mathbf{\bar C}}_u} = {\mathrm{diag}}\left\{ {\begin{array}{cccccccccccccccccccc}{e^{j2\pi {\omega _1}{t_\tau }},}&{\cdots,}&{e^{j2\pi {\omega _P}{t_\tau }}} \end{array}} \right\}.
\tag{98}
$$

矩阵 $\bar{\mathbf B}_u$ 包含多径时延响应向量，给出如下：

$$
{ {\mathbf{\bar B}}_u} = \left[ {\begin{array}{cccccccccccccccccccc}{ {\mathbf{\bar b}}({f_1}),}&{\cdots,}&{ {\mathbf{\bar b}}({f_{ {N_f}}})} \end{array}} \right],
\tag{99}
$$

其中

$$
{\mathbf{\bar b}}({f_{n_f}}) = {\left[ {\begin{array}{cccccccccccccccccccc}{e^{ - j2\pi {f_{n_f}} {k_{ {\tau _1}}} {t_\tau }},}&{\cdots,}&{e^{ - j2\pi {f_{n_f}} {k_{ {\tau _P}}} {t_\tau }}} \end{array}} \right]^T}\!\!.
\tag{100}
$$

三维 MP 矩阵可表示为

$$
\!{ {\mathbf{\tilde G}}_u}(t + {t_\tau }) \!=\! { {\check{\mathbf{E}}}_{2}}(t + {t_\tau }){\mathbf{Y}}(t + {t_\tau }){ {\check{\mathbf{F}}}_{2}}(t + {t_\tau }) + {\mathbf{N}_{ {\mathbf{\tilde G}}_u}},
\tag{101}
$$

其中 $\mathbf N_{\tilde{\mathbf G}_u}\in\mathbb C^{\mu_1\times\mu_2}$ 由 $\mathbf N$ 生成，并有

$$
{\mathbf{Y}}(t + {t_\tau }) = {\mathbf{Y}}{ {\mathbf{\bar C}}_u}{\mathrm{diag}}\left\{ { {\mathbf{\bar b}}({f_1})} \right\},
\tag{102}
$$

$$
\ \ \ \ \ \ \ \ \ { {\check{\mathbf{E}}}_{2}}(t + {t_\tau }) = {\left[\! {\begin{array}{cccccccccccccccccccc}{({ {\check{\mathbf{E}}}_{1}})^T,}\!\!&\!{\cdots,}\!\!&\!{({ {\check{\mathbf{E}}}_{1}}{ {\mathbf{Z}}_{ {t_\tau}}^{K - 1}})^T} \end{array}} \!\right]^T}\!,
\tag{103}
$$

$$
\!{ {\check{\mathbf{F}}}_{2}}(t + {t_\tau }) = \left[\! {\begin{array}{cccccccccccccccccccc}{ {\check{\mathbf{F}}}_{1}}\!&\!{\cdots,}\!&\!{ { {\mathbf{Z}}_{ {t_\tau}}^{ {N_f} - K}}{ {\check{\mathbf{F}}}_{1}}} \end{array}} \!\right],
\tag{104}
$$

以及

$$
{ {\mathbf{Z}}_{t_\tau}} = { {\mathbf{Z}}_\tau} {\mathrm{diag}}\left\{ { {\mathbf{\bar b}}({f_{ {n_f}+1}})} \right\}{\left( { {\mathrm{diag}}\left\{ { {\mathbf{\bar b}}({f_{n_f}})} \right\}} \right)^*}.
\tag{105}
$$

由于 $N_h^{\mathrm{BS}}-P+1>L>P$、$N_v^{\mathrm{BS}}-P+1>R>P$、$N_f-P+1>K>P$，可得 $r(\tilde{\mathbf G}_u(t+t_\tau))\geq P$，且 $\tilde{\mathbf G}_u(t+t_\tau)$ 包含各路径的角度与时延信息。$\tilde{\mathbf G}_u(t+t_\tau)$ 的 SVD 为 $\tilde{\mathbf G}_u(t+t_\tau)=\tilde{\mathbf U}_{u,t_\tau}\tilde{\mathbf S}_{u,t_\tau}\tilde{\mathbf V}_{u,t_\tau}^H$，其中 $\tilde{\mathbf U}_{u,t_\tau}=[\tilde{\mathbf u}_{u,t_\tau,1},\ldots,\tilde{\mathbf u}_{u,t_\tau,M_\tau}]$，$\tilde{\mathbf S}_{u,t_\tau}=\operatorname{diag}\{\tilde s_{u,t_\tau,1},\ldots,\tilde s_{u,t_\tau,M_\tau}\}$，$\tilde{\mathbf S}_{u,t_\tau}$ 的对角元素按非递增次序排列。不失一般性，令 $\mu_1<\mu_2$、$M_\tau=\mu_1$。

设置新阈值 $\gamma_2$，确定不可忽略的路径数量为 $P_1\leq P$。将 $\tilde{\mathbf U}_{u,t_\tau}$ 的相应 $P_1$ 列记为 $\tilde{\mathbf U}_{u,s,t_\tau}$。从 $\check{\mathbf E}_2(t+t_\tau)$ 选择 $P_1$ 列构成 $\check{\mathbf E}_{s,2}(t+t_\tau)$。由于 $r(\tilde{\mathbf U}_{u,s,t_\tau})=r(\check{\mathbf E}_{s,2}(t+t_\tau))=P_1$，两者可满足映射关系 $\tilde{\mathbf U}_{u,s,t_\tau}=\check{\mathbf E}_{s,2}(t+t_\tau)\mathbf T_1$，其中 $\mathbf T_1\in\mathbb C^{P_1\times P_1}$ 为满秩矩阵。分别将 $\tilde{\mathbf U}_{u,s,t_\tau}$ 的前 $KRL-RL$ 行、后 $KRL-RL$ 行记为 $\tilde{\mathbf U}_{u,s1}$、$\tilde{\mathbf U}_{u,s2}$，它们满足

$$
\!{ {\mathbf{\tilde U}}_{u,s2}} \!-\! { {\mathbf{\tilde U}}_{u,s1}}{ {\boldsymbol{\lambda }}_{t_\tau} } \!\!=\! { {\mathbf{J}}_1}{ {\check{\mathbf{E}}}_{s,2}}(t \!+\! {t_\tau })({ {\mathbf{T}}_1^{ - 1}}{ {\mathbf{ Z}}_{t_\tau}}{\mathbf{T}}_1 \!-\! { {\boldsymbol{\lambda }}_{t_\tau} }) \!= \!{\mathbf{0}},
\tag{106}
$$

其中 $\boldsymbol\lambda_{t_\tau}=\tilde{\mathbf U}_{u,s1}^\dagger\tilde{\mathbf U}_{u,s2}=\mathbf T_1^{-1}\mathbf Z_{t_\tau}\mathbf T_1$。矩阵 $\boldsymbol\lambda_{t_\tau}$ 与对角矩阵 $\mathbf Z_{t_\tau}$ 相似，具有相同的特征值。

使用 UMP 方法，$\tilde{\mathbf G}_u(t+t_\tau)$、$\mathbf Z_{t_\tau}$ 和 $\boldsymbol\lambda_{t_\tau}$ 分别变换为 $\tilde{\mathbf G}_{\mathrm{re}}(t+t_\tau)$、$\hat{\mathbf Z}_{t_\tau}$ 和 $\tilde{\boldsymbol\Psi}_{t_\tau}$，其中 $\tilde{\mathbf G}_{\mathrm{re}}(t+t_\tau)$ 定义为

$$
\begin{array}{l}
{ { {\mathbf{\tilde G}}}_{ {\mathrm{re}}}}(t + {t_\tau }) = { { {\mathbf{G}}}_{ {\mathrm{re}}}}(t + {t_\tau }) + { { {\mathbf{N}}}_{ {\mathrm{re}}}},
\end{array}
\tag{107}
$$

且 $\mathbf N_{\mathrm{re}}$ 由 $\mathbf N_{\tilde{\mathbf G}_u}$ 生成。对角矩阵 $\hat{\mathbf Z}_{t_\tau}$ 和矩阵 $\tilde{\boldsymbol\Psi}_{t_\tau}$ 由下式引入：

$$
\begin{array}{l}
{ { {\mathbf{\hat Z}}}_{t_\tau}} = {\mathrm{diag}}\{ \tan (\pi \Delta f({\tau _1}(t + {t_\tau }))), \cdots ,\\
\ \ \ \ \ \ \ \tan (\pi \Delta f({\tau _{ {P_1}}}(t+{t_\tau })))\},
\end{array}
\tag{108}
$$

$$
{ {\mathbf{\tilde \Psi }}_{ {t_\tau }}} = {\left[ { {\mathop\mathrm{Re}\nolimits} ({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ {\mathbf{\tilde U}}_{s,t_\tau} }} \right]^\dagger }{\mathop\mathrm{Im}\nolimits}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ {\mathbf{\tilde U}}_{s,t_\tau} },
\tag{109}
$$

其中 $\tilde{\mathbf U}_{s,t_\tau}$ 为 $\tilde{\mathbf U}_{t_\tau}$ 中的 $P_1$ 列，而 $\tilde{\mathbf U}_{t_\tau}$ 由对 $\tilde{\mathbf G}_{\mathrm{re}}(t+t_\tau)$ 作 SVD 得到：

<a id="page-13"></a>

$$
{ { {\mathbf{\tilde G}}}_{ {\mathrm{re}}}}(t + {t_\tau }) = { {\mathbf{\tilde U}}_{t_\tau} }{ {\mathbf{\tilde S}}_{t_\tau} }{\mathbf{\tilde V}}_{t_\tau} ^H = { {\mathbf{ U}}_{t_\tau} }{ {\mathbf{ S}}_{t_\tau} }{\mathbf{ V}}_{t_\tau} ^H + { {\mathbf{ U}}_{ {\mathbf{N}}_{\mathrm{re}}} }{ {\mathbf{ S}}_{ {\mathbf{N}}_{\mathrm{re}}} }{\mathbf{ V}}_{ {\mathbf{N}}_{\mathrm{re}}} ^H,
\tag{110}
$$

其中 $\tilde{\mathbf U}_{t_\tau}=[\tilde{\mathbf u}_{t_\tau,1},\ldots,\tilde{\mathbf u}_{t_\tau,\mu_1}]$，$\tilde{\mathbf S}_{t_\tau}=\operatorname{diag}\{\tilde s_{t_\tau,1},\ldots,\tilde s_{t_\tau,\mu_1}\}$，$\mathbf U_{t_\tau}=[\mathbf u_{t_\tau,1},\ldots,\mathbf u_{t_\tau,\mu_1}]$，$\mathbf S_{t_\tau}=\operatorname{diag}\{s_{t_\tau,1},\ldots,s_{t_\tau,\mu_1}\}$。

显然，$\tilde{\boldsymbol\Psi}_{t_\tau}$ 和 $\hat{\mathbf Z}_{t_\tau}$ 是相似矩阵。对 $\tilde{\boldsymbol\Psi}_{t_\tau}$ 作 EVD，可按 $\hat{\mathbf Z}_{t_\tau}=\mathbf W_{t_\tau}^{-1}\tilde{\boldsymbol\Psi}_{t_\tau}\mathbf W_{t_\tau}$ 估计 $\hat{\mathbf Z}_{t_\tau}$，其中 $\mathbf W_{t_\tau}$ 包含 $\tilde{\boldsymbol\Psi}_{t_\tau}$ 的特征向量。经历 CSI 时延 $t_\tau$ 后，路径时延 $\hat\tau_p(t+t_\tau)$ 的估计为

$$
\begin{array}{l}
{\hat \tau _p}(t + {t_\tau }) = \frac{ { { {\tan }^{ - 1}}\left( { { {\hat z}_{t_\tau,p}}(t + {t_\tau })} \right)}}{ {\pi \Delta f}},
\end{array}
\tag{111}
$$

其中 $\hat z_{t_\tau,p}(t+t_\tau)$ 是 $\hat{\mathbf Z}_{t_\tau}$ 的第 $p$ 个估计对角元素。用两个不同样本估计路径时延变化率 $\hat k_{\tau_p}$：

$$
{\hat k_{ {\tau _p}}} = \frac{ { { {\tan }^{ - 1}}\left( { { {\hat z}_{t_\tau,p}}({t_2} + {t_\tau })} \right) - { {\tan }^{ - 1}}\left( { { {\hat z}_{t_\tau,p}}({t_1} + {t_\tau })} \right)}}{ {\pi \Delta f({t_2} - {t_1})}}\!.
\tag{112}
$$

其余参数，即多普勒、EOD 和 AOD，也可采用类似于估计 $\hat\tau_p(t+t_\tau)$ 的过程得到，具体细节省略。

至此，完成了利用观测样本估计各参数的步骤。接下来推导假设 1 下参数估计的渐近性能。当基站天线数和带宽较大时，$\tilde{\mathbf G}_{\mathrm{re}}(t+t_\tau)$ 的相关矩阵为

$$
\begin{array}{l}
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } { {\boldsymbol{R}}_{ { { {\mathbf{\tilde G}}}_{ {\mathrm{re}}}}}} = E\{ { { {\mathbf{\tilde G}}}_{ {\mathrm{re}}}}(t + {t_\tau }){ { { {\mathbf{\tilde G}}}_{ {\mathrm{re}}}}^H}(t + {t_\tau })\}  \\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ = { {\boldsymbol{R}}_{ { {\mathbf{G}}_{ {\mathrm{re}}}}}} + {\sigma ^2}{ {\mathbf{I}}_{ {\mu_1}}},
\end{array}
\tag{113}
$$

其中 $\boldsymbol R_{\mathbf G_{\mathrm{re}}}=E\{\mathbf G_{\mathrm{re}}(t+t_\tau)\mathbf G_{\mathrm{re}}^H(t+t_\tau)\}$，$\sigma^2\mathbf I_{\mu_1}=E\{\mathbf N_{\mathrm{re}}\mathbf N_{\mathrm{re}}^H\}$，$E\{\cdot\}$ 表示对基站天线及带宽取期望。对 $\boldsymbol R_{\tilde{\mathbf G}_{\mathrm{re}}}$ 进行 SVD 得

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } \!\!\!\!\!\!\!{ {\mathbf{\tilde U}}_{ {t_\tau }}}{ {\mathbf{\tilde \Sigma }}_{ {t_\tau }}}{\mathbf{\tilde U}}_{ {t_\tau }}^H \!=\! { {\mathbf{U}}_{ {t_\tau }}}{ {\mathbf{\Sigma }}_{ {t_\tau }}}{\mathbf{U}}_{ {t_\tau }}^H \!+\! { {\mathbf{U}}_{ {t_\tau }}}{ {\mathbf{\Sigma }}_{ {\mathbf{N}}_{\mathrm{re}}}}{\mathbf{U}}_{ {t_\tau }}^H,
\tag{114}
$$

其中 $\boldsymbol\Sigma_{\mathbf N_{\mathrm{re}}}=\sigma^2\mathbf I_{\mu_1}$，且

$$
{ {\mathbf{\tilde \Sigma }}_{ {t_\tau }}}={\mathrm{diag}}\{ {\begin{array}{cccccccccccccccccccc}{\lvert{ {\tilde s}_{ {t_\tau },1}}\rvert^2,}&{\cdots,}&{\lvert{ {\tilde s}_{ {t_\tau },{\mu_1}}}\rvert^2} \end{array}}\},
\tag{115}
$$

$$
{ {\mathbf{\Sigma }}_{ {t_\tau }}} = {\mathrm{diag}}\{ {\begin{array}{cccccccccccccccccccc}{\lvert{s_{ {t_\tau },1}}\rvert^2,}&{\cdots,}&{\lvert{s_{ {t_\tau },{\mu_1}}}\rvert^2} \end{array}}\}.
\tag{116}
$$

在假设 1 下可以得到

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } { { {\mathbf{\tilde u}}}_{ {t_\tau },n}} = { {\mathbf{u}}_{ {t_\tau },n}}{e^{j{\vartheta _n}}},
\tag{117}
$$

其中 $\vartheta_n\in[0,2\pi]$，且

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } \!{ {\mathbf{\tilde \Sigma }}_{ {t_\tau }}} \!=\! \mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } ({ {\mathbf{\Sigma }}_{ {t_\tau }}} \!+\! { {\mathbf{\Sigma }}_{ {\mathbf{N}}_{\mathrm{re}}}}) = { {\mathbf{\Sigma }}_{ {t_\tau }}}.
\tag{118}
$$

换言之，$\tilde{\boldsymbol\Sigma}_{t_\tau}$ 与 $\boldsymbol\Sigma_{t_\tau}$ 的第 $n$ 个对角元素满足 $\lim_{N_h^{\mathrm{BS}},N_v^{\mathrm{BS}},N_f\to\infty}|\tilde s_{t_\tau,n}|^2=|s_{t_\tau,n}|^2$。根据式 (110)，可得 $\lim_{N_h^{\mathrm{BS}},N_v^{\mathrm{BS}},N_f\to\infty}\tilde{\mathbf S}_{t_\tau}=\mathbf S_{t_\tau}$，且 $\lim_{N_h^{\mathrm{BS}},N_v^{\mathrm{BS}},N_f\to\infty}P_1=P$。根据式 (110)，将 $\mathbf U_{t_\tau}$ 的 $P$ 列记为 $\mathbf U_{s,t_\tau}$，可得

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } { { {\mathbf{\tilde U}}}_{ {s, t_\tau}}} = { { {\mathbf{ U}}}_{ {s, t_\tau}}}{\mathbf{\Gamma }},
\tag{119}
$$

其中 $\boldsymbol\Gamma=[\boldsymbol\chi_1,\ldots,\boldsymbol\chi_P]\in\mathbb C^{P\times P}$，$\boldsymbol\chi_n$ 是一个 $P\times1$ 单位向量，其第 $n$ 个元素为 $e^{j\vartheta_n}$。与路径时延相关的实矩阵渐近收敛于

$$
\begin{array}{l}
\!\!\!\!\!\!\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty }\!\!\!\!{ {\mathbf{\tilde \Psi }}_{ {t_\tau }}}\!=\!\!\!\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } \!{\left[{ {\mathrm{Re}}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ { {\mathbf{\tilde U}}}_{s,{t_\tau }}}} \!\right]^\dagger }\\
 \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ {\mathrm{Im}}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ { {\mathbf{\tilde U}}}_{s,{t_\tau }}}\\
\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ = \mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } {\mathbf{\Gamma }}^{ - 1}{ {\mathbf{\hat \Psi }}_{t_\tau}}{ {\mathbf{\Gamma }}},
\end{array}
\tag{120}
$$

其中 $\hat{\boldsymbol\Psi}_{t_\tau}$ 由无噪声的样本生成：

$$
\begin{array}{l}
{ {\mathbf{\hat \Psi }}_{t_\tau}} = {\left[ { {\mathrm{Re}}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ { {\mathbf{U}}}_{s,{t_\tau }}}} \right]^\dagger }{\mathrm{Im}}({\mathbf{Q}}_{\mu_3}^H{ {\mathbf{J}}_1}{\mathbf{Q}}_{\mu_1}^{}){ { {\mathbf{U}}}_{s,{t_\tau }}}
\end{array}.
\tag{121}
$$

显然，$\tilde{\boldsymbol\Psi}_{t_\tau}$ 与 $\hat{\boldsymbol\Psi}_{t_\tau}$ 相似，具有相同的特征值。换言之，尽管存在观测噪声，第 $p$ 条路径的时延估计 $\hat\tau_p(t+t_\tau)$ 仍渐近收敛到精确值，即

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } {\hat \tau _p}(t+{t_\tau }) = { \tau _p}(t+{t_\tau }).
\tag{122}
$$

类似地，

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty } { {\mathbf{\hat \Omega }}(t + {t_\tau })} = { {\mathbf{\Omega }}(t + {t_\tau })}.
\tag{123}
$$

使用 $\hat{\boldsymbol\Omega}(t+t_\tau)$ 中的参数估计，将经历 $t_\tau$ 后的信道重构为 $\hat{\mathbf H}_u(t+t_\tau)$，可得

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}},{N_f} \to \infty }\!\!\!\!\!\! \frac{ {\left\| { { { { {\mathbf{\hat h}}}_u}(t + {t_\tau })} \!-\! { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}}{ {\left\| { { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}} = 0.
\tag{124}
$$

至此，定理 1 得证。

### B. 定理 2 的证明

首先推导最少样本数。用观测样本生成的二维 MP 矩阵 $\tilde{\boldsymbol{\mathcal G}}_u(n_s,f_1)$ 定义为

$$
{ { {\boldsymbol{\tilde \mathcal G}}_u}({n_s},{f_1})} = { { {\boldsymbol{\mathcal G}}_u}({n_s},{f_1})} + { {\mathbf{N}}_{ {\boldsymbol{\mathcal G}},{n_s}}},
\tag{125}
$$

其中 $\mathbf N_{\boldsymbol{\mathcal G},n_s}\in\mathbb C^{LR\times(N_h^{\mathrm{BS}}-L+1)(N_v^{\mathrm{BS}}-R+1)}$ 为噪声矩阵。三维 MP 矩阵 $\tilde{\boldsymbol{\mathcal G}}_u(f_1)$ 表示为

$$
{ { {\boldsymbol{\tilde \mathcal G}}_u}({f_1})} = { { {\boldsymbol{\mathcal G}}_u}({f_1})} + { {\mathbf{N}}_{ {\boldsymbol{\mathcal G}}}},
\tag{126}
$$

其中 $\mathbf N_{\boldsymbol{\mathcal G}}\in\mathbb C^{\omega_{\mu_1}\times\omega_{\mu_2}}$。由于 $N_h^{\mathrm{BS}}-P+1>L>P$ 和 $N_v^{\mathrm{BS}}-P+1>R>P$，可得 $r(\boldsymbol{\mathcal G}_u(n_s,f_1))=P$。因此，$\boldsymbol{\mathcal G}_u(n_s,f_1)$ 与 $\tilde{\boldsymbol{\mathcal G}}_u(n_s,f_1)$ 包含角度信息。根据式 (60) 中 $\boldsymbol{\mathcal G}_u(n_s,f_1)$ 的表达式，$r(\check{\mathbf E}_1)=r(\mathbf Y_\omega)=r(\mathbf Z_{\omega_\tau})=r(\check{\mathbf F}_1)=P$。根据式 (65)，应用如下不等式：

$$
r(A) \!+\! r(B) \!-\! {n_1} \!\le\! r(AB) \!\le\! \min(r(A),\!r(B)),
\tag{127}
$$

$$
r(A + B) \le r(A,B) \le r(A) + r(B),
\tag{128}
$$

<a id="page-14"></a>

其中 $A\in\mathbb C^{m_1\times n_1}$，$B\in\mathbb C^{n_1\times m_2}$，可得 $\check{\mathbf E}_{\omega,2}$ 的秩满足

$$
\begin{array}{l}
r({ {\check{\mathbf{E}}}_{\omega,2}}) \ge r({ {\check{\mathbf{E}}}_{1}} +  \cdots  + { {\check{\mathbf{E}}}_{1}}{\mathbf{Z}}_{\omega_\tau}^{Q - 1})\\

\ \ \ \ \ \ \ \ \ \ \ge r({ {\check{\mathbf{E}}}_{1}}) + r((\sum\limits_{q = 1}^Q { {\mathbf{Z}}_{\omega_\tau}^{q - 1}} )) - P\\
\ \ \ \ \ \ \ \ \ \  = P,
\end{array}
\tag{129}
$$

并且 $r(\check{\mathbf E}_{\omega,2})\leq\min(LRQ,P)=P$，因为 $\check{\mathbf E}_{\omega,2}\in\mathbb C^{LRQ\times P}$。因此，$r(\check{\mathbf E}_{\omega,2})=P$。类似地，$r(\check{\mathbf F}_{\omega,2})=r(\mathbf Y_\omega)=P$。由式 (127)，$r(\boldsymbol{\mathcal G}_u(f_1))$ 满足

$$
\begin{array}{l}
r({ {\boldsymbol{\mathcal G}}_u}({f_1})) \!\le\! \min(r({ {\check{\mathbf{E}}}_{\omega,2}}),r({ {\mathbf{Y}}_\omega}),r({ {\check{\mathbf{F}}}_{\omega,2}})) \!= \!P,
\end{array}
\tag{130}
$$

$$
\ \ \ \ \ r({ {\boldsymbol{\mathcal G}}_u}({f_1})) \!\ge\! r({ {\check{\mathbf{E}}}_{\omega,2}}) \!+\! r({ {\mathbf{Y}}_\omega}) \!+\! r({ {\check{\mathbf{F}}}_{\omega,2}}) \!-\! 2P \!\!=\! P.
\tag{131}
$$

因此 $r(\boldsymbol{\mathcal G}_u(f_1))=P$，且当 $N_s=Q=2$ 时仍成立。类似地，可以推导子载波数的最小值满足 $N_f=K=2$。设 $N_s=Q=2$、$N_f=K=2$ 即可计算参数估计，细节省略。按照附录 A 中式 (113) 到式 (122) 之间的类似步骤可证明

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}} \to \infty} { {\mathbf{\hat \Omega }}(t + {t_\tau })} = { {\mathbf{\Omega }}(t + {t_\tau })}.
\tag{132}
$$

换言之，

$$
\mathop {\lim }\limits_{N_h^{ {\mathrm{BS}}},N_v^{ {\mathrm{BS}}} \to \infty}\!\!\!\!\!\! \frac{ {\left\| { { { { {\mathbf{\hat h}}}_u}(t + {t_\tau })} \!-\! { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}}{ {\left\| { { { {\mathbf{h}}_u}(t + {t_\tau })}} \right\|_2^2}} = 0.
\tag{133}
$$

至此，定理 2 得证。

### C. 命题 1 的证明

在多普勒估计中，根据式 (67)，$N_h^{\mathrm{BS}}$ 应满足 $N_h^{\mathrm{BS}}\geq F_1(L,R)$。在 $LR=\mathcal Q$ 的条件下，定义 Lagrange 函数

$$
F(L,R,\lambda ) = {F_1}(L,R) + \lambda (LR - \mathcal{Q}).
\tag{134}
$$

令 $\partial F(L,R,\lambda)/\partial L=\partial F(L,R,\lambda)/\partial R=\partial F(L,R,\lambda)/\partial\lambda=0$，得到 $R$ 和 $L$ 的两个极值点 $(R_1,L_1)$ 和 $(R_2,L_2)$，分别如式 (91) 与式 (92) 所示。若 $\mathcal Q=\mathcal N_s$，则略去 $R_2$ 与 $L_2$。此外，式 (86) 对 $L$ 和 $R$ 的条件还覆盖另外三个极值点，即 $(R_3=\mathcal Q/2,L_3=2)$、$(R_4=2,L_4=\mathcal Q/2)$ 和 $(R_5=N_v^{\mathrm{BS}},L_5=\mathcal Q/N_v^{\mathrm{BS}})$。将这些极值点代入 $F_1(L,R)$ 得 $N_t\geq f_{N_v^{\mathrm{BS}},N_s,1}$，其中 $f_{N_v^{\mathrm{BS}},N_s,1}$ 见式 (90)。

至此，已导出多普勒估计的子下界。接下来推导角度估计的子下界。在角度估计中，$N_h^{\mathrm{BS}}$ 和 $N_s$ 满足

$$
\begin{array}{l}
(N_h^{ {\mathrm{BS}}} \!-\! L \!+\! 1)({N_s} \!-\! Q \!+\! 1) \!\ge\! \max \left(\! {\frac{P}{ {N_v^{ {\mathrm{BS}}} - R + 1}},1}\! \right).
\end{array}
\tag{135}
$$

根据 $R$ 的大小，将式 (88) 对 $R$ 的条件（$LQ\geq\max(P/(R-1),4)$ 且 $N_v^{\mathrm{BS}}\geq R\geq2$）分为四种情形：

1. $N_v^{\mathrm{BS}}-P+1\geq R\geq P/4+1$。
2. $\min(N_v^{\mathrm{BS}}-P+1,P/4+1)\geq R\geq2$。
3. $N_v^{\mathrm{BS}}\geq R\geq\max(N_v^{\mathrm{BS}}-P+1,P/4+1,2)$。
4. $P>R\geq\max(N_v^{\mathrm{BS}}-P+1,2)$。

由此得到式 (93) 的 $f_{N_v^{\mathrm{BS}},N_s,2}$。若 $\partial F_2(R)/\partial R=0$，可求出 $R_6$、$R_7$，见式 (95) 和式 (96)。根据 $Q$ 的取值分别为 $Q<(N_s+1)/2$、$Q>(N_s+1)/2$、$Q=(N_s+1)/2$，得到式 (94) 的 $F_{2,\mathrm{max}}(R)$。

最后，$N_t$ 的下界为 $N_t\geq\max(f_{N_v^{\mathrm{BS}},N_s,1},f_{N_v^{\mathrm{BS}},N_s,2})$。命题 1 得证。

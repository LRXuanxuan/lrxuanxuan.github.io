# PilotWiMAE：面向无线信道的原生导频表示学习

**原题：** PilotWiMAE: Pilot-Native Representation Learning for Wireless Channels

**作者：** Berkay Guler、Giovanni Geraci、Hamid Jafarkhani。

**来源：** arXiv:2605.22856v1，2026-05-19，共 14 页。该版本已提交 IEEE 待审；部分结果投稿至非归档的 ICML AI4NextG Workshop [1]。本文对原始论文做中文翻译，保留原公式、图表、参考文献编号。

**状态：** 中文全文初稿已覆盖摘要、六节正文、公式 (1)–(18)、表 I–VII、图 1–12 图注、附录 A–D 与参考文献 [1]–[44]；待最终页面渲染与逐项复核后验收。

## 摘要

现有信道基础模型假定可以取得完整观测的信道，但该假设在实际部署中并不成立。本文提出 PilotWiMAE，一种自监督学习框架，其编码器直接接收含噪导频观测，注意力机制将时间处理和联合空间—频率处理分解到不同轴上，这是受到问题物理规律启发的归纳偏置。使用导频输入使观测空间最多缩小两个数量级，同时消除完整 CSI 必须可用这一不现实假设，并降低推理时延。通过利用信道的可分离结构，分解式设计能够生成稳健的表示，使预训练掩码比例可高达 99%。作者将捕获小尺度衰落结构的 patch 归一化重建与恢复大尺度衰落特征的辅助尺度损失配合使用，并通过加性白高斯噪声（AWGN）课程学习，使预训练中的导频噪声与部署条件相匹配。模型仅使用 3.5 GHz 数据预训练，再在 28 GHz 的分布内和分布外场景下评价。尽管输入观测空间更小，PilotWiMAE 在跨频段波束选择和信道表征任务上仍优于监督基线。为了减弱解码器容量与表示质量之间的耦合，作者在编码器—解码器联合预训练后加入以解码器为中心的第二阶段预训练，在不牺牲表示质量的情况下获得具有竞争力的信道估计性能。为支持该方向的进一步研究，作者公开了 PilotWiMAE 的预训练权重、训练流程、基于 Sionna 射线追踪的信道生成工具 CSIGen，以及本文使用的信道数据集。

**索引词：** 自监督学习；无线信道表示；基础模型；AI 原生无线系统。

## I. 引言

近期的信道基础模型通过对随机信道模拟器或射线追踪器生成的完整信道进行预训练和评价，在学习可迁移无线信道表示方面取得显著进展 [2]–[18]。其中一些工作为了提高现实性，会在完整观测信道上加入独立同分布的加性白高斯噪声（i.i.d. AWGN）[2]、[4]–[10]、[15]–[18]；另一些则完全不进行噪声条件下的评价。两种设置都不能真实反映实际信道状态信息（CSI）误差的产生方式。

真实接收机根据导频估计信道；在没有导频复用干扰时，只有导频资源元素处的误差才可建模为 i.i.d. AWGN [19]。占据网格绝大多数位置的非导频资源元素，其误差取决于插值方法、信道时延—多普勒结构、导频密度、导频处 SNR 和导频设计，无法用简单 i.i.d. 模型表征 [20]。因此，使用完整信道或 i.i.d. 加噪信道评价模型，只能检验其学习信道结构的能力，却无法回答当真实系统中根本无法直接获得完整信道时，模型会有何表现。考虑到学习式方法对噪声及分布偏移的已知敏感性 [21]、[22]，有必要弥补这一缺口。

第二个缺口涉及实际部署成本。无线基础模型在很大程度上继承了计算机视觉和语言模型中的 Transformer 架构 [23]、[24] 及训练方法 [25]、[26]。在这些领域中，参数数量与序列长度通常不受严格的运行时上限约束，增加数据和计算往往可以可预测地提升性能 [27]–[29]。但无线系统中的预编码、调度和解码必须在时隙级预算内完成，典型时间尺度为 1 ms 或更短 [30]。然而，现有信道基础模型论文很少报告计算开销；即使报告，往往采用高端 GPU 和不统一的优化软件栈（例如量化或 FlashAttention [31]），使大型模型看起来可以实用部署，却掩盖了其真实成本。

本文以两个同等重要的设计原则同时解决上述问题。首先是**从设计上保证稳健性**：直接在稀疏、含噪的导频观测上运行。这样可以把显式信道估计器从关键推理路径中移除，避免低 SNR 下的误差传播；输入与部署时真正可观测的数据一致，消除了已有信道基础模型的完整 CSI 假设，并可与既有基于导频的通信协议自然融合。信道恢复则被视为利用同一学习表示的下游任务，与基于重建的预训练目标天然一致。

其次是**从设计上体现无线专用性**：将注意力分解为时间域和空间—频率域两部分。这一归纳偏置来自广义平稳非相关散射（WSSUS）模型 [32] 及其 MIMO 推广 [33]；时间相关和频谱—空间相关源于不同的物理机制。同一原则也决定预训练目标：使用 patch 归一化重建学习小尺度衰落，同时以辅助尺度损失恢复大尺度衰落统计特征。

总体上，导频输入缩小了观测空间，分解式架构利用可分离的信道结构，使预训练能够采用 99% 的高掩码率。两者结合，在真实存在噪声和部分观测的决策场景下获得亚毫秒级推理时延与可靠表示。

### A. 相关工作

已有无线信道基础模型大致采用三种编码器学习范式：（i）联合嵌入方法，包括对比学习 [3]、[9]、[13]、[34]、[35]；（ii）掩码重建学习 [2]、[4]–[7]、[9]、[13]、[15]、[16]；（iii）重建与对比相结合的目标 [9]、[13]。与这些以编码器为中心的方法并行，另有一类解码器专用的因果生成模型，用于时间预测和未来信道推断 [8]、[12]、[14]。虽然它们能够有效生成序列，但并不是编码器意义上的表示学习器，因为无法直接提供紧凑、与具体任务无关的表示供下游适配。因而本文聚焦基于编码器的自监督框架。

即使限定在编码器范畴，仍面临重要设计选择。对比学习可以学习可迁移无线特征，但通常在每次参数更新前需要多个数据增强视图和前向传播，且结果很大程度上取决于视图构造以及正负样本定义 [3]、[9]、[13]。JEPA 风格的非对比联合嵌入方法 [34]、[35] 通过掩码潜变量预测器避免显式负样本对，通常依赖掩码上下文预测的一致性，而不需要人为设计数据增强；但正因如此，它们没有显式学习面向重建的特征。无线系统中，信道重建本身是重要下游目标，因此希望预训练能够让表示保留恢复信道所需的信号结构，而不只是抽象的潜空间不变量。

在重建学习中，BERT 风格 [25] 的掩码建模把密集序列输入编码器，同时处理掩码和可见 token，再以轻量预测头仅预测被掩码位置 [2]、[6]、[7]、[13]。但这一范式面对很高掩码率时，计算仍随全部网格 token 增加而膨胀。与之不同，MAE 风格 [26] 的编码器只处理可见 token，解码器才加入掩码 token 以重建完整数据；使编码器可以大幅减少输入。先前某些无线 MAE 工作已利用这一方案 [4]、[9]、[15]、[16]，但训练和评价仍假设完整 CSI，或者在其上施加简化 i.i.d. 噪声。

另一项相关工作针对预测型信道基础模型 [14]，使用过去的 LMMSE 信道估计而非干净全 CSI 进行预训练，并在推理中使用自回归预测状态作为先验，根据当前导频细化信道估计。它重点研究的是生成式未来预测和先验辅助信道估计，而不是可跨多个任务使用的自监督编码器表示学习。

另一挑战在于架构归纳偏置。多数已有信道表示模型对所有信道 token 使用密集全连接注意力，尽管信道统计规律具有物理结构。近期有研究在角度—时延—时间表示上，仅关注落在角度—时延窗口和时间锥内的 token，以稀疏化注意力并捕捉散射体演变 [6]。但这一方案无法直接迁移到稠密空间—频率输入，因为相关性不局限在每个 token 的局部邻域，频谱—空间特征必须对整个空间—频率网格进行广泛注意。即便如此，温和的 WSSUS 假设仍意味着时间相关可从联合空间—频率相关中分离 [32]、[33]，因此可以使用分解式注意力。这类注意力已用于视频理解 [37]、[38]，也用于以降低复杂度为目的的同期无线研究 [7]、[39]、[40]，但尚未作为无线自监督 CSI 表示学习中结合原生导频输入、以物理规律区分时间与频谱—空间的专用归纳偏置。PilotWiMAE 在同一框架中联合对齐“实际可观测的数据”（含噪导频）与“处理这些数据的方式”（WSSUS 驱动的分解式注意力），弥补这一缺口。

### B. 贡献与结果概述

本文提出 PilotWiMAE¹，一种采用基础模型设计思路的自监督无线信道表示学习框架，其贡献如下。

1. 提出原生导频输入接口，使模型可直接根据含噪导频观测执行决策任务，绕过信道估计过程，消除已有信道基础模型中普遍采用的完整 CSI 假设。
2. 设计分解式空时（Factorized Space-Time，FST）编码器，分别对不同时间槽执行时间注意力、对每个时间槽内部执行频谱—空间注意力。该设计基于 WSSUS 可分离性，生成高性能、稳健的表示，并支持 99% 的高掩码率预训练。
3. 把刻画小尺度衰落的 patch 归一化重建与恢复路径损耗、阴影衰落等大尺度衰落的辅助尺度损失结合，在编码器与解码器两侧特征上提供监督。
4. 在联合编码器—解码器预训练之后，进一步引入以解码器为中心的掩码重建预训练，将解码器能力与编码器表示质量解耦。
5. 通过 3.5→28 GHz 的跨频段迁移实验（分布内 ID、分布外 OOD）证明，冻结的 PilotWiMAE 表示无需针对任务微调，就能在波束选择和信道表征方面超过监督基线，尽管使用的输入观测空间更小。
6. 通过实验证明，该方法不依赖特定导频图样，也能稳健恢复含噪信道，并且与针对固定导频图样训练的监督基线相比具有竞争力；进一步分析仅微调冻结编码器之上解码器的情况下，性能随解码器深度的变化。
7. 引入稳健的 AWGN 课程预训练，在各 epoch 逐渐降低 SNR 下界，使模型逐步接触更困难的低 SNR 条件，同时保证噪声形式与导频噪声统计特征一致。

## II. 问题描述

考虑一个基站在连续 \(T\) 个时隙上运行，每个时隙有 \(N_{\mathrm{sc}}\) 个子载波，阵列为 \(N_h\times N_v\) 均匀平面阵列。完整信道张量
\(\mathbf H\in\mathbb C^{T\times N_hN_v\times N_{\mathrm{sc}}}\)
实际上不可直接观测。接收机只能在稀疏导频资源元素索引集合 \(\mathcal P\) 处获得含噪观测：

\[
\widehat{\mathbf H}_{\mathcal P}
=\mathbf H_{\mathcal P}+\mathbf N_{\mathcal P}(\mathrm{SNR}), \tag{1}
\]

其中 \(\mathbf N_{\mathcal P}(\mathrm{SNR})\) 是独立同分布的圆对称复高斯噪声，其方差仅由导频 SNR 决定 [19]。更具体地，导频在选定 OFDM 符号索引
\(\mathcal T_p\subset\{0,\ldots,T-1\}\)
和子载波索引
\(\mathcal F_p\subset\{0,\ldots,N_{\mathrm{sc}}-1\}\)
上发送；在每个 \((t,f)\in\mathcal T_p\times\mathcal F_p\) 处可以观测到全部 \(N_hN_v\) 个天线的值。提出方法不依赖于 \((\mathcal T_p,\mathcal F_p)\) 的具体排列。

已有信道基础模型通常采用稠密 CSI 接口，而非式 (1) 的导频观测。可用一般估计残差表示其输入与真实信道之间的差别：

\[
\widehat{\mathbf H}=\mathbf H+\mathbf E(\boldsymbol\theta). \tag{2}
\]

误差 \(\mathbf E(\boldsymbol\theta)\) 通常相关，其统计特征取决于估计器以及场景专属、一般不可得的信道参数。已有方法不是忽略 \(\mathbf E(\boldsymbol\theta)\)，就是用 i.i.d. 圆对称复高斯噪声代替它；后者虽方便分析，却并非真实误差模型。

一种直接替代方案是在编码器前增加信道估计器，先恢复 \(\widehat{\mathbf H}\) 再提取表示。这样要么需要端到端训练额外模块，要么要求编码器适应特定估计器造成的伪影，均使设计更复杂，却没有解决根本问题。本文直接将导频 \(\widehat{\mathbf H}_{\mathcal P}\) 输入编码器：

\[
\widehat{\mathbf H}_{\mathcal P}
\longrightarrow\mathrm{Encoder}
\longrightarrow\mathrm{Representations}
\longrightarrow\mathrm{Decision}. \tag{3}
\]

其研究假设是：当预训练采用掩码重建时，即使只输入稀疏导频，编码器潜空间也能够保留全局信道结构。刻意采用的浅层解码器使编码器潜变量成为表示瓶颈，迫使编码器整合可见导频 token 在资源栅格中的信息，才能预测被掩盖内容。对于波束选择、信道表征等不需要密集 CSI 的任务，只读取导频表示即可执行紧凑推理路径，无须在推理时恢复完整网格。

一般而言，联合预训练会使潜表示质量与解码器容量相耦合，因此作者进一步丢弃旧解码器、冻结编码器，再使用重建能力更强的新解码器进行预训练。第二阶段提高密集信道恢复精度，同时保持编码器表示不变。

## III. PilotWiMAE 框架

本节介绍 PilotWiMAE 的六个组成部分，分别对应以下六个小节，具体架构见图 2。

**图 2：** PilotWiMAE 架构。导频 patch 送入 FST 编码器；得到的表示由联合空时（Joint Space-Time，JST）Transformer 解码；最后将输出 token 映射回 patch 维度，以实现信道重建。图中仅展示主前向路径，省略部分细节。

### A. 原生导频输入接口

预训练时，编码器处理在 AWGN 条件下经过结构化随机掩码得到的极度稀疏输入；推理时则处理由实际导频图样形成的稀疏输入 \(\widehat{\mathbf H}_{\mathcal P}\)（见附录 B）。

在 token 化之前，使用预训练数据划分上计算的数据集级参考功率 \(P_{\mathrm{ref}}\) 对每个样本归一化，定义
\(\overline{\mathbf H}=\mathbf H/\sqrt{P_{\mathrm{ref}}}\)。
记 \(S=N_hN_v\)、\(F=N_{\mathrm{sc}}\)，则复信道输入
\(\overline{\mathbf H}\in\mathbb C^{T\times S\times F}\)。
采用三维 patch 大小 \((p_t,p_s,p_f)\)，定义
\[
(n_t,n_s,n_f)=
\left(\frac T{p_t},\frac S{p_s},\frac F{p_f}\right),
\]
token 化产生 \(P=n_tn_sn_f\) 个 patch，每个时间槽对应 \(N_{\mathrm{sf}}=n_sn_f\) 个频谱—空间 token。把实部和虚部分开，并在每个 patch 内拼接，使原始 patch 向量在投影前的维度为 \(D_p=2p_tp_sp_f\)，然后线性投影至模型维度 \(d\)。

用偏移 \((i_t,i_s,i_f)\) 索引各轴 patch，其中
\(i_t\in\{0,\ldots,n_t-1\}\)、
\(i_s\in\{0,\ldots,n_s-1\}\)、
\(i_f\in\{0,\ldots,n_f-1\}\)。
采用时间优先的展开顺序，映射成扁平索引
\(p=i_tn_sn_f+i_sn_f+i_f\in\{0,\ldots,P-1\}\)。
每个 token \(\mathbf x_p\in\mathbb R^d\) 由对应 \(D_p\) 维实虚拼接 patch 线性投影得到。

在每个 token 上加入轴向正弦位置编码。把模型维度分成三轴子维度
\(d=d_t+d_s+d_f\)，其中
\(d_t=d_s=\lfloor d/3\rfloor\)，
\(d_f=d-2\lfloor d/3\rfloor\)。
对于轴 \(a\in\{t,s,f\}\)，令该轴 patch 数为 \(n_a\)、子维度为 \(d_a\)，索引 \(i\in\{0,\ldots,n_a-1\}\)。该轴的位置编码 \(\boldsymbol\psi_i^{(a)}\in\mathbb R^{d_a}\) 按标准 Transformer 一维正余弦公式 [23]：

\[
[\boldsymbol\psi_i^{(a)}]_{2j}
=\sin\bigl(i\cdot10000^{-2j/d_a}\bigr), \tag{4}
\]

\[
[\boldsymbol\psi_i^{(a)}]_{2j+1}
=\cos\bigl(i\cdot10000^{-2j/d_a}\bigr). \tag{5}
\]

其中 \(j=0,\ldots,\lfloor(d_a-1)/2\rfloor\)，仅当 \(2j+1<d_a\) 时才应用式 (5)。将三轴编码拼接：
\[
\mathbf e_p^{\mathrm{pe}}=
\bigl[(\boldsymbol\psi_{i_t}^{(t)})^\mathsf T,
(\boldsymbol\psi_{i_s}^{(s)})^\mathsf T,
(\boldsymbol\psi_{i_f}^{(f)})^\mathsf T\bigr]^\mathsf T
\in\mathbb R^d.
\]
token 采用
\(\mathbf x_p\leftarrow\mathbf x_p+\alpha_{\mathrm{pe}}\mathbf e_p^{\mathrm{pe}}\)
加入该位置编码。\(\alpha_{\mathrm{pe}}\) 为可学习标量，初始化在接近零的位置，以免固定正余弦编码的数值幅度在预训练早期掩盖线性 patch 嵌入。

### B. WSSUS 驱动的分解式注意力

根据经典 WSSUS 模型 [32] 及其 MIMO 推广 [33]，时间相关由多普勒谱（与环境运动相关）支配；频谱—空间相关则由联合角度—时延功率谱（与散射几何相关）支配。将信道自相关表示为时间差 \(\Delta t\)、频率差 \(\Delta f\)、空间差 \(\Delta s\) 的函数，WSSUS 假设以及 MIMO-WSSUS 信道中多普勒与角度—时延扩展的标准可分离性给出

\[
R_H(\Delta t,\Delta f,\Delta s)
\approx R_t(\Delta t)\,R_{\mathrm{sf}}(\Delta f,\Delta s). \tag{6}
\]

式 (6) 意味着时间相关与联合空间—频率相关的耦合较弱，表示学习器不必显式建模这两个域之间的全部交叉相关。另一方面，空间与频率通过同时依赖角度和时延的散射结构仍然耦合，因此不宜再将两者完全拆开，否则会抛弃编码器应该学习的真实物理结构。

由此得到注意力分解。为表示输入掩码保留的稀疏 token 子集，记保留时间 patch 数为 \(n_k\le n_t\)，保留频谱—空间 patch 数为 \(N_{\mathrm{sf}}'\le N_{\mathrm{sf}}\)。无论预训练时的结构化随机掩码（第 III-C 节），还是推理时固定导频图样（附录 B），所保留的位置都构成矩形子集。不进行掩码的特例为
\((n_k,N_{\mathrm{sf}}')=(n_t,N_{\mathrm{sf}})\)。

令
\(\mathbf Z^{(\ell)}\in\mathbb R^{n_k\times N_{\mathrm{sf}}'\times d}\)
为第 \(\ell\) 个编码器块的输入 token 张量，
\(\ell\in\{0,1,\ldots,L_{\mathrm{FST}}\}\)，
\(L_{\mathrm{FST}}\) 表示 FST 编码器块的数量。每块先在固定频谱—空间位置沿时间维执行注意力，再在每个保留时间切片内部执行频谱—空间注意力：

\[
\mathbf Z_{:,s,:}^{(\ell+1/2)}
=\operatorname{Attn}_{n_t}\bigl(
\mathbf Z_{:,s,:}^{(\ell)}\bigr),\quad
s=1,\ldots,N_{\mathrm{sf}}', \tag{7}
\]

\[
\mathbf Z_{t,:,:}^{(\ell+1)}
=\operatorname{Attn}_{n_{\mathrm{sf}}}\bigl(
\mathbf Z_{t,:,:}^{(\ell+1/2)}\bigr),\quad
t=1,\ldots,n_k. \tag{8}
\]

这里 \(\mathbf Z^{(\ell+1/2)}\) 为两个注意力子层之间的中间状态。为突出核心公式，省略残差连接和前馈子层。如图 3，跨时间槽信息仅在固定频谱—空间位置执行时间注意力时交换；频谱—空间信息仅在固定时间槽内部交换，与式 (6) 相呼应。分解是一种归纳偏置，而不是对某个注意力矩阵作简单稀疏化，因此不应损害 WSSUS 模型能够捕获的结构的表达能力。实验中的等参数量 JST 基线对照表明，该方法在 ID 和 OOD 波束选择、信道表征中均有持续收益。

除归纳偏置外，相较联合空时注意力，分解还降低了每层注意力计算量；其复杂度、实测 FLOPs 和逐样本时延见第 V 节。

### C. 分解式注意力支持高强度掩码

由于注意力分解与相关性可分离，可以使用异常激进的预训练掩码。采用结构化随机掩码，仅保留 \(n_t\) 个时间 patch 索引中的 \(n_k\) 个；在保留时间位置处，进一步保留相同的频谱—空间 token 位置子集，比例为 \(\rho_k\in(0,1)\)。同一保留位置集合在所有已保留时间 patch 中共享，而不是每个 patch 独立重新采样。因此，总可见比例为
\((n_k/n_t)\rho_k\)，掩码率为
\(1-(n_k/n_t)\rho_k\)，也即式 (7) 中
\(N_{\mathrm{sf}}'=\rho_kN_{\mathrm{sf}}\)。

这种掩码结构与注意力分解匹配：时间块在每个固定频谱—空间位置混合 \(n_k\) 个保留时间 patch 的信息，频谱—空间块在每个保留时间 patch 内混合可见位置的信息。于是，解码器在每个可见位置获得经过上下文整合的 token。由于每个训练样本使用随机掩码，编码器不会依赖某一种特定导频图样；推理时，可直接接受接收机的固定导频配置。

这种结构化保留集合也与物理相关规律相符，因为 FST 中每一对被注意力处理的 token 最多只在一个轴上不同。根据式 (6)，单轴的自相关仅由 \(R_t\) 或 \(R_{\mathrm{sf}}\) 支配，因此这些 token 对根据物理规律应具有较强相关性。相较之下，同样的保留集合输入 JST 编码器后，二次复杂度注意力预算会分散到全部保留 token 对，其中包括时间与空间—频率两轴同时不同的 token 对。这些跨轴对的相关性是
\(R_t(\Delta t)R_{\mathrm{sf}}(\Delta f,\Delta s)\)，可能因任一因子衰减而迅速减小，提供的信息相对有限。因此，同样的可见 token 预算下，FST 能从中提取更多有用信息，使高强度掩码仍然有效，而不至于退化为对弱相关数据的混合。

**图 3：** 在 \((n_t,n_s,n_f)\) patch token 网格上进行分解式空时注意力。示例中
\(n_t=8,n_s=3,n_f=6,n_k=3,\rho_k=1/8\)，掩码率约 94%。一个注意力模块在固定空间—频率位置混合时间，另一模块在固定时间槽混合空间—频率。


### D. Patch 归一化重建与辅助尺度损失

无线信道的功率在不同样本之间变化范围极大。即使同一训练数据集中的不同信道，路径损耗和阴影衰落也可能相差数十 dB；但与波束选择和许多其他下游任务相关的小尺度多径衰落，发生在更加精细的幅度尺度。若直接在原始幅度域计算重建损失，高功率 patch 会主导目标，网络会倾向于拟合大尺度趋势，而无法充分学习多径几何。为此，在计算重建损失之前，先按每个 patch 自身的均值和方差归一化。

设 \(\mathbf p_{b,i}\in\mathbb R^{D_p}\) 是第 \(b\) 个样本中第 \(i\) 个 patch，\(\mu_{b,i}\) 和 \(\sigma_{b,i}^2\) 是其经验均值和方差。对被掩码 patch 集合 \(\mathcal M\)，重建损失为

\[
\mathcal L_{\mathrm{recon}}
=\frac1{|\mathcal M|}
\sum_{(b,i)\in\mathcal M}
\left\|
\widehat{\mathbf p}_{b,i}
-\frac{\mathbf p_{b,i}-\mu_{b,i}\mathbf1}
{\sqrt{\sigma_{b,i}^2+\epsilon_r}}
\right\|_2^2, \tag{9}
\]

其中 \(\epsilon_r\) 为防止数值问题的小常数。通过消去每个 patch 的幅度比例，该损失迫使编码器学习 patch 之间的衰落结构与相关性，而不是被原始信号中的样本级功率主导，同时避免仅靠预测原始幅度均值就减小重建损失的捷径。

但消除 patch 幅度也会舍弃路径损耗、阴影衰落等大尺度衰落信息，而某些下游任务恰恰依赖这些特征。因此作者引入辅助尺度损失。对每个原始 patch，构造尺度目标

\[
\mathbf s_{b,i}=
\begin{bmatrix}\mu_{b,i}\\\log(\sigma_{b,i}^2+\epsilon_s)\end{bmatrix}. \tag{10}
\]

使用对数尺度表示方差，提高数值稳定性。模型同时从编码器和解码器的 token 特征预测 \(\mathbf s_{b,i}\)。编码器侧预测 \(\widehat{\mathbf s}_{b,i}^{\mathrm{enc}}\) 在可见集合 \(\mathcal K\) 上进行自监督，使编码器潜变量自身携带大尺度统计量；解码器侧预测 \(\widehat{\mathbf s}_{b,i}^{\mathrm{dec}}\) 在掩码集合 \(\mathcal M\) 上进行自监督，使重建路径也能恢复尺度信息。虽然解码器侧损失在解码器处计算，但梯度会通过解码器传回编码器，因此同样促使可见 token 表示包含可用于推断掩码位置尺度的信号。

对应损失为

\[
\mathcal L_{\mathrm{scale,enc}}
=\frac1{|\mathcal K|}\sum_{(b,i)\in\mathcal K}
\left\|\widehat{\mathbf s}_{b,i}^{\mathrm{enc}}-\mathbf s_{b,i}\right\|_2^2,
\qquad
\mathcal L_{\mathrm{scale,dec}}
=\frac1{|\mathcal M|}\sum_{(b,i)\in\mathcal M}
\left\|\widehat{\mathbf s}_{b,i}^{\mathrm{dec}}-\mathbf s_{b,i}\right\|_2^2. \tag{11}
\]

于是，完整预训练目标是

\[
\mathcal L_{\mathrm{pretrain}}
=\mathcal L_{\mathrm{recon}}
+\lambda_{\mathrm{enc}}\mathcal L_{\mathrm{scale,enc}}
+\lambda_{\mathrm{dec}}\mathcal L_{\mathrm{scale,dec}}. \tag{12}
\]

图 4 总结预训练的连接方式：导频张量进入 FST 编码器和 JST 解码器；patch 归一化重建在掩码集合 \(\mathcal M\) 上预测 \(\widehat{\mathbf p}_{b,i}\)；编码器侧尺度头在 \(\mathcal K\) 上预测 \(\widehat{\mathbf s}_{b,i}^{\mathrm{enc}}\)，解码器侧尺度头在 \(\mathcal M\) 上预测 \(\widehat{\mathbf s}_{b,i}^{\mathrm{dec}}\)，分别对应式 (9)、(11)、(12)。

**图 4：** PilotWiMAE 预训练流程与损失分组。编码器和解码器均连接辅助尺度预测头；重建和解码器尺度损失作用于掩码 patch，编码器尺度损失作用于可见 patch。

### E. 噪声稳健的预训练课程

预训练时，只对稀疏掩码输入加入 AWGN，重建与尺度监督目标仍由干净信道计算。这使编码器能够适应实际部署：在相应噪声条件下处理符合导频图样的稀疏输入。

具体地，设 \(e\in\{0,\ldots,E-1\}\) 是预训练 epoch，\(s_0\) 是 dB 域的初始 SNR 下界，\(s_{\max}\) 是上界。采用余弦调度将下界从 \(s_0\) 逐渐降低至 0 dB：

\[
s_{\min}(e)=\frac{s_0}{2}
\left(1+\cos\frac{\pi e}{E-1}\right). \tag{13}
\]

这样训练早期主要使用高 SNR 观测；随着编码器稳定，训练后期逐步接触低 SNR，更广泛地覆盖实际部署条件。每个样本的 SNR 从以下区间均匀抽样：

\[
\mathrm{SNR}_{b,\mathrm{dB}}\sim
\mathcal U[s_{\min}(e),s_{\max}]. \tag{14}
\]

对样本 \(b\)，在编码器实际接收的可见 patch 上计算信道功率 \(P_b\)，并根据线性尺度 SNR 设置噪声方差
\(\sigma_b^2=P_b/\mathrm{SNR}_{b,\mathrm{lin}}\)。
分别对可见元素加入方差为 \(\sigma_b^2\) 的独立圆对称复高斯噪声；重建和尺度损失的目标，仍使用干净完整信道 \(\mathbf H_b\) 的统计量计算。

### F. 两阶段预训练方案

掩码重建会将编码器表示与搭配的解码器耦合起来。若解码器较小，训练梯度会迫使编码器从可见导频中整合更多上下文；若解码器较大，它可能部分弥补潜变量质量不足，使编码器学习有用几何结构的压力减弱。

**阶段 1：编码器—解码器联合预训练。** 使用刻意设计得较浅、含 \(L_{\mathrm{JST}}\) 层的 JST 解码器，最小化式 (12) 的完整目标。这样可得到适合下游原生导频任务的编码器表示，同时限制解码器容量。

**阶段 2：以解码器为中心的预训练。** 丢弃第一阶段浅层解码器的权重，冻结编码器，重新初始化一个重建能力更强的解码器（例如具有更多层、更宽的前馈网络或更多注意力头），仅使用重建目标训练它。如此，编码器表示保持不变，新解码器负责从冻结的 token 表示恢复密集信道 patch。

从程序上看，第二阶段类似于下游适配：固定主干、训练新任务头；但其目标仍是通过结构化随机掩码执行自监督重建，而不是在固定导频网格上针对全 CSI 进行监督训练。因此，所学习的重建不依赖某一种特定导频图样；这与传统信道估计有本质区别，传统信道估计常使解码器学习从某个固定导频图样到完整 CSI 的监督映射。

两阶段训练产生一对预训练的编码器与解码器。不需要密集 CSI 的下游决策任务只使用编码器特征；需要完整 CSI 的应用可以额外使用解码器输出。相关预训练参数见第 IV-B 节和表 II。


## IV. 实验

使用 3.5 GHz 射线追踪信道数据预训练 PilotWiMAE，然后在未见测试数据上评价无需任务微调的表示迁移。跨频段波束选择和信道表征包括分布内（In-Distribution，ID）与分布外（Out-of-Distribution，OOD）两种情况。ID 指在预训练城市中，从 3.5 GHz 迁移到 28 GHz，只有载频失配；OOD 则在留出的城市进行 3.5→28 GHz 迁移，同时存在频段与场景失配。信道估计任务在留出的城市、相同 3.5 GHz 载频下评价密集信道恢复，从而单独考察场景失配。

### B. 预训练

按第 III-F 节的两阶段方案在 3.5 GHz 预训练：阶段 1 为 500 个 epoch，阶段 2 为 200 个 epoch。FST 编码器由 \(L_{\mathrm{FST}}=3\) 个块构成，使用 8 个注意力头；阶段 1 的 JST 解码器为 \(L_{\mathrm{JST}}=2\) 层、4 个注意力头，阶段 2 改为 8 个注意力头；模型维度始终 \(d=128\)。

第一阶段采用激进分解式掩码：\(n_k=2,\rho_k=0.1\)，整体掩码率约 99%；第二阶段改为较温和的
\(n_k=4,\rho_k=0.75\)，整体掩码率约 79%。两阶段设置不同的原因是目标不同。第一阶段着重塑造编码器表示，迫使其用极少可见 token 预测被掩盖内容，整合资源栅格上的远程结构；实验发现，将掩码率推向激进区间可改善下游精度。第二阶段编码器已经冻结，目标转向训练解码器；降低掩码率至约 79% 可以提供足够的可见上下文，实现准确的密集恢复，同时仍通过随机化保留集合保持不依赖导频图样的性质。

### C. 评价任务

评价三个下游任务。跨频段波束选择与信道表征（LoS/NLoS 分类）均采用 3.5→28 GHz 迁移方案。前者检验表示是否在跨频段后保留方向结构，后者检验表示能否在频率相关的信道统计变化下保留传播状态语义。两者均使用冻结预训练表示及 k 近邻（kNN）评价，无任务专用微调；波束选择标签由 DFT 码本 [43] 定义。信道估计在保持 3.5 GHz 不变、但场景留出的条件下评价，直接从解码器读取密集信道重建结果。

**1）共同迁移评价方案。** 波束选择与信道表征均使用以下方式：先在 3.5 GHz 预训练编码器并冻结；在 28 GHz 上直接评价；所有方法统一使用 kNN 及平均池化的编码器表示，进行 10 折互不重叠交叉验证；每折用 90% 样本拟合 kNN、10% 样本测试；报告各折均值和标准差。

选择 kNN 是因为它不需要新训练参数，能够直接考察学习到的特征空间是否已经将同类信道组织在相近位置。线性探针即使取得更高精度，也会加入新的、通过训练得到的线性决策边界归纳偏置，从而部分弥补邻域结构本身的不足；而 kNN 只有在表示空间中的近邻确实具有相同下游标签时才有效，更符合评价自监督表示质量的目标。

**2）kNN 细节。** 采用 \(k=20\) 和基于余弦距离的加权投票 [44]。平均池化后的编码器特征直接输入 kNN，不执行外部特征归一化；计算余弦距离时应用 L2 归一化。对于全部模型的完整信道输入和仅导频输入，编码 patch 的平均池化结果均为 \(d=128\) 维。

**3）跨频段波束选择。** 该任务检验预训练表示是否在不同频段之间保留方向结构，以 top-3 波束选择准确率评价。对于水平 \(N_h\) 列、垂直 \(N_v\) 行、两轴均为半波长间距的 UPA，令 \(K_h,K_v\) 为两个方向上的角度网格数。每轴可选用过采样 DFT 网格（临界采样为 \(K_h=N_h,K_v=N_v\) 的特例）或欠采样网格：

\[
K_h=\begin{cases}
O_hN_h,&\text{过采样 }(O_h\ge1),\\
N_h/U_h,&\text{欠采样 }(U_h\ge1,\ U_h\mid N_h),
\end{cases}
\quad
K_v=\begin{cases}
O_vN_v,&\text{过采样 }(O_v\ge1),\\
N_v/U_v,&\text{欠采样 }(U_v\ge1,\ U_v\mid N_v).
\end{cases}\tag{15}
\]

符号 \(a\mid b\) 表示 \(a\) 整除 \(b\)；\(O_h,O_v,U_h,U_v\) 为正整数，每个轴只启用其中一种分支。欠采样码本在对应环上仍按 \([0,2\pi)\) 均匀布点。总码本大小
\(M=K_hK_v\)。码字由一维导向矢量的 Kronecker 积组成：

\[
[\mathbf a_h(m_h)]_n=
\frac1{\sqrt{N_h}}\exp(jn\varphi_{m_h}),
\quad \varphi_{m_h}=\frac{2\pi m_h}{K_h},
\quad n=0,\ldots,N_h-1,
\]

\[
[\mathbf a_v(m_v)]_n=
\frac1{\sqrt{N_v}}\exp(jn\psi_{m_v}),
\quad \psi_{m_v}=\frac{2\pi m_v}{K_v},
\quad n=0,\ldots,N_v-1, \tag{16}
\]

\[
\mathbf w_{m_h,m_v}
=\mathbf a_v(m_v)\otimes\mathbf a_h(m_h). \tag{17}
\]

其中 \(m_h=0,\ldots,K_h-1\)、
\(m_v=0,\ldots,K_v-1\)，扁平索引
\(m=m_vK_h+m_h\)，\(\mathbf w_m\equiv\mathbf w_{m_h,m_v}\)，\(\otimes\) 表示 Kronecker 积。式 (16) 的归一化使任意 \(K_h,K_v\) 下均有 \(\|\mathbf w_m\|_2=1\)。设时隙 \(t\)、子载波 \(f\) 的信道向量为 \(\mathbf h_{t,f}\)，通过对整个帧中的子载波和时隙波束增益求平均，为每帧分配单一标签：

\[
m^\star=\arg\max_{m\in\{0,\ldots,M-1\}}
\frac1{TN_{\mathrm{sc}}}
\sum_{t=0}^{T-1}\sum_{f=0}^{N_{\mathrm{sc}}-1}
|\mathbf w_m^\mathsf H\mathbf h_{t,f}|^2. \tag{18}
\]

这是因为一个 OFDM 帧内角度结构近似保持不变。除非另行说明，使用 \((N_h,N_v)=(8,4)\)。主要波束选择图固定 \(M=128\)，通过过采样系数 \((O_h,O_v)=(2,2)\) 实现。图 5 还遍历其他码本规模，包括临界采样、较小 \(M\) 下的欠采样，以及较大 \(M\) 下的过采样。图例注明每条曲线的生效系数。

**4）信道表征。** 该任务考察预训练表示在相同 3.5→28 GHz 迁移中保留传播状态语义的能力。二分类 LoS/NLoS 标签来自射线追踪器的几何 LoS 指示，即 BS–UE 直达路径是否无遮挡，因此与载波无关。同一链路在 3.5 GHz 和 28 GHz 具有相同标签，即使其小尺度、大尺度信道统计随频段变化。评价指标是在 ID 和 OOD 下的 LoS 分类准确率；不同测试城市的数据集信息见附录 A。

**5）对比方法。**

对于波束选择和信道表征，比较：
- **监督基线：** FST 编码器及线性分类头，在完整信道输入上用交叉熵端到端训练。kNN 评价时丢弃分类头，仅使用平均池化表示。
- **自监督 JST 基线：** JST 编码器与相同容量的 JST 解码器，仅使用 patch 归一化重建进行预训练（无 AWGN 课程、无尺度头）。
- **PilotWiMAE 消融：** 共用 FST 编码器与第一阶段 JST 解码器，分别启用预训练组件。FST 仅使用 patch 归一化重建；FST+scale 增加编码器和解码器的辅助尺度头；FST+noise 增加 AWGN SNR 课程。
- **完整 PilotWiMAE（图中标为 FST+noise+scale）：** 使用 FST 编码器、JST 解码器，同时加入 AWGN 课程与辅助尺度头。

全部模型均使用与 PilotWiMAE 相同的 3.5 GHz 预训练划分训练（监督基线则采用监督训练）。为隔离分解式注意力的归纳偏置，JST 和 FST 编码器的容量严格匹配：模型维数同为 128、注意力头数 8，注意力子层总数相同。三个 FST 块共有六个注意力子层，对应 JST 的六层，因此可训练参数量相同。自监督 JST 基线的解码器深度和头数与 PilotWiMAE 阶段 1 相同。由此，JST 与 FST 消融之间的差距反映注意力分解本身，而不是解码器选择。监督基线使用相同 FST 编码器，但以任务专用线性头代替 JST 解码器；具体配置见附录 D。

对于密集信道恢复，比较：
- **线性插值：** 轻量经典基线。
- **实用 LMMSE（practical）：** 具有 Kronecker 结构的 LMMSE 估计器，从 3.5 GHz 预训练数据估计二阶信道统计，在洛杉矶 3.5 GHz 测试信道上评价，体现载频匹配但城市失配。
- **理想 LMMSE（gold）：** 使用相同的 Kronecker 结构，但直接从洛杉矶数据估计并评价协方差，作为与部署场景匹配的 oracle 参考。
- **监督 FST：** 与 PilotWiMAE 相同的 FST 编码器和阶段 2 JST 解码器，在附录 B 的固定导频图样上输入，从端到端监督损失中恢复完整信道。
- **监督 JST：** 采用与监督 FST 相同的端到端设置，仅把编码器改为标准 JST，以检验注意力分解是否仍对信道估计回归任务具有足够表达能力。

两个 LMMSE 参考都使用 Kronecker 协方差模型，因为它与 FST 的分解式归纳偏置相呼应，并使大规模网格上的 LMMSE 计算可行。


### D. 实验结果

在波束选择和信道表征任务中，分解式编码器系列在 ID、OOD 两种迁移条件下，尤其低 SNR 时，均比 JST 更稳健。噪声稳健预训练改善了整个 SNR 范围内的稳定性；辅助尺度目标对信道表征最有利，因为它直接提供可供使用的大尺度衰落信息，而对波束选择影响较小。总体来看，PilotWiMAE（图中标为 FST+noise+scale）在图 6～9 中表现最好；即使仅用导频输入，也能保持与完整信道输入相近的性能，而观测空间显著缩小。信道估计方面，增加解码器深度可改善密集信道恢复的 NMSE。尽管未针对某种具体导频图样预训练，PilotWiMAE 相较传统方法以及针对固定导频图样的监督编码器—解码器，仍可取得有竞争力的结果（图 10～11）。

**1）跨频段波束选择。** 在洛杉矶的 28 GHz OOD 测试中，图 5 展示了各种码本规模下 top-3 波束选择准确率随 SNR 的变化，包括多种具有相同总码本大小 \(M\) 的水平—垂直 Kronecker 组合。对于每种组合，作者都使用相同的 PilotWiMAE 冻结编码器特征，分别从仅导频输入和完整信道输入得到表示，并使用完全相同的 kNN 读取方式进行比较。

导频与完整信道输入之间的差距强烈依赖于 SNR，通常低 SNR 时最大，高 SNR 时缩小；但当改变码本大小及水平—垂直组合时，准确率与 \(M\) 之间并不存在简单的单调规律。特别地，在 \(M\) 相同的情况下，水平—垂直角度网格的组合方式本身即可改变几个百分点的准确率。给水平方向分配更多角度网格（如欠采样时 \(U_h<U_v\)，或过采样时 \(O_h>O_v\)）的配置，总体优于其水平、垂直因素互换的对应配置。这表明在本文所考虑的城市环境中，表示对水平方向的分辨能力比垂直方向更敏锐。因此，在固定码本预算下，垂直方向欠采样或水平方向过采样，保留了更多有区分力的角度结构。

图 6 和图 7 将码本大小固定为 \(M=128\)，分别在 ID、OOD 数据上与监督基线、自监督 JST 编码器和中间 FST 消融版本比较。可以观察到以下规律。

首先，低 SNR 是区分方法性能的主要区域。采用噪声预训练的模型（FST+noise 和 FST+noise+scale）在低 SNR 时具有显著优势，说明增强低 SNR 性能的主要因素是噪声稳健预训练，而不是单凭编码器架构或监督目标就能获得的效果。

其次，监督基线的完整信道与仅导频输入之间存在明显差距，从中等 SNR 开始出现并持续存在；反之，每一种 FST 配置在两种输入方式下几乎具有重合的准确率曲线。这是原生导频预训练的经验证据。由于监督基线使用与 PilotWiMAE 相同的编码器主干，这种差异反映的是预训练目标的作用，而不是编码器结构的差异。

第三，JST 在全 SNR 范围以及两种数据划分中均弱于每一种 FST 变体，支持高度掩码预训练下采用分解式归纳偏置的设计。第四，在噪声预训练基础上加入尺度损失，对波束选择反而有轻微负面影响；这与尺度损失更有助于信道表征、而非波束选择的总体结论一致。最后，从 ID 变为 OOD 仅造成小幅绝对性能下降，各方法相对排序基本保持不变，说明迁移到留出城市及新频段后未出现特定方法的性能崩溃。

**2）信道表征。** 图 8 和图 9 报告 ID、OOD 数据集上 LoS 分类准确率随 SNR 的变化，比较方法与波束选择相同。与波束选择的消融结果正好相反，这一任务中辅助尺度损失是最关键的性能因素。具有尺度监督的变体（FST+scale 与 FST+noise+scale）在全部 SNR、两种数据划分上均领先，因为 LoS/NLoS 标签与大尺度衰落统计的关系更紧密，而不只依赖精细角度结构。完整 PilotWiMAE（FST+noise+scale）不仅准确率领先，随 SNR 变化也最平坦；原因是 AWGN 课程提高了低 SNR 性能下限。

其次，相比波束选择，监督基线在仅导频与完整输入之间的差距小得多，因为只要恢复与总信道功率相关的标签，稀疏导频就可以达到接近密集网格的效果。第三，ID 到 OOD 的偏移几乎不可见：洛杉矶的曲线以及各方法相对排名基本保持不变。

## V. 计算复杂度

本节采用论文所实现的 profiling 程序，报告 PilotWiMAE 和监督基线的训练与推理成本。全部测量在单张 NVIDIA RTX A4000 上使用 PyTorch 和混合精度。训练成本以 batch size \(B_{\mathrm{tr}}=256\) 统计，见表 III；推理以 \(B_{\mathrm{inf}}=32\) 统计，预热后重复计时 100 次，得到按样本摊销的时延，见表 IV。该摊销口径在附录 C 中解释。

**表 III：单张 RTX A4000 上，每 epoch 的训练开销（训练 batch size 256；FLOPs 以 PFLOPs 为单位）。**

| 方法 | 编码器 | 可训练参数 | FLOPs / epoch | 时间 / epoch (s) |
|---|---|---:|---:|---:|
| PilotWiMAE | FST | 1,594,658 | 2.017 P | 208.01 |
| PilotWiMAE | JST | 1,594,658 | 2.115 P | 204.43 |
| 监督基线 | FST | 1,210,369 | 2.656 P | 653.69 |

**表 IV：单张 RTX A4000 上推理开销；batch size 32，预热后重复 100 次。**

| 编码器 | 输入 | 编码器参数 | 逐样本时延 (ms) |
|---|---|---:|---:|
| FST | 仅导频 | 1,594,658 | 0.153 ± 0.007 |
| JST | 仅导频 | 1,594,658 | 0.073 ± 0.000 |
| FST | 完整信道 | 1,594,658 | 0.698 ± 0.007 |
| JST | 完整信道 | 1,594,658 | 1.833 ± 0.015 |

由这两张表可得三个观察。首先，FST 或 JST 的自监督预训练，每 epoch 的耗时均约为使用相同 FST 主干进行端到端监督训练的三分之一，因为预训练只处理可见 token 子集，而监督基线总是处理完整网格。

其次，FST 编码器在推理时明显受益于仅导频输入：逐样本时延从完整信道输入的约 0.70 ms 降低至仅导频输入的约 0.15 ms，缩短 4.6 倍。这与序列长度减少以及分解式注意力复杂度
\(O(n_tN_{\mathrm{sf}}(n_t+N_{\mathrm{sf}})d)\)
相一致。

第三，JST 注意力复杂度为
\(O((n_tN_{\mathrm{sf}})^2d)\)，其渐近复杂度比 FST 高约
\(n_tN_{\mathrm{sf}}/(n_t+N_{\mathrm{sf}})\) 倍；但在仅导频输入时，JST 反而比 FST 更快。这是因为掩码后 JST 的序列已足够短，二次复杂度不再成为瓶颈，结构较简单的 JST 块占优。相反，在完整网格上，JST 的二次复杂度暴露出来，逐样本时延达到全部设置中最大的 1.83 ms。

## VI. 结论

PilotWiMAE 表明，可以通过设计选择使自监督无线信道表示学习同时具有稳健性和部署感知能力。原生导频输入避免不现实的完整 CSI 假设；分解式注意力在频段偏移、包括留出城市迁移时改善了表示迁移能力，同时降低推理开销。仅在 3.5 GHz 自监督预训练后，学习到的表示无需针对任务微调，就能迁移至 28 GHz 的波束选择和 LoS/NLoS 分类，在 ID 和 OOD 设置下均表现出色。消融实验表明，噪声稳健预训练是维持低 SNR 稳定性的关键，而辅助尺度监督对信道状态语义尤其有用。上述结果为未来无线表示学习提供了一条可行路线：采用结构感知编码器、与部署一致的噪声扰动，以及物理感知的预训练目标。进一步支持更广泛的导频图样、更多频段及系统级时延测量，是自然的下一步。

作者公开 PilotWiMAE 的预训练权重、训练流程、CSIGen 射线追踪信道生成工具及本文数据集，以促进自监督无线信道表示学习的可复现研究及后续发展。

## 附录 C：逐样本时延的统计口径

本文所报告的推理逐样本耗时，是用每 batch 推理时延除以推理 batch size \(B_{\mathrm{inf}}\) 得到的。这种按样本摊销的口径与性能分析程序一致，在中等至较大 batch、GPU 利用较充分、batch 耗时近似随 batch size 线性增长时，适合作为反映吞吐量的指标。但当 batch 非常小时，固定的 GPU kernel 启动和存储器传输开销不可忽略，因此 batch size 为 1 时的真实时延可能高于上述摊销逐样本时延。

# PilotWiMAE：面向无线信道的原生导频表示学习

**原题：** PilotWiMAE: Pilot-Native Representation Learning for Wireless Channels

**作者：** Berkay Guler、Giovanni Geraci、Hamid Jafarkhani。

**来源：** arXiv:2605.22856v1，2026-05-19，共 14 页。该版本已提交 IEEE 待审；部分结果投稿至非归档的 ICML AI4NextG Workshop [1]。本文对原始论文做中文翻译，保留原公式、图表、参考文献编号。

**状态：** 全文译稿编制中，尚未最终验收。

## 摘要

现有信道基础模型假定可以取得完整观测的信道，但该假设在实际部署中并不成立。本文提出 PilotWiMAE，一种自监督学习框架，其编码器直接接收含噪导频观测，注意力机制将时间处理和联合空间—频率处理分解到不同轴上，这是受到问题物理规律启发的归纳偏置。使用导频输入使观测空间最多缩小两个数量级，同时消除完整 CSI 必须可用这一不现实假设，并降低推理时延。通过利用信道的可分离结构，分解式设计能够生成稳健的表示，使预训练掩码比例可高达 99%。作者将捕获小尺度衰落结构的 patch 归一化重建与恢复大尺度衰落特征的辅助尺度损失配合使用，并通过加性白高斯噪声（AWGN）课程学习，使预训练中的导频噪声与部署条件相匹配。模型仅使用 3.5 GHz 数据预训练，再在 28 GHz 的分布内和分布外场景下评价。尽管输入观测空间更小，PilotWiMAE 在跨频段波束选择和信道表征任务上仍优于监督基线。为了减弱解码器容量与表示质量之间的耦合，作者在编码器—解码器联合预训练后加入以解码器为中心的第二阶段预训练，在不牺牲表示质量的情况下获得具有竞争力的信道估计性能。为支持该方向的进一步研究，作者公开了 PilotWiMAE 的预训练权重、训练流程、基于 Sionna 射线追踪的信道生成工具 CSIGen，以及本文使用的信道数据集。

**索引词：** 自监督学习；无线信道表示；基础模型；AI 原生无线系统。

## I. 引言

近期的信道基础模型通过对随机信道模拟器或射线追踪器生成的完整信道进行预训练和评价，在学习可迁移无线信道表示方面取得显著进展 [2]–[18]。其中一些工作为了提高现实性，会在完整观测信道上加入独立同分布的加性白高斯噪声（i.i.d. AWGN）[2]、[4]–[10]、[15]–[18]；另一些则完全不进行噪声条件下的评价。两种设置都不能真实反映实际信道状态信息（CSI）误差的产生方式。

真实接收机根据导频估计信道；在没有导频复用干扰时，只有导频资源元素处的误差才可建模为 i.i.d. AWGN [19]。占据网格绝大多数位置的非导频资源元素，其误差取决于插值方法、信道时延—多普勒结构、导频密度、导频处 SNR 和导频设计，无法用简单 i.i.d. 模型表征 [20]。因此，使用完整信道或 i.i.d. 加噪信道评价模型，只能检验其学习信道结构的能力，却无法回答当真实系统中根本无法直接获得完整信道时，模型会有何表现。考虑到学习式方法对噪声及分布偏移的已知敏感性 [21]、[22]，有必要弥补这一缺口。

第二个缺口涉及实际部署成本。无线基础模型在很大程度上继承了计算机视觉和语言模型中的 Transformer 架构 [23]、[24] 及训练方法 [25]、[26]。在这些领域中，参数数量与序列长度通常不受严格的运行时上限约束，增加数据和计算往往可以可预测地提升性能 [27]–[29]。但无线系统中的预编码、调度和解码必须在时隙级预算内完成，典型时间尺度为 1 ms 或更短 [30]。然而，现有信道基础模型论文很少报告计算开销；即使报告，往往采用高端 GPU 和不统一的优化软件栈（例如量化或 FlashAttention [31]），使大型模型看起来可以实用部署，却掩盖了其真实成本。

本文以两个同等重要的设计原则同时解决上述问题。首先是**从设计上保证稳健性**：直接在稀疏、含噪的导频观测上运行。这样可以把显式信道估计器从关键推理路径中移除，避免低 SNR 下的误差传播；输入与部署时真正可观测的数据一致，消除了已有信道基础模型的完整 CSI 假设，并可与既有基于导频的通信协议自然融合。信道恢复则被视为利用同一学习表示的下游任务，与基于重建的预训练目标天然一致。

其次是**从设计上体现无线专用性**：将注意力分解为时间域和空间—频率域两部分。这一归纳偏置来自广义平稳非相关散射（WSSUS）模型 [32] 及其 MIMO 推广 [33]；时间相关和频谱—空间相关源于不同的物理机制。同一原则也决定预训练目标：使用 patch 归一化重建学习小尺度衰落，同时以辅助尺度损失恢复大尺度衰落统计特征。

总体上，导频输入缩小了观测空间，分解式架构利用可分离的信道结构，使预训练能够采用 99% 的高掩码率。两者结合，在真实存在噪声和部分观测的决策场景下获得亚毫秒级推理时延与可靠表示。

### A. 相关工作

已有无线信道基础模型大致采用三种编码器学习范式：（i）联合嵌入方法，包括对比学习 [3]、[9]、[13]、[34]、[35]；（ii）掩码重建学习 [2]、[4]–[7]、[9]、[13]、[15]、[16]；（iii）重建与对比相结合的目标 [9]、[13]。与这些以编码器为中心的方法并行，另有一类解码器专用的因果生成模型，用于时间预测和未来信道推断 [8]、[12]、[14]。虽然它们能够有效生成序列，但并不是编码器意义上的表示学习器，因为无法直接提供紧凑、与具体任务无关的表示供下游适配。因而本文聚焦基于编码器的自监督框架。

即使限定在编码器范畴，仍面临重要设计选择。对比学习可以学习可迁移无线特征，但通常在每次参数更新前需要多个数据增强视图和前向传播，且结果很大程度上取决于视图构造以及正负样本定义 [3]、[9]、[13]。JEPA 风格的非对比联合嵌入方法 [34]、[35] 通过掩码潜变量预测器避免显式负样本对，通常依赖掩码上下文预测的一致性，而不需要人为设计数据增强；但正因如此，它们没有显式学习面向重建的特征。无线系统中，信道重建本身是重要下游目标，因此希望预训练能够让表示保留恢复信道所需的信号结构，而不只是抽象的潜空间不变量。

在重建学习中，BERT 风格 [25] 的掩码建模把密集序列输入编码器，同时处理掩码和可见 token，再以轻量预测头仅预测被掩码位置 [2]、[6]、[7]、[13]。但这一范式面对很高掩码率时，计算仍随全部网格 token 增加而膨胀。与之不同，MAE 风格 [26] 的编码器只处理可见 token，解码器才加入掩码 token 以重建完整数据；使编码器可以大幅减少输入。先前某些无线 MAE 工作已利用这一方案 [4]、[9]、[15]、[16]，但训练和评价仍假设完整 CSI，或者在其上施加简化 i.i.d. 噪声。

另一项相关工作针对预测型信道基础模型 [14]，使用过去的 LMMSE 信道估计而非干净全 CSI 进行预训练，并在推理中使用自回归预测状态作为先验，根据当前导频细化信道估计。它重点研究的是生成式未来预测和先验辅助信道估计，而不是可跨多个任务使用的自监督编码器表示学习。

另一挑战在于架构归纳偏置。多数已有信道表示模型对所有信道 token 使用密集全连接注意力，尽管信道统计规律具有物理结构。近期有研究在角度—时延—时间表示上，仅关注落在角度—时延窗口和时间锥内的 token，以稀疏化注意力并捕捉散射体演变 [6]。但这一方案无法直接迁移到稠密空间—频率输入，因为相关性不局限在每个 token 的局部邻域，频谱—空间特征必须对整个空间—频率网格进行广泛注意。即便如此，温和的 WSSUS 假设仍意味着时间相关可从联合空间—频率相关中分离 [32]、[33]，因此可以使用分解式注意力。这类注意力已用于视频理解 [37]、[38]，也用于以降低复杂度为目的的同期无线研究 [7]、[39]、[40]，但尚未作为无线自监督 CSI 表示学习中结合原生导频输入、以物理规律区分时间与频谱—空间的专用归纳偏置。PilotWiMAE 在同一框架中联合对齐“实际可观测的数据”（含噪导频）与“处理这些数据的方式”（WSSUS 驱动的分解式注意力），弥补这一缺口。

### B. 贡献与结果概述

本文提出 PilotWiMAE¹，一种采用基础模型设计思路的自监督无线信道表示学习框架，其贡献如下。

1. 提出原生导频输入接口，使模型可直接根据含噪导频观测执行决策任务，绕过信道估计过程，消除已有信道基础模型中普遍采用的完整 CSI 假设。
2. 设计分解式空时（Factorized Space-Time，FST）编码器，分别对不同时间槽执行时间注意力、对每个时间槽内部执行频谱—空间注意力。该设计基于 WSSUS 可分离性，生成高性能、稳健的表示，并支持 99% 的高掩码率预训练。
3. 把刻画小尺度衰落的 patch 归一化重建与恢复路径损耗、阴影衰落等大尺度衰落的辅助尺度损失结合，在编码器与解码器两侧特征上提供监督。
4. 在联合编码器—解码器预训练之后，进一步引入以解码器为中心的掩码重建预训练，将解码器能力与编码器表示质量解耦。
5. 通过 3.5→28 GHz 的跨频段迁移实验（分布内 ID、分布外 OOD）证明，冻结的 PilotWiMAE 表示无需针对任务微调，就能在波束选择和信道表征方面超过监督基线，尽管使用的输入观测空间更小。
6. 通过实验证明，该方法不依赖特定导频图样，也能稳健恢复含噪信道，并且与针对固定导频图样训练的监督基线相比具有竞争力；进一步分析仅微调冻结编码器之上解码器的情况下，性能随解码器深度的变化。
7. 引入稳健的 AWGN 课程预训练，在各 epoch 逐渐降低 SNR 下界，使模型逐步接触更困难的低 SNR 条件，同时保证噪声形式与导频噪声统计特征一致。

# 2026-07-16 每日前沿论文推荐

## 今日组合逻辑

今天恢复常规多方向均衡，不再延续 7 月 15 日的 CM 专题加权。5 篇形成一条完整链路：

1. **MultiCE-Flow**：把环境多模态与稀疏导频直接接入 DiT/Flow Matching，面向条件信道分布 (p(H\mid Y_{\text{pilot}},e))；
2. **Anchor-CKM**：强调“先由观测定义可信场，再施加结构先验”，补足显式数据一致性与布局先验；
3. **CAR-Flow**：把连续条件从网络内部扩展到源/目标概率路径的重参数化；
4. **Bayesian active-learning CKM**：把不确定性用于下一批测点选择，构成闭环观测策略；
5. **RadioMapMotion**：提供动态、连续、跨环境的可复现数据与基线。

这 5 篇不是普通 diffusion/flow 的重复迁移：它们分别新增**多模态稀疏导频、pilot-support 稳定化、条件化源分布、认知不确定性主动采样、动态连续数据**五个独立维度。

## 1. Improving Channel Estimation via Multimodal Diffusion Models with Flow Matching

- **作者**：Xiaotian Fan, Xingyu Zhou, Le Liang, Xiao Li, Shi Jin
- **年份/状态**：2026，arXiv 预印本
- **核验标识**：[arXiv:2603.13440](https://arxiv.org/abs/2603.13440)，DOI `10.48550/arXiv.2603.13440`
- **PDF**：[arXiv PDF](https://arxiv.org/pdf/2603.13440)
- **代码状态**：**未发现公开代码**。已检查 arXiv 页面、作者/题名 GitHub 检索；第三方聚合页仅提供 “Request Code”。

**核心问题与方法。** 论文提出 MultiCE-Flow：以多模态感知模块融合 LiDAR、相机和位置数据形成环境语义条件 (C_{\mathrm{env}})，将稀疏导频作为结构条件 (C_{\mathrm{pilot}})，共同引导 Diffusion Transformer（DiT，扩散 Transformer）主干；训练目标采用 Flow Matching，并主张一步采样。

**结果与局限。** 摘要报告其在分布外场景和不同 pilot density 下优于传统及既有生成式基线，但没有在摘要中给出可核对的具体增益。更重要的是，你现有 Sheet2 城市条件并不具备完整的 LiDAR/相机/位置联合监督，因此不能直接照搬端到端配置；而且其导频主要作为条件输入，不等同于 PnP 投影或显式后验数据一致性。

**相对阅读笔记的位置。** 硬去重已排除。它填补了“**环境语义条件 + 稀疏导频结构条件 + DiT/Flow 一步信道生成**”的缺口，区别于阅读笔记中的无条件 FM-MIMO CE、RC-Flow，以及一般 cross-modal channel inference。

**对课题的迁移接口。** 可把现有 SRF/GMFlow 改为

\[
v_\theta(H_t,t;C_{\mathrm{env}},C_{\mathrm{pilot}},m),
\]

其中 (m) 是缺失模态 mask。建议把 MultiCE-Flow 作为快速条件先验或初始化，再外接 Anchor-CKM/PnP 数据步做后验校正，而不是把一步生成结果直接视为最终估计。

## 2. Channel Knowledge Map Reconstruction From Sparse Measurements via Pilot-Anchored Layout-Conditioned Fourier Refinement

- **作者**：Zhonghao Jiu, Fan Meng, Yongming Huang, Hang Zhan, Zening Liu, Xiaohu You
- **年份/状态**：2026，arXiv 预印本；论文页注明 submitted to IEEE TWC，不能视为已录用
- **核验标识**：[arXiv:2607.01453](https://arxiv.org/abs/2607.01453)，DOI `10.48550/arXiv.2607.01453`
- **PDF**：[arXiv PDF](https://arxiv.org/pdf/2607.01453)
- **代码状态**：**未发现公开代码**。已检查论文页、题名/作者 GitHub 检索和无线地图代码汇总仓库。

**核心问题与方法。** Anchor-CKM 指出：直接在零填充 pilot grid 上施加卷积或谱算子，会把采样 mask 的伪结构与真实信道场混在一起。其处理顺序是：

\[
\text{sparse pilots}
\rightarrow \text{support-aware partial convolution}
\rightarrow \text{layout-conditioned dual-path Fourier refinement}
\rightarrow (\mu(r),\sigma^2(r)).
\]

也就是先构造有测量支撑的 radio field，再施加布局/频域先验，最后输出均值和逐位置异方差。

**结果与局限。** 在 transmitter-disjoint DeepMIMO 场景、缺失率 0.3–0.95（含 5%–10% pilot coverage）下，显式布局室外场景的 received-power RMSE 相对最强复现基线降低 0.79–1.33 dB。局限是它仍以确定性重建主干为主，依赖可用的 layout descriptor，也没有验证多模态生成后验的校准与多样性。

**相对阅读笔记的位置。** 硬去重已排除；属于对 TGPP、PnP-ADMM、DPS/FlowDPS 与 CKMImage 类工作的深化。它新增的不是又一个 backbone，而是“**pilot-support 稳定化必须先于结构先验**”这一可直接审稿辩护的处理顺序。

**对课题的迁移接口。** 可把 partial-convolution 输出作为 SRF/GMFlow 的初值或条件 token；在 PnP 中，可把它视为比简单 (A^\dagger y) 更稳健的测量支撑编码器。建议优先验证：零填充、mask channel、partial convolution 三种 pilot 表征对 NMSE、边界误差与后验残差的影响。

## 3. CAR-Flow: Condition-Aware Reparameterization Aligns Source and Target for Better Flow Matching

- **作者**：Chen Chen, Pengsheng Guo, Liangchen Song, Jiasen Lu, Rui Qian, Xinze Wang, Tsu-Jui Fu, Wei Liu, Yinfei Yang, Alex Schwing
- **年份/会议**：2025，NeurIPS 2025 Spotlight；Apple
- **核验来源**：[Apple Machine Learning Research](https://machinelearning.apple.com/research/car-flow)，[arXiv:2509.19300](https://arxiv.org/abs/2509.19300)
- **PDF**：[NeurIPS 官方 PDF](https://papers.nips.cc/paper_files/paper/2025/file/8838314582eb031f55aee65a703e76c5-Paper-Conference.pdf)
- **代码状态**：**未发现公开代码**。已检查 Apple 官方页、NeurIPS/OpenReview、arXiv 与 GitHub。

**核心问题与方法。** 标准条件 Flow Matching 常从与条件无关的标准高斯出发，网络同时承担“质量搬运”和“条件语义注入”。CAR-Flow 学习轻量条件 shift：

\[
x_0' = x_0+\mu_0(c),\qquad x_1'=x_1+\mu_1(c),
\]

并考察 source-only、target-only 与 joint 三种形式，使不同条件的概率路径更短、更易学习。

**结果与局限。** 在 ImageNet-256 的 SiT-XL/2 上，FID 从 2.07 降至 1.68，额外参数少于 0.6%。这些数字不能直接外推到复数 MIMO 信道；论文尚无无线任务验证。

**相对阅读笔记的位置。** 硬去重已排除。它是对 BeamCKMDiff 的 adaLN、FiLM、cross-attention 和条件 token 的原则性扩展：条件不仅进入网络，也进入**概率路径端点/源分布**。

**对课题的迁移接口。** 对连续位置 (r)、波束 (b)、环境编码 (e)，可令

\[
H_0 = \epsilon + \mu_0(r,b,e),
\]

让初始噪声先靠近对应信道簇。建议在 GMFlow/SRF 中做 source-only / target-only / joint 消融，并报告路径曲率、NFE–NMSE 与跨城市泛化，而不只报告最终 NMSE。

## 4. Active Learning for Channel Knowledge Map Construction via Bayesian Inference Diffusion Models

- **作者**：Yunzhe Zhu, Xuewen Liao, Zhenzhen Gao, Linzhou Zeng, Yong Zeng
- **年份/状态**：2026，arXiv 预印本
- **核验标识**：[arXiv:2606.29862](https://arxiv.org/abs/2606.29862)，DOI `10.48550/arXiv.2606.29862`
- **PDF**：[arXiv PDF](https://arxiv.org/pdf/2606.29862)
- **代码状态**：**未发现公开代码**。已检查论文页、作者/题名 GitHub 检索和无线地图代码汇总仓库。

**核心问题与方法。** 论文针对有限采样点被浪费在空间冗余或高度可预测区域的问题，把 Bayesian inference 与 diffusion 结合，在不重新训练模型的情况下估计逐元素 epistemic uncertainty，并同时考虑不确定性与空间均匀性选择下一批测点。

**结果与局限。** 摘要报告在静态和动态 CGM 数据集上优于基线，但没有给出可直接核验的具体提升值。当前任务仍以 CGM 为主；diffusion 反向过程中的不确定性传播开销，以及它对 CSI/AoA/AoD 的可扩展性，都需要实验验证。

**相对阅读笔记的位置。** 硬去重已排除；它深化了 TGPP 的轨迹/观测风险先验，新增“**模型认知不确定性 + 空间均匀性**”的主动采样闭环。普通 diffusion 只是载体，不应作为唯一创新点。

**对课题的迁移接口。** 可把后验残差、epistemic uncertainty 与轨迹可达性合成采样评分：

\[
s(r)=\lambda_1 U_{\mathrm{epi}}(r)+\lambda_2 R_{\mathrm{post}}(r)-\lambda_3 C_{\mathrm{motion}}(r).
\]

这样可直接比较随机、轨迹风险、不确定性、联合策略四类测点选择，形成闭环 CKM/WCM 实验。

## 5. RadioMapMotion: A Dataset and Benchmark for Proactive Spatio-Temporal Radio Environment Prediction

- **正式版作者**：Nan Cheng, Honggang Jia, Xiucheng Wang, Haixia Peng, Ruijin Sun, Conghao Zhou
- **年份/期刊**：2026，IEEE Transactions on Cognitive Communications and Networking (TCCN)
- **DOI**：[10.1109/TCCN.2026.3685413](https://doi.org/10.1109/TCCN.2026.3685413)
- **预印本 PDF**：[arXiv:2511.17526 PDF](https://arxiv.org/pdf/2511.17526)。注意：早期预印本题名含 “Baseline”，作者列表也少于正式版；这里以正式 DOI 与作者仓库引用为准。
- **代码状态**：**完整作者官方代码与公开数据**：[UNIC-Lab/RadioMapMotion](https://github.com/UNIC-Lab/RadioMapMotion)。仓库含数据下载、配置、data loader、ConvLSTM-UNet、训练脚本和三类测试脚本。

**核心问题与方法。** 现有 radio map 往往把动态环境当作彼此独立的静态帧。RadioMapMotion 提供由物理一致车辆轨迹生成的连续 RM 序列，并以 ConvLSTM-UNet 型 RadioMotionNet 做多步预测。官方仓库给出的划分为 15000 训练、5000 验证、5000 常规测试和 5000 新环境测试序列；每个序列用 8 帧上下文预测 5 帧。

**结果与局限。** 论文报告其在预测精度、结构保真与推理时延上优于代表性基线，但这里不补写摘要未给出的数值。它主要针对 pathloss/radio map，基线也是 ConvLSTM，而不是端到端 MIMO CSI 生成器。

**相对阅读笔记的位置。** 硬去重已排除；填补动态连续序列、物理一致车辆轨迹和 new-environment split 三个缺口。它应定位为**数据/系统约束工具与基线**，而不是生成式方法主锚点。

**对课题的迁移接口。** 可用同一数据划分比较 ConvLSTM、DiT、Flow Matching 与 CM：

\[
p(H_{t+1:t+K}\mid H_{t-T:t},\mathrm{trajectory},e),
\]

尤其应保留 new-environment split，避免随机 patch 切分造成过乐观泛化结论。

## 为什么不是重复

已对《每日论文推荐.xlsx》、阅读笔记全部工作表、反馈、工作区 Markdown，以及 142 份本地 PDF（3838 页）进行标题标准化、arXiv/DOI、URL/仓库与全文交叉去重。5 个 arXiv ID `2603.13440`、`2607.01453`、`2509.19300`、`2606.29862`、`2511.17526` 在历史资料中均为零命中。

相对既有脉络：

- MultiCE-Flow：不是普通 FM-MIMO CE，而是多模态环境 + sparse-pilot 双条件 DiT；
- Anchor-CKM：不是再换 backbone，而是新增 measurement-first/pilot-support 顺序；
- CAR-Flow：不是只加 adaLN，而是条件化源/目标概率路径；
- Active-learning CKM：不是再做一次 CGM diffusion，而是把模型不确定性用于下一批测点；
- RadioMapMotion：不是静态 radio map 数据，而是连续动态序列与跨环境测试。

## 建议精读顺序

1. **MultiCE-Flow**：最接近“环境先验 + 稀疏导频 + DiT/Flow + MIMO 信道估计”的主线。
2. **Anchor-CKM**：最容易直接改造成现有论文中的显式数据一致性/观测支撑模块。
3. CAR-Flow：作为条件化机制消融；随后读主动学习 CKM 和 RadioMapMotion，分别补闭环采样与动态数据。

## 下一步实验切入点

### 最小可行版本：MultiCE × Anchor × CAR

1. 保留现有 SRF/GMFlow 主干；将 pilot mask 和观测值分通道输入 support-aware partial convolution；
2. 以坐标、环境栅格、可用角域条件组成 (C_{\mathrm{env}})，不可用模态用 mask token；
3. 增加 CAR source-only shift (\mu_0(C_{\mathrm{env}}))；
4. 输出后执行一次显式导频一致性投影或 PnP 数据步；
5. 做四项消融：baseline、+Anchor、+CAR、+Anchor+CAR；报告 NMSE、pilot residual、NFE、跨城市性能和缺失模态退化。

### 进阶版本：动态闭环 CKM

1. 先复现 RadioMapMotion 的 RadioMotionNet 与 new-environment 测试；
2. 用时空 DiT/Flow 替换 ConvLSTM；
3. 加入 epistemic uncertainty head；
4. 在运动预算下比较随机、TGPP 风险图、不确定性、联合评分四种测点策略；
5. 验收标准不只看平均 RMSE，还应看 NLoS 边界、最坏 10% 区域、校准误差和采样成本。

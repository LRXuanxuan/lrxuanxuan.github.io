# 2026-09-23 每日前沿论文推荐

## 本轮结论

本轮新增 5 篇均为 2026-09-15 至 09-22 的 arXiv 预印本。它们分别覆盖渐进观测条件、空间非平稳物理先验、在线 CKM/频谱图主动采样、高移动系统约束，以及稀疏幅度观测下的物理一致 flow 逆问题。它们不与既有 FlowADMM、DT 导频定律、环境条件 diffusion、OTFS-SBGM、BeamRMX 重复。

## 逐篇卡片

### 1. MIMO-OFDM AI Receiver Based on Incrementally Conditioned Diffusion with Soft Decision

- 作者/年份：Weijie Zhou, Zhaoyang Zhang, Zhixian Kong, Zhaohui Yang；2026 arXiv v1（2026-09-22）。[论文页](https://arxiv.org/abs/2609.25923)｜[PDF](https://arxiv.org/pdf/2609.25923)
- 问题与方法：面向 MIMO-OFDM，将稀疏导频初始条件与逐轮软判决形成的增量条件共同用于联合检测/信道估计。其 condition-adaptive post-training 适配条件分布变化，并以条件 diffusion transformer 把多步生成缩减为一步。
- 结果与局限：作者报告在统计和站点射线追踪信道、不同 SNR/导频率/调制下稳定提升，导频密度低至 1/32。每轮虽为单次生成，默认仍迭代 5 轮；文中 3.02M 参数与 478.40M FLOPs/轮的口径不等于低总计算。速度设定为 0--10 m/s，未给高速移动实测；也未给 CKM、PnP 或复杂零空间恢复的分离归因。
- 迁移与差异：可将“条件逐步丰富 + 可靠性连续化”做成独立分支：令 `Y,P,mask,noise` 为固定条件，追加软检测置信度 token 或残差 token；不与现有 Robust-CKMSRF 或主线模块叠加。
- 代码：未发现公开代码（论文页/全文及精确标题、arXiv ID 的 GitHub 两轮查询）。

### 2. A Gram-Attention Learning Framework for Spatially Non-Stationary Channel Estimation

- 作者/年份：Jiannan Wang, Xianghao Yu, Chenshu Wu；2026 arXiv v1（2026-09-22）。[论文页](https://arxiv.org/abs/2609.26437)｜[PDF](https://arxiv.org/pdf/2609.26437)
- 问题与方法：针对 XL-MIMO 阵列孔径上的空间非平稳，构造 joint angle-subarray (JAS) 码本，把 CE 化为层级稀疏支持检测；再把匹配滤波响应编码为特征，以 Gram-attention 用测量字典 Gram 矩阵抑制泄漏，并由 LS 重构路径增益。
- 结果与局限：摘要报告最高支持检测 F1 与最低 NMSE，并含模块消融；尚未见真实测量、生成先验或 CKM 条件实验，不能外推到地图失配情形。
- 迁移与差异：它不是另一种生成模型，而是为现有导频算子提供可解释的 Gram/相干性特征。可独立比较“仅 residual、residual+Gram token、oracle support”，报告 `E_obs/E_null`、NMSE、残差与 FLOPs；这补充当前主稿对可观测子空间的诊断。
- 代码：作者预告/部分代码。全文第 10 页脚注预告接收后发布源代码；目前未找到公开实现，不能列为完整开源。

### 3. Sensing While Communicating: Active Online Spectrum Cartography via Air-Ground Cooperation

- 作者/年份：Shangjie Zhuang, Jiahui Liang, Shijian Gao；2026 arXiv v1（2026-09-21）。[论文页](https://arxiv.org/abs/2609.24119)｜[PDF](https://arxiv.org/pdf/2609.24119)
- 问题与方法：在低空 UAV 频谱图中联合考虑采样、上报与在线更新。方法包括在线深度展开张量分解、比特深度相关插值误差模型，以及基于不确定性的 UAV 采样/UGV 链路维持。
- 结果与局限：作者报告相对在线张量分解约 27 倍加速，城市场景 NMSE 与 outage 均下降超过 23%；对象是 PSD 地图而非复数 CSI，且包含 UAV/UGV 协同假设。
- 迁移与差异：适合作为 CKM 置信度输出如何落到“下一条测量/导频预算/上报比特”的系统级闭环参考，而非替换 FlowADMM。可做小型仿真：以预测方差或校准残差选择下一批 pilot/location，并固定总测量与计算预算。
- 代码：未发现公开代码（同上核验）。

### 4. Joint Channel Estimation, Detection, and Resource Allocation for OTFS-RSMA

- 作者/年份：Chaedam Son, Si-Hyeon Lee；2026 arXiv v1（2026-09-21，已投稿 IEEE）。[论文页](https://arxiv.org/abs/2609.24121)｜[PDF](https://arxiv.org/pdf/2609.24121)
- 问题与方法：为高速移动 OTFS-RSMA 联合优化导频、估计、检测和资源分配。论文比较 guard-based 与 superimposed transmission，导出 LMMSE、误差感知消息传递检测器和速率代理式，再用 SCA 与低复杂度替代算法求解。
- 结果与局限：摘要称 guard-based common message 在若干工况更优，低复杂度法接近 SCA，且单 SIC 下与 OTFS-NOMA 竞争；未涉及生成式先验、站点条件或真实高速链路。
- 迁移与差异：这是高移动系统约束锚点。它要求将 NMSE 与 pilot overhead/BER/SE 一起报告，避免只在信道恢复指标上比较先验；适合后续独立 OTFS/DD 分支，不应把 RSMA 模块并入当前 MIMO-OFDM 主线。
- 代码：未发现公开代码（同上核验）。

### 5. AntennaFlow: A Generative Flow Model for Offset Correction in Phaseless Antenna Testing

- 作者/年份：Yongzhi Li, Chongting Shen, Menglin Chen, Xun Jiang, Zhengpeng Wang；2026 arXiv v1（2026-09-15）。[论文页](https://arxiv.org/abs/2609.16948)｜[PDF](https://arxiv.org/pdf/2609.16948)
- 问题与方法：从稀疏、无相位、位置偏移的近场幅度测量恢复居中近场，并完成 NF–FF 变换。它结合偏移不变对比编码、确定性 flow-matching transport 与仅在居中场有效的 Green 函数 Taylor 校正。
- 结果与局限：作者报告稀疏幅度、无偏移向量条件下优于比较方法并保持物理一致性；其观测与目标是天线场，未验证多径 MIMO、导频噪声或 CKM。
- 迁移与差异：其价值在“先学习失配不变表征，再施加明确物理校正”，可用于研究导频相位/阵列标定/位置误差的独立压力测试；不可据此声称可直接改善当前 CKM 条件先验。
- 代码：未发现公开代码（同上核验）。

## 组合逻辑与建议 MVP

组合由“生成条件更新（1）→物理观测字典（2）→不确定性驱动数据采集（3）→高速移动系统效益（4）”构成闭环；第 5 篇提供独立的观测失配与物理校正视角，避免 5 篇都停留在同一种 diffusion/CKM 迁移。

优先精读 1–2 篇为 Diff-Rx 与 Gram-Attention。最小可行实验：在冻结 MC-CKM straight-flow + FlowADMM 设置中，仅加一条 residual/soft-decision 可靠性条件支路；另一独立实验只把导频算子 Gram 特征送入条件编码器。共同固定数据划分、种子、`K`、`M`、PnP 参数与推理预算，报告 NMSE、归一化残差、`E_obs/E_null`、NFE/运行时间及 clean/corrupt 条件消融。两支不得叠加后归因。

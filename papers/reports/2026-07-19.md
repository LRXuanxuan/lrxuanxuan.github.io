# 2026-07-19 每日前沿论文推荐

## 当日组合逻辑

今日 5 篇按“生成先验与观测后验闭环”组织：

1. **FlowADMM**：把 flow prior（流模型先验）的 renoise–denoise 操作正式嵌入 PnP-ADMM，并给出收敛条件；
2. **Posterior-Transport View**：解释 FlowDPS、FLOWER、PnP-Flow 等究竟逼近什么后验，指出确定性流的条件化首先是源分布重加权；
3. **RadioDiff-v2**：以 Flow Matching 训练一维 Diffusion Transformer，生成角功率谱（APS），补足连续角域 CKM 与下游波束/定位接口；
4. **M3F-UAV**：面向 RGB、深度、LiDAR、CSI 缺失组合的统一表征，直接对应现有城市数据条件不完整；
5. **GeoGS-CE**：把高移动场景的几何散射支撑渲染为 delay–beam 功率先验，再通过 LMMSE 与稀疏导频闭环。

这组论文分别回答“PnP 怎么稳定求解”“flow 后验校正理论上在做什么”“角域信道分布如何连续条件生成”“条件模态缺失如何训练”“环境几何如何进入高速移动导频估计”。五篇不是同一扩散模板的重复迁移。

## 1. FlowADMM: Plug-and-play ADMM with Flow-based Renoise-Denoise Priors

- **作者**：Hendrik Sommerhoff, Michael Moeller
- **年份/状态**：2026，arXiv 预印本
- **研究方向**：Flow Matching；Plug-and-Play（PnP，即插即用先验）；ADMM；线性逆问题；数据一致性
- **可核验标识**：arXiv:2605.08640；DOI: 10.48550/arXiv.2605.08640
- **论文页/PDF**：[arXiv](https://arxiv.org/abs/2605.08640)；[PDF](https://arxiv.org/pdf/2605.08640)
- **核心问题**：现有 flow/diffusion PnP 常用随机 renoise–denoise，既增加方差，也使收敛分析困难。
- **方法**：作者将随机操作背后的确定性均值算子形式化为对潜在噪声分布的去噪器期望，并把该算子作为 ADMM 的先验子步；分析覆盖固定和非平稳时间表，在 flow 网络满足弱 Lipschitz 条件时给出收敛保证。
- **关键结果/局限**：论文报告其在去噪、去模糊、超分辨和修补中达到 flow-based PnP 的领先结果，并减少数据一致性求值；晚期增加平均次数的三阶段计划比常数计划平均高约 0.275 dB。局限是理论假设固定点存在、网络 Lipschitz 常数未显式训练约束，且实际 Monte Carlo 近似的随机性没有完全纳入证明；实验仍是图像逆问题。
- **迁移到用户课题**：可直接将现有 `CKM prior + PnP-ADMM` 中的 CM/SRF 去噪子步替换为 deterministic mean renoise–denoise，并保留导频算子解析近端步。首轮只比较同一 prior、同一初始化、同一 SNR/pilot mask 下的当前 PnP-ADMM 与 FlowADMM，报告 NMSE、数据残差、NFE、数据一致性求值次数和收敛曲线。
- **相对阅读笔记的位置**：**对既有方向的深化**。阅读笔记已有 PnP-ADMM、PnP-Flow、Flower、FlowDPS 和 PnP-CM；本篇新增的是“确定性均值算子 + ADMM 分裂 + 收敛条件”，不是普通 PnP-Flow 的再次推荐。
- **代码状态**：**完整开源实现**。[官方仓库](https://github.com/hesom/FlowADMM) 含 `flowadmm/methods/flowadmm.py`、任务配置、数据/checkpoint 下载、主结果与调参复现脚本；作者提示仓库内移植的部分基线未逐一验证与原仓库完全一致。
- **推荐定位**：**可直接复现并改造成现有求解器**；今日优先精读 1。

## 2. What Do Flow-Based Inverse Solvers Approximate? A Posterior-Transport View

- **作者**：Jian Xu, Delu Zeng, John Paisley, Qibin Zhao
- **年份/状态**：2026，arXiv 预印本
- **研究方向**：Flow-based inverse solver；后验传输；源分布重加权；不确定性；后验偏差
- **可核验标识**：arXiv:2606.24516v2；DOI: 10.48550/arXiv.2606.24516
- **论文页/PDF**：[arXiv](https://arxiv.org/abs/2606.24516)；[PDF](https://arxiv.org/pdf/2606.24516)
- **核心问题**：FlowDPS、FLOWER、PnP-Flow 等在 probability-flow ODE 上逐步增加测量引导，但这些修正距离真实后验 \(p(x\mid y)\) 多远，此前缺少统一解释。
- **方法**：对确定性 flow prior，精确贝叶斯条件化可写为源分布
  \[
  p_0^y(z)\propto p\!\left(y\mid \Phi(z)\right)p_0(z),
  \]
  再经未修改的流映射 \(\Phi\) 推送到数据空间。作者把轨迹引导解释为从无条件源出发、将其变形成后验所需的最小动能修正场，并将 FlowDPS、FLOWER、PnP-Flow统一为零阶、Gaussian 或 proximal 近似。
- **关键结果/局限**：在有闭式后验的 2D 实验中，源重加权达到 Monte Carlo 误差底，而轨迹引导的分布误差大 200–800 倍并出现模态坍缩；提出的低成本 velocity-correction solver 在 AFHQ、CelebA 及 OOD 任务中保持样本多样性，且不确定性与重建误差相关。局限是理论依赖确定性、可逆且足够光滑的 flow map；高维源重加权本身仍可能昂贵，结论尚未在无线复信道后验上验证。
- **迁移到用户课题**：它与 CAR-Flow 的“条件化源分布/路径”形成理论闭环。建议把当前 GMFlow/SRF 的三种后验接口分开比较：source-only conditioning、trajectory guidance、terminal RC/PnP；除 NMSE 外增加 posterior coverage、样本有效秩、条件协方差校准及误差—不确定性相关性，避免只看单点重建。
- **相对阅读笔记的位置**：**填补理论缺口**。阅读笔记已收集 FlowDPS、FLOWER、PnP-Flow 与 Bayesian inverse + flow matching；本篇第一次把这些方法放入同一 posterior-transport 目标，并明确源重加权与漂移修正的差异。
- **代码状态**：**未发现公开代码**。已检查 arXiv 页面/源码、作者与题名检索及 GitHub 仓库检索；论文未给出对应实现链接。
- **推荐定位**：**理论启发 + 评估协议来源**，不宜直接声称可即插即用。

## 3. RadioDiff-v2: Generative Angular Radio Maps for Multi-Beam Selection and Localization

- **作者**：Xiucheng Wang, Junxi Huang, Nan Cheng
- **年份/状态**：2026，arXiv 预印本
- **研究方向**：角域 CKM；Angular Power Spectrum（APS，角功率谱）；Diffusion Transformer；Flow Matching；连续波束管理
- **可核验标识**：arXiv:2607.08045；DOI: 10.48550/arXiv.2607.08045
- **论文页/PDF**：[arXiv](https://arxiv.org/abs/2607.08045)；[PDF](https://arxiv.org/pdf/2607.08045)
- **核心问题**：几何到 APS 的映射在 NLoS 下是一对多的；仅优化均方误差的回归器会输出过平滑条件均值，抹去波束选择与定位依赖的多径峰。
- **方法**：双分支一维 Diffusion Transformer 采用 Flow Matching 训练，结合周期角编码、adaptive LayerNorm（adaLN，自适应层归一化）条件化、Fourier angular mixer，以及 velocity/clean-signal 双头。输入包含收发坐标、阵列几何和与 APS 角轴对齐的接收机中心极坐标建筑占用图；同一模型分别读取分布样本、回归点估计、Bayes 波束规则和定位似然。
- **关键结果/局限**：在 99 个未见环境、约 100 万链路的 zero-shot 测试中，论文报告 Wasserstein-1 距离 0.39 dB、八波束 NLoS 扫描损失 2.43 dB、四基站定位误差 20.6 pixel，并在分布与逐 bin 指标上超过各类基线。局限是当前集中于二维、单一角轴 APS；论文明确将宽带和 elevation-resolved APS 留作后续。
- **迁移到用户课题**：这是 BeamCKMDiff 之后更直接的“连续角域分布”结构来源：将现有 AoA/AoD map 作为周期 token/极坐标条件，用 adaLN 注入位置与阵列信息，同时保留 clean head 供点估计、sample head 供后验多样性。可进一步把 LS CSI/导频残差作为 cross-attention 观测 token，而不把离散 beam index 当作唯一条件。
- **相对阅读笔记的位置**：**对既有方向的深化**。相对 RadioDiff-3D，它从标量/体素 radio map 转向 APS 分布；相对 BeamCKMDiff，它增加周期角结构、Flow-Matching DiT、双头 perception–distortion 权衡和波束/定位统一读出。
- **代码状态**：**作者预告/占位仓库**。[官方仓库](https://github.com/UNIC-Lab/RadioDiff-v2) 当前只有 README，明确表示代码将在论文接收后发布，不能标为完整实现。
- **推荐定位**：**结构设计与无线应用锚点**；代码发布前需自行实现。

## 4. M3F-UAV: A Missing-Modality Multimodal Foundation Model for Low-Altitude Wireless Sensing

- **作者**：Pengxuan Gao, Kai Ying, Botao Wu, Jianhua Mo, Qingsong Wen
- **年份/状态**：2026，arXiv 预印本
- **研究方向**：缺失模态学习；低空 UAV；RGB/Depth/LiDAR/CSI 融合；masked reconstruction；无线基础模型
- **可核验标识**：arXiv:2607.13678；DOI: 10.48550/arXiv.2607.13678
- **论文页/PDF**：[arXiv](https://arxiv.org/abs/2607.13678)；[PDF](https://arxiv.org/pdf/2607.13678)
- **核心问题**：视觉遮挡、稀疏点云、传感器故障与多径会使低空无线系统在部署时缺少部分模态；固定要求全模态输入的模型无法使用。
- **方法**：为 RGB、depth、LiDAR 与 CSI 使用模态专用预训练编码器，经统一 cross-modal fusion 得到固定维度表征；训练同时使用特征级 masked reconstruction 与 UAV localization 目标，使任意可用模态组合可经轻量 task head 适配定位与波束预测。
- **关键结果/局限**：论文在 LAMBDA 数据集上报告相对单模态基线更好的定位/波束预测，并在缺失模态和模态失效下保持稳健。局限是当前任务偏无线感知/决策，不直接生成 \(p(H\mid r,e,M)\)；主要验证来自高保真仿真，论文模型代码尚未公开。
- **迁移到用户课题**：与 Sheet2 事实直接对应：城市数据中坐标与 AoA/AoD 监督不能同时完整获得。建议把每种条件表示为 `(feature, availability_mask, confidence)`，训练时按真实城市缺失模式做 modality dropout；输出 token 作为 GMFlow/CM 的条件，而非先强行补齐全部原始模态。跨城市测试必须按城市整体留出，不能随机打散链路。
- **相对阅读笔记的位置**：**填补研究缺口**。相对 PilotWiMAE，它从“导频缺失”扩展到视觉、几何和 CSI 组合缺失；相对 QuaMoE-DRF/环境辅助估计，它显式训练缺失模态，而不是假定所有输入齐全。它是条件编码前端，不是新的信道后验求解器。
- **代码/数据状态**：**完整数据与工具链，M3F 模型代码未发现**。[LAMBDA 仓库](https://github.com/SJTU-WirelessAI-Lab/LAMBDA) 含 CSI 读取、MIMO-OFDM CSI/雷达生成、场景配置、示例、测试和部分论文用例；[数据集 DOI](https://doi.org/10.57760/sciencedb.36052)。未找到 M3F-UAV 预训练/融合模型的对应实现。
- **推荐定位**：**可直接复用数据与缺失模态协议；模型仅作结构参考**。

## 5. GeoGS-CE: Learning Delay–Beam Channel Priors with 3D Gaussians for High-Mobility Scenarios

- **作者**：Yumeng Zhang, Jiajia Guo, Chaozheng Wen, Chenghong Bian, Jun Zhang
- **年份/状态**：2026，arXiv 预印本
- **研究方向**：高移动宽带 MIMO；3D Gaussian 场景先验；delay–beam PSD；可微无线渲染；稀疏导频 LMMSE
- **可核验标识**：arXiv:2605.16094；DOI: 10.48550/arXiv.2605.16094
- **论文页/PDF**：[arXiv](https://arxiv.org/abs/2605.16094)；[PDF](https://arxiv.org/pdf/2605.16094)
- **核心问题**：高速移动下瞬时复 CFR 相位快速变化，而稀疏导频难以恢复全带宽、全阵列信道；但轨迹、速度、主径支撑及 delay–beam 功率谱更稳定。
- **方法**：离线阶段学习场景级 3D Gaussians 表示 NLoS 散射支撑，并加入显式虚拟 LoS 分量；leakage-aware 可微无线渲染器把几何映射到 delay–beam 功率谱，同时建模 OFDM delay leakage 与阵列 beam leakage。在线阶段按用户位置预测功率谱，转为协方差先验，再由 LMMSE 从稀疏导频恢复和跟踪 CFR。
- **关键结果/局限**：在 Sionna RT 生成的广深高铁片段中，350 km/h、100 阵元 ULA、1024 子载波及每时隙 4 个导频 OFDM symbol 的设置下，论文报告其优于 pilot-only、压缩感知和非几何/基础 3D-GS 先验，并接近 genie-prior 上界。局限是单一仿真路线与固定阵列设置，尚无真实测量或跨城市验证。
- **迁移到用户课题**：这篇给出从 WCM/CKM 到 MIMO 后验恢复的清晰中间变量：不直接预测瞬时 \(H\)，而预测较稳定的 delay–beam PSD/协方差，再与导频 LMMSE、PnP 或 CM 结合。最小可行版本可先用现有 scatterer/blocker 粗布局生成 PSD condition，不必声称复现完整 3DGS；随后比较 `pilot-only`、`position-only`、`geometry→PSD`、`oracle PSD` 四档先验。
- **相对阅读笔记的位置**：**填补高移动物理接口缺口**。相对 F4-CKM/无线 radiance field，它的目标不是连续渲染 radio map，而是为稀疏导频 CE 提供 leakage-aware delay–beam covariance；相对 MultiCE-Flow，它把环境信息先物理压缩为可解释协方差，再进入经典估计器。
- **代码状态**：**未发现公开代码**。已检查 arXiv 页面/源码、题名与 arXiv ID 的 GitHub 检索及作者关键词检索；未找到对应仓库。
- **推荐定位**：**可改造成环境先验模块，暂不能直接复现**；今日优先精读 2。

## 下一步实验切入点

### MVP-A：FlowADMM 替换现有 PnP 子步

- 固定 `7_14/MIMO_ckmsrf` 的数据、checkpoint、初始化、pilot mask、SNR、PnP 外层次数；
- 仅替换 prior step：当前 CM/SRF 单次去噪 vs FlowADMM mean renoise–denoise；
- 报告 NMSE、导频残差、外层收敛、NFE、data-consistency evaluations 和采样时延；
- 增加常数 \(K_{\text{avg}}\) 与 late-heavy schedule 消融，避免把调度收益误归因于 ADMM。

### MVP-B：Geometry → PSD → Posterior

- 先用现有 BS/scatterer/blocker 粗布局构造位置条件的 delay–beam PSD 预测头；
- 将 PSD 转为协方差先验，分别接 LMMSE、当前 PnP-ADMM 与 FlowADMM；
- 对比 `pilot-only / position-only / geometry-PSD / oracle-PSD`，并在未见轨迹或未见城市上测试；
- 如无完整 AoA/AoD 标签，用 availability mask 和弱监督功率谱一致性损失，不假设 Sheet2 各城市全模态齐备。

### 进阶：Posterior calibration

- 对同一观测生成多样本，评估 posterior coverage、样本协方差与真实误差相关性、beam/effective-rank 分布；
- 单独比较 source reweighting、trajectory guidance、terminal RC/PnP，保持 prior 与算子完全一致；
- 只有在全数据、多随机种子实验通过后，才将 CPU smoke test 以外的结果写成性能结论。

## 1. Provable diffusion-based posterior sampling for linear inverse problems via DDIM

- **作者 / 年份 / venue**：Yuchen Jiao, Na Li, Changxiao Cai, Yuxin Chen, Gen Li；2026；arXiv 预印本。
- **方向与问题**：Diffusion posterior sampling、线性逆问题、低额外开销的数据一致性。
- **方法**：Posterior-DDIM 在测量算子 SVD 的每个奇异方向上比较 observation SNR 与 diffusion SNR；低观测可信度方向沿生成先验更新，高可信度方向切换为校准后的测量预测器。只需对标准 DDIM 做逐坐标修改。
- **关键结果**：给出收敛到真实贝叶斯后验的渐近一致性证明；图像修复实验覆盖 inpainting、4× super-resolution、Gaussian deblurring 和 compressed sensing。默认 NFE=100（DPS=1000），质量在 NFE 超过约 80 后趋于饱和；compressed sensing 上相对 DDNM+ 在感知指标 LPIPS/FID 更优。
- **局限**：当前理论与算法限定在线性观测；未给出收敛速率；实验是图像任务，且需要利用测量算子的奇异结构，尚未验证大规模 MIMO 导频算子的实际 SVD/FFT 代价。
- **迁移类型**：**可改造工具 / 理论启发**。把导频算子在角延迟、DFT 或已知子空间中对角化，按方向选择 prior update 与 measurement predictor，可作为 PnP-ADMM 之外的独立后验采样分支。
- **与既有阅读差异**：相对 DDNM、DPS、MACS、PnP-CM 和 FlowADMM，本篇独立贡献是“按奇异方向比较两种 SNR 并切换更新”的可证明 posterior-consistent 规则，而非统一步长的投影或近端更新。
- **位置**：深化——补齐“生成先验 + 明确线性观测”中的理论一致性与方向自适应数据一致性。
- **代码状态**：**未发现公开代码**。论文页、全文、精确标题和 arXiv ID 两轮检索均未发现作者实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.19333)｜[PDF](https://arxiv.org/pdf/2607.19333)
- **推荐理由**：可直接启发 pilot/operator-aware 的后验修正，而且比单纯再推荐一种 diffusion sampler 多出清晰、可验证的理论与实现维度。

## 2. Data-aided Channel Estimation and Sensing With Sparse Bayesian Learning for AFDM-ISAC System

- **作者 / 年份 / venue**：Yirui Luo, Yong Liang Guan, Yao Ge, Yonghong Jiang, Lingsheng Meng, David González G.；2026；已接收 IEEE Transactions on Communications，正式 DOI 待核验。
- **方向与问题**：高速 AFDM-ISAC、superimposed pilot、MMV off-grid sparse recovery、数据辅助信道估计。
- **方法**：D-GESBL 将可靠解码数据反馈为 pseudo-pilots，与真实导频联合迭代；在 DAF 域用 grid evolution 修正 fractional delay/Doppler 离栅误差。D-GAMP-GESBL 用 GAMP 替代矩阵求逆以降低复杂度。
- **关键结果**：60 GHz、256 子载波、8 接收天线、3 目标、最高 540 km/h 的仿真中，NMSE/BER 约 4 次数据辅助迭代后稳定；低复杂度 GAMP 版本基本保持性能。网格点为 65/650/1280 时，论文图示 GAMP 版本每轮约 0.0043/0.1156/0.3741 s，明显低于 GESBL 的约 0.0029/0.0233/0.0404 s 仅在小网格不占优、在大网格体现更有利的复杂度扩展（数值按图读取，需复现核验）；导频功率在实验设定下约 0.2 附近最优。
- **局限**：仿真限定于 AFDM、稀疏单路径目标和特定 DAF 结构；pseudo-pilot 依赖可靠判决，错误传播风险仍需单独压力测试；不是 CKM 或生成模型方法。
- **迁移类型**：**可直接复现的算法基线 / 可改造工具**。可把“可靠数据 → pseudo-pilot → posterior update”改造成 CKM prior + PnP 的软置信闭环，并保留 off-grid delay/Doppler 物理基线。
- **与既有阅读差异**：不同于纯导频的 Diffusion/Flow CE，也不同于静态 CKM；它新增判决数据回灌、离栅网格演化和高速 AFDM-ISAC 的严格系统约束。
- **位置**：缺口——补齐高移动、fractional delay/Doppler 与 data-aided closed loop。
- **代码状态**：**未发现公开代码**。论文页、全文、精确标题和 arXiv ID 两轮检索均未发现作者实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.18881)｜[PDF](https://arxiv.org/pdf/2607.18881)
- **推荐理由**：它是今日最容易转成可控消融的通信论文：pilot-only、hard pseudo-pilot、soft-confidence pseudo-pilot 三组即可验证闭环收益与错误传播。

## 3. Tensor-Based Dynamic Channel Estimation for mmWave Movable Antenna MIMO Systems

- **作者 / 年份 / venue**：Zhendong Li, Linchu Chen, Lin Chen, Zhou Su, Ruoyu Zhang, Guangji Chen, Ying Wang, Wen Chen；2026；arXiv 预印本。
- **方向与问题**：动态 mmWave movable-antenna MIMO、结构化参数估计、CRB。
- **方法**：把多 MA 对、多载波观测构造成四阶张量，采用 ALS 与 structured CP decomposition（SCPD）恢复因子，再估计 path loss、frequency offset、AoA/AoD、delay 并重建信道；给出分解唯一性与各参数 CRB。
- **关键结果**：SCPD/ALS 在 NMSE 上优于 MUSIC/OMP，SCPD 在低 SNR 最稳；SNR 高于约 15 dB 后角度误差出现平台，作者将其归因于降维和 MA 非均匀阵列破坏 Vandermonde 结构。表中 SCPD 总 CPU 时间约 0.0251 s、ALS 约 0.0209 s（具体硬件与规模依论文设置）。
- **局限**：纯仿真、稀疏路径与参数模型较强；角度高 SNR 平台和阵列非均匀性限制仍存在；不是生成先验，也未覆盖跨场景环境条件。
- **迁移类型**：**理论启发 / 物理基线**。用其参数 CRB、角延迟/频偏重建与张量低秩结构约束 CKM-SRF 输出，或作为 high-mobility physical baseline。
- **与既有阅读差异**：相对 GeoGS-CE 的 geometry→delay–beam PSD，本篇从实际多维观测出发做可辨识参数恢复；相对生成式 CE，它提供独立的模型驱动下界和结构化误差诊断。
- **位置**：应用/基线——高移动与可移动阵列的物理可解释参照。
- **代码状态**：**未发现公开代码**。论文页、全文、精确标题和 arXiv ID 两轮检索均未发现作者实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.17591)｜[PDF](https://arxiv.org/pdf/2607.17591)
- **推荐理由**：适合补强论文实验的“物理结构 + CRB + 参数误差”维度，避免只报告端到端 NMSE。

## 4. Scalable Attention for 5G NR Channel Estimation

- **作者 / 年份 / venue**：Mahdi Abdollahpour, Marco Bertuletti, Yichao Zhang, Yawei Li, Luca Benini, Alessandro Vanelli-Coralli；2026 IEEE PIMRC Workshops。
- **方向与问题**：标准兼容 5G NR PUSCH、MU-MIMO channel estimation、线性复杂度 attention。
- **方法**：CHEA 用 high-resolution window encoder 保留局部导频细节，以 low-resolution window encoder 汇聚宽频上下文，再通过 local cross-attention 解码并按 PRB 上采样；固定窗口使计算随子载波数线性增长，一个模型支持不同 PRB allocation。
- **关键结果**：3GPP TDL-A、120/264 子载波设置下获得优于传统和神经基线的 MSE；约 36K 参数，264 子载波约 1.7M MACs，相对其他 attention estimator 减少 2.8×–22.0× MACs、5.9×–38.6× 参数。
- **局限**：尚缺 component-wise ablation、attention pattern 分析和端到端 link-level evaluation；只验证 TDL-A/PUSCH，未证明跨场景或 CKM 环境先验泛化。
- **迁移类型**：**可改造工具**。把现有 pilot/LS-CSI token 分成局部高分辨率与宽域低分辨率两路，再用局部 cross-attention 融入 CKM 条件，可作为 PilotWiMAE 之外的轻量结构分支。
- **与既有阅读差异**：相对 PilotWiMAE 强调自监督预训练，本篇的独立贡献是固定窗口、多分辨率局部 cross-attention、跨 PRB allocation 共用模型和明确 MAC/参数预算。
- **位置**：深化——将稀疏导频表征落到标准 PUSCH 与复杂度约束。
- **代码状态**：**作者预告/部分代码**。论文称 CHEA 实现将上传至 [mdx](https://github.com/Mahdi-Abdollahpour/mdx)，但当前仓库仍是既有 MDX 接收机，README 未出现 CHEA/2607.16462，不能归类为完整实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.16462)｜[PDF](https://arxiv.org/pdf/2607.16462)
- **推荐理由**：给出现成的“局部导频细节 + 低分辨率宽域上下文”融合模板，并把复杂度—精度权衡量化到可复现实验指标。

## 5. Hierarchical Wireless Foundation Model for Multi-Task Optimization

- **作者 / 年份 / venue**：Yangjing Wang, Ouya Wang, Shenglong Zhou, Geoffrey Ye Li；2026；arXiv 预印本。
- **方向与问题**：wireless foundation model、masked channel modeling、geometry-aware cross-attention、跨环境多任务泛化。
- **方法**：上游 foundation channel encoder（FCE）用 self-supervised masked reconstruction 学习任务无关 CSI 表征；下游 foundation optimization decoder（FOD）通过 geometry-aware cross-attention 和可微 task heads 完成 beamforming、user scheduling、beam selection 等任务，并采用 supervised warm-up → unsupervised optimization。
- **关键结果**：表中 WFM-CE 的信道估计 NMSE 为 −13.3 dB（任务专用 Transformer 为 −14.0 dB、LMMSE 为 −8.98 dB）；WFM-FOD beamforming 达数值 WMMSE 的 98.5%，推理约 2.67 ms，对比 WMMSE 104 ms；user scheduling 与 beam selection 也实现毫秒级推理，并报告对未见传播环境、约束和系统配置的稳健泛化。
- **局限**：41.37M 参数、378.24G FLOPs 的 WFM-CE 明显重于任务专用 Transformer；主要证据来自仿真，跨城市/真实链路与缺失 AoA/AoD 模态仍未验证；它不是生成式 posterior solver。
- **迁移类型**：**可改造工具 / 系统基线**。优先抽取 masked FCE 和 geometry-aware condition tokens，不建议直接搬整套大模型；可作为 CKM 条件编码器或多任务下游接口。
- **与既有阅读差异**：相对 PilotWiMAE 只做信道表征，本篇把 masked channel encoder 与 geometry-aware cross-attention 接到多种无线优化任务；相对 Wireless Context Engineering，它给出具体可训练架构和延迟/性能表。
- **位置**：应用/缺口——补齐从通用信道表征到 beamforming/调度/beam selection 的系统闭环。
- **代码状态**：**未发现公开代码**。论文页、全文、精确标题和 arXiv ID 两轮检索未发现可核验的作者实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.16877)｜[PDF](https://arxiv.org/pdf/2607.16877)
- **推荐理由**：它提供原则化的 masked conditioning 与 geometry-aware cross-attention，但应作为条件编码/下游任务参考，而不是替代 CKM prior + PnP 主线。

## 为什么这 5 篇不重复

1. **Posterior-DDIM**回答“已知线性观测时如何按方向进行可证明的后验校正”。
2. **D-GESBL**回答“高速、离栅且导频稀缺时如何让可靠数据反哺信道估计”。
3. **Tensor MA-MIMO**提供与生成方法独立的参数化物理恢复、唯一性和 CRB 基线。
4. **CHEA**回答“导频 token 的局部—宽域条件融合如何做到线性复杂度并适应不同带宽”。
5. **Hierarchical WFM**回答“如何学习可跨环境、跨任务复用的 CSI 表征并接入系统优化”。

它们分别覆盖后验求解、观测闭环、物理结构、低复杂度条件编码和系统泛化，没有把 diffusion/MAE/WFM 的名称相似性当作创新，也没有假设现有 Sheet2 同时具有坐标与 AoA/AoD 全模态监督。

## 优先精读

1. **Posterior-DDIM**：重点看奇异方向集合划分、observation/diffusion SNR 比较、定理假设以及线性算子对角化代价。
2. **D-GESBL**：重点看 pseudo-pilot 可靠度门控、grid evolution、GAMP 近似与 4 次迭代收敛；这是最容易转成 MIMO/CKM 可控消融的一篇。

## 可执行 MVP（保持互斥）

### MVP-A：SVD/FFT 方向自适应 Posterior-DDIM 分支

- 在当前导频观测算子可 FFT/DFT 对角化的设定下，计算每个角延迟 bin 的 observation SNR。
- 与当前 diffusion/CM noise schedule 对应的 diffusion SNR 比较，分别执行 prior update 或 calibrated measurement predictor。
- 与现有 PnP-ADMM、FlowADMM、统一步长 DDIM 做独立比较；共同初始化、相同 test split/SNR/seed/pilot mask。
- 验收：NMSE、normalized measurement residual、NFE、sampler-only latency、SVD/FFT 额外时间和显存；先验证线性算子，暂不扩展非线性观测。

### MVP-B：Soft pseudo-pilot D-GESBL/PnP 闭环分支

- 每轮只选 posterior probability 或 LLR 超阈值的数据符号，作为带权 pseudo-pilots；权重直接进入数据一致性项。
- 设置 pilot-only、hard pseudo-pilot、soft-confidence pseudo-pilot 三组，并记录误判率、残差与迭代次数。
- CKM/GMFlow prior 保持冻结，避免把 posterior loop 与新先验混合归因。
- 验收：不同 SNR/移动速度/导频率下的 NMSE、BER、错误传播率、4–6 次迭代曲线与运行时；CPU smoke test 仅作为执行证据。

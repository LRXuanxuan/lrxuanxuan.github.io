## 本篇推荐与证据

## 4. Ensemble Controlled-Flow Filtering for Implicit Data Assimilation

- **作者 / 年份 / venue**：Zhuoyuan Li, Yue Zhao, Ming Li；2026；arXiv 预印本。
- **方向与问题**：controlled flow、sequential Bayesian update、implicit/many-to-one observations、likelihood-free data assimilation。
- **方法**：以能量倾斜定义 analysis law，`π_a(x|y) ∝ π_f(x) exp[-J(x;y)]`；EnCF 通过 stochastic controlled flow 与 adjoint matching 学习 observation-dependent control，EnCF-LF 则从 simulator samples 学习 surrogate conditional energy。
- **关键结果与局限**：在平滑加性高斯观测下，EnKF/LETKF 仍优于 EnCF；当噪声变为明显双峰时，约在 mode offset `a≈4` 后 EnCF 的 RMSE 低于两种 EnKF；对 many-to-one/implicit observations 能更好保留多峰 ensemble。代价是每次 analysis step 需训练 control，wall-clock 明显高于 Kalman 类方法；尚未验证通信导频算子。
- **迁移类型**：**理论启发 / 可改造求解器**。可将量化导频、幅度-only、硬判决或 simulator-only 信道观测写成 energy，而不强求可微 likelihood；应作为独立 posterior-correction 分支与 PnP-ADMM/FlowADMM 比较。
- **与既有阅读差异**：相对 Bayesian Inverse Problems Meet FM 的一次性 amortized posterior，本篇面向序列 filtering；相对 FlowADMM/PnP-CM，它允许非加性、非光滑、many-to-one 的观测接口并显式保持 ensemble diversity。
- **相对阅读笔记的位置**：**缺口填补**。补齐“隐式/量化/多峰观测下如何做 flow posterior update”。
- **一手来源**：[arXiv:2607.12975](https://arxiv.org/abs/2607.12975)；[PDF](https://arxiv.org/pdf/2607.12975)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者实现。
- **推荐理由**：它不是普通 FM 迁移，而是把观测机制改写为 energy tilt，并清楚给出 Kalman 方法何时更优、controlled flow 何时才值得使用，适合严谨设计对照实验。

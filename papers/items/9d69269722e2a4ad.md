## 摘要（中文译文）

夹持天线系统（pinching-antenna system, PASS）是灵活天线技术中的突破性方案，支持大规模天线重构、构建视距（line-of-sight, LoS）链路、可扩展实现并获得近场增益，从而把无线通信从“最后一英里”推进至“最后一米”。本文给出系统性教程：首先讨论 PASS 基础，包括信号模型、硬件模型、功率辐射模型与夹持天线（pinching antenna, PA）激活方法；在此基础上刻画其信息论容量极限，并分析典型性能指标以显示其相对传统天线技术的优越性。随后研究夹持波束成形设计，先针对单波导单用户情形刻画功率缩放律；对于一般多波导情形下的联合发射与夹持设计，1）针对单用户通信提出子连接与全连接两种传输策略（按基带射频链与波导的连接方式划分），以验证 PASS 的优越性；2）针对多用户通信提出波导切换、波导划分与波导复用三种实用协议。文中还指出 PASS 在宽带通信中的可行实现。此外，给出 PASS 中信道状态信息（channel state information, CSI）获取的两类方案，分别基于导频信道估计与波束训练。为克服传统凸优化方法的高复杂度与次优性，进一步探讨面向 PASS 运行的机器学习方法，重点关注深度神经网络架构与训练算法。最后指出 PASS 在下一代无线网络中的若干应用前景。

## 贡献点

- 梳理 PASS 的信号、硬件、功率辐射模型与 PA 激活方法
- 刻画 PASS 信息论容量极限并比较其相对传统天线技术的性能优势
- 针对单/多波导场景提出子连接与全连接传输策略及三种多用户协议
- 给出基于导频估计与波束训练的两类 PASS 信道获取方案
- 探讨以深度神经网络等机器学习方法降低 PASS 运行优化复杂度

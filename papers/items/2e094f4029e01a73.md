## 本篇推荐与证据

## 3. Map as a Prompt: Learning Multi-Modal Spatial-Signal Foundation Models for Cross-scenario Wireless Localization

- **作者 / 年份 / venue**：Yong Chu, Xun Zhou, Zenglin Xu, Hui Wang, Yue Yu；2026；论文全文标注 ICLR 2026 conference paper，arXiv comment 标注 ICLR 2026 poster。
- **方向与问题**：3D map soft prompt、cycle-adaptive masked modeling、cross-scenario wireless localization、parameter-efficient adaptation。
- **方法**：SigMap 先用与 CSI 周期相关的自适应 mask 防止 masked modeling 走周期性捷径，再用 GNN 编码 3D 地图/BS 几何为 soft prompt；下游只更新轻量 task head/prompt。
- **关键结果与局限**：DeepMIMO O2 上 MAE 1.026 m，WAIR-D 100 城市场景上表格报告 MAE 1.880 m；相对 LWLM 分别改善约 53.2% 和 44.3%，推理约 0.83 ms/sample。需特别注意：摘要写“zero-shot”，但正文实验对每个目标场景使用约 100 个样本微调下游 head，因此更准确的表述是 **few-shot cross-scenario adaptation**。此外，任务是定位而非 CSI posterior，且依赖地图与射线追踪数据。
- **迁移类型**：**可改造工具**。最值得迁移的是“map-as-prompt + availability/confidence mask”，而不是完整复现定位模型；可将现有粗 BS/scatterer/blocker 几何编码为 prompt token，避免假设 Sheet2 存在完整坐标与 AoA/AoD 联合监督。
- **与既有阅读差异**：相对 PilotWiMAE，它新增周期自适应 mask 与地图 prompt；相对 Robust-CKMSRF，它处理“怎样把地图压缩成可调条件”，而不只处理缺失/噪声模态；相对 RadTwin，它不要求每层显式射线路径 mask。
- **相对阅读笔记的位置**：**深化 + 缺口**。补齐 principled conditioning、跨城市轻量适配和几何先验 token 化。
- **一手来源**：[arXiv:2607.15713](https://arxiv.org/abs/2607.15713)；[PDF](https://arxiv.org/pdf/2607.15713)。DOI：待核验。
- **代码状态**：**作者预告/部分代码**。[论文给出的匿名仓库](https://anonymous.4open.science/r/SigMap_anonymous-838D) 声称包含数据生成、预训练、微调和评估全流程，但当前 API 返回 `repository_expired`，无法核验或复现其实际文件，故不能归类为“完整开源实现”。
- **推荐理由**：这是今天与用户选题优先级最贴合的论文：轻量 soft prompt、mask-aware 表征、跨场景适配和明确的环境条件接口都可独立落到 CKM-SRF/GMFlow。

## 本篇推荐与证据

## 3. TGPP: Trajectory-Guided Plug-and-Play Priors for Sparse Radio Map Reconstruction

- **作者**：Jiawen Zhang, Zhiyuan Jiang, Sheng Zhou, Zhisheng Niu
- **年份/状态**：2026，arXiv:2605.05844v1
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2605.05844)；[PDF](https://arxiv.org/pdf/2605.05844)
- **核心问题**：真实无线测量常沿车辆/UAV 轨迹采集，而非均匀随机采样；远离轨迹或被遮挡区域的约束明显更弱。
- **方法**：TGPP 学习显式输入空间风险图与隐式引导特征，可插接到确定性、GAN、图网络与 latent flow 等骨干；论文同时提出 RadioFlow-LDM 作为潜空间 flow-matching 生成骨干，并加入观测一致性监督。
- **关键结果与局限**：在 RadioMapSeer 的 5 种轨迹采样率上，相对相应无 TGPP 骨干最高报告 43.1% NMSE 降低。当前仅为 v1，主要验证单一基准与预设轨迹；尚不能证明跨城市、真实车载测量或 AoA/AoD 多任务下同样有效。
- **与用户课题的关系**：可把高速场景中车辆轨迹、导频采样掩码、距离轨迹的风险图接入 CKM-aware SRF；显式风险图适合作为 posterior correction 的空间权重，隐式特征可通过 FiLM/cross-attention 注入 flow/DiT。
- **为什么不是重复**：不同于 RadioDiff/WiFi-Diffusion 的“稀疏图像补全”，TGPP 新增的是**移动采样几何与空间异方差风险先验**，并验证跨多类骨干的 PnP 可插接性。定位为**填补高速移动测量机制缺口**。
- **代码状态**：**未发现公开代码**。已核查 arXiv 页面、PDF 和 GitHub 仓库检索；未找到与论文对应的作者仓库。

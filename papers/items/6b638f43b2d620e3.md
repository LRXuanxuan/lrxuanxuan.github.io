## 本篇推荐与证据

## 4. BS-1-to-N: Diffusion-Based Environment-Aware Cross-BS Channel Knowledge Map Generation for Cell-Free Networks

- **作者**：Zhuoyin Dai, Di Wu, Yong Zeng, Xiaoli Xu, Xinyi Wang, Zesong Fei
- **年份/状态**：2025，arXiv:2507.23236v1
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2507.23236)；[PDF](https://arxiv.org/pdf/2507.23236)
- **核心问题**：逐个基站采集 CKM 代价高，固定输入/输出结构也难适应 cell-free 网络中不断变化的源/目标基站数量。
- **方法**：以源 CKM、源/目标 BS 坐标为控制条件；BS location embedding（BSLE）编码连续位置，cross-attention 学习源—目标关系，self-attention 建模多个目标之间的依赖，从而支持任意数量源/目标 BS 的并行 CKM 推断。
- **关键结果与局限**：论文给出多基准比较及 BS 部署优化用例。其关键假设是同一区域的不同 BS 共享环境结构；尚未证明跨城市、缺少环境图或角度监督不齐全时仍可泛化，且多步扩散的时延仍值得与 flow/CM 比较。
- **与用户课题的关系**：它与 BeamCKMDiff 的连续波束 adaLN 形成互补：后者解决连续波束条件，本文解决**连续 BS 位置 + 可变数量 CKM 集合条件**。可迁移为 set-to-set 条件编码器，再接 SRF/CM 做快速生成或导频一致性校正。
- **为什么不是重复**：阅读笔记已有 Cross-AP CKM inference，但本工作新增任意源/目标数量、位置嵌入与 cross/self-attention 的生成式多视角建模。定位为**对跨 AP/BS 推断的深化与缺失条件补全思路**，不是普通 diffusion 基线。
- **代码状态**：**未发现公开代码**。已核查 arXiv 页面、PDF 和 GitHub 仓库检索；未找到与论文对应的作者实现。

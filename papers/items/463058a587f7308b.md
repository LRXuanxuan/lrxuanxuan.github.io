## 本篇推荐与证据

## 1. Site-Specific MIMO Channel Generation via Diffusion and Flow Matching: Fidelity, Efficiency, and Downstream Utility

**作者**：Sina Beyraghi, Masoud Sadeghian, Firdous Bin Ismail, Angel Lozano, Paul Almasan, Giovanni Geraci  
**年份/类型**：2026，arXiv 预印本  
**标识**：[arXiv:2606.20098](https://arxiv.org/abs/2606.20098)；[DOI: 10.48550/arXiv.2606.20098](https://doi.org/10.48550/arXiv.2606.20098)  
**PDF**：[官方 PDF](https://arxiv.org/pdf/2606.20098)  
**代码**：[Telefonica-Scientific-Research/GenAI_Channel_Modeling](https://github.com/Telefonica-Scientific-Research/GenAI_Channel_Modeling)  
**代码状态**：**完整作者官方实现**。仓库包含 cDDIM/cFMM 训练与推理、Sionna RT 数据生成、CSI compression、beam alignment、effective-rank 分析，以及公开模型/数据入口。

### 核心问题与方法

论文比较两类位置条件生成模型：conditional DDIM（cDDIM）与 conditional Flow Matching Model（cFMM）。二者都以用户坐标为连续条件，直接生成复数 MIMO 信道矩阵，目标不是只让样本“看起来像”，而是同时验证：

- 统计保真度：beam consistency、full beamspace coverage、effective rank；
- 生成效率：采样 latency；
- 下游效用：CSI compression 与 beam alignment 中的数据增强收益。

在 28 GHz、3.5 GHz 以及 LoS/NLoS 设置下，两种模型均能学习站点特定分布；cFMM 在相近质量下的推理时间约低一个数量级。论文也显示，有限真实样本加入生成信道后，下游性能优于只用少量真实数据或随机信道模型。

### 与用户课题的关系

- **可直接复现**：这是今日最接近当前 `p(H|r)` 主干的论文，且生成对象是复数 MIMO 信道而非 radio-map 图像。
- **具体迁移接口**：把坐标条件分支扩展为 `r + CKM/environment token + modality mask`，继续采用现有 FiLM/AdaGN；生成 `H_0` 后，再接现有 RC/PBG 或 PnP 导频一致性修正。
- **评价升级**：除 NMSE 外，引入 beam consistency、effective rank、pilot residual、NFE/latency 和下游 beam/CSI compression 指标。

### 为什么不是重复

**硬去重已排除；对既有方向的深化。** 昨日 MultiCE-Flow 更接近“多模态环境 + 稀疏导频的一步直接估计”；本篇增加的是“站点特定复数信道分布生成 + scarce-data augmentation + 通信结构与下游效用”。它也不是普通 WiFi diffusion 的场景迁移。

### 局限

当前条件主要是坐标，尚未显式加入地图/射线环境先验和导频观测；因此更适合先作为条件生成先验，再外接后验校正，而不是直接当成最终信道估计器。

## 原推荐表字段

**日期：** 2026-07-17

**标题：** Site-Specific MIMO Channel Generation via Diffusion and Flow Matching: Fidelity, Efficiency, and Downstream Utility

**内容：** 核心问题：在有限站点数据下学习位置条件的复数 MIMO 信道分布，并验证生成信道是否真正服务于通信任务。方法：比较位置条件 cDDIM 与 conditional Flow Matching（cFMM），直接生成复数信道矩阵，并用波束一致性、全波束空间覆盖、有效秩及 CSI 压缩/波束对齐评估。结果：28 GHz 与 3.5 GHz、LoS/NLoS 条件下保持较高统计保真度，cFMM 的采样延迟约低一个数量级；局限：尚未显式纳入导频观测、地图或射线先验。

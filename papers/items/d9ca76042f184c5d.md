## 本篇推荐与证据

## 4. Multimodal-NF: A Wireless Dataset for Near-Field Low-Altitude Sensing and Communications

- **作者**：Mengyuan Li, Qianfan Lu, Jiachen Tian, Hongjun Hu, Yu Han, Xiao Li, Chao-Kai Wen, Shi Jin
- **年份 / venue**：2026，IEEE Wireless Communications Letters Early Access
- **DOI**：10.1109/LWC.2026.3702704
- **方向**：低空近场 XL-MIMO；多模态数据；高移动轨迹；波束预测
- **问题**：现有多模态无线数据多为 2D、地面、远场，缺少低空 3D 轨迹、近场 CSI 与同步环境模态。
- **方法**：基于 Sionna RT 的可配置生成器同步产生近场 CSI、RGB、LiDAR、GPS/轨迹、LoS/NLoS、Top-5 波束与增益标签；公开数据覆盖 30 个场景、10 类 UAV 轨迹和 215,400 个样本，默认采用 \(64\times64\) UPA、7 GHz、128 子载波和 20 帧轨迹。
- **关键结果**：案例表明 near-field 两阶段波束训练优于 far-field 基线，多模态 LLM 波束预测接近 exhaustive-search 上界；GPS、RGB、LiDAR 与 prompt 消融显示各模态互补。数据按城市划分 train/val/test，可用于跨环境泛化。
- **局限**：公开数据 LoS 占 93.35%、NLoS 仅 6.65%；当前射线追踪未启用 diffraction 与 diffuse scattering，只含 LoS 和有限阶镜面反射。它是合成数据/生成工具，不能替代真实链路验证；现有用户数据也没有同城完整多模态监督。
- **迁移类型**：**可直接复现**
- **与既有阅读差异**：相对 PilotWiMAE/RadioDiff，它不是再次强调 masked/diffusion，而是提供**同步近场 CSI + 视觉/LiDAR/GPS + 轨迹/波束标签**的数据与生成接口。
- **课题接口**：优先抽取 CSI、GPS、LoS、beam index 和 availability mask 做缺失模态实验；RGB/LiDAR 仅在独立第二阶段使用，不与当前 Sheet2 数据混称全模态监督。
- **相对阅读笔记位置**：**应用/数据缺口**——填补低空近场多模态与高移动轨迹数据。
- **代码状态**：**完整开源实现**。官方仓库含场景/轨迹、近场 CSI、RGB/LiDAR、beam label、H5 打包和统计脚本；Hugging Face 数据约 283 GB。
- **链接**：
  - 官方页：https://arxiv.org/abs/2603.28280
  - PDF：https://arxiv.org/pdf/2603.28280
  - DOI：https://doi.org/10.1109/LWC.2026.3702704
  - 代码：https://github.com/Lmyxxn/Multimodal-NF
  - 数据：https://huggingface.co/datasets/lmyxxn/MultimodalNF
- **推荐理由**：它能为 Robust-CKMSRF 的缺失模态、轨迹扰动和跨城市测试提供真实可下载的结构化数据源，但需要严格报告合成与 LoS 偏置。

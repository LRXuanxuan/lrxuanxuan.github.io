## 本篇推荐与证据

## 2. Data-aided Channel Estimation and Sensing With Sparse Bayesian Learning for AFDM-ISAC System

- **作者 / 年份 / venue**：Yirui Luo, Yong Liang Guan, Yao Ge, Yonghong Jiang, Lingsheng Meng, David González G.；2026；已接收 IEEE Transactions on Communications，正式 DOI 待核验。
- **方向与问题**：高速 AFDM-ISAC、superimposed pilot、MMV off-grid sparse recovery、数据辅助信道估计。
- **方法**：D-GESBL 将可靠解码数据反馈为 pseudo-pilots，与真实导频联合迭代；在 DAF 域用 grid evolution 修正 fractional delay/Doppler 离栅误差。D-GAMP-GESBL 用 GAMP 替代矩阵求逆以降低复杂度。
- **关键结果**：60 GHz、256 子载波、8 接收天线、3 目标、最高 540 km/h 的仿真中，NMSE/BER 约 4 次数据辅助迭代后稳定；低复杂度 GAMP 版本基本保持性能。网格点为 65/650/1280 时，论文图示 GAMP 版本每轮约 0.0043/0.1156/0.3741 s，明显低于 GESBL 的约 0.0029/0.0233/0.0404 s 仅在小网格不占优、在大网格体现更有利的复杂度扩展（数值按图读取，需复现核验）；导频功率在实验设定下约 0.2 附近最优。
- **局限**：仿真限定于 AFDM、稀疏单路径目标和特定 DAF 结构；pseudo-pilot 依赖可靠判决，错误传播风险仍需单独压力测试；不是 CKM 或生成模型方法。
- **迁移类型**：**可直接复现的算法基线 / 可改造工具**。可把“可靠数据 → pseudo-pilot → posterior update”改造成 CKM prior + PnP 的软置信闭环，并保留 off-grid delay/Doppler 物理基线。
- **与既有阅读差异**：不同于纯导频的 Diffusion/Flow CE，也不同于静态 CKM；它新增判决数据回灌、离栅网格演化和高速 AFDM-ISAC 的严格系统约束。
- **位置**：缺口——补齐高移动、fractional delay/Doppler 与 data-aided closed loop。
- **代码状态**：**未发现公开代码**。论文页、全文、精确标题和 arXiv ID 两轮检索均未发现作者实现。
- **链接**：[arXiv](https://arxiv.org/abs/2607.18881)｜[PDF](https://arxiv.org/pdf/2607.18881)
- **推荐理由**：它是今日最容易转成可控消融的通信论文：pilot-only、hard pseudo-pilot、soft-confidence pseudo-pilot 三组即可验证闭环收益与错误传播。

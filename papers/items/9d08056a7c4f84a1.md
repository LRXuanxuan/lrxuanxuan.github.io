## 本篇推荐与证据

## 1. Variational Flow Maps: Make Some Noise for One-Step Conditional Generation

- **作者**：Abbas Mammadov, So Takao, Bohan Chen, Ricardo Baptista, Morteza Mardani, Yee Whye Teh, Julius Berner
- **年份 / venue**：2026，arXiv 预印本
- **方向**：Flow map；一/少步条件生成；逆问题后验采样
- **问题**：普通 flow map 虽能单步生成，但没有显式采样轨迹，难以像 diffusion/PnP 一样在轨迹中持续加入观测约束。
- **方法**：学习噪声适配器 \(q_\phi(z\mid y)\)，令观测 \(y\) 决定初始噪声分布，再通过 flow map \(x=f_\theta(z)\) 直接得到满足观测与数据先验的样本。论文用变分目标联合优化 noise adapter 与 flow map，使简单条件高斯适配器也能表达复杂后验。
- **关键结果**：论文在多种图像逆问题上报告一/少步校准后验采样；box inpainting 中 VFM 的 FID 为 33.3，而同一 flow backbone 的若干 guidance 基线约为 63–76。其主要优势是把通常 50–250 次函数评估的迭代 flow 推理压缩为 1 或少量 NFE。
- **局限**：实验仍是 ImageNet/图像退化；需联合微调 flow map 与适配器，不能直接复用为免训练 PnP；尚未验证复数 MIMO、结构化导频、SNR 外推和跨场景 CKM 条件。
- **迁移类型**：**可改造工具**
- **与既有阅读差异**：相对 CAR-Flow 的“条件重参数化全局 source/target 路径”，VFM 学习的是**逐观测的条件初始噪声分布**；相对 FlowADMM/PnP-CM，它不依赖每一步外部投影，而是把后验条件前移到初始分布。
- **课题接口**：可令适配器输入 \(y,\Phi,\mathrm{mask},\mathrm{SNR},e,M\)，输出复数信道潜变量的均值/低秩协方差；与现有 Site-cFM、CAR-Flow、PnP 分支分开比较。
- **相对阅读笔记位置**：**深化**——深化 CM/flow 少步生成与条件后验，但提供了不同于普通 guidance 的独立机制。
- **代码状态**：**完整开源实现**。官方仓库含训练、六类逆问题条件采样、1–4 步推理、checkerboard 快速测试、脚本、依赖和 checkpoint 说明。
- **链接**：
  - 官方页：https://arxiv.org/abs/2603.07276
  - PDF：https://arxiv.org/pdf/2603.07276
  - 代码：https://github.com/abbasmammadov/VFM
- **推荐理由**：这是今天最直接对应“连续条件 + 低 NFE + 后验生成”的方法论文，且与已采用 CAR-Flow、CM/PnP 保持可归因的独立创新维度。

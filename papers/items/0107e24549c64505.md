## 摘要（中文译文）

夹持天线（pinching antenna, PA）是一种由波导与多个介质颗粒构成的柔性天线，能够在视距链路中智能重构无线信道。利用 PA 的独特特性，我们研究了夹持天线系统（pinching antenna system, PASS）中的上行（uplink, UL）传输。为全面评估 PASS 在上行传输中的性能增益，考虑了三种场景：单用户多 PA（multiple PAs for a single user, MPSU）、单用户单 PA（single PA for a single user, SPSU）与多用户单 PA（single PA for multiple users, SPMU）。在各场景中优化 PA 位置以获得最大信道增益。对 MPSU 与 SPSU 场景，应用优化后的 PA 位置，推导了遍历速率（ergodic rate）的解析、渐近与近似闭式表达式。进一步，在 SPMU 场景中固定单个 PA 时，推导了近似遍历速率的闭式表达式。我们的结果揭示以下关键洞见：i）利用 PA 的灵活性，所提 PASS 显著优于传统多输入单输出（multiple-input single-output, MISO）网络；ii）在 MPSU 场景中 PA 分布服从非对称非均匀分布；iii）优化 PA 位置显著提升遍历和速率性能。

**摘要依据：** [查看原文摘要](https://doi.org/10.1109/TCOMM.2025.3618726)（机器辅助翻译，仅供阅读参考）

## 贡献点

- 研究 PASS 上行传输并划分单用户多 PA、单用户单 PA 与多用户单 PA 三种场景
- 在各场景优化夹持天线位置以获得最大信道增益
- 推导 MPSU 与 SPSU 场景下遍历速率的解析、渐近与近似闭式表达式
- 在 SPMU 场景固定单 PA 时推导近似遍历速率的闭式表达式
- 验证 PASS 显著优于传统多输入单输出网络且 PA 位置优化提升和速率

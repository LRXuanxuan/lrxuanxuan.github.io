## 本篇推荐与证据

## 1. Dynamic Channel Knowledge Map: Fundamentals, Construction, and Applications

- **作者 / 年份 / venue**：Wenjun Jiang, Xiaojun Yuan；2026；arXiv 预印本（未核验正式录用）。
- **方向与问题**：动态 CKM、时变散射体、终端姿态与 RF impairments、CKM—物理层协同。传统 CKM 多描述建筑/地形等准静态环境，难以覆盖毫秒至秒级动态分量。
- **方法**：提出 dynamic CKM 作为准静态 CKM 与瞬时物理层之间的中间层，讨论 construction、pilot design、interference suppression、ISAC，以及 dynamic-CKM construction 与 channel estimation 的迭代 co-design。
- **关键结果与局限**：概念性仿真中，在 SNR=5 dB、静态/动态功率比为 2 dB 时，多轮 co-design 相对单轮定位 RMSE 约降低 1.5 m。它是架构/综述型论文，作者也明确指出 scalability、协议与真实场测仍未解决，不能把初步仿真当成普适性能证据。
- **迁移类型**：**理论启发与系统路线图**。可把现有 CKM prior 拆成慢时标静态条件与快时标动态 residual/state，再由导频残差更新后者。
- **与既有阅读差异**：相对静态 CKM、RadioDiff、GeoGS-CE，本篇新增“时标分层 + CKM construction/PHY joint inference”；相对 RadioMapMotion，它更偏系统架构与 co-design，而非单一预测模型。
- **相对阅读笔记的位置**：**深化**。直接推进 CKM/WCM → 动态先验 → pilot/channel-estimation co-design。
- **一手来源**：[arXiv:2607.17133](https://arxiv.org/abs/2607.17133)；[PDF](https://arxiv.org/pdf/2607.17133)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者实现。
- **推荐理由**：它把用户当前“准静态环境先验 + 瞬时导频后验校正”明确提升为 dynamic CKM 研究问题，适合作为论文动机、系统框架和 future-work 的核心引用。

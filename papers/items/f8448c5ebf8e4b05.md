## 摘要（中文译文）

柔性天线系统近来因具备智能重构无线信道的潜力而受到广泛研究关注。然而，现有柔性天线系统仍受自由空间路径损耗与视距遮挡等根本性限制。本文介绍一种新型柔性天线系统，称为夹持天线系统（Pinching-Antenna SyStem, PASS）。PASS 以介质波导为主要传输介质，通过沿波导灵活夹持离散介质颗粒（称为夹持天线）将信号辐射至自由空间。通过结合无线与有线通信的优势，PASS 有效缓解无线通信的固有局限，同时提供较高的天线可重构性。本文回顾 PASS 相较于传统无线系统的关键特征，分析其主要优势，并讨论潜在设计、传输架构与应用场景。最后，概述与 PASS 相关的前景研究方向与开放挑战。

**摘要依据：** [查看原文摘要](https://doi.org/10.1109/MCOM.001.2500037)（机器辅助翻译，仅供阅读参考）

## 贡献点

- 提出以介质波导与可夹持离散介质颗粒为传输载体的夹持天线系统 PASS 架构
- 对比分析 PASS 相较传统无线系统在自由空间路径损耗与视距遮挡上的优势
- 设计 PASS 的潜在系统设计、传输架构与应用场景框架
- 梳理 PASS 的前景研究方向与待解决的开放挑战

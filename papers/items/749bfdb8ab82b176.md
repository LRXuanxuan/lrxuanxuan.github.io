## 本篇推荐与证据

## 1. Channel2World: A Wireless Foundation Model for RF Environment Representation

- **作者 / 年份**：Hyung-Joo Moon, Joonkyu Jang, Kwang Soon Kim, Seong-Lyun Kim, Robert W. Heath Jr., Chan-Byoung Chae；2026。
- **方向**：环境级无线表征、MIMO path token、context-query pretraining、跨场景泛化。
- **问题**：单链路 CSI embedding 仍难表达“同一环境中多条链路共享的传播结构”，跨场景往往依赖显式地图或 site-specific fine-tuning。
- **方法**：把同一 BS 场景内多个 channel-position observations 分解为 delay/AoA/relative-gain path tokens，以可变长 context set 通过 cross/self-attention 聚合为固定长度 wireless world embedding；用 disjoint query channels 的位置和相对路径增益进行预训练，之后冻结 encoder 条件化下游任务。
- **关键结果**：Wireless InSite 生成 26,000 个 BS-centered 工厂环境，平均约 5,000 条 channel-position pairs；9.2M 参数 encoder 在未见工厂布局上支持定位、稀疏 beam-domain CSI 重构和反射交互点恢复，环境条件模型优于无条件 Global，并可优于有限数据的 site-specific 参考。
- **局限**：7 GHz RT、规则工厂布局；依赖路径分解、场景内 128 条上下文和位置标签；当前城市数据不满足完整监督接口。
- **迁移类型**：可改造工具 / 长期主线。
- **相对既有阅读**：相对 MultiPathFormer 的单链路 path sequence，本篇把多链路聚合为环境级先验；相对 GeoGS-CE，它无需显式 3D Gaussian renderer，但需要可用的路径参数。
- **一手来源**：[arXiv:2608.17544](https://arxiv.org/abs/2608.17544)；[PDF](https://arxiv.org/pdf/2608.17544)。
- **代码状态**：**未发现公开代码**。论文页、全文、作者主页及两轮精确检索均未发现可核验论文仓库。
- **推荐位置**：核心深化；**优先精读 1**。

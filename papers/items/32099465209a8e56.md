## 2. Channel Knowledge Map Reconstruction From Sparse Measurements via Pilot-Anchored Layout-Conditioned Fourier Refinement

- **作者**：Zhonghao Jiu, Fan Meng, Yongming Huang, Hang Zhan, Zening Liu, Xiaohu You
- **年份/状态**：2026，arXiv 预印本；论文页注明 submitted to IEEE TWC，不能视为已录用
- **核验标识**：[arXiv:2607.01453](https://arxiv.org/abs/2607.01453)，DOI `10.48550/arXiv.2607.01453`
- **PDF**：[arXiv PDF](https://arxiv.org/pdf/2607.01453)
- **代码状态**：**未发现公开代码**。已检查论文页、题名/作者 GitHub 检索和无线地图代码汇总仓库。

**核心问题与方法。** Anchor-CKM 指出：直接在零填充 pilot grid 上施加卷积或谱算子，会把采样 mask 的伪结构与真实信道场混在一起。其处理顺序是：

\[
\text{sparse pilots}
\rightarrow \text{support-aware partial convolution}
\rightarrow \text{layout-conditioned dual-path Fourier refinement}
\rightarrow (\mu(r),\sigma^2(r)).
\]

也就是先构造有测量支撑的 radio field，再施加布局/频域先验，最后输出均值和逐位置异方差。

**结果与局限。** 在 transmitter-disjoint DeepMIMO 场景、缺失率 0.3–0.95（含 5%–10% pilot coverage）下，显式布局室外场景的 received-power RMSE 相对最强复现基线降低 0.79–1.33 dB。局限是它仍以确定性重建主干为主，依赖可用的 layout descriptor，也没有验证多模态生成后验的校准与多样性。

**相对阅读笔记的位置。** 硬去重已排除；属于对 TGPP、PnP-ADMM、DPS/FlowDPS 与 CKMImage 类工作的深化。它新增的不是又一个 backbone，而是“**pilot-support 稳定化必须先于结构先验**”这一可直接审稿辩护的处理顺序。

**对课题的迁移接口。** 可把 partial-convolution 输出作为 SRF/GMFlow 的初值或条件 token；在 PnP 中，可把它视为比简单 (A^\dagger y) 更稳健的测量支撑编码器。建议优先验证：零填充、mask channel、partial convolution 三种 pilot 表征对 NMSE、边界误差与后验残差的影响。

**内容：** 核心问题：稀疏、非规则观测与粗布局下刷新 CKM。方法：先用 support-aware partial convolution 构造 pilot-supported 表征，再做 layout-conditioned 双路径 Fourier refinement，并输出坐标条件的均值与异方差。结果：DeepMIMO、5%–10% pilot coverage 下，相对最强复现基线的 received-power RMSE 降低 0.79–1.33 dB；局限：仍是确定性重建主干，依赖布局描述，尚未验证生成式后验多样性。

# 绘画归纳练习室维护说明

页面入口保持为 `/color-block-studio.html`。本次改造围绕明暗归纳、色彩归纳、线条取舍、局部压黑四种练习，沿用博客的浅蓝／深蓝外观。不要把它重新描述为能自动判断绘画结构或给作品打分的工具。

## 文件与接入点

| 文件 | 职责 |
| --- | --- |
| `color-block-studio.html` | 页面、既有颜色提取与线条候选算法、图片读取、导出／打印／批量容器，以及新控制器的接入 |
| `assets/color-block-studio/study-core.js` | 不依赖 DOM 的确定性运算：L* 明暗分组、黑块候选、索引缩放、局部笔画重放 |
| `assets/color-block-studio/studio-study.js` | 四模式状态、固定分块、局部修改、撤销／重做、A/B 对照、缩放平移、侧栏收起与各导出路径 |
| `assets/color-block-studio/study.css` | 学习界面、模式控件、工具栏、画布辅助层与响应式样式 |

HTML 先载入核心函数和控制器，再在旧应用初始化阶段调用 `ColorBlockStudy.create(...)`。该适配层替换 `recolor`、`computeLinePreview`、`extractAndRecolor`、`setMode`、`applyImage`、显示与导出相关入口，复用已有图片读取和下载逻辑。维护时应检查实际调用的新入口，不能只修改文件中保留的旧函数。

没有新增框架、字体、后台或第三方图片处理 API。页面依赖同站的 JS 与 CSS，不应宣称下载单个 HTML 就包含全部离线功能。发布资源变化时，同步更新 HTML 中资源版本参数，避免旧缓存混用。

顶部的双画室切换在第一次点击时建立一对标签，之后可返回原来编辑的页面。带参考时只变更轻绘的参考内容。下载的 PNG、ZIP 使用北京时间的年、日、月、时、分命名，压缩包内保留各结果的语义文件名。

## 四种练习的语义

### 明暗归纳

- 支持 2、3、5 组，默认三组。
- 分界使用 sRGB/D65 下的 CIE L* 明度，范围 0–100。它控制每个像素归哪一组。
- 两组使用暗组分界；三组使用暗／亮两处分界；五组在暗端与亮端各自动细分一级。五组的全部分界应在界面文字中展示。
- 色板决定输出颜色或灰阶；修改色板不改变分组归属。输出灰度滑杆为 0–255，不能将它标为 L*。
- 默认灰阶、均分输出灰阶只是练习起点，不是唯一正确的绘画安排。
- 柔化、毛边整理、小区域合并仍会影响最终分组形状；它们应作为明确的独立操作，而非调色的隐式副作用。

### 色彩归纳

- 默认固定分块。保存当前 `indices` 后，修改色板、设为透明或白色应只改变这些区域的呈现，不移动边界。
- “按当前色板重新分块”是明确重新分类入口。色数、柔化或分块参数的变化也可能重新计算区域。
- “合并两组”只重标指定组的索引并移除一个色板条目，其余区域应保持原位置。
- 关闭固定分块后，重新着色可以按照新色板重分区域。
- 覆盖位置检查与“灰度检查配色”只是预览辅助层，不写入最终 PNG；后者检查当前配色的明度关系，不重新分块。

### 线条取舍

- 自动算法输出边缘候选，不能判断哪条是外轮廓、遮挡、结构线或花纹。
- 补画添加黑线；删去变白；减弱将候选线变浅灰；保留／擦除修改恢复该处的自动候选。
- “保留”是局部恢复，不是语义锁定。改变候选参数后，自动底图可能变化。
- 减弱后输出包含灰色，帮助、参考卡、打印和导出说明不可继续承诺“纯黑白输出”。
- 排线默认关闭，仅按固定方向、密度示意明暗，不会顺着人体或衣褶转面。

### 局部压黑

- 采用 L* 分界生成黑块候选，默认关闭肤色色域保护。
- 深衣物、头发、投影和暗背景都可能进入候选，不能将所有黑块解释成阴影。
- 补黑、留白、擦除修改均在结果图上操作。留白用于保护关键间隙，擦除修改恢复阈值候选。
- “只看黑块”控制是否叠加线条；显示的纯黑面积仅用于观察记录，不是评分或合格比例。
- 肤色保护是颜色范围近似，可能选中暖色衣物、木头等区域，不是人脸识别。

## 局部笔画、历史与模式状态

笔画保存为归一化图片坐标、相对半径及工具类型，再由核心函数重放。画布缩放和平移改变显示，不改变图片上的笔画位置。线条与黑块分别保存笔画。

四个练习方向为当前图片保留各自设置、色板和分块，来回切换不应清空已经做过的修改。

“收起侧栏／展开侧栏”按钮始终位于画布工具栏，使用 `aria-controls="panel"` 和 `aria-expanded` 表示状态。收起时隐藏侧栏并将画布扩展到可用空间，重新适配显示尺寸；不得重载图片、重算参数或清除笔画和历史。展开后恢复原控件状态。

手机和平板默认收起侧栏：条件与轻绘相同，为视口不超过 1024 px，或
以触摸为主且视口不超过 1440 px。展开按钮始终可用，用户仍可手动打开。
触屏上的选图、侧栏开关、画布工具与缩放按钮最小高度为 36 px；侧栏自己
滚动，滚到边界时不将手势继续传给整页。这些调整只改变界面，不改练习结果。

撤销／重做保存参数、色板、分块索引与笔画，不为每一步复制整张彩色画布。通常保留最多 20 步，并以索引数组占用约 48 MiB 为缩减历史的参考阈值；这不是整个页面内存的硬上限。一次拖动滑杆和一次完整笔画应分别形成一个可撤销操作。

A 记录当时的结果画布和状态，B 为继续修改后的当前结果。查看 A 时使用只读覆盖层，并禁用当前结果导出按钮，避免用户将 A 预览误认为导出的 B。返回 B 后继续编辑与导出。A/B 仅是本次练习的对照，不是永久版本管理。

**图片、笔画、历史、模式缓存和 A/B 均只在当前页面会话中保存。** 换图会清空当前图片的修改与历史，刷新也会丢失练习状态。界面必须提醒用户先导出要保留的结果，不能暗示自动保存、云同步或跨设备恢复。

## 导出与预览的边界

- 工作图长边最多 2000 px；普通 PNG 使用当前工作结果。
- “按原图尺寸”保持原图比例，长边最多 6000 px。它保留当前分块与局部修改，按最近邻索引或最近邻像素缩放，不在高分辨率上重新提取，也不会创造新细节。
- 色块透明选项写入 PNG alpha；白色选项将对应区域写为白像素。参考卡和打印将结果合成到纸面背景，不能承诺它们保留透明 alpha。
- 当前模式的参考卡和打印必须使用已经包含局部修改的结果画布；不能重新走旧算法而丢弃笔画。
- 保存多种结果时，优先使用当前图片已保留的模式结果；没有建立过的模式只能生成初始结果，不能称为已经完成的练习。
- A 覆盖层、色组覆盖检查、小稿缩略图、画布衬底、缩放和平移均属于界面辅助，不应混进图片导出。
- 批量对每张图片重新计算，不复制当前图片的固定分块或局部笔画。批量分组阈值、模式和黑块／线条叠加设置应与当前参数保持一致；不要在明暗练习中静默退回旧的颜色聚类规则。

## 参考图与隐私

**2026-11-20 用户明确要求删除内置例图，网站倾向于不上传图片。** 已移除四张例图、对应缩略图、图库入口及图片课数据。后续维护不要自动恢复这些文件，也不要替换成外链图库或内嵌 Base64 图片。

练习从用户选择、拖入或粘贴本机图片开始。图片只进入本机浏览器内存，不提交网站或仓库；不得为分析、日志、错误上报或云服务擅自上传。网页保留纯文字练习提示，自动结果仍只是观察起点。

浅色／深色／跟随系统沿用博客 `localStorage['theme']`：显式值仅为 `light` 或 `dark`，跟随系统时删除键。此偏好只改变界面，不能改变图像色值或导出内容。它是本页面唯一需要长期沿用的浏览器偏好，不能借此保存或上传练习图像。

## 维护时的验收重点

1. 明暗改输出灰阶不改变像素分组；调分界能改变分组，三组与五组数量及说明一致。
2. 固定分块改色保持索引；重新分块确实重算；合并组保留其他区域。
3. 鼠标、触控笔和触摸绘制的位置与结果图一致；缩放、平移、对比分隔不使笔画偏移。
4. 一笔和一次滑杆操作分别可撤销／重做；切换四模式、收起与展开侧栏不丢修改。
5. 黑块单独显示不夹带线条；开启叠加后包括线条修改；面积不被描述为质量评分。
6. 当前 PNG、原尺寸 PNG、参考卡和打印均保留局部修改，弱线保留灰色，透明输出保留 alpha。
7. 批量应用当前模式的计算规则，绝不把本图笔画复制到别图。
8. 浅／深蓝外观、跟随系统、360 px 窄屏、较矮视窗、键盘焦点和按钮状态正确。尤其要检查 `body.line-mode .line-only` 的 `!important` 不覆盖 `[hidden]`，黑块模式不显示隐藏的线条参数。
9. 页面没有内置图库、例图请求或已删除资源的引用；本机选择、拖入和粘贴图片可用；收起侧栏后仍能找到展开按钮。
10. 发布只改本工具及其资源、文档；读取最新主分支并通过现有部署工作流后，再核对实际公开页面。

这些条目是后续维护的验收要求，不能仅凭静态阅读就宣称浏览器功能或部署已经通过。

## 可重复运行的代码验证

核心算法测试无需第三方包：

```sh
node tools/test_color_block_core.cjs
```

集成测试使用开发环境中的 `jsdom` 和 `@napi-rs/canvas`（仅测试需要，网站不加载）：

```sh
npm install --prefix /tmp/color-study-test jsdom@26 @napi-rs/canvas
NODE_PATH=/tmp/color-study-test/node_modules node tools/test_color_block_integration.cjs
```

集成脚本只运行本地 DOM 与 Canvas，不启动浏览器。它使用临时合成图片，验证模式、改色、笔画、撤销、透明导出、侧栏状态及批量 ZIP 中的实际 PNG，不依赖站内图片文件。另需实际浏览器检查布局、触控和真实下载行为；不能以代码测试替代这一步。

# 轻绘 · 本地画室

入口为 `/drawing-studio.html`，与 `/playthings/`、
`/color-block-studio.html`（归纳练习室）相连。它用原生 HTML、CSS、
JavaScript 和 Canvas 提供绘画、图层、参考、取色与导出；文件和绘画内容
在当前浏览器中处理，不上传到博客、公开仓库或第三方服务。

这份文档说明实现结构、功能边界和维护验收要求，不作为浏览器测试已通过
或真实数位板已验证的声明。

Windows 桌面版入口为 `/drawing-desktop.html`，复用当前页面与本机资源。
原生保存、关闭保护和发布规则见 [桌面版维护说明](drawing-desktop.md)。

## 笔刷、压感与防抖

26 种数字笔刷共用画布笔触引擎。每支笔和橡皮各自在当前浏览器记住大小、浓度、防抖与压感开关。即使隔天再打开、新建画布或载入旧工程，已经调过的笔都会沿用本机偏好。初次使用某支笔时，打开工程可沿用文件中这支笔的参数。颜色跟随当前色盘。笔刷库的试笔使用各支笔记住的参数，点“恢复这支笔的推荐参数”只重置当前一支。

| 笔刷 | 当前实现 |
| --- | --- |
| G 笔 | 随数位笔压力改变宽度，连贯的变宽笔形与圆形端点 |
| 基础方头笔 | 固定轴向正方笔尖，连贯铺色，支持非整数位置，边缘抗锯齿 |
| 软尖钢笔 | 轻压细尖起笔，压力扩大笔腹；属于画笔库，继续保留 |
| 载色混色笔、无色推抹 | 沿当前图层拾取颜色。前者从当前色起笔，后者从已有笔迹向外带色，混色在色相上过渡 |
| 吹石参考（石灰岩、柔圆、方头） | 原创三种铺色笔尖，以较温和的尺寸和出色压力响应分别处理碎纹、柔边及平面切边 |
| 轻包浆、重包浆 | 分别用于细小绒边墨线和斑驳积墨，可用行笔速度影响沉积 |
| 针管笔 | 等宽圆头线条；不通过压力改变宽度 |
| HB 石墨铅笔 | 细纸纹叠印，压力同时改变笔幅和落色深度 |
| 侧锋炭笔 | 扁椭圆侧锋与较粗纸纹，适合擦出成片灰调 |
| 斜头马克笔 | 固定角度扁尖，同一笔径下，行笔方向决定线宽 |
| 软头马克笔 | 压力控制笔腹宽度和笔尖落色，较硬的中心与柔边支持收尖 |
| 干鬃平笔 | 分束鬃毛在行笔方向上留下纹路，纸纹产生飞白 |
| 柔边喷枪 | 径向衰减的笔尖沿路径按间距沉积，轻压减淡，边缘自然过渡 |
| 水粉榛形笔 | 不透明圆扁笔腹随走向转动，笔尖保留细微鬃毛边缘 |
| 湿边水彩 | 沿整笔湿区的外轮廓计算渗化和局部积色，纸纹与低频沉积分布影响干湿浓淡，抬笔后可以另起一层叠染 |
| 飞溅点彩 | 在笔幅内按面积散布大小不同的颗粒，压力控制数量 |
| 漫画丸笔 | 偏细的压力曲线适合睫毛、发梢与衣物细节 |
| 发丝排线 | 五根分离的细线随行笔转向和压力收放 |
| 漫画网点笔 | 固定笔径下的网点在图层坐标中对齐，压力改变点径 |
| 四角星芒笔 | 单击放置一颗四角高光，拖动按笔径留出星芒间距 |
| 二值笔 | 按整数像素跨度绘制硬边圆笔触，笔触掩膜没有抗锯齿边缘；可使用压感 |
| 像素笔 | 整数坐标方形笔头与 Bresenham 连线；保持像素网格，不做防抖插值 |

二值与像素笔的“无抗锯齿”指绘制出的原始栅格笔触。降低笔触浓度会统一
改变不透明度，缩放画布或变换图层也可能改变屏幕显示；不能因此承诺所有
导出、缩放和变换结果的 alpha 永远只为 0 或 255。

压感通过标准 Pointer Events 读取。必须收到 `pointerType: 'pen'` 和可变的
`pressure` 才能使用真实压力；如果系统或驱动把数位板当成鼠标，浏览器端
不能自行恢复压力。鼠标使用固定笔宽。没有物理数位板验证时，记录为
“已接入压感事件”，不得写成“所有 Wacom 型号已兼容”。

防抖是可调的笔尖位置滤波，强度越高，跟随延迟越明显。笔画在临时透明层
内绘制，再统一应用整笔浓度。铅笔、炭笔和软边工具可在这一浓度上限内
随笔尖流量积色。抬笔的
零压力不能转成最大宽度；失去捕获、窗口失焦或取消输入都必须结束笔画。

## 橡皮：局部与整笔

橡皮下拉框使用「局部 / 整笔」。局部按经过的位置擦除，可处理新笔画、
旧像素与导入图片。整笔依据一次落笔的真实记录删除，不按颜色或连通区域
猜测笔画；交叉处选择最上面仍可见的一笔。一次扫过可以删除多笔，并作为
一步撤销。命中以这次手势开始时的记录为准，避免停在交叉处连续剥掉下方笔画。

两种模式都只修改当前可见且未锁定的图层。移动、缩放和复制图层保留笔画
身份。局部擦除作为有序掩膜参与重放，整笔擦除不会把旧孔洞补回；形状与
文字作为覆盖内容保留，不作为可整笔删除的笔画。

记录按 64 × 64 px 稀疏瓦片存储，每层最多 128 次笔画、局部擦除和覆盖操作，
所有当前图层的记录 RGBA 缓冲合计最多 16 MiB。超过限额时，从最旧记录开始
合成普通像素，画面保留，但这些旧笔迹之后只能局部擦除。填色、抠图、混色
推抹和更改画布尺寸等依赖现有像素的操作，也会合成相关图层的旧记录；撤销
可恢复操作前的记录。较大的单次笔画可能直接成为普通像素。

可追溯记录随 `.lrxdraw` 和本机续画保存；旧工程中只有栅格图片的内容不冒充
可追溯笔画。记录快照不可变，并复用已有瓦片，保存缓存计入现有历史内存
预算；48 MiB 是撤销与相关记录的清理目标，不是整个浏览器标签的内存上限。
模块不引入外部绘图库，也不上传笔画。

## 自由调色、形状、文字与材质

自由调色盘用连续色相条和二维饱和度／明亮度平面选择颜色，也支持 HEX、
RGB 数值输入和键盘微调。调色盘、顶栏颜色、参考取色和色卡双向同步；
黑、白、灰状态应保留当前色相，不能因外部回传同一颜色而跳回红色。
这里的 HSV 明亮度 V 是当前画笔颜色的参数，与整幅画作的亮度增益不同。

形状工具提供 18 种几何、线条和装饰形状，包含多边形、箭头、四芒星、
闪电、云朵和水滴。勾选固定比例或拖动时按 Shift 可得到正方形、圆形等图形。
画直线时按 Shift，方向按 45° 间隔吸附。闭合形状的填充与描边可独立启用，描边
颜色和粗细可设置。文字提供中文常用字体族与 Arial、Times New Roman、
Georgia、等宽字体等系统字体选项，支持多行、粗体、斜体及对齐；没有安装
的字体由系统回退，不下载字体包，不能保证不同设备的字形相同。

形状与文字使用临时画布预览，只有 `pointerup` 才写入当前像素图层，并形成
一次像素撤销记录。Esc、取消指针、失去捕获、切换工具或窗口失焦均丢弃
未落下的几何／文字预览。预览与提交都按当前图层的位置及缩放反算坐标，
字号、描边粗细、材质间距等按画面像素换算。落下后是像素内容，不是可重新
编辑字句的文字对象；需要单独移动和缩放时先新建图层。SVG 导出仍是合成
画面的轮廓描摹，不应将它描述为原生矢量对象编辑器。

文本框提供侧线题签、漫画对白、丝带、折角便笺与藏书签五种样式，框底和
饰边可分别取色。边框按多行文字的实际字体度量扩展。形状菜单内的四种画框
都保留透明内芯，框体、饰线、框宽可调。拖动可为局部加框，“沿整张画布加框”
会在顶部建立独立画框图层，可调整透明度、隐藏或单步撤销。

填充材质包含纯色、横线、竖线、斜线、交叉排线、水玉圆点、棋盘格、纸纹、
点描和编织，并提供线性、径向和镜像三种渐变。前景／背景色可独立设置，
线宽／点径与间距可调，斜线及线性渐变可
调整方向。透明底材质叠加到现有像素上；透明渐变的末端使用同色零 alpha，
减少黑色边缘。渐变按形状、文字或填充选区的范围计算。

材质油漆桶必须先从边界取样生成完整拓扑掩膜，再将材质限制在掩膜内，不能
直接填满选区包围盒。所有材质先满浓度绘制到临时层，再统一应用工具浓度，
避免形状填充、描边交叠处额外变深。材质通过 Canvas 几何、微小重复图块
和渐变现场生成，不携带纹理图片。工具选项保存在工程 `settings.marks`，
读取旧工程时使用默认值；不可信字段须在交换当前工程前规范化。

## 图层、填充、抠图与透明背景

图层的顺序、不透明度、大小与位置由主控管理；画作导出只合成可见图层。
参考面板独立于画作，只有“放入新图层”后才参与作品合成。

新建画布时可从样本选择底纸，绘画中也可在“画布与背景”更换。各图层叠在底纸之上，
吸管可取到合成后的纸色。更换底纸支持撤销，工程保存纸张种类，重开时重建相同纹理。
导出 PNG 或 WebP 时勾选“不导出纸张背景”，可单独保留图层内容与透明通道。

整体调色是非破坏性的色相、饱和度和明亮度调整，不改写各图层的原始像素。
支持 Canvas `filter` 的浏览器依次使用 CSS `hue-rotate()`、`saturate()`、
`brightness()`；不支持时由 `DrawingCore.adjustFilter` 按同样的 sRGB
颜色矩阵和各阶段裁剪规则回退，并保留 alpha。这里的明亮度是 RGB
乘法增益，不是 HSL 的 L 分量；纯黑不会随着增益变成灰色。预览与图片、
SVG 导出共用同一合成与调色流程。半透明像素在 Canvas 预乘 alpha 与
整数像素读写之间可能产生微小舍入差异，不能承诺不同浏览器逐字节相同。

油漆桶先从取样图计算选区，再写入当前图层，可参考所有可见图层的线稿
边界，在线稿下方的透明图层填色。颜色容差、是否只选择相连区域、边缘
扩展均应在撤销记录中作为一次操作处理。算法不判断物体的语义：开口的
轮廓可能漏色，容差过大可能越过颜色相近的边界。

“抠图”从点击位置移除颜色相近的背景，支持相连区域选择；不运行人像
识别或自动分割模型。头发、毛发、半透明物体或颜色相近的前景需要手工
修边。抠图结果的透明像素必须保留到 PNG / WebP / 工程保存中。

**纸张背景与图层里的白色像素不同。** 将画布背景设为透明，只取消额外
铺设的底色；已经导入图片的白色背景仍是图层内容，需要抠图或橡皮擦移除。
棋盘格只用于显示透明区域，不得画入图片或工程图层。

## 参考图、PDF 与取色

参考可以在原图、灰度归纳、有限色彩、线稿和色卡概括间切换，颜色与灰阶各有色卡。
参考视图的拖动和缩放独立于绘画视图；取色坐标需要换算到参考像素坐标。
参考栏右边界可左右拖动，也可聚焦分隔条后用方向键、Shift、Home / End
调整，设置里的宽度滑块与之同步。范围根据可用工作区计算，避免挤没画布。
栏宽变化按新旧适应比例连续缩放参考，保留视图中心与相对放大倍率，不能
每帧强制重新居中。分隔条须支持指针捕获、触控、失焦清理与窄屏覆盖布局。
默认色卡对应 Copic Sketch 原厂 36 色套装，也可选择漫画插画 24 色、海洋与
天空 6 色等原厂套装，每套都附厂商页面。全色号收录 357 个着色色号，原厂
358 支系列另含一支 0 号无色调和液。全部保留原厂英文色名。色号／色名搜索已按用户要求暂时撤下。
色卡可切换「紧凑排列 / 按色系」：紧凑模式跨色系连续排列，按色系模式保留
标题和分组。Copic、荷尔拜因与百乐每行六色；视爵每行五色，每个原版十色小系列在按色系模式
排成两行。默认紧凑排列，本机记住所选模式。右侧单独常驻五个无文字勾线色块：
纯黑 `#000000`、深棕 `#3f271f`、中棕 `#75503b`、深灰 `#3a3a3a`、中灰 `#808080`。
这一快捷栏替换原来的“线稿黑／背景白”两项，不占色卡列数或套装色数。
概括算法独立保留纯黑与纯白候选，不从右侧快捷栏生成或扩充候选列表。
Copic 显示色采用官方数字色样中央 17 × 17 像素各通道中位数。实体效果还取决于纸张
与叠涂次数。[Copic Sketch 色号与色样](https://copic.jp/en/color/sketch/) · [原厂套装目录](https://copic.jp/en/product/copic-set/)

「视爵水彩」包含大艺术家 50 色、高级灰 60 色和电影 60 色，分别保留五个、六个、六个十色

## 保存与恢复

在画布视口内点击鼠标右键，会调用与工具栏撤销按钮相同的 `undo()`，一次
右键撤销一步。右键按下不落笔；正在画的笔触先收笔，再按现有撤销流程处理。
触控长按、键盘菜单、画布外的右键以及弹窗内操作不触发该快捷方式。

默认导出名按北京时间生成，顺序为年、日、月、时、分，例如 2026年21日11月14时05分.png。画室可在导出对话框自行改名，归纳页导出的 ZIP 保留包内各结果的用途和原图文件名。工程标题保存在文件内容中。

“存工程”生成 `.lrxdraw` 文件，用于保留图层及参考，之后可通过“打开”
继续编辑。普通 PNG、JPEG、WebP、SVG 导出用于图片交付，不保留本工具全部
图层编辑状态；不能将图片导出当作工程备份。工程可能包含参考 PDF，文件
大小会随其增长。

画室自动保存一份正在编辑的作品。用同一浏览器重新打开画室，会接回上次的图层、画幅、纸纹和参考页。新建或打开工程会替换当前作品。废纸篓清除整幅作品及参考，笔刷偏好独立保留。清除网站数据或使用无痕窗口会影响本机留存。

自动保存使用 IndexedDB `rc-drawing-studio-v1` 的 `current` 对象存储和固定键 `artwork`。图层以 PNG Blob 保存。迁移时将旧版 `drafts` 的最近一份移入当前作品，其余原有草稿可手动打开。新的编辑只更新当前作品。浏览器空间不足时画面留在内存中，可用「存工程」保存到文件。

| 方法 | 返回值及用途 |
| --- | --- |
| `readCurrent()` | 读取作品、版本标记和保存时间，首次使用可自动迁移旧稿 |
| `writeCurrent(project, expectedStamp)` | 原子核对版本并写入作品，返回新的版本标记与保存时间 |
| `writeCurrent(null, expectedStamp)` | 清空本机当前作品并更换版本标记 |
| `list() / load(id)` | 列出并读取此前版本保存的草稿 |

每次写入先核对上次读取的版本标记。另一个标签已更新或丢弃作品时，旧标签的过期写入会收到 `CURRENT_CONFLICT`。保存冲突或配额失败时，仍可从当前页面导出工程文件。

## 导出与 SVG 的适用范围

新建和更改画布尺寸均可选 A3、A4、A5、A6、ISO B5、US Letter、明信片、
书签，也可选屏幕尺寸或输入像素。纸张规格可切换横竖方向，并从 150、200、
300 ppi 中选取满足画布上限的一档。每边像素数按毫米数乘以 ppi 再除以
25.4 后四舍五入。A4 竖向在 300 ppi 下为 2480 × 3508 px。A3 在
300 ppi 下超过单边上限，可选 200 ppi。自定义画布、屏幕规格及
JPEG、WebP、SVG 导出均以像素尺寸为准。

- PNG 无损保留透明区域。选择纸张规格后，导出会写入 `pHYs` 像素密度，供打印软件按毫米还原尺寸。
- JPEG：不支持透明，需要合成到选择的实色背景上。
- WebP：浏览器支持编码时可导出，并可保留透明区域。
- SVG：将画作的有限色区域描摹为闭合路径。底色使用独立矩形，选择保留纸纹时另用 pattern 平铺一小块纹理。

PNG 之外的 `toBlob` 编码支持取决于浏览器。必须检查返回 Blob 是否存在及
实际 MIME；不支持 WebP 而返回 PNG 时，应正确提示并使用 `.png` 扩展名。

SVG 适合线稿、剪影、标志式图形和平涂色块。照片、纹理、柔和渐变会被有限
色彩归纳；它不会推断原始笔画、物体结构或贝塞尔曲线。当前实现会将 alpha
归为最多八档，并保留透明孔洞，因此半透明边缘会有取舍。SVG 的画布比例
保留原图比例，但细节来自选定工作分辨率，放大后不会还原原先舍弃的细节。

轮廓简化、色数和工作分辨率影响形状与文件大小。算法设置边界数量及节点
数量上限，复杂画面达到上限时应提示减少细节，而不是冻结页面。预览应与
实际导出的相同参数、同一画作版本一致。用户导入的任意 SVG 不得以内联
HTML 插入页面执行。

## 轻量边界与依赖

画板使用系统字体，普通绘画、色卡、图片参考、取色、填充和工程保存不加载
外部框架或 PDF 库，没有统计追踪、登录、图片上传和在线推理服务。

PDF.js 固定为 **6.5.438 legacy min**，同源运行资源为 **4,769,494 字节，
约 4.77 MB**，包含主库、worker、字形映射、必需备用字体、图像解码模块和
许可证。普通画板首屏加载 **0 字节 PDF 资源**；选择 PDF 后才加载主库和
worker，字形或解码文件按该文档实际需要读取。详见 vendor 目录的 README。

这不等于“第一次访问也能完全离线”。页面及静态依赖需要先可访问或已有
缓存；本地处理是指用户的图像和文档内容在本机运算。不得为了写“离线”
而默认预缓存全部 PDF 资源或整站大文件。

大画布、多图层、历史快照、原参考 PDF 和复杂矢量化会消耗内存。主控必须
保留对画布边长、总像素、图层总像素与撤销记录的限制；提高限制前说明实际
内存代价。按需释放临时 Canvas、对象 URL、PDF 文档和过期笔画缓冲。

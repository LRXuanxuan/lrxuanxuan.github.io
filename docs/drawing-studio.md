# 轻绘 · 本地画室

入口为 `/drawing-studio.html`，与 `/playthings/`、
`/color-block-studio.html`（归纳练习室）相连。它用原生 HTML、CSS、
JavaScript 和 Canvas 提供绘画、图层、参考、取色与导出；文件和绘画内容
在当前浏览器中处理，不上传到博客、公开仓库或第三方服务。

这份文档说明实现结构、功能边界和维护验收要求，不作为浏览器测试已通过
或真实数位板已验证的声明。

## 页面与模块

| 文件 | 职责与接口 |
| --- | --- |
| `drawing-studio.html` | 独立全屏工作台、原生控件与使用说明；不套入博客正文窄栏 |
| `assets/drawing-studio/style.css` | 系统字体、明暗主题、可收起侧栏和窄屏布局 |
| `assets/drawing-studio/app.js` | Pointer Events、画布视图、图层状态、撤销、调色、导入导出与保存流程 |
| `assets/drawing-studio/core.js` | `DrawingCore.makeStroke / floodFill / adjustFilter / vectorize`；独立像素算法，无网络依赖；另保留 HSL `adjust` 接口 |
| `assets/drawing-studio/palettes.js` | `DrawingPalettes`：勾线、灰阶、肤色、街景、植物、动漫、马卡龙、莫兰迪色卡 |
| `assets/drawing-studio/reference.js` | `DrawingReference`：图片和 PDF、四种参考模式、色卡、参考包保存与恢复 |
| `assets/drawing-studio/bridge.js` | `DrawingBridge.put / take`：同一浏览器、同源页面间的一次性参考传递 |
| `assets/drawing-studio/storage.js` | `DrawingStorage`：只在浏览器 IndexedDB 中存储最近四份草稿 |
| `assets/drawing-studio/vendor/pdfjs/` | 固定版本的同源 PDF 解析资源；仅导入 PDF 时加载 |

不要将各模块复制到其他页面形成多个维护版本。新入口应复用这些模块。
教学页向画室传递参考时，保留其已经调整过的色块、灰度、线稿和调色板；
只有用户在画室改变色数后才重新从参考原图归纳。

## 笔刷、压感与防抖

四类笔刷是轻量数字笔触，不能当作实体工具或专业软件笔刷的精确复刻。

| 笔刷 | 当前实现 |
| --- | --- |
| G 笔 | 随数位笔压力改变宽度，连贯的变宽笔形与圆形端点 |
| 针管笔 | 等宽圆头线条；不通过压力改变宽度 |
| 二值笔 | 按整数像素跨度绘制硬边圆笔触，笔触掩膜没有抗锯齿边缘；可使用压感 |
| 像素笔 | 整数坐标方形笔头与 Bresenham 连线；保持像素网格，不做防抖插值 |

二值与像素笔的“无抗锯齿”指绘制出的原始栅格笔触。降低笔触浓度会统一
改变不透明度，缩放画布或变换图层也可能改变屏幕显示；不能因此承诺所有
导出、缩放和变换结果的 alpha 永远只为 0 或 255。

压感通过标准 Pointer Events 读取。必须收到 `pointerType: 'pen'` 和可变的
`pressure` 才能使用真实压力；如果系统或驱动把数位板当成鼠标，浏览器端
不能自行恢复压力。鼠标使用固定笔宽。没有物理数位板验证时，记录为
“已接入压感事件”，不得写成“所有 Wacom 型号已兼容”。

防抖是可调的笔尖位置滤波，强度越高，跟随延迟越明显。笔画在临时透明层
内绘制，再统一应用浓度合成，避免圆点重叠导致一笔之内越叠越黑。抬笔的
零压力不能转成最大宽度；失去捕获、窗口失焦或取消输入都必须结束笔画。

## 图层、填充、抠图与透明背景

图层的顺序、不透明度、大小与位置由主控管理；画作导出只合成可见图层。
参考面板独立于画作，只有“放入新图层”后才参与作品合成。

整体调色是非破坏性的色相、饱和度和明亮度调整，不改写各图层的原始像素。
支持 Canvas `filter` 的浏览器依次使用 CSS `hue-rotate()`、`saturate()`、
`brightness()`；不支持时由 `DrawingCore.adjustFilter` 按同样的 sRGB
颜色矩阵和各阶段裁剪规则回退，并保留 alpha。这里的明亮度是 RGB
乘法增益，不是 HSL 的 L 分量；纯黑不会随着增益变成灰色。预览与图片、
SVG 导出共用同一合成与调色流程。半透明像素在 Canvas 预乘 alpha 与
整数像素读写之间可能产生微小舍入差异，不能承诺不同浏览器逐字节相同。

油漆桶先从取样图计算选区，再写入当前图层，可参考所有可见图层的线稿
边界，在线稿下方的透明图层填色。颜色容差、是否只选择相连区域、边缘
扩展均应在撤销记录中作为一次操作处理。算法不判断物体的语义：开口的
轮廓可能漏色，容差过大可能越过颜色相近的边界。

“抠图”从点击位置移除颜色相近的背景，支持相连区域选择；不运行人像
识别或自动分割模型。头发、毛发、半透明物体或颜色相近的前景需要手工
修边。抠图结果的透明像素必须保留到 PNG / WebP / 工程保存中。

**纸张背景与图层里的白色像素不同。** 将画布背景设为透明，只取消额外
铺设的底色；已经导入图片的白色背景仍是图层内容，需要抠图或橡皮擦移除。
棋盘格只用于显示透明区域，不得画入图片或工程图层。

## 参考图、PDF 与取色

参考可以在原图、灰度归纳、有限色彩和线稿间切换，颜色与灰阶各有色卡。
参考视图的拖动和缩放独立于绘画视图；取色坐标需要换算到参考像素坐标。
默认备选色卡是手工整理的绘画起点，不是品牌色号、实体颜料色卡或行业标准。

普通参考的工作长边限制为 **1600 px**。PDF 每次只渲染当前页，翻页和换文件
时取消过期任务，避免旧页覆盖新页；不预渲染整本书。需要密码或已损坏的
文件应给出可恢复提示，且不能破坏当前画作或已有参考。

`DrawingReference` 提供 `load`、`loadBundle`、`setMode`、`setPage`、`setCount`、
`getCanvas`、`getInfo`、`getSourceBlob`、`exportBundle`、`destroy`。
参考包使用 Blob 保存四种模式及色卡；PDF 原件可以留在参考包中，供工程
恢复后继续翻页。工作副本经过降采样，不能将参考图显示尺寸等同于原文件
的完整分辨率。

PDF.js 6.5 的文档释放使用 `pdfDocument.loadingTask.destroy()`；不要沿用
已移除的 `pdfDocument.destroy()`。渲染中的 `RenderTask` 先取消，当前页
资源用 `page.cleanup()` 清理，未完成的加载用其 loading task 销毁。

教学页联动使用 IndexedDB `rc-drawing-transfer-v1` / `transfers`。临时记录
有效期为 24 小时，领取后删除，链接中的随机 ID 只定位本机记录；链接本身
不包含图片，也不能让其他浏览器或其他设备取得参考。传递失败时保留教学
页内容，并允许用户导出图片再手动放入画室。

## 保存与恢复

“存工程”生成 `.lrxdraw` 文件，用于保留图层及参考，之后可通过“打开”
继续编辑。普通 PNG、JPEG、WebP、SVG 导出用于图片交付，不保留本工具全部
图层编辑状态；不能将图片导出当作工程备份。工程可能包含参考 PDF，文件
大小会随其增长。

自动草稿只保存在当前浏览器的 IndexedDB `rc-drawing-studio-v1` / `drafts`，
最多保留最近四份。清理网站数据、无痕环境、存储配额或设备故障都可能影响
草稿；这不是云同步或长期备份，重要作品应主动保存工程文件。

`DrawingStorage` 的契约如下：

| 方法 | Promise 返回结果 |
| --- | --- |
| `save(id, project)` | 草稿摘要；调用当下克隆快照，不转移调用方的内存缓冲 |
| `latest()` | 最新 `{id, project, savedAt}` 或 `null` |
| `load(id)` | 对应 `{id, project, savedAt}` 或 `null` |
| `list()` | 按新到旧排序的 `{id,title,savedAt,width,height,layerCount}` 数组 |
| `remove(id)` | 删除完成，无返回数据 |

`savedAt` 使用毫秒时间戳。写入串行执行，事务提交后才清理旧稿，失败不得
先删备份。保存失败时主控仍保留内存中的画作，并显示导出工程的途径。
如果保存已提交而清理失败，异常带 `saved: true`。

各标签页使用独立草稿 ID；恢复已有草稿进入编辑时，也不能让两个页面无意
争写同一份记录。主控的异步 `toBlob` 和参考序列化同样要串行或检查版本号，
不能让较旧的序列化结果最后写入。不要用 `localStorage` 保存图层的大段
base64；工程文件需要的编码仅用于用户请求的文件导入导出。

## 导出与 SVG 的适用范围

- PNG：无损，可保留透明区域。
- JPEG：不支持透明，需要合成到选择的实色背景上。
- WebP：浏览器支持编码时可导出，并可保留透明区域。
- SVG：将合成画作的有限色区域描摹为闭合路径；不是把 PNG 塞进 `<image>`。

PNG 之外的 `toBlob` 编码支持取决于浏览器。必须检查返回 Blob 是否存在及
实际 MIME；不支持 WebP 而返回 PNG 时，应正确提示并使用 `.png` 扩展名。

SVG 适合线稿、剪影、标志式图形和平涂色块。照片、纹理、柔和渐变会被有限
色彩归纳；它不会推断原始笔画、物体结构或贝塞尔曲线。当前实现会将 alpha
归为最多八档，并保留透明孔洞，因此半透明边缘会有取舍。SVG 的画布比例
保留原图比例，但细节来自选定工作分辨率，放大后不会还原原先舍弃的细节。

轮廓简化、色数和工作分辨率影响形状与文件大小。算法设置边界数量及节点
数量上限，复杂画面达到上限时应提示减少细节，而不是冻结页面。预览应与
实际导出的相同参数、同一画作版本一致。用户导入的任意 SVG 不得以内联
HTML 插入页面执行。

## 轻量边界与依赖

画板使用系统字体，普通绘画、色卡、图片参考、取色、填充和工程保存不加载
外部框架或 PDF 库，没有统计追踪、登录、图片上传和在线推理服务。

PDF.js 固定为 **6.5.438 legacy min**，同源运行资源为 **4,769,494 字节，
约 4.77 MB**，包含主库、worker、字形映射、必需备用字体、图像解码模块和
许可证。普通画板首屏加载 **0 字节 PDF 资源**；选择 PDF 后才加载主库和
worker，字形或解码文件按该文档实际需要读取。详见 vendor 目录的 README。

这不等于“第一次访问也能完全离线”。页面及静态依赖需要先可访问或已有
缓存；本地处理是指用户的图像和文档内容在本机运算。不得为了写“离线”
而默认预缓存全部 PDF 资源或整站大文件。

大画布、多图层、历史快照、原参考 PDF 和复杂矢量化会消耗内存。主控必须
保留对画布边长、总像素、图层总像素与撤销记录的限制；提高限制前说明实际
内存代价。按需释放临时 Canvas、对象 URL、PDF 文档和过期笔画缓冲。

## 更新前的验收要求

以下是维护检查项目，不表示已经执行或通过：

1. 从小玩意、归纳练习室两处能进入画室；原有页面功能不受影响。
2. 鼠标绘画、四类笔刷、半透明笔触、数位笔事件、取消/失焦收笔、缩放后的
   落点、撤销和重做正确。像素与二值检查原始像素，不能只看缩略截图。
3. 图层增删、复制、隐藏、锁定、上下顺序、大小、位置与透明度正确；合成
   取样填充可在线稿下方工作；抠除背景与透明纸张分别检查。
4. 图片、粘贴、拖入、四模式与两套色卡正确；参考不会混入普通作品导出。
5. 两页以上 PDF 翻页正确；快速翻页再回原页、换文件、打开失败和工程恢复
   不会留下旧结果覆盖新结果；全部资源同源，首屏没有 PDF 请求。
6. `.lrxdraw` 保存后重新打开保留图层与参考；草稿配额失败不丢内存或删旧稿；
   同 ID 保存顺序、跨标签页独立 ID 和四份保留规则正确。
7. PNG 透明、JPEG 底色、WebP 实际 MIME、SVG 真实路径与透明孔洞正确；
   SVG 预览与下载一致，无以栅格封装冒充矢量的情况。
8. 明暗主题、较窄窗口、折叠与专注模式可用；输入框和弹窗不会触发绘图
   快捷键，Tab 不应妨碍原生控件的键盘导航。
9. 发布前读取最新 main、保留其他任务的变更，通过现有构建并检查线上入口；
   没有真实浏览器或硬件证据时，明确记录验证范围。

轻绘 0.1.0 · 安卓版

这是轻绘画室与绘画归纳练习室的本机版本。安装后即可离线使用画板、参考图、
配色与 PDF 资源；无需账号。左侧参考栏在手机和平板布局下默认收起，点“参考”
或“展开侧栏”即可打开。

系统要求：Android 8.0（API 26）或更新，并安装可用的 Android System WebView。
较旧 WebView 如缺少应用所需能力会显示提示；系统版本并不代表所有设备或触控笔
均已验证。更新 WebView 请使用设备的官方应用商店或系统更新。

使用方法
1. 安装正式签名的 lightdraw-0.1.0-android.apk，打开“轻绘”。
2. “图片 / PDF”调用系统文件选择器；只读取你主动选中的文件。
3. “存工程”导出 .lrxdraw，可保留图层和参考；图片“导出”用于分享作品。
   系统询问保存位置时选择本机目录即可。取消保存不会被记为导出成功。
4. “归纳练习室”在应用里切换；再次返回画室保留当前画作。
5. 自动续画保存在本应用内。网页版、Windows 版、安卓版的自动保存互相独立，
   用 .lrxdraw 文件迁移；卸载应用或清除应用数据前务必主动备份。
6. 本应用不主动上传图片、作品或 PDF。若你主动选择系统文件选择器中的云盘，
   文件提供者自身可能通过网络读写该文件，这由你选择的位置决定。

安装与更新
请保留原应用后覆盖安装使用同一签名的新版本。未知来源安装提醒由 Android
管理，请核对来源及 SHA256，不需要关闭 Play Protect 等系统安全保护。
带 -debug 或 -test 的文件只用于构建测试，不是正式交付包。

PDF runtime:
PDF.js 6.5.438 and its fonts, CMaps, ICC and WebAssembly resources are bundled
with their existing LICENSE and NOTICE files under assets/drawing-studio/vendor/pdfjs/.
Their README records provenance and licenses. The engine is loaded only after
the user chooses a PDF, not at application startup.

WebView:
This application uses the device's installed Android System WebView. It does
not bundle a browser runtime. System components remain under their own terms.

Palette values are approximate screen references. Existing sources are recorded
in the drawing palette documentation in the source repository. No user artwork,
reference photographs, or reference PDFs are bundled.

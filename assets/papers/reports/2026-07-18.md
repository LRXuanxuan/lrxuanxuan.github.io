## 1. Diffusion-Based Noise-Adaptive Null-Space Channel Estimation for OFDM Systems

- **作者**：Heqiang Qi, Yirun Chen, Xiangming Meng, Chunxiao Jiang, Sheng Wu, Linling Kuang
- **年份/类型**：2026，arXiv 预印本
- **编号**：arXiv:2607.03348；DOI: 10.48550/arXiv.2607.03348
- **论文页**：[arXiv](https://arxiv.org/abs/2607.03348)
- **PDF**：[官方 PDF](https://arxiv.org/pdf/2607.03348)
- **代码状态**：**未发现公开代码**。已检查论文页、全文及题名、ID、DANCE+OFDM、作者关键词的 GitHub 检索。

### 核心问题与方法

论文面向稀疏、带噪且配置可变的 5G NR DMRS 信道估计，将导频观测写成线性逆问题，并把信道分解为：

\[
\mathbf H
=
\underbrace{\mathcal A^\dagger \mathbf y}_{\text{受观测约束的值域分量}}
+
\underbrace{\left(\mathbf I-\mathcal A^\dagger\mathcal A\right)\mathbf z}_{\text{未观测零空间分量}}.
\]

扩散先验主要补全零空间，而值域部分由观测约束。关键增量不是“用了扩散”，而是引入**噪声自适应 posterior correction**：根据观测噪声同时调节修正系数与残差采样方差，避免把带噪导频当成绝对真值。复信道以实部/虚部双通道表示，网络只沿子载波维下采样。

论文在 TDL/CDL、不同 SNR、DMRS 配置、Doppler 与 train-test mismatch 下报告比传统估计器及 diffusion posterior sampling 更低的 NMSE；没有公开真实链路验证。

### 与既有阅读的关系：对既有方向的深化

- 相对 DDNM、DPS/FlowDPS：从通用图像逆问题推进到真实 DMRS 配置，并显式处理导频噪声；
- 相对 `Null-Space Flow Matching for MIMO Channel Estimation`：共享“观测子空间 + 生成补全”思想，但 DANCE 增加噪声自适应软校正；
- 相对现有 CKM-SRF 的 RC/PBG：可把统一投影替换为“值域解析更新 + 零空间生成 + 噪声自适应权重”。

### 可迁移性

**可直接改造成求解器模块。** 建议保持当前 \(p_\theta(\mathbf H\mid \mathbf r,\mathbf e,\mathcal M)\) 条件先验，只替换数据一致性步，并测试：

- 未见 pilot pattern；
- pilot ratio 与 SNR 联合变化；
- Doppler/高速移动；
- CKM 条件失配下是否仍会过度相信观测。

## 2. Diffusion Inpainting MIMO-OFDM Channels with Limited Noisy Observations

- **作者**：Weijie Zhou, Zhaoyang Zhang, Yuzhi Yang, Sen Yan, Zhixian Kong, Mérouane Debbah
- **年份/类型**：2026，arXiv 预印本
- **编号**：arXiv:2604.09039；DOI: 10.48550/arXiv.2604.09039
- **论文页**：[arXiv](https://arxiv.org/abs/2604.09039)
- **PDF**：[官方 PDF](https://arxiv.org/pdf/2604.09039)
- **代码状态**：**未发现公开代码**。论文页未提供仓库，题名、ID 与作者关键词 GitHub 检索均无对应实现。

### 核心问题与方法

论文把 MIMO-OFDM 信道估计改写为 conditional generative inpainting：

\[
\widetilde{\mathbf H}
=
\mathbf M\odot(\mathbf H+\mathbf N),
\]

其中 \(\mathbf M\) 是可变导频 mask。模型采用 Conditional Diffusion Transformer（CDiT）：

- 把原始导频估计作为 prompt；
- 显式编码 pilot mask、噪声水平和导频间隔；
- 在每个去噪步用 cross-attention 对齐原始观测与当前生成信道。

论文报告相对基线超过 5 dB 增益，在 1/32 导频密度下仍保持稳健，并可在 10 个推理步内恢复信道。局限是仍需多步扩散，且无公开代码。

### 与既有阅读的关系：填补 DiT 条件接口缺口

- 相对 BeamCKMDiff：后者强调连续 beam 条件；本文进一步给出**原始导频 prompt + mask/SNR token + 逐步 cross-attention**；
- 相对 Adaptive PnP-CM：本文把观测融合进网络内部，可作为“隐式数据一致性”基线，与显式 PnP/ADMM 对比；
- 相对现有 FiLM/AdaGN：适合引入可变长度或空间结构化观测，而不是只注入全局条件向量。

### 可迁移性

**结构可直接迁移，原扩散求解器只作基线。** 可保留 prompt encoder 与 cross-attention，将骨干替换为 CM/GMFlow：

\[
q_\theta\!\left(
\mathbf U\mid
\mathbf X_t,t,
\mathbf M_{\rm pilot},
\widehat{\mathbf H}_{\rm LS},
\sigma_n^2,
\mathbf c_{\rm CKM}
\right).
\]

重点消融 cross-attention 的插入层、pilot mask 编码和显式 PnP 是否仍有增益。

## 3. BDFlow-3DRM: Height-Coherent 3D Radio Map Construction via Bi-Dynamical Flow Matching

- **作者**：Jun Yu, Meixia Tao, Shu Sun
- **年份/类型**：2026，arXiv 预印本
- **编号**：arXiv:2607.09778；DOI: 10.48550/arXiv.2607.09778
- **论文页**：[arXiv](https://arxiv.org/abs/2607.09778)
- **PDF**：[官方 PDF](https://arxiv.org/pdf/2607.09778)
- **代码状态**：**未发现公开代码**。已检查论文页、全文及 BDFlow-3DRM、Bi-Dynamical Flow Matching、题名和作者关键词的 GitHub 检索。

### 核心问题与方法

现有 3D radio map 常把高度当成离散层，导致未见高度泛化差、相邻高度不连续。BDFlow-3DRM 在语义潜空间中学习确定性 probability flow，并引入：

- 连续收发高度条件；
- 相邻高度层的双向动力学依赖；
- 多高度 radio map 的联合生成。

论文报告：相对扩散基线 NMSE 降低 28.6%，推理复杂度降低 180 倍；只使用 20 个接收高度层训练，可覆盖 1–120 m 连续接收高度和可变发射高度。其输出仍主要是 radio map，而非完整 MIMO CSI。

### 与既有阅读的关系：填补连续高度与层间一致性缺口

- 相对 RadioDiff-3D/RadioMapMotion：新增连续高度条件与跨层双向一致性；
- 相对 F4-CKM：F4-CKM 强调空间—频率连续场，本文专门解决高度层稀疏监督；
- 相对 Sheet2 的不完整城市监督：可在少量高度层有标签时学习连续高度表示，不要求每个高度均有完整条件。

### 可迁移性

**仅作方法启发，可较低成本形成消融。** 最小版本：

1. 将 \(h_{\rm Tx},h_{\rm Rx}\) 作为连续 FiLM/AdaGN 条件；
2. 对相邻高度样本增加双向一致性损失；
3. 检验未见高度、未见城市与跨 BS 泛化；
4. 若数据仅有离散高度，不宣称可直接恢复完整 3D CSI。

## 4. Digital Twin-Based Channel Generation Toolchain and Foundation Model for Low-Altitude XL-MIMO

- **作者**：Mengyuan Li, Yu Han, Jiachen Tian, Chao-Kai Wen, Shi Jin
- **年份/期刊**：2026，IEEE Journal of Selected Topics in Signal Processing Early Access
- **DOI**：10.1109/JSTSP.2026.3705369
- **论文页**：[DOI](https://doi.org/10.1109/JSTSP.2026.3705369)
- **预印本/PDF**：[arXiv:2606.14114](https://arxiv.org/abs/2606.14114) / [PDF](https://arxiv.org/pdf/2606.14114)
- **代码**：[LAETwin-XL GitHub](https://github.com/Lmyxxn/LAETwin-XL)
- **数据**：[Hugging Face 数据集](https://huggingface.co/datasets/lmyxxn/LAETwin-XL)
- **代码状态**：**作者预告/部分代码 + 完整数据工具链**。仓库含 OSM→3D 场景、UAV 轨迹、Sionna 逐阵元 RT、数据切分/合并脚本；Hugging Face 数据约 70.4 GB。当前仓库根目录未见论文所述 CDDIM 基础模型训练代码。

### 核心问题与方法

LAETwin-XL 面向低空三维移动与近场 XL-MIMO：

- 用 OSM 和 SUMO 构建城市/郊区环境与 UAV 轨迹；
- 用 Sionna RT 逐阵元生成近场球面波与远场信道；
- 输出位置、轨迹、信道与多种无线标签；
- 在不完整天线观测上预训练 CDDIM 生成式基础模型，用轻量任务头迁移到信道估计、分类与定位。

论文报告零样本信道外推和参数高效迁移，但基础模型部分暂不能按公开仓库完整复现。

### 与既有阅读的关系：数据/系统约束补强

- 相对 CSRD2025：从频谱感知与硬件损伤扩展到低空逐阵元 XL-MIMO；
- 相对 OpenPathNet/UrbanMIMOMap：新增动态 UAV、近场球面波、不完整阵元观测和基础模型接口；
- 相对当前城市条件缺失：可人为构造 antenna mask、pilot mask、跨高度和跨城市任务，建立可控缺失监督。

### 可迁移性

**数据生成工具链可直接改造；基础模型只能部分借鉴。** 建议先把输出整理为：

\[
\{\mathbf H,\mathbf r_{\rm Tx},\mathbf r_{\rm Rx},h,v,
\text{LoS/NLoS},\text{path labels},\mathbf M_{\rm antenna}\},
\]

再接入 CKM-SRF 的连续条件与导频后验修正。不要把公开仓库误写成完整端到端 CSI 生成器。

## 5. PilotWiMAE: Pilot-Native Representation Learning for Wireless Channels

- **作者**：Berkay Guler, Giovanni Geraci, Hamid Jafarkhani
- **年份/类型**：2026，arXiv；作者主页注明 ICML 2026 AI4NextG Workshop accepted，并提交 IEEE JSTSP
- **编号**：arXiv:2605.22856；DOI: 10.48550/arXiv.2605.22856
- **论文页**：[arXiv](https://arxiv.org/abs/2605.22856)
- **PDF**：[官方 PDF](https://arxiv.org/pdf/2605.22856)
- **代码**：[官方 GitHub](https://github.com/BerkIGuler/PilotWiMAE)
- **代码状态**：**完整开源实现**。仓库包含模型、两阶段预训练、配置、监督基线、三类下游评估、测试、requirements、MIT 许可证与 checkpoints。

### 核心问题与方法

PilotWiMAE 直接从稀疏、带噪导频自监督预训练：

- 时间轴与联合空频轴的 factorized attention；
- patch-normalized reconstruction 学小尺度衰落；
- scale loss 保留大尺度衰落；
- AWGN curriculum 对齐预训练和部署噪声；
- decoder-centric 第二阶段改善信道估计，同时尽量不破坏表示质量。

论文报告输入空间最多缩小两个数量级，预训练 mask 可达 99%；仅在 3.5 GHz 训练后，在 28 GHz 跨频 beam selection 和 channel characterization 上超过监督基线，并保持有竞争力的信道估计。

### 与既有阅读的关系：填补弱监督与缺失观测缺口

- 相对已有 diffusion/flow/CM：它不是另一个后验采样器，而是 pilot-native 前端；
- 相对 LAETwin-XL：在线输入不要求完整 RT CSI；
- 相对 Sheet2：不假定坐标、AoA/AoD、gain map 同时齐全，可先学习观测可得的信道表示，再做缺失条件融合。

### 可迁移性

**可直接复现，并作为 CKM-SRF 的前置表示模块。** 推荐两种接口：

1. 将 frozen encoder token 作为 GMFlow/CM 的 cross-attention 条件；
2. 用 encoder 输出构造 data-informed source，再由 DANCE/PnP 完成显式数据一致性。

## 精读优先级

1. **DANCE**：最直接补强现有 RC/PBG/PnP 数据一致性，且能形成清晰的导频噪声消融；
2. **LAETwin-XL**：工程价值最高，能补齐低空近场 XL-MIMO 数据与跨高度任务；
3. **PilotWiMAE**：有完整代码，适合快速验证 pilot-native encoder 是否能改善现有 GMFlow/CM。

若今天只读两篇：先读 **DANCE**，再读 **LAETwin-XL**。

## 下一步实验切入点

### 最小可行实验 A：DANCE-style 数据一致性替换

- 固定现有 CKM-conditioned GMFlow/CM 先验；
- 比较 RC/PBG、硬投影、DANCE-style 软值域修正；
- 变量：pilot ratio、pilot pattern、SNR、Doppler、CKM mismatch；
- 指标：NMSE、pilot residual、BER、NFE/时延、校准误差。

### 最小可行实验 B：PilotWiMAE encoder + CKM-SRF

- 直接复现官方 checkpoint；
- 将 pilot encoder token 通过 cross-attention 注入现有 U-Net；
- 与“仅 FiLM/AdaGN CKM 条件”“仅 LS CSI”“CKM + LS CSI”比较；
- 重点检查 3.5→28 GHz、跨城市和 99% mask 下的泛化。

### 进阶实验：LAETwin-XL 连续高度任务

- 从公开工具链生成 3–5 个高度层训练、未见高度测试；
- 加入 BDFlow 风格连续高度条件和双向层间一致性；
- 以 DANCE/PnP 做在线导频后验修正，形成：

\[
\text{DT/CKM prior}
\rightarrow p_\theta(\mathbf H\mid \mathbf r,\mathbf e,h,\mathbf M)
\rightarrow \text{pilot posterior correction}
\rightarrow \text{beam/ISAC/trajectory task}.
\]

## 结论

今天的核心不是再增加一种无线 diffusion，而是把现有研究链路向部署条件推进：**观测噪声可校准、导频模式可变化、条件监督可缺失、低空高度可连续、数据生成可复现**。其中 DANCE 与 PilotWiMAE 最适合直接改造现有代码，LAETwin-XL 最适合作为下一阶段数据与 Sim2Real 工具链。

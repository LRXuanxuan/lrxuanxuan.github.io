## 1. Dynamic Channel Knowledge Map: Fundamentals, Construction, and Applications

- **作者 / 年份 / venue**：Wenjun Jiang, Xiaojun Yuan；2026；arXiv 预印本（未核验正式录用）。
- **方向与问题**：动态 CKM、时变散射体、终端姿态与 RF impairments、CKM—物理层协同。传统 CKM 多描述建筑/地形等准静态环境，难以覆盖毫秒至秒级动态分量。
- **方法**：提出 dynamic CKM 作为准静态 CKM 与瞬时物理层之间的中间层，讨论 construction、pilot design、interference suppression、ISAC，以及 dynamic-CKM construction 与 channel estimation 的迭代 co-design。
- **关键结果与局限**：概念性仿真中，在 SNR=5 dB、静态/动态功率比为 2 dB 时，多轮 co-design 相对单轮定位 RMSE 约降低 1.5 m。它是架构/综述型论文，作者也明确指出 scalability、协议与真实场测仍未解决，不能把初步仿真当成普适性能证据。
- **迁移类型**：**理论启发与系统路线图**。可把现有 CKM prior 拆成慢时标静态条件与快时标动态 residual/state，再由导频残差更新后者。
- **与既有阅读差异**：相对静态 CKM、RadioDiff、GeoGS-CE，本篇新增“时标分层 + CKM construction/PHY joint inference”；相对 RadioMapMotion，它更偏系统架构与 co-design，而非单一预测模型。
- **相对阅读笔记的位置**：**深化**。直接推进 CKM/WCM → 动态先验 → pilot/channel-estimation co-design。
- **一手来源**：[arXiv:2607.17133](https://arxiv.org/abs/2607.17133)；[PDF](https://arxiv.org/pdf/2607.17133)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者实现。
- **推荐理由**：它把用户当前“准静态环境先验 + 瞬时导频后验校正”明确提升为 dynamic CKM 研究问题，适合作为论文动机、系统框架和 future-work 的核心引用。

## 2. Radio Map Updating from Streaming Spectrum Measurements via Memory-Based Online Gaussian Processes

- **作者 / 年份 / venue**：Yuanyuan Deng, Bo Zhou, Tian Chen, Shijian Gao, Jia Yan, Lantu Guo, Qiuming Zhu, Qihui Wu；2026；arXiv 预印本。
- **方向与问题**：streaming radio map、online sparse variational GP、catastrophic forgetting、uncertainty quantification。批处理地图每次需重算全部历史测量，难以在线更新。
- **方法**：M-OSVGP 用新 batch 与历史 memory subset 构造 hybrid objective；GOIPS 根据空间测量密度和相关性动态调整 inducing points 的数量与位置。
- **关键结果与局限**：在 campus/urban 仿真、30 次独立运行中，M-OSVGP 相对 SVGP/SSVGP/Memory-DGP 的 RMSE 最高下降 4.9%/4.3%/25.6%（campus），运行时间最高下降 71.3%/36.1%/68.3%；GOIPS 再带来最高 1.8% RMSE 改善。局限是主要验证 RSS 地图与合成 streaming batches，尚非宽带 MIMO/角延迟 CKM，也未展示真实长期漂移。
- **迁移类型**：**可改造工具**。可把 memory subset 与 adaptive inducing points 用作动态 CKM 的轻量 online head 或教师基线，并输出 posterior variance 作为 PnP 权重/条件置信度。
- **与既有阅读差异**：相对 TGPP/Anchor-CKM 的一次性稀疏重建，本篇关注持续到达数据、遗忘和在线不确定性；相对动态 CKM 概念文，它提供可实现的更新器。
- **相对阅读笔记的位置**：**缺口填补**。补齐当前研究中“地图建成后如何低成本持续更新”的工程环节。
- **一手来源**：[arXiv:2607.17954](https://arxiv.org/abs/2607.17954)；[PDF](https://arxiv.org/pdf/2607.17954)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者仓库。
- **推荐理由**：它能直接形成 dynamic-CKM online update 基线，并把 uncertainty、memory size、update latency 引入现有只看 NMSE 的评估体系。

## 3. Map as a Prompt: Learning Multi-Modal Spatial-Signal Foundation Models for Cross-scenario Wireless Localization

- **作者 / 年份 / venue**：Yong Chu, Xun Zhou, Zenglin Xu, Hui Wang, Yue Yu；2026；论文全文标注 ICLR 2026 conference paper，arXiv comment 标注 ICLR 2026 poster。
- **方向与问题**：3D map soft prompt、cycle-adaptive masked modeling、cross-scenario wireless localization、parameter-efficient adaptation。
- **方法**：SigMap 先用与 CSI 周期相关的自适应 mask 防止 masked modeling 走周期性捷径，再用 GNN 编码 3D 地图/BS 几何为 soft prompt；下游只更新轻量 task head/prompt。
- **关键结果与局限**：DeepMIMO O2 上 MAE 1.026 m，WAIR-D 100 城市场景上表格报告 MAE 1.880 m；相对 LWLM 分别改善约 53.2% 和 44.3%，推理约 0.83 ms/sample。需特别注意：摘要写“zero-shot”，但正文实验对每个目标场景使用约 100 个样本微调下游 head，因此更准确的表述是 **few-shot cross-scenario adaptation**。此外，任务是定位而非 CSI posterior，且依赖地图与射线追踪数据。
- **迁移类型**：**可改造工具**。最值得迁移的是“map-as-prompt + availability/confidence mask”，而不是完整复现定位模型；可将现有粗 BS/scatterer/blocker 几何编码为 prompt token，避免假设 Sheet2 存在完整坐标与 AoA/AoD 联合监督。
- **与既有阅读差异**：相对 PilotWiMAE，它新增周期自适应 mask 与地图 prompt；相对 Robust-CKMSRF，它处理“怎样把地图压缩成可调条件”，而不只处理缺失/噪声模态；相对 RadTwin，它不要求每层显式射线路径 mask。
- **相对阅读笔记的位置**：**深化 + 缺口**。补齐 principled conditioning、跨城市轻量适配和几何先验 token 化。
- **一手来源**：[arXiv:2607.15713](https://arxiv.org/abs/2607.15713)；[PDF](https://arxiv.org/pdf/2607.15713)。DOI：待核验。
- **代码状态**：**作者预告/部分代码**。[论文给出的匿名仓库](https://anonymous.4open.science/r/SigMap_anonymous-838D) 声称包含数据生成、预训练、微调和评估全流程，但当前 API 返回 `repository_expired`，无法核验或复现其实际文件，故不能归类为“完整开源实现”。
- **推荐理由**：这是今天与用户选题优先级最贴合的论文：轻量 soft prompt、mask-aware 表征、跨场景适配和明确的环境条件接口都可独立落到 CKM-SRF/GMFlow。

## 4. Ensemble Controlled-Flow Filtering for Implicit Data Assimilation

- **作者 / 年份 / venue**：Zhuoyuan Li, Yue Zhao, Ming Li；2026；arXiv 预印本。
- **方向与问题**：controlled flow、sequential Bayesian update、implicit/many-to-one observations、likelihood-free data assimilation。
- **方法**：以能量倾斜定义 analysis law，`π_a(x|y) ∝ π_f(x) exp[-J(x;y)]`；EnCF 通过 stochastic controlled flow 与 adjoint matching 学习 observation-dependent control，EnCF-LF 则从 simulator samples 学习 surrogate conditional energy。
- **关键结果与局限**：在平滑加性高斯观测下，EnKF/LETKF 仍优于 EnCF；当噪声变为明显双峰时，约在 mode offset `a≈4` 后 EnCF 的 RMSE 低于两种 EnKF；对 many-to-one/implicit observations 能更好保留多峰 ensemble。代价是每次 analysis step 需训练 control，wall-clock 明显高于 Kalman 类方法；尚未验证通信导频算子。
- **迁移类型**：**理论启发 / 可改造求解器**。可将量化导频、幅度-only、硬判决或 simulator-only 信道观测写成 energy，而不强求可微 likelihood；应作为独立 posterior-correction 分支与 PnP-ADMM/FlowADMM 比较。
- **与既有阅读差异**：相对 Bayesian Inverse Problems Meet FM 的一次性 amortized posterior，本篇面向序列 filtering；相对 FlowADMM/PnP-CM，它允许非加性、非光滑、many-to-one 的观测接口并显式保持 ensemble diversity。
- **相对阅读笔记的位置**：**缺口填补**。补齐“隐式/量化/多峰观测下如何做 flow posterior update”。
- **一手来源**：[arXiv:2607.12975](https://arxiv.org/abs/2607.12975)；[PDF](https://arxiv.org/pdf/2607.12975)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者实现。
- **推荐理由**：它不是普通 FM 迁移，而是把观测机制改写为 energy tilt，并清楚给出 Kalman 方法何时更优、controlled flow 何时才值得使用，适合严谨设计对照实验。

## 5. Spatial Transport of Integration Error in Generative ODEs

- **作者 / 年份 / venue**：Songheng Yin；2026；arXiv 预印本。
- **方向与问题**：few-step generative ODE、local truncation error、Flow Complexity、NFE—quality trade-off。
- **方法**：把每步有符号截断残差沿模型线性化 dynamics 传播到终点，解释误差从何处注入、如何跨区域传播；提出 Flow Complexity (FC) 预测困难区域，并用 FCM penalty 从训练阶段降低少步误差。
- **关键结果与局限**：传播后的误差重构与真实终点误差方向 cosine 达 0.81–0.87；FC 对区域终点误差的相关性约 0.57–0.70。FCM 在低 NFE 更有效，但每步多一次 forward、训练步耗时约 1.9×；256×256 结果每个 cell 只有单次训练，且目标是图像/latent 区域误差而非无线 NMSE 或 pilot residual。
- **迁移类型**：**理论启发**。可把“空间区域”改为 antenna–pilot、delay–beam 或 subcarrier–antenna blocks，诊断 Site-cFM/GMFlow 在 4–10 NFE 下哪些块积累最大求解误差；先做 post-hoc FC diagnostic，再决定是否训练 FCM penalty。
- **与既有阅读差异**：相对 PnP-Flow continuous viewpoint 的全局 Lipschitz/步长误差，本篇解释误差在结构域内的注入和传播；相对 CAR-Flow，它不改变 source path，而是诊断/正则化数值可积性。
- **相对阅读笔记的位置**：**深化**。补齐低 NFE 评价不应只有总 NMSE，还需 block-wise solver discrepancy 与误差传播证据。
- **一手来源**：[arXiv:2607.16361](https://arxiv.org/abs/2607.16361)；[PDF](https://arxiv.org/pdf/2607.16361)。DOI：待核验。
- **代码状态**：**未发现公开代码**。论文页、全文以及题名/arXiv ID 精确检索均未发现作者实现。
- **推荐理由**：它给低 NFE 研究提供了独立于“一步生成”的可解释维度，能直接改善当前 Site-cFM/GMFlow 的 NFE—NMSE—结构误差诊断。

## 可执行 MVP 实验

### MVP-A：Dynamic CKM + Map Prompt（条件建模分支）

- 冻结 `7_14/MIMO_ckmsrf` 主干与共同初始化，只新增一个独立 `map_prompt` 分支。
- 输入使用当前真实存在的粗几何：BS/scatterer/blocker；编码为 4–8 个 soft prompt tokens，并附 `availability/confidence/age`。
- 训练时只在有坐标的城市启用坐标 prompt；AoA/AoD-only 城市保持坐标 unavailable，不做伪补齐。
- 对照：无地图、FiLM/adaLN、prompt token、prompt + structured mask；统一 test split、SNR、seed、PnP 参数。
- 验收：NMSE、normalized pilot residual、跨城市性能、参数量、训练/推理时间、NFE 与 sampler-only latency。

### MVP-B：低 NFE Flow Complexity 诊断（求解器分支）

- 不改 checkpoint，先在现有 Site-cFM/GMFlow 的 NFE={4,6,8,10} 上保存每步 velocity。
- 将复数信道划分为 antenna–pilot 或 delay–beam blocks，比较 cheap Euler/Heun 与高精度参考解的 block-wise discrepancy。
- 计算简化 FC：相邻时间速度变化范数；验证它与最终 block error 的 Spearman 相关性，并检查高误差块是否跨步传播。
- 只有 post-hoc 相关性稳定后，再单独训练 FCM penalty；不得与 map-prompt 分支叠加后归因。
- 验收：总 NMSE、block-wise error、pilot residual、NFE、额外 forward 次数与实际 wall-clock。

## 核验边界

- 5 篇均由 arXiv 一手页面与 PDF 核验；未发现 DOI 的均标为待核验。
- SigMap 摘要的 “zero-shot” 与正文约 100 个目标样本微调不完全一致，本文按更保守的 **few-shot cross-scenario** 表述。
- CPU smoke test、图像任务 FID 或非无线数据同化结果均不能直接写成 MIMO 性能增益；所有迁移结论仍需在统一无线数据与观测协议下实验验证。

## 1. Physics-Unrolled Neural Operator for Wireless Field Modeling

- 作者：Rafid Umayer Murshed, Saif Ur Rahman, Mingyue Tang, Elahe Soltanaghai
- 年份/venue：2026，arXiv 预印本；正式 venue/DOI 待核验
- 方向：无线场建模、radio map、physics-unrolled neural operator、射线追踪多保真学习
- 问题：高保真 radio map 依赖昂贵的密集射线追踪；廉价有限射线标签又含 Monte Carlo 噪声，普通图像回归会平滑掉覆盖空洞和局部衰落结构。
- 方法：PU-HNO 以低保真 radio map、有效区域 mask、场景几何/材料语义、射线方向描述符和坐标编码为条件，按反射、衍射、散射三阶段残差级联精化；每一阶段使用与传播复杂度匹配的监督和结构损失。论文还证明在条件无偏标签噪声下，模型可以学习稳定传播结构并优于自身训练标签。
- 关键结果：在 Sionna RT 随机场景上，完整模型的 Outage F1 为 0.820、fading ratio 为 1.013、tail error 为 0.101、RMSE 为 3.471 dB；未见房间数/杂物密度组合上 RMSE 为 3.31–3.89 dB、Outage F1 为 0.74–0.87。去掉材料/语义条件时 Outage F1 从 0.82 降至 0.001，说明环境语义不是装饰性输入。
- 局限：仅 5.5 GHz、室内单发射机、固定天线、RSS 标量；不包含相位、CIR、角谱或 MIMO 矩阵。训练与测试都来自同一射线追踪引擎，存在系统偏差时理论无偏噪声保证不成立，真实部署仍需测量校准或 Sim2Real。
- 迁移类型：可改造工具。可先把三阶段输出改为 delay–beam PSD/协方差或 CKM 标量场精化，不应直接宣称完成复 CSI/MIMO 复现。
- 与既有阅读差异：相对 RadioUNet、F4-CKM、GeoGS-CE，本篇的独立增量不是更换 backbone，而是显式把反射、衍射、散射拆成逐级可监督的物理残差；相对 Robust-CKMSRF，它解决标签保真度与传播机制分解，而非缺失模态鲁棒性。
- 相对阅读笔记的位置：核心深化；连接环境/射线先验与 geometry-to-PSD 路线。
- 官方页：https://arxiv.org/abs/2608.18495
- PDF：https://arxiv.org/pdf/2608.18495
- 代码状态：未发现公开代码。论文/全文未给出仓库；作者 GitHub 与精确题名、arXiv ID 检索均未发现论文专属实现。
- 推荐理由：这是今天最接近“环境结构 → 可解释无线先验”的工作，且给出了材料语义消融、OOD 场景和标签噪声边界，适合形成独立的 physics-unrolled CKM 分支。

## 2. RMWorld: Task-Aware Radio World Models with Value-of-Information Guided Multi-Trial Learning for Multi-UAV Communication Control

- 作者：Xiucheng Wang, Nan Cheng, Junxi Huan
- 年份/venue：2026，arXiv 预印本；正式 venue/DOI 待核验
- 方向：radio world model、CKM 校准、多 UAV 通信控制、value of information、active learning
- 问题：全局 RMSE 较低的 radio world model 仍可能在高业务走廊或关联边界犯错，从而反转控制决策；普通不确定性采样没有衡量“一条新链路标签能减少多少任务风险”。
- 方法：用 Bayesian residual 修正有偏传播公式；以单条新链路对任务加权 posterior rate variance 的精确减少量作为 acquisition score，并用 task-gated log-determinant 选择可信且多样的 counterfactual trials，随后执行冲突投影与固定批次验证。
- 关键结果：100 个配对 3GPP TR 36.777 试验上任务加权 RMSE 为 0.949 bit/s/Hz；30 个严重负载 DeepMIMO 试验上，相比 Ensemble UCB，median backlog 减少 0.967，但使用多 37.5% 的离线 rollout。论文给出方差缩减恒等式、posterior task-risk 等价性和贪心子模保证。
- 局限：实验场景均为 2 UAV、4 用户；3GPP 块使用公式信道，DeepMIMO 控制块只验证 held-out O1 slice。长时域 stress test 不能可靠区分方法，论文也明确不宣称 blanket SOTA；离线 rollout 增量不能忽略。
- 迁移类型：理论启发/系统基线。可把“均匀采集 CKM 样本”改为“优先采集会改变波束/关联/队列决策的链路”。
- 与既有阅读差异：相对 TGPP 和动态 CKM，本篇新增的是从地图误差到任务风险的 value-of-information 闭环；相对一般 ensemble uncertainty，它对冗余链路做 sequential conditioning，并将 channel acquisition 与 policy-trial selection 明确分层。
- 相对阅读笔记的位置：应用深化；面向 PASS/低空 UAV 控制的系统出口。
- 官方页：https://arxiv.org/abs/2608.20126
- PDF：https://arxiv.org/pdf/2608.20126
- 代码状态：未发现公开代码。论文页、全文、作者线索以及题名/arXiv ID 精确检索未定位可核验实现。
- 推荐理由：它把 CKM 的评价从“地图是否准确”推进到“误差是否改变控制决策”，可用于重构现有实验的任务加权采样和下游指标，但不应替代 CKM 生成先验本身。

## 3. RadioVIL: Anomaly-Aware Diffusion Models for Radio Map Inpainting and Zero-Shot Vehicle Localization

- 作者：Ruixin Zhao, Xiucheng Wang, Qiming Zhang, Nan Cheng, Ruijin Sun, Conghao Zhou
- 年份/venue：2026，IEEE GLOBECOM 2026 Wireless Communications Symposium 已接收
- 方向：扩散先验、radio map inpainting、稀疏物理逆问题、零样本车辆定位、ISAC
- 问题：普通 MSE/GAN/扩散补全倾向于语义和谐与过度平滑，会抹掉隐藏车辆造成的高频散射异常；因此地图看起来更平滑，却失去感知目标。
- 方法：先训练冻结 DDPM 表示静态环境传播背景；推理时使用 DMILO，在扩散中间层逐层优化带 L1 正则的稀疏偏差变量，把不能被平滑先验解释的车辆散射从背景中分离，再用 connected-component analysis 进行无车辆标签的定位。
- 关键结果：RadioMapSeer 上 LPIPS 为 0.0587；隐藏车辆 Recall 75.20%、F1 0.6799、平均定位误差 3.31 m。RePaint 的 Recall 仅 11.44%。建筑数超过 30 时 F1 仍为 0.681；50–800 m 传输距离上表现较稳定。
- 局限：仅 6 页会议论文，使用 RadioMapSeer 合成数据；输入保留静态设施、BS 坐标、绿化带附近单像素观测带以及 5%–10% 自由空间随机像素，和当前城市 Sheet2 的实际模态并不等价。它仍需要外层扩散过程和内层优化，未报告面向实时 ISAC 的完整 NFE/时延/显存权衡。
- 迁移类型：可改造工具。可以把 CKM/SRF 输出定义为平滑背景，把稀疏偏差定义为动态 blocker/scatterer 或测量异常；必须与普通 diffusion inpainting 做独立对照。
- 与既有阅读差异：相对 RadioDiff/普通扩散补全，本篇不是再次证明扩散能补图，而是显式引入“背景先验 + 稀疏物理异常”的可解释分解；相对 Robust-CKMSRF，它关注动态异常留存，不是条件模态缺失/噪声。
- 相对阅读笔记的位置：核心生成/逆问题深化；同时连接 ISAC 应用。
- 官方页：https://arxiv.org/abs/2608.16167
- PDF：https://arxiv.org/pdf/2608.16167
- 代码状态：未发现公开代码。arXiv/全文无仓库链接；作者与题名/arXiv ID 精确检索未发现可核验论文实现。
- 推荐理由：它提供一个对当前 PnP/生成先验很有价值的独立维度：不是让先验吸收所有结构，而是给观测不一致保留稀疏物理解释变量。

## 4. CSI RefineNet: A Soft Data-Aided Iterative Receiver for High-Mobility OFDM Systems

- 作者：Yirui Luo, Yihang Xie, Yao Ge, Yong Liang Guan, David González G.
- 年份/venue：2026，arXiv 预印本；正式 venue/DOI 待核验
- 方向：高速移动 OFDM、软数据辅助信道估计、迭代接收机、pilot consistency
- 问题：高速移动下，导频子载波得到的 CSI 与数据子载波的有效信道不一致；只依赖稀疏导频会留下严重 ICI 与时间变化误差。
- 方法：第一遍用 PilotCE 得到粗 CSI，并通过均衡与检测得到符号 posterior；随后把 soft symbol posterior 转成全子载波的数据辅助观测，与初始 CSI 融合后由 RefineNet 修正，再反馈到均衡/检测，形成两遍闭环。训练采用先稳定 pilot-driven detector、再展开完整闭环的两阶段策略。
- 关键结果：3GPP CDL-C、24 clusters、4 taps、15 kHz 子载波间隔、默认 200 km/h、pilot spacing=4 下，论文报告不同速度、调制阶数和 pilot spacing 上 BER 均优于对照。复杂度为 34.1M FLOPs、4.2 MB，低于 DeepRx 的 37.8M FLOPs、5.0 MB，并优于其 BER。
- 局限：仍是仿真 CDL-C 与固定两遍展开；soft decision 错误可能形成误差传播。论文主指标为 BER，不能直接替代 CKM-SRF 的 NMSE 和归一化测量残差；也未覆盖完整真实硬件/跨场景校准。
- 迁移类型：可直接复现思想/可改造工具。可将 soft posterior 形成的伪导频观测作为 PnP 数据一致性更新，而不是把检测网络整体迁入当前模型。
- 与既有阅读差异：相对 D-GESBL 的 soft pseudo-pilot，本篇提供端到端两遍 Transformer receiver、明确两阶段训练和 FLOPs/内存对照；相对 FlowADMM，它是 receiver-level feedback loop，而不是生成先验求解器。
- 相对阅读笔记的位置：高速移动与导频后验修正缺口。
- 官方页：https://arxiv.org/abs/2607.23691
- PDF：https://arxiv.org/pdf/2607.23691
- 代码状态：未发现公开代码。作者 GitHub 为空或无相关仓库，题名/arXiv ID 精确检索亦无结果。
- 推荐理由：它是今天最直接可落入现有 MIMO/OFDM 实验的闭环模块，但应作为独立“软数据辅助”分支，与 PnP/CM/Flow 主线共享初始化和 test protocol。

## 5. Temporal Channel Estimation for Generalized CSI Feedback

- 作者：Minwoo Kim, Hyeonsu Lyu, Sehyun Ryu, Sojeong Park, Hyun Jong Yang
- 年份/venue：2026，arXiv 预印本；论文标注 submitted to IEEE transaction，具体 venue 待核验
- 方向：FDD massive MIMO CSI feedback、连续时延、off-grid、one-shot、跨环境泛化
- 问题：OMP 等压缩感知方法迭代慢且受离散 delay grid mismatch 影响；常规 DL 压缩器又把阵列尺寸和场景统计写死在网络中，难以跨阵列/跨环境部署。
- 方法：TAP 用轻量 1D network 从多个时间 CSI 快照中预测主径，并通过可微 sub-grid center-of-mass extractor 得到连续 fractional delays；共享连续 Fourier dictionary 后只做一次正则 LS 幅度估计。深度可分离卷积和天线平均使参数量不随 BS 天线数增长，BS 侧可用简单 IFFT 重构。
- 关键结果：五种 3GPP/Sionna RT/DeepMIMO 环境上，相对 CsiNet 的 CFR-NMSE 改善 3.13–12.22 dB；模型小于 1 MB、比文中 CsiNet 小 660 倍，推理比迭代 OMP 快约 2700 倍，并满足亚毫秒目标。1×32 ULA 表中不同训练环境的 mean CFR-NMSE 为 −25.88 至 −37.01 dB，而 CsiNet-UPA 为 −15.54 dB。
- 局限：当前连续时延字典基于 far-field 和共享空间 delay 假设，尚未覆盖 near-field、FR2 hybrid beamforming 和真实 OTA 验证；zero-shot 结论主要来自仿真域。它解决 CSI feedback/compression，不等同于导频稀疏 MIMO CE。
- 迁移类型：可改造工具/低时延基线。最合适的接口是把连续 delay support 作为 CKM/geometry-to-PSD 的可解释条件或初始化，而不是替换 PnP 后验恢复。
- 与既有阅读差异：相对 Anchor-CKM 的空间 Fourier refinement，本篇解决时间序列中的连续 off-grid delay；相对 PilotWiMAE/Transformer CSI 方法，新增固定大小、decoder-free 和跨阵列结构泛化，而不是纯 token 建模。
- 相对阅读笔记的位置：方法缺口与工程基线；补足 off-grid delay、跨环境和低时延维度。
- 官方页：https://arxiv.org/abs/2608.01713
- PDF：https://arxiv.org/pdf/2608.01713
- 代码状态：未发现公开代码。论文/作者 GitHub 未给出实现，精确题名/arXiv ID 检索无结果。
- 推荐理由：它和当前 WCM 高移动/off-grid delay 主线直接相连，且提供参数量、推理时延、跨环境和完整 CFR-NMSE，而不是只给 patch NMSE。

## 组合逻辑与为何不重复

1. PU-HNO 解决“环境与低保真射线怎样变成高保真无线场先验”。
2. RadioVIL 解决“稀疏观测下如何让生成先验保留动态物理异常”。
3. CSI RefineNet 解决“导频之后怎样用软数据形成观测闭环”。
4. TAP 解决“怎样用连续物理参数获得低时延、跨环境的 CSI 表达”。
5. RMWorld 解决“地图/信道误差怎样进入 UAV 通信控制与采样预算”。

因此没有把五篇都包装成 CKM 生成模型：两篇是环境/生成先验，两篇是 CSI 获取与修正，一篇是系统级任务风险闭环。RadioVIL 虽然使用 DDPM，但其独立贡献是稀疏异常分解；不是普通 WiFi diffusion 的重复推荐。

## 优先精读

1. **PU-HNO**：优先看输入表示、三阶段残差算子、材料语义消融、标签噪声假设和 OOD 场景。它最适合作为 geometry-to-PSD/CKM 精化的独立分支。
2. **RadioVIL**：优先看 DMILO 的优化变量、L1 稀疏偏差、mask 构造和扩散中间层接口。它最接近“生成先验 + 可解释观测异常”的 PnP 思路。

若近期工作重点转向高速移动接收机，则把 CSI RefineNet 提升为第二优先；它比 RMWorld 更容易直接进入现有导频实验。

## 可执行 MVP 实验

### MVP-A：Physics-Unrolled CKM/PSD 精化分支

- 输入：低保真 CKM/射线图、有效观测 mask、距离/LoS/障碍物/材料 proxy、坐标 Fourier features。
- 模型：三个串联残差块分别对应 broad reflection、edge diffraction、fine scattering；每块输出一个残差与可选不确定性。
- 输出：先做 scalar pathloss 或 delay–beam PSD，暂不宣称复 CSI/MIMO 复现。
- 对照：相同初始化和数据划分下比较 U-Net/FNO、单体 SRF/GMFlow、三阶段 PU-HNO；分别去掉材料、mask、ray descriptors。
- 指标：NMSE/RMSE、5% tail error、outage F1、归一化测量残差、参数量、训练/推理时间、显存；增加 clean/corrupt 条件成对测试。
- 验收：至少在未见布局上同时改善平均误差与 outage/tail 指标，且增益不能只来自更大参数量。

### MVP-B：RadioVIL-style 稀疏异常后验分支

- 冻结现有 CKM/SRF 生成先验作为平滑背景；另设稀疏变量 `ν` 表示 blocker/scatterer 或观测异常。
- 优化目标：`pilot/measurement residual + λ||ν||_1 + prior consistency`，只在中间特征或少量 PnP 步上更新 `ν`。
- 对照：普通 diffusion/flow inpainting、只有观测一致性的 PnP、只有稀疏残差的传统 robust recovery。
- 指标：背景 NMSE、异常 support F1、定位误差、测量残差、NFE、每步时延、显存。
- 约束：不得与 PU-HNO 或 CSI RefineNet 堆叠后归因；若无真实车辆/动态 blocker 标注，只能做合成异常或压力测试，并明确数据边界。

### MVP-C：软伪导频闭环（独立替代实验）

- 第一遍使用共同 pilot/LS/PnP 初始化；只保留高置信 soft symbol posterior，构造带置信权重的伪导频观测。
- 第二遍更新 CSI，并记录伪导频正确率、测量残差、BER 与 NMSE 的联动。
- 设置置信阈值/温度消融，防止错误反馈；在相同速度、SNR、pilot spacing 和随机种子下对比一次与两次迭代。
- 该分支和 RadioVIL-style 稀疏异常分支互斥，避免把两个后验修正模块混合后失去归因。

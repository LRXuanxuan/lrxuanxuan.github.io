## 1. Multistep Consistency Models

- **作者**：Jonathan Heek, Emiel Hoogeboom, Tim Salimans
- **年份/来源**：2024，arXiv:2403.06807v3
- **研究位置**：CM 基础原理、Consistency Training（CT，一致性训练）、Consistency Distillation（CD，一致性蒸馏）、少步数质量—复杂度权衡
- **核心问题**：传统 CM 要在一次映射中跨越整条概率流 ODE 轨迹，训练困难；纯一步虽快，但质量常弱于多步扩散。
- **方法**：把轨迹划分为多个区间，每个区间学习局部一致性映射但共享网络参数，同时兼容 CT 与 CD；提出 aDDIM 以补偿 DDIM 的方差缺失。
- **关键结果与局限**：论文在 ImageNet-64/128 上报告 4 步 FID 1.6/2.3、8 步 FID 1.4/2.1。局限是 1–2 NFE 时对抗式方法仍可能更强，且没有复数信道、连续环境条件或测量一致性实验。
- **迁移到课题的接口**：将复数信道表示为实虚双通道或幅相/角时延张量，把现有 CM/DiT 的全轨迹损失改为分段一致性损失；保持同一导频数据步，比较 \(K=1,2,4,8\) 的 NMSE、pilot residual、achievable rate、NFE 和实测时延。
- **与既有阅读的关系**：这是对 PnP-CM 与 MIMO-CM 的训练层深化。新增维度是“分段 CT/CD + 可调 NFE”，不是再提出一个图像 PnP 算法。
- **可迁移性**：**仅作理论与训练设计启发**；需要自行完成信道条件化和复数网络实现。
- **代码状态**：未发现论文特定官方实现；可复用 OpenAI 原始 CM 基线，但不能把它视为本文的完整复现。
- **核验链接**：[arXiv](https://arxiv.org/abs/2403.06807)；[PDF](https://arxiv.org/pdf/2403.06807)；[原始 CM 基线](https://github.com/openai/consistency_models)

## 2. Consistency Posterior Sampling for Diverse Image Synthesis

- **作者**：Vishal Purohit, Matthew Repasky, Jianfeng Lu, Qiang Qiu, Yao Xie, Xiuyuan Cheng
- **年份/来源**：CVPR 2025, pp. 28327–28336；DOI: 10.1109/CVPR52734.2025.02638；arXiv:2410.02078 的正式会议版本
- **研究位置**：CM/蒸馏流生成先验、Langevin 后验采样、逆问题不确定性
- **核心问题**：多数生成式逆问题方法输出单个重建；若要获得多样后验样本，通常必须反复重启整条扩散链，开销大。
- **方法**：把 1–2 步 CM 或蒸馏流视为确定性噪声到数据映射 \(\Phi:z\mapsto x\)，在源噪声空间执行 Langevin 动力学：

  \[
  z_{k+1}=z_k-\tau\left(z_k+\nabla_z\mathcal L_y(\Phi(z_k))\right)+\sqrt{2\tau}\,\xi_k.
  \]

  先对测量损失 warm start，再连续产生后验样本，不必为每个样本重新运行完整生成链。
- **关键结果与局限**：在线性和非线性图像逆问题上，其重建质量与扩散基线相当，并提高后验样本多样性；实验显示较少 Langevin 步数即可稳定。主要开销是反向传播穿过 \(\Phi\) 及 warm start，且原文没有复数信道、导频或真实通信验证。
- **迁移到课题的接口**：设置

  \[
  \mathcal L_Y(H)=\frac{\|Y-\mathcal A(H)\|_F^2}{2\sigma_n^2},
  \]

  让条件 CM/Flow 建模 \(\Phi(z;r,e,M)\)，从而生成 \(p(H\mid Y,r,e,M)\) 的样本集合。除 NMSE 外，可评估 posterior coverage、beam-selection entropy、outage calibration 和 achievable-rate 分布。
- **与既有阅读的关系**：填补 PnP-CM、DPS/FlowDPS、Bayesian Flow Matching 之间的“多样后验与不确定性”缺口。它不是点估计式 PnP，而是在源空间保持生成先验并探索后验。
- **可迁移性**：**求解器可直接复现，信道算子需改造**。
- **代码状态**：完整作者官方 PyTorch 实现，含线性/非线性算子、1/多步 CM、fidelity/diversity 脚本与预训练模型说明。
- **核验链接**：[CVPR 页面](https://openaccess.thecvf.com/content/CVPR2025/html/Purohit_Consistency_Posterior_Sampling_for_Diverse_Image_Synthesis_CVPR_2025_paper.html)；[官方 PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Purohit_Consistency_Posterior_Sampling_for_Diverse_Image_Synthesis_CVPR_2025_paper.pdf)；[代码](https://github.com/Vishal-S-P/CPS_Diverse)；[arXiv 初版](https://arxiv.org/abs/2410.02078)

## 3. MACS: Measurement-Aware Consistency Sampling for Inverse Problems

- **作者**：Amirreza Tanevardi, Pooria Abbas Rad Moghadam, Seyed Mohammad Eshtehardian, Sajjad Amini, Babak Khalaj
- **年份/来源**：arXiv:2510.02208v3；初稿 2025，当前版更新于 2026-07-04
- **研究位置**：测量感知 CM、2 NFE 逆问题、数据一致性
- **核心问题**：少步 CM 虽然快，但标准随机更新没有利用前向算子和当前测量残差，容易生成感知自然却与观测不一致的结果。
- **方法**：在 aDDIM 更新中，用测量残差代替固定方差补偿项：

  \[
  r_k=\gamma\|y-\mathcal A(\hat x_k)\|_2^2,
  \]

  并令下一步随机性由 \(r_k\) 自适应控制。CM 与条件网络保持冻结，无需针对新采样器重训练。
- **关键结果与局限**：在 Fashion-MNIST 与 LSUN 的超分、修复和线性/非线性去模糊上，2 NFE 即获得最优或有竞争力的 FID/KID，并保持 PSNR/SSIM。局限是 \(\gamma\) 按任务经验调节，理论论证主要针对线性算子，未覆盖复数 MIMO、不同导频长度与跨 SNR 泛化。
- **迁移到课题的接口**：在标准模式使用 \(\mathcal A_P(H)=HP\)，CFO/ICI 模式使用现有 `ckmsrf_apply_operator`；建议把残差归一化为

  \[
  \tilde r=\frac{\|Y-\mathcal A(H)\|_F^2}{m\sigma_n^2+\epsilon},
  \]

  并令 \(\gamma\) 依赖 SNR、导频比例和算子谱范数，避免跨观测配置时尺度漂移。
- **与既有阅读的关系**：这是对 PnP-CM 的深化而非重复。新增维度是把数据一致性写入 CM 自身的随机更新幅度，而不是在外层 ADMM/PGD 中另做投影。
- **可迁移性**：**可直接改造成两步导频后验校正模块**，但代码需自行实现。
- **代码状态**：未发现论文特定公开代码；已检查 arXiv/PDF、作者检索和 GitHub 标题检索。
- **核验链接**：[arXiv](https://arxiv.org/abs/2510.02208)；[PDF](https://arxiv.org/pdf/2510.02208)

## 4. UrbanMIMOMap: A Ray-Traced MIMO CSI Dataset with Precoding-Aware Maps and Benchmarks

- **作者**：Honggang Jia, Xiucheng Wang, Nan Cheng, Ruijin Sun, Changle Li
- **年份/来源**：IEEE GLOBECOM 2025；arXiv:2509.06270
- **研究位置**：CKM/WCM 数据、射线追踪、复数 MIMO CSI、precoding-aware map
- **核心问题**：公开 radio-map 数据多为 SISO 路损/RSS，不能支撑阵列相关性、beamforming、capacity 或生成式 MIMO 信道先验。
- **方法与数据**：用真实地理场景、WinProp Dominant Path Model（DPM）和阵列响应生成 4×4 复数信道矩阵 \(H\)。官方仓库说明数据含 350 个场景、每场景 120 个收发配置，并提供 C++ 数据生成、Python/RadioUNet 基线、样例和完整数据下载入口。
- **关键结果与局限**：论文给出基于环境图、发射机位置和方位编码的 RadioUNet 基线，证明数据可用于预编码感知地图生成。局限是默认 4×4、DPM 对多径作简化；完整数据主要通过外链分发，路径级 DoA/DoD 标签的公开完备性仍需单独核验，不能直接假定它补齐所有角度监督。
- **迁移到课题的接口**：将复数 \(H\) 映射为角域/波束特征并合成 \(Y=HP+N\)，形成 CKM 条件 CM/Flow 的外部测试集；可与现有 64×16 CKM-SRF 生成器做“同模型、不同数据源”泛化实验。
- **与既有阅读的关系**：相对 CKMImageNet、RadioDiff 和 OpenPathNet，新增的是完整复数 MIMO 矩阵、阵列/预编码感知指标和可运行的城市数据生成链，不是另一套标量路损图。
- **可迁移性**：**可直接改造成数据/仿真工具与外部基准**。
- **代码状态**：完整官方代码与数据入口；GitHub 含核心 C++/Python 实现和样例，完整代码及 350-map 数据由 OneDrive/百度网盘提供。
- **核验链接**：[arXiv](https://arxiv.org/abs/2509.06270)；[PDF](https://arxiv.org/pdf/2509.06270)；[代码与数据](https://github.com/UNIC-Lab/UrbanMIMOMap)

## 5. QuaMoE-DRF: Proactive Beam and Rate Adaptation via Multimodal Dynamic Radio Map Forecasting in ISAC Networks

- **作者**：Zhihan Zeng, Kaihe Wang, Zhongpei Zhang, Chongwen Huang
- **年份/来源**：2026，arXiv:2607.00974v1
- **研究位置**：动态 CKM/RM、缺失模态、质量感知 Mixture-of-Experts（MoE，专家混合）、ISAC beam/rate adaptation
- **核心问题**：静态 CKM 无法刻画短时动态阻塞；简单拼接多模态又无法处理事件缺失、感知噪声、历史 CSI 过期等异方差可靠性变化。
- **方法**：预测未来 beam-SINR field，融合静态几何、事件式运动、结构化感知状态和无线历史；质量向量控制稀疏 MoE 路由，理论动机是异方差条件下的逆方差加权。下游联合预测 BS、beam、MCS、goodput 和 outage。
- **关键结果与局限**：仿真测试报告 402.5 Mbps effective rate、0.0417 outage、0.1836 map RMSE；去掉质量向量后 outage 从 0.0417 升至 0.0530。事件/历史完全丢失和感知噪声压力测试仍保持较好性能。局限是标签来自紧凑 blockage/path-loss 模拟器，Sionna RT 只用于 600 条链路校准，尚无真实多模态、完整射线追踪或跨城市验证。
- **迁移到课题的接口**：为每个条件模态增加 `mask + confidence + age`，分别编码坐标、环境图、AoA/AoD、CKM/历史观测，再由质量感知 gating 融合；生成器仍可用 DiT/CM/Flow，下游损失增加 effective rate、outage、tied-beam accuracy，而不只优化地图 NMSE。
- **与既有阅读的关系**：直接填补 Sheet2 的模态不完整问题，并把 CKM 从地图重建推到系统决策。它不是生成式核心方法，应定位为条件编码与系统损失的应用/结构基线。
- **可迁移性**：**可改造成条件融合与下游损失模块**；当前不可直接复现完整结果。
- **代码状态**：未发现论文特定公开代码；已检查 arXiv/PDF、作者检索和 GitHub 标题检索。
- **核验链接**：[arXiv](https://arxiv.org/abs/2607.00974)；[PDF](https://arxiv.org/pdf/2607.00974)

## 优先精读顺序

1. **MACS**：与导频残差和当前 CKM-SRF 前向算子接口最直接，可立即形成“两步 CM + 观测一致性”实验。
2. **UrbanMIMOMap**：最适合马上下载并建立外部复数 MIMO 数据基准，验证现有模型是否只记住内部生成器。
3. **Consistency Posterior Sampling**：若论文需要不确定性或后验多样性，这是比单点 NMSE 更有理论价值的扩展。

## 下一步实验切入点

### 最小可行版本：MACS-SRF-2step

1. 在现有 CKM-SRF 数据上训练/蒸馏角域 CM，先不加入复杂环境条件。
2. 复用 `Y=HP+N` 与现有伴随算子，把 MACS 残差替换为归一化 pilot residual。
3. 固定 2 NFE，与 PnP-CM、SRF、无残差 Multistep CM 比较。
4. 指标：`NMSE_total`、`NMSE_null`、pilot residual、achievable rate、NFE、GPU wall-clock latency。
5. 验收标准：在相同 2 NFE 下，至少不牺牲 pilot residual；跨 SNR/导频比例时不依赖逐配置重新调 \(\gamma\)。

### 进阶版本：CM 后验集合 + 缺失模态条件

1. 用 CPS 在 CM 源空间生成 8–16 个 \(H\) 后验样本。
2. 将 QuaMoE 的 `mask + confidence + age` 机制用于坐标、环境图、AoA/AoD 与历史 CSI。
3. 在 UrbanMIMOMap 与现有城市库上人为制造模态缺失，评估 posterior coverage、beam outage、effective rate 与跨场景退化。
4. 风险：UrbanMIMOMap 未必提供完整路径级角度标签；先以复数 \(H\) 和环境图为共同监督，AoA/AoD 只作为可派生或待核验辅助量。

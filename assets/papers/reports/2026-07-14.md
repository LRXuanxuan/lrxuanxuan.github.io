今天的 5 篇围绕一条完整研究链路组织：

\[
\text{条件信道分布 }p(H\mid r,e,M,Y,A)
\rightarrow \text{少步数生成先验}
\rightarrow \text{观测/导频一致性后验修正}
\rightarrow \text{移动采样与跨基站 CKM}
\rightarrow \text{逐径物理数据生成}
\]

- **核心求解方法**：PnP-CM 给出“一致性模型（Consistency Model, CM）作为近端先验 + ADMM 数据一致性”的通用实现；Transformer 条件流匹配则直接学习可变观测集合下的后验分布。
- **无线地图/条件机制**：TGPP 显式建模移动轨迹导致的非均匀观测风险；BS-1-to-N 用位置嵌入与 cross/self-attention 处理任意数量源/目标基站。

## 1. PnP-CM: Consistency Models as Plug-and-Play Priors for Inverse Problems

- **作者**：Merve Gülle, Junno Yun, Yaşar Utku Alçalar, Mehmet Akçakaya
- **年份/状态**：CVPR 2026；arXiv:2509.22736v2
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2509.22736)；[PDF](https://arxiv.org/pdf/2509.22736)；[作者官方代码](https://github.com/MerveGulle/PnP-CM)
- **核心问题**：现有 CM 逆问题求解器往往需要任务特定训练，或数据保真步骤收敛慢，难扩展到大规模及非线性观测。
- **方法**：将 CM 重新解释为先验的近端算子，嵌入 PnP-ADMM；以噪声扰动和动量更新强化低 NFE（neural function evaluations，网络调用次数）区域的性能。官方实现覆盖去模糊、修补、超分辨、JPEG、相位恢复与 fastMRI，并提供多个预训练 CM。
- **关键结果与局限**：论文报告 4 NFE 即可获得高质量恢复，2 步已有有意义结果。局限是实验域仍为图像/MRI；迁移到复数 MIMO 信道时，需要重新训练角域或时延-角域 CM，并验证不同导频矩阵、SNR 和信道分布下的调度稳定性。
- **与用户课题的关系**：这是 7 月 13 日 MIMO PnP-CM 应用论文背后的更通用方法锚点。可令数据一致性子问题使用导频模型 \(Y=AH+N\)，CM 负责信道先验；它比“把扩散模型直接换成 CM”更有价值，因为给出了通用 PnP-ADMM、非线性扩展和可运行代码。
- **为什么不是重复**：阅读笔记已有 PnP-ADMM、DPS、PNPFlow 与 MIMO 版 PnP-CM，但没有这篇 CVPR 2026 的通用 CM 近端解释和官方完整实现。定位为**对既有方向的深化/核心方法补全**。
- **代码状态**：**完整作者官方实现**。仓库含任务配置、PnP-CM 主体、多个观测算子、预训练模型说明和可执行评估脚本。

## 2. Bayesian Inverse Problems Meet Flow Matching: Efficient and Flexible Inference via Transformers

- **作者**：Daniil Sherki, Ivan Oseledets, Ekaterina Muravleva
- **年份/状态**：2025，arXiv:2503.01375v2；OpenReview 记录为 TPM 2025
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2503.01375)；[PDF](https://arxiv.org/pdf/2503.01375)；[作者代码](https://github.com/FlowMatchingInverseProblems/Bayesian-Inverse-Meet-FM)
- **核心问题**：传统 MCMC 在高维逆问题中需要大量前向求解；固定观测维度的条件网络又难适应导频数或传感器数变化。
- **方法**：用 Transformer 编码可变数量的观测 token，并以 Conditional Flow Matching（条件流匹配，CFM）直接学习从简单源分布到参数后验的条件概率路径。
- **关键结果与局限**：论文在非线性模型、SEIR 和二维 Darcy 流上报告相对参数恢复误差最低约 1.5%，CPU 推断相对 MCMC 最多加速约 2000 倍。数值不能直接外推到大规模 MIMO；其训练依赖由前向模型生成的配对样本，分布外信道与观测算子变化仍需验证。
- **与用户课题的关系**：可以把每个 \((a_i,y_i)\) 导频/观测对作为 token，学习 \(p(H\mid Y,A,e,M)\)，自然支持可变导频数；也可作为 SRF/GMFlow 的后验初始化器，再用 PnP 数据一致性修正。
- **为什么不是重复**：阅读笔记已有 FlowDPS、Flower、PNPFlow 与 MIMO flow prior，但它新增了**可变观测集合 Transformer + 直接条件后验流**，不是沿无条件先验轨迹做梯度引导。定位为**填补条件后验表征缺口**。
- **代码状态**：**完整作者实验实现**。仓库分别提供非线性、SEIR、PDE 三套数据生成、训练、MCMC 对照与评估脚本；未提供无线信道适配。

## 3. TGPP: Trajectory-Guided Plug-and-Play Priors for Sparse Radio Map Reconstruction

- **作者**：Jiawen Zhang, Zhiyuan Jiang, Sheng Zhou, Zhisheng Niu
- **年份/状态**：2026，arXiv:2605.05844v1
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2605.05844)；[PDF](https://arxiv.org/pdf/2605.05844)
- **核心问题**：真实无线测量常沿车辆/UAV 轨迹采集，而非均匀随机采样；远离轨迹或被遮挡区域的约束明显更弱。
- **方法**：TGPP 学习显式输入空间风险图与隐式引导特征，可插接到确定性、GAN、图网络与 latent flow 等骨干；论文同时提出 RadioFlow-LDM 作为潜空间 flow-matching 生成骨干，并加入观测一致性监督。
- **关键结果与局限**：在 RadioMapSeer 的 5 种轨迹采样率上，相对相应无 TGPP 骨干最高报告 43.1% NMSE 降低。当前仅为 v1，主要验证单一基准与预设轨迹；尚不能证明跨城市、真实车载测量或 AoA/AoD 多任务下同样有效。
- **与用户课题的关系**：可把高速场景中车辆轨迹、导频采样掩码、距离轨迹的风险图接入 CKM-aware SRF；显式风险图适合作为 posterior correction 的空间权重，隐式特征可通过 FiLM/cross-attention 注入 flow/DiT。
- **为什么不是重复**：不同于 RadioDiff/WiFi-Diffusion 的“稀疏图像补全”，TGPP 新增的是**移动采样几何与空间异方差风险先验**，并验证跨多类骨干的 PnP 可插接性。定位为**填补高速移动测量机制缺口**。
- **代码状态**：**未发现公开代码**。已核查 arXiv 页面、PDF 和 GitHub 仓库检索；未找到与论文对应的作者仓库。

## 4. BS-1-to-N: Diffusion-Based Environment-Aware Cross-BS Channel Knowledge Map Generation for Cell-Free Networks

- **作者**：Zhuoyin Dai, Di Wu, Yong Zeng, Xiaoli Xu, Xinyi Wang, Zesong Fei
- **年份/状态**：2025，arXiv:2507.23236v1
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2507.23236)；[PDF](https://arxiv.org/pdf/2507.23236)
- **核心问题**：逐个基站采集 CKM 代价高，固定输入/输出结构也难适应 cell-free 网络中不断变化的源/目标基站数量。
- **方法**：以源 CKM、源/目标 BS 坐标为控制条件；BS location embedding（BSLE）编码连续位置，cross-attention 学习源—目标关系，self-attention 建模多个目标之间的依赖，从而支持任意数量源/目标 BS 的并行 CKM 推断。
- **关键结果与局限**：论文给出多基准比较及 BS 部署优化用例。其关键假设是同一区域的不同 BS 共享环境结构；尚未证明跨城市、缺少环境图或角度监督不齐全时仍可泛化，且多步扩散的时延仍值得与 flow/CM 比较。
- **与用户课题的关系**：它与 BeamCKMDiff 的连续波束 adaLN 形成互补：后者解决连续波束条件，本文解决**连续 BS 位置 + 可变数量 CKM 集合条件**。可迁移为 set-to-set 条件编码器，再接 SRF/CM 做快速生成或导频一致性校正。
- **为什么不是重复**：阅读笔记已有 Cross-AP CKM inference，但本工作新增任意源/目标数量、位置嵌入与 cross/self-attention 的生成式多视角建模。定位为**对跨 AP/BS 推断的深化与缺失条件补全思路**，不是普通 diffusion 基线。
- **代码状态**：**未发现公开代码**。已核查 arXiv 页面、PDF 和 GitHub 仓库检索；未找到与论文对应的作者实现。

## 5. OpenPathNet: An Open-Source RF Multipath Data Generator for AI-Driven Wireless Systems

- **作者**：Lizhou Liu, Xiaohui Chen, Wenyi Zhang
- **年份/状态**：arXiv:2512.17286v2（2025/2026 修订）；作者仓库注明已接收 IEEE VTC2026-Spring
- **一手来源**：[arXiv 摘要](https://arxiv.org/abs/2512.17286)；[PDF](https://arxiv.org/pdf/2512.17286)；[官方代码与数据](https://github.com/liu-lz/OpenPathNet)
- **核心问题**：CKMImageNet 等图像化数据隐藏了逐径传播细节，难支撑角度、时延、波束与物理一致性研究；大规模跨城市 RT 数据生成又缺少可复现工具链。
- **方法**：从 OpenStreetMap 获取真实建筑，生成 3D 数字孪生场景，用 NVIDIA Sionna RT 批量仿真，并输出逐径增益、ToA 与空间角度；仓库支持 30+ 城市配置、CPU/单 GPU/多 GPU、CSV/Pickle/NPY（DeepMIMO 风格）输出，并发布数据集和示例场景。
- **关键结果与局限**：其核心价值是可复现、可扩展的物理数据，而不是新的端到端估计器。主要局限是仿真到真实域差距、材质/几何误差以及对 Sionna 0.19.2 生态的依赖；使用前应做实测校准和 Sim2Real 压力测试。
- **与用户课题的关系**：可为现有“坐标但无 AoA/AoD”的城市补充逐径角度与 ToA，也可为“有 AoA/AoD 但缺坐标条件”的数据重新生成统一元数据；但必须在同一场景/链路标识下严格对齐，不能把不同来源直接拼成监督对。
- **为什么不是重复**：相比 7 月 13 日 CSRD2025 偏频谱感知与 RF 损伤，OpenPathNet 面向**逐径信道建模**，直接输出 gain/ToA/angle，并提供跨城市 OSM→RT→数据全链路。定位为**可改造成 SRF/CKM 数据与仿真工具**，不是现成 CSI 生成器。
- **代码状态**：**完整作者官方代码与公开数据**。仓库包含场景生成、Sionna RT、批处理、配置、示例数据、日志和多种导出格式。

## 精读优先级

1. **优先精读 PnP-CM**：直接抽取其 ADMM 更新、CM 噪声层级、动量与 NFE 调度，最适合改造成 MIMO 导频逆问题基线。
2. **随后精读 TGPP**：把轨迹采样风险图接入现有 SRF/GMFlow，能形成“高速移动采样几何 + 生成先验 + 数据一致性”的清晰论文增量。

## 最小可行复现实验

### MVP-A：PnP-CM → MIMO 导频恢复

1. 用现有角域信道训练一个小型 CM denoiser，先不加 CKM 条件。
2. 将 PnP-CM 中数据一致性项替换为 \(\|Y-AH\|_2^2\)；线性子问题使用闭式解或共轭梯度。
3. 与 RC-Flow、Null-Space Flow Matching、MIMO PnP-CM 预印本比较 NMSE、NFE、端到端时延和残差白化。
4. 再加入位置/环境条件，以 adaLN/FiLM 与 cross-attention 两种方式做消融。

### MVP-B：OpenPathNet → 缺失模态补全数据

1. 选 2 个现有坐标条件完整但无 AoA/AoD 的城市，生成少量对齐的 gain/ToA/AoA/AoD 样本。
2. 先验证 RT 输出坐标系、角度定义、天线方向和链路索引，再转换成现有 GMFlow/SRF 数据格式。
3. 用 BS-1-to-N 式位置 token + cross-attention 做多 BS 条件生成；缺失模态用 modality mask 明确标记，不做伪标签硬拼接。
4. 以跨城市留一法评估条件缺失、场景迁移和 Sim2Real 鲁棒性。

## 今日结论

今天最值得保留的不是某个“新 diffusion 名称”，而是三种可复用机制：

1. **CM 作为近端先验并与数据一致性闭环迭代**；
2. **可变观测/可变 BS 集合的 Transformer 条件后验建模**；
3. **轨迹风险、BS 位置和逐径物理量作为明确条件，而不是把所有环境信息压成一张无解释图像**。

## 1. Channel Knowledge Map Enabled Low-Complexity Dynamic Radio Environment Reconstruction

- 作者：Yujun Lin, Zhiqiang Xiao, Hao Wu, Xiaoqiang Qiao, Fayu Wan, Tao Zhang；2026，arXiv:2608.17322。
- 问题/方法：把复增益、时延、AoD 等 path state information 存入 any-to-any CKM，与发射机位置、功率和方向图解耦；配置变化时只需 CKM 查询与前向叠加，无需重采目标地图。
- 结果：Etoile 仿真归一化 RMSE 0.0161、SSIM 0.9837，优于 U-Net 的 0.0472/0.7384；2–14 个发射机变化下仍保持最低 RMSE。
- 局限：依赖准确路径 CKM、已知发射配置及 28 GHz 射线追踪；CKM 建设成本、误差传播和实测动态环境未验证。
- 迁移：可改造工具/系统基线；相对 Dynamic CKM 综述和在线 GP，新增“路径 CKM—发射配置解耦—前向合成”。
- 链接：[arXiv](https://arxiv.org/abs/2608.17322)｜[PDF](https://arxiv.org/pdf/2608.17322)
- 代码：未发现公开代码。相对阅读笔记属于应用深化。

## 2. Zero-Shot Frequency Generalization for Radio Map Prediction via Cross-Attention Physics-Residual Learning

- 作者：Sajjad Hussain；2026，arXiv:2608.16194；标注 submitted to IEEE WCL，正式接收待核验。
- 问题/方法：在查询频率上先计算 free-space + single knife-edge prior，再学习 residual；环境流以 cross-attention 查询物理流，多尺度 gate 选择可信物理区域。
- 结果：150 个射线追踪场景；1.8/3.5/7/28 GHz 训练、10/60 GHz 留出。未见场景+频率 RMSE 降低 35.3%，60 GHz 外推降低 37.6%。
- 局限：仅合成 pathloss、固定栅格和少数频点；真实材料/遮挡误差与完整 leave-one-frequency-out 未验证。
- 迁移：可直接复现数据协议/可改造工具；不同于普通 frequency token，它先用查询频率解析先验吸收主尺度。
- 链接：[arXiv](https://arxiv.org/abs/2608.16194)｜[PDF](https://arxiv.org/pdf/2608.16194)｜[仓库](https://github.com/sajjadhussa1n/PRCA-Net)
- 代码：作者预告/部分代码。已有 loader、冻结 split、下载/校验脚本，但数据与 checkpoint 链接仍占位，未见模型训练代码。相对阅读笔记填补跨频泛化缺口。

## 3. Channel Map-Based Channel Estimation for Near-Field UM-MIMO with Movable Planar Arrays

- 作者：Shuaifei Chen, Cheng-Xiang Wang, Chen Huang, Qianze Yang, Xiping Wu, Yunfei Chen, El-Hadi M. Aggoune；2026，arXiv:2608.05520。
- 问题/方法：粗位置 + Fisher information 指导阵位估计 LoS；NLoS 采用 sketch-based RSLS 或由 scatterer-location map 构造 CM-RSLS；多用户加入 visibility region 与结构相似度导频分配。
- 结果：`N=1024, rank=10` 时 SA-RSLS 约 `1.8×10^5` 运算，相比完整 RSLS 的约 `1.1×10^9` 低三个数量级；CM-RSLS 复杂度为 `O(NL^2)`。
- 局限：仿真为主且依赖较准散射体地图；位置、scatterer 与 visibility map 误差的实测敏感性待核验。
- 迁移：理论启发/非生成式强基线；相对 GeoGS-CE/GeoPSD 新增 map-derived NLoS subspace、阵位设计和 pilot assignment。
- 链接：[arXiv](https://arxiv.org/abs/2608.05520)｜[PDF](https://arxiv.org/pdf/2608.05520)
- 代码：未发现公开代码。相对阅读笔记属于核心深化。

## 4. MultiPathFormer: Towards a Foundation Model for Multipath Wireless Propagation

- 作者：Blessed Guda, Kayley Sze, Carlee Joe-Wong；2026，arXiv:2608.05076。
- 问题/方法：将 Tx–Rx 链路表示为按功率排序的连续 path-token 序列，做 next-path prediction，并加入 Environmental RAG 与 first-path codebook。
- 结果：相对直接自回归基线，delay MAE 降低 38.7%、power MAE 降低 59.2%；下游为 5.57 m 定位误差、0.914 top-3 beam accuracy、0.994 LoS accuracy、0.561 CE NMSE。
- 局限：全部基于 DeepMIMO/射线追踪；RAG/codebook 提供额外先验，headline gain 不能完全归因于 path-token 预训练；实测不足。
- 迁移：理论启发/长期基线；相对 PilotWiMAE/CSI-MAE，把预训练对象换成 delay/angle/power/interaction 的可变长物理序列。
- 链接：[arXiv](https://arxiv.org/abs/2608.05076)｜[PDF](https://arxiv.org/pdf/2608.05076)
- 代码：未发现公开代码；第三方声称 checkpoint 已发布但无一手链接，故保守处理。相对阅读笔记属于表示缺口。

## 5. Hybrid-Domain Posterior Sampling for Inverse Problems via Latent Flow Matching

- 作者：Hongjie Wu, Yiping Xie, Jiancheng Lv；ACM MM 2026；DOI:10.1145/3767308.3835243；arXiv:2608.00537。
- 问题/方法：指出压缩 decoder 的秩亏 Jacobian 会使部分测量残差对 latent gradient 不可见；每个 flow timestep 依次做 latent anchor、pixel-space Langevin correction、decoder-inversion alignment、stochastic state update。
- 结果：三个数据集、五类线性逆问题相对最强基线 PSNR 提升超过 2 dB；优化式 alignment 比直接 encoder projection 在 inpainting 上提升 3.38 dB。
- 局限：验证对象是图像而非 CSI；多重内循环和约 24 GB 显存意味着低 NFE 不等于低时延。
- 迁移：可改造工具/求解器基线；相对 FlowADMM/PnP-Flow 新增 latent blind-subspace 解释和 measurement-domain correction→latent alignment 闭环。
- 链接：[arXiv](https://arxiv.org/abs/2608.00537)｜[PDF](https://arxiv.org/pdf/2608.00537)｜[DOI](https://doi.org/10.1145/3767308.3835243)｜[代码](https://github.com/74587887/HDPS)
- 代码：完整开源实现，含 sampler、five-task operators、solve/eval、依赖与样例。相对阅读笔记属于求解器深化。

## 为何不重复与精读顺序

五篇分别解决地图复用、跨频条件、直接 MIMO CE、传播表征和逆问题一致性，没有把普通 diffusion/MAE 再包装。优先精读：

1. **PRCA-Net（2608.16194）**：最容易成为独立 `frequency-aware physics residual + cross-attention` 分支。
2. **Channel Map-Based CE（2608.05520）**：最直接回答环境/地图先验如何进入 CE、导频分配和复杂度分析。

HDPS 第三顺位，重点看 measurement-domain correction 与 latent alignment，不照搬图像参数。

## 可执行 MVP（互斥归因）

### MVP-A：跨频 physics-residual CKM

- 在现有环境条件与 mask 上新增连续 `log(f/f0)`；构造简化 FSPL/距离/LoS 先验，网络只预测 CSI/PSD 或 pathloss residual。
- 冻结城市 split，并完整留出内插与外推频率。
- 对照：无频率、frequency token、prior+concat、prior+cross-attention。
- 报告 NMSE、地图 RMSE、归一化 measurement residual、参数量、训练/推理时延和显存。
- 不与 CAR-Flow source shift 或 Robust-CKMSRF corruption 同时开启。

### MVP-B：map-derived subspace CE

- 用现有 scatterer/blocker/DFT-PSD 生成 `Q_map`，先实现 fixed-array CM-RSLS；给出 oracle、perturbed、PSD-only 三档。
- 与 LS、LMMSE/RSLS、现有 PnP-ADMM 在相同 pilot、SNR、test split 下比较。
- 报告 NMSE、归一化 pilot residual、复杂度/时延与 map 误差敏感性。
- movable-array/Fisher 阵位设计留作进阶版本。

HDPS-style 分支只在存在明确 latent bottleneck 时做独立验证，并同时报告外层 NFE、Langevin/alignment 内循环、总时延、显存和测量残差。

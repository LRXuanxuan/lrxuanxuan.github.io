五篇不是同一类扩散/MAE 的重复迁移：它们分别改变**待估物理变量、条件融合接口、采样可辨识性、生成路径耦合、表征评价目标**。

## 1. RadioTrace: Transmitter-Aware Diffusion for Radio Map Estimation without Deployment-Time Fine-Tuning

- **作者**：Liu Yang, Qiang Li, Zhuo Cao, Weijie Xiong, Guomin Sun, Jingran Lin
- **年份/venue**：2026 arXiv；稿件标注 IEEE Transactions on Wireless Communications，正式录用与出版信息待核验
- **方向**：稀疏 RadioMap、未知发射机、冻结扩散先验、物理变量后验修正
- **问题**：稀疏 RSS 重建通常假设发射机位置已知；当 Tx 未知时，仅做地图级 measurement consistency 无法修正生成条件。
- **方法**：在冻结 RadioDiff 反向去噪内显式参数化 Tx 坐标；用 propagation-guided K-means 初始化，以稀疏观测残差更新 Tx，并用 incumbent best-anchor 抑制低噪声阶段振荡。
- **关键结果**：
  - RadioMapSeer 限制区域、1% 采样：NMSE 0.0174、SSIM 0.9518、PSNR 31.95 dB。
  - 0.05% 采样（约 33/65,536 个点）：SSIM 0.9087、PSNR 27.40 dB，Tx 平均定位误差仍由 41.28 m 降至 33.88 m。
  - 完整方法相对仅 PG-KMeans 的 RMSE 约低 25%；相对 PG-KMeans+Momentum GD 约低 10%。
- **局限**：使用约 137M 参数 U-Net 与 87M 条件网络，默认 100 步；主要输出 RSS 标量图，不能外推为完整 CIR、AoA/AoD 或 MIMO CSI；数据以 RadioMapSeer/BART-Lab 为主。
- **迁移类型**：**可直接复现 / 可改造工具**。
- **课题接口**：把 Tx/BS/粗几何或 CKM 条件 token 视为待估变量，与 \(H\) 或 PSD 在 PnP/CM 迭代中交替更新；这是比“固定 CKM 条件”更强的 posterior correction。
- **与既有阅读差异**：相对 RadioDiff-Inverse/LaPnP，独立增量是**观测同时更新地图和物理条件**，不是只把扩散先验作为正则项。
- **来源**：[arXiv](https://arxiv.org/abs/2607.20909)｜[PDF](https://arxiv.org/pdf/2607.20909)
- **代码状态**：**完整开源实现**；[YannLeo/RadioTrace](https://github.com/YannLeo/RadioTrace) 包含配置、PG-KMeans、Tx 更新、推理/评估、训练入口和 checkpoint 说明。
- **相对阅读笔记位置**：**深化**（CKM/RadioMap + PnP 后验闭环）。

## 2. A Foundation Model for Cross-Band CSI Reconstruction

- **作者**：Hongpu Zhang, Shu Sun, Ruifeng Gao, Tongjia Zhang, Feng Yang
- **年份/venue**：2026 IEEE/CIC ICCC Workshops（arXiv 元数据标注已接收）
- **方向**：跨频 CSI、低空多频段、稀疏噪声导频、pilot-guided cross-attention
- **问题**：不同频段的子载波、阵列规模和带宽不同，低频 CSI 不能直接映射到高频 CSI；目标频段仍需稀疏导频锚定。
- **方法**：将各频段变换到固定尺寸 power-angle-delay spectrum（PADS）；RF metadata 作为条件 prompt；目标导频 token 作为 query，通过 cross-attention 融合源频段结构；采用 pilot-densification 预训练和跨频监督微调。
- **关键结果**：
  - 六个频段对平均比最强 full-shot 基线改善 6.1 dB。
  - 未见配对 \(2.4\!\to\!40\) 与 \(3.5\!\to\!40\) GHz 均达到约 \(-27.0\) dB，领先全监督基线 7.5/7.1 dB。
  - 40.7M 参数；RTX 4090、batch 1 时约 9.6 ms、505 MB peak memory。
- **局限**：未见“频段对”并不等于未见“频段”，40 GHz 在其他训练配对中出现过；要求源/目标频段同步 CSI；使用 RT、3GPP、DeepMIMO 仿真数据，作者明确将实测多频段验证列为未来工作。
- **迁移类型**：**可改造工具**。
- **课题接口**：以 CKM/低频 CSI/PSD 为 source context，以目标 pilot/LS CSI 为 query；RF metadata、mask、SNR 作为连续条件 token，末端保留显式测量残差。
- **与既有阅读差异**：相对 PilotWiMAE 的单网格 masked pretraining，新增**异构频段统一表示、RF prompt、source–pilot cross-attention 和未见配对迁移**。
- **来源**：[arXiv](https://arxiv.org/abs/2607.22204)｜[PDF](https://arxiv.org/pdf/2607.22204)
- **代码状态**：**未发现公开代码**。论文只链接作者 [RT-Datasets](https://github.com/Zetahp/RT-Datasets)；未发现模型训练、权重或复现实代码。
- **相对阅读笔记位置**：**深化**（PilotWiMAE/条件 token → 多频段导频融合）。

## 3. Toward Alias-Free Channel Extrapolation in Upper Mid-Band Systems: A Spatial-Frequency-Temporal Tensor Learning Approach

- **作者**：Jiawei Zhuang, Hongwei Hou, Yafei Wang, Xinping Yi, Wenjin Wang, Jiangzhou Wang, Björn Ottersten
- **年份/venue**：2026 arXiv；仅标注已投稿 IEEE，正式 venue/DOI 待核验
- **方向**：FR3 massive MIMO、高移动、SFT/ADD、support-prior-assisted 去混叠
- **问题**：均匀导频抽取与天线端口选择会让不同 angle-delay-Doppler 分量在观测域不可区分，形成结构化 alias groups。
- **方法**：Tucker SFT 张量模型 + LS 得到的 alias-group 输入；TANN 用逐轴 attention 降低三维注意力复杂度，并用多尺度 CNN 生成 FiLM 式 support gate；以 SFT NMSE 与 ADD 频谱一致性联合训练。
- **关键结果**：
  - 在 20 dB、60 km/h、\((N_s,N_f)=(1,2)\) 时，SPA-TANN 在 UMa/UMi/RMa NLoS 分别达到 \(-16.87/-17.26/-18.21\) dB。
  - 较强抽取 \((2,4)\) 时仍达到 \(-9.05/-8.52/-13.29\) dB。
  - 论文报告可在相近精度下实现最高 8× 频域、4× 空域导频压缩，并对未见 90 km/h 与 20 GHz 更稳健。
- **局限**：30,000 个 QuaDRiGa/3GPP 样本；真实 support prior 的获取、偏差和缺失鲁棒性没有充分验证；轴向注意力仍不是轻量闭式求解器。
- **迁移类型**：**理论启发 / 可改造工具**。
- **课题接口**：把 GeoPSD/CKM 生成的 delay–beam PSD 或粗 support mask 注入去混叠模块；若无真实 AoA/AoD 标签，只能先用 DFT/合成 oracle 构造受控先验。
- **与既有阅读差异**：相对 GeoGS-CE 的“几何→PSD”，本篇补上“PSD/support→稀疏导频可辨识性与去混叠”的中间桥梁。
- **来源**：[arXiv](https://arxiv.org/abs/2607.24330)｜[PDF](https://arxiv.org/pdf/2607.24330)
- **代码状态**：**未发现公开代码**；论文、作者页及题名/arXiv ID 精确检索未找到作者仓库。
- **相对阅读笔记位置**：**缺口**（高移动多域外推与物理 alias 解释）。

## 4. Low-Latency Generative Semantic Communication via Channel-Realization Flow Matching

- **作者**：Fan Gao, Youzheng Wang, Zhijin Qin, Feifei Gao
- **年份/venue**：IEEE GLOBECOM 2026（arXiv 元数据标注已接收）
- **方向**：conditional Flow Matching、信道 realization coupling、低 NFE
- **问题**：独立端点耦合忽略真实 source–channel link，会造成条件 flow 的 train–test mismatch 和弯曲轨迹。
- **方法**：RC-BFM 从信道诱导的粗语义状态出发；RC-OT 仅在匹配的源图像/信道 realization 上构造 entropic coupling；两阶段训练后用 Euler 少步积分。
- **关键结果**：
  - FFHQ-64×64、10 dB AWGN、4 NFE：PSNR 31.58 dB、LPIPS 0.086、FID 22.3、156.4 ms/A800。
  - 同表中 200-NFE DiffCom 为 7,964 ms；RC-BFM 约快 50×，且 FID 更好。
  - NFE 从 1 增至 4 时 PSNR 上升，之后主要改善 LPIPS/FID，明确呈现复杂度—感知权衡。
- **局限**：图像语义通信、像素空间、AWGN/Rayleigh 仿真；并非 MIMO 信道估计，不能把 PSNR/FID 直接映射为 CSI NMSE。
- **迁移类型**：**理论启发 / 基线**。
- **课题接口**：用共同场景/信道 realization 约束 \(z\leftrightarrow H\) 或 observation-to-posterior pairing，比较独立耦合、CAR source shift 与 realization-coupled OT 的路径长度和 NFE–NMSE 曲线。
- **与既有阅读差异**：相对 CAR-Flow 的 source reparameterization、Site-cFM 的直线路径，本篇改变的是**训练配对/coupling**。
- **来源**：[arXiv](https://arxiv.org/abs/2607.24876)｜[PDF](https://arxiv.org/pdf/2607.24876)
- **代码状态**：**未发现公开代码**；全文无仓库，题名、RC-BFM 和 arXiv ID 精确检索未找到作者实现。
- **相对阅读笔记位置**：**理论深化**（条件路径设计与低 NFE）。

## 5. Beam-Response Contrastive Learning for Transmitter-Side MIMO CSI Representation

- **作者**：Sehyun Ryu, Yumin Kim, Minjae Lee, Hyun Jong Yang, John M. Cioffi
- **年份/venue**：2026 arXiv；稿件页标注 submitted to IEEE Transactions on Wireless Communications
- **方向**：自监督 CSI、Gram/beam-response、跨城市、波束管理
- **问题**：像素重构误差或通用 augmentation 不能保证 embedding 保留发射端波束/调度所需的物理相似性。
- **方法**：以逐子载波 \(R_f=H_f^{\mathrm H}H_f\) 构造 soft relational target；将归一化 Gram shape 与绝对 gain 分开度量，并与 instance contrastive/reconstruction loss 联合。
- **关键结果**：
  - 56 城训练、10 个未见城测试；2.5M 训练 CSI、0.55M 测试 CSI。
  - 仅 1% 下游标签时，AE+BRCL 的 beamforming gain ratio 比最强非 BRCL 基线高约 6.23%。
  - MU-MIMO user selection 的 top sum-rate ratio 为 98.97%；未来波束选择在 1% 标签下最高改善 9.74%。
- **局限**：射线追踪 CSI；默认约 10 km/h，未覆盖真正高速移动；优化目标偏发射端任务，不保证 CSI 元素级 NMSE 或测量一致性。
- **迁移类型**：**理论启发 / 可改造工具**。
- **课题接口**：将 beam-response consistency 用作生成模型的 auxiliary loss 或下游评估，检查“NMSE 相近但 beam utility 不同”的情况；不要替代 NMSE、测量残差和不确定性指标。
- **与既有阅读差异**：相对 PilotWiMAE/MAE 的重构预训练，BRCL 提供**任务对齐的物理相似度**；相对 CKM 工作则连接 PASS/beam selection。
- **来源**：[arXiv](https://arxiv.org/abs/2607.24872)｜[PDF](https://arxiv.org/pdf/2607.24872)
- **代码状态**：**未发现公开代码**；全文、作者页及题名/arXiv ID 精确检索未找到作者仓库。
- **相对阅读笔记位置**：**应用/评估缺口**（生成质量 → 波束与调度效用）。

## 为何不重复

- **RadioTrace vs 既有 RadioDiff**：更新未知 Tx 条件，而非仅换扩散架构。
- **Cross-Band CSI vs PilotWiMAE**：异构频段统一 PADS + source/pilot cross-attention，而非单一 \([N_r,N_{\text{pilot}}]\) 代理网格的 masked reconstruction。
- **SPA-TANN vs GeoGS-CE**：解决由导频抽取引起的可辨识性/alias 问题，是“几何→PSD”之后的后验恢复层。
- **RC-BFM vs CAR-Flow/Site-cFM**：修改物理 realization 下的 endpoint coupling，不是简单改 source distribution 或采样器。
- **BRCL vs 普通 MAE/contrastive**：相似度由发射端 Gram/beam response 定义，评价目标从像素一致转向系统效用。

## 可执行 MVP（保持互斥归因）

### MVP-A：Tx-aware CKM posterior correction

- **基线**：现有 CKM prior + PnP/CM，固定环境条件。
- **唯一改动**：新增可更新 Tx/BS 粗位置 token（或其 2D heatmap），每个外循环用观测残差更新一次；先用已知 Tx 加可控偏移模拟未知条件。
- **对照**：固定错误 Tx、仅 K-means 初始化、K-means+迭代更新、完整 best-anchor。
- **指标**：NMSE、normalized measurement residual、Tx error、PnP iterations/NFE、sampler-only latency、总时延和显存。
- **验收**：在相同 checkpoint/test split/SNR/mask 下，条件误差下降且 measurement residual 不恶化；不以 CPU smoke test 宣称性能增益。

### MVP-B：PADS source-context + pilot-query cross-attention

- **基线**：PilotWiMAE/random-init 与现有 CKM 条件编码器。
- **唯一改动**：将 CKM/低频 CSI/PSD 映射到统一 PADS token，目标 pilot/LS CSI 作为 query，RF metadata、SNR、mask 作为条件 token。
- **对照**：concat、FiLM、cross-attention；必须保留 PilotWiMAE random-init control。
- **指标**：NMSE、测量残差、跨频段/跨阵列/跨城市泛化、参数量、训练/推理时间、显存。
- **数据边界**：当前 Sheet2 没有任何城市同时具备完整坐标与 AoA/AoD 监督；MVP 不得写成全模态、全频段端到端复现。

两条 MVP 不同时叠加。先分别相对共同初始化基线验证，再决定是否进入更高阶组合。

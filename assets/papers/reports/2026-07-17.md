## 1. Site-Specific MIMO Channel Generation via Diffusion and Flow Matching: Fidelity, Efficiency, and Downstream Utility

**作者**：Sina Beyraghi, Masoud Sadeghian, Firdous Bin Ismail, Angel Lozano, Paul Almasan, Giovanni Geraci  
**年份/类型**：2026，arXiv 预印本  
**标识**：[arXiv:2606.20098](https://arxiv.org/abs/2606.20098)；[DOI: 10.48550/arXiv.2606.20098](https://doi.org/10.48550/arXiv.2606.20098)  
**PDF**：[官方 PDF](https://arxiv.org/pdf/2606.20098)  
**代码**：[Telefonica-Scientific-Research/GenAI_Channel_Modeling](https://github.com/Telefonica-Scientific-Research/GenAI_Channel_Modeling)  
**代码状态**：**完整作者官方实现**。仓库包含 cDDIM/cFMM 训练与推理、Sionna RT 数据生成、CSI compression、beam alignment、effective-rank 分析，以及公开模型/数据入口。

### 核心问题与方法

论文比较两类位置条件生成模型：conditional DDIM（cDDIM）与 conditional Flow Matching Model（cFMM）。二者都以用户坐标为连续条件，直接生成复数 MIMO 信道矩阵，目标不是只让样本“看起来像”，而是同时验证：

- 统计保真度：beam consistency、full beamspace coverage、effective rank；
- 生成效率：采样 latency；
- 下游效用：CSI compression 与 beam alignment 中的数据增强收益。

在 28 GHz、3.5 GHz 以及 LoS/NLoS 设置下，两种模型均能学习站点特定分布；cFMM 在相近质量下的推理时间约低一个数量级。论文也显示，有限真实样本加入生成信道后，下游性能优于只用少量真实数据或随机信道模型。

### 与用户课题的关系

- **可直接复现**：这是今日最接近当前 `p(H|r)` 主干的论文，且生成对象是复数 MIMO 信道而非 radio-map 图像。
- **具体迁移接口**：把坐标条件分支扩展为 `r + CKM/environment token + modality mask`，继续采用现有 FiLM/AdaGN；生成 `H_0` 后，再接现有 RC/PBG 或 PnP 导频一致性修正。
- **评价升级**：除 NMSE 外，引入 beam consistency、effective rank、pilot residual、NFE/latency 和下游 beam/CSI compression 指标。

### 为什么不是重复

**硬去重已排除；对既有方向的深化。** 昨日 MultiCE-Flow 更接近“多模态环境 + 稀疏导频的一步直接估计”；本篇增加的是“站点特定复数信道分布生成 + scarce-data augmentation + 通信结构与下游效用”。它也不是普通 WiFi diffusion 的场景迁移。

### 局限

当前条件主要是坐标，尚未显式加入地图/射线环境先验和导频观测；因此更适合先作为条件生成先验，再外接后验校正，而不是直接当成最终信道估计器。

## 2. Conditional flow matching for physics-constrained inverse problems with finite training data

**作者**：Agnimitra Dasgupta, Ali Fardisi, Mehrnegar Aminy, Brianna Binder, Bryan Shaddy, Saeed Moazami, Assad Oberai  
**年份/类型**：2026，arXiv 预印本（v3）  
**标识**：[arXiv:2603.14135](https://arxiv.org/abs/2603.14135)；[DOI: 10.48550/arXiv.2603.14135](https://doi.org/10.48550/arXiv.2603.14135)  
**PDF**：[官方 PDF](https://arxiv.org/pdf/2603.14135)  
**代码状态**：**未发现公开代码**。已检查论文页、正文中的资源入口、作者线索以及题名/arXiv ID 的 GitHub 检索。

### 核心问题与方法

论文将 conditional Flow Matching 用于 physics-constrained Bayesian inverse problems。网络学习 probability-flow ODE 的速度场，把选定的 source distribution 直接输运到观测条件后验：

\[
x_0\sim p_{\rm src}(x),\qquad x_1\sim p(x\mid y),\qquad
\frac{\mathrm d x_t}{\mathrm dt}=v_\theta(x_t,t,y).
\]

该 black-box 形式不要求显式计算 prior/likelihood density，可处理非线性、高维、甚至不可微的前向模型。更关键的是，论文专门分析有限训练数据：过训练会导致 posterior variance collapse 和 selective memorization；用验证/测试损失早停能够缓解。Lorenz-63、PDE inverse problem 与实验数据用于验证，source 可以是 Gaussian，也可以是 data-informed prior。

### 与用户课题的关系

- **理论与算法迁移**：令 `x=H`、`y=HP+n`，把 CKM/GMFlow 生成样本作为 data-informed source，比总从标准高斯出发更符合“先验生成—观测后验”的链路。
- **诊断指标迁移**：信道实验不能只看平均 NMSE；应同时跟踪后验方差、coverage/calibration、pilot residual 以及相近观测下的样本多样性，以识别 selective memorization。
- **工程边界**：若前向算子或仿真器不可微，本篇仍可训练 amortized posterior；但需要联合 `(H,Y)` 样本，和 PnP 在线迭代的适用场景不同。

### 为什么不是重复

**硬去重已排除；对既有 Bayesian inverse + FM 的深化。** 相比阅读笔记中的一般 Bayesian inverse Flow Matching，它独立增加了黑盒/不可微物理、data-informed source 以及有限数据后验坍缩机制；相比 PnPFlow/PCFM，它更偏 measurement-conditioned amortized posterior，而不是测试时插入数据一致性算子。

### 局限

没有无线信道实验和公开源码。迁移到 MIMO 时，必须实证复数表征、不同 SNR/导频率下的校准性和跨场景泛化，不能直接把 PDE 结论外推为无线收益。

## 3. F^4-CKM: Learning Channel Knowledge Map with Radio Frequency Radiance Field Rendering

**作者**：Kequan Zhou, Guangyi Zhang, Hanlei Li, Yunlong Cai, Shengli Liu, Guanding Yu  
**年份/期刊**：2026，IEEE Transactions on Communications  
**标识**：[DOI: 10.1109/TCOMM.2026.3668162](https://doi.org/10.1109/TCOMM.2026.3668162)；[arXiv:2601.03601](https://arxiv.org/abs/2601.03601)  
**PDF**：[官方预印本 PDF](https://arxiv.org/pdf/2601.03601)  
**代码**：[kqzzzz/F4CKM](https://github.com/kqzzzz/F4CKM)  
**代码状态**：**作者预告/部分代码**。仓库已有配置、训练、测试、评估和消融入口，但 README 明确表示完整版本将逐步上传；数据与预训练权重通过外部入口提供。

### 核心问题与方法

论文以 RF radiance field 的思路构建 WiRARE，用连续空间-频率场代替规则栅格上的 CKM 插值。关键机制包括空间/频率感知编码、shaping filter 和 angular sampling，使模型能够按查询位置与频率“渲染”信道。

论文在模拟室内场景和 Argos 真实测量上验证。其报告三个场景的中位 PSNR 约为 17.13–19.23 dB，多数样本的 SGCS 高于 0.976，并进一步用系统 spectral efficiency 检查信道重建的通信意义。

### 与用户课题的关系

- **可改造成条件编码器**：把 WiRARE 的局部连续场表征变成 SRF/GMFlow/DiT 的环境 token，而不是仅把离散城市标签或坐标拼到网络输入。
- **适配不完整模态**：当前数据不存在同一城市同时完整具备坐标与 AoA/AoD 监督。可以先学习空间-频率连续场，再按现有模态分别提供位置、角域或增益条件，避免强行全监督绑定。
- **后续组合**：`RF field prior -> conditional cFMM -> pilot/PnP correction`，对应完整的先验、生成与观测修正链路。

### 为什么不是重复

**硬去重已排除；填补研究缺口。** 不同于 RadioDiff/CKMImage 的栅格图像生成，本篇的独立维度是连续 RF 场渲染、频率泛化、角度采样和真实测量验证；也不同于只用位置坐标的普通神经场回归。

### 局限

仓库尚非完整公开版本，外部数据下载的可持续性也需复现前再检查。论文核心是场重建/渲染，并非观测条件后验采样器。

## 4. Radio Map Prediction from Noisy Environment Information and Sparse Observations

**作者**：Fabian Jaensch, Çağkan Yapar, Giuseppe Caire, Begüm Demir  
**年份/类型**：2026，arXiv 预印本  
**标识**：[arXiv:2602.11950](https://arxiv.org/abs/2602.11950)；[DOI: 10.48550/arXiv.2602.11950](https://doi.org/10.48550/arXiv.2602.11950)  
**PDF**：[官方 PDF](https://arxiv.org/pdf/2602.11950)  
**代码**：[fabja19/RML_indoor](https://github.com/fabja19/RML_indoor)；环境生成器 [WI_indoor_projects](https://github.com/fabja19/WI_indoor_projects)  
**数据**：[Zenodo record 18631406](https://zenodo.org/records/18631406)，[DOI: 10.5281/zenodo.18631406](https://doi.org/10.5281/zenodo.18631406)  
**代码状态**：**完整作者官方代码与公开数据**。包含环境生成、data loader、训练/测试、噪声严重度评估、基线、测量实验 notebook、检查点与 Wireless InSite 项目文件。

### 核心问题与方法

真实 radio map 部署中，环境几何、材料标签和发射机位置都可能有误差。论文把稀疏观测与 noisy environment information 联合输入 CNN，并在训练时施加任务化环境扰动（SNDA），使模型显式学习条件误差鲁棒性。

论文报告：在含噪仿真环境中，任务化增强相对基线最多降低约 25% 误差；真实测量 RMSE 为 2.1 dB，完整环境信息时为 1.3 dB。单房间设置下，二值 occupancy map 的表现不弱于详细材料标签，说明“条件是否可靠”可能比“条件是否丰富”更重要。

### 与用户课题的关系

- **可直接复现并改造**：这是当前 Sheet2 不完整条件事实的直接方法接口。对坐标、AoA/AoD 图和环境图分别加入 modality mask、位置偏差、结构缺失与语义扰动。
- **观测校正**：保留少量导频/测点作为数据一致性锚点，比较 `condition-only`、`sparse-observation-only` 与联合输入。
- **跨城市实验**：构建 `coordinate-only city -> angle-map-only city` 的 cross-city split，测试条件损坏是否改善迁移而非只改善同分布验证集。

### 为什么不是重复

**硬去重已排除；对环境辅助 CKM 的深化。** Anchor-CKM 关注非规则测点支撑稳定化，本篇独立增加环境先验有误、任务化条件扰动和真实测量 Sim2Real；二者可以组合，而非互相替代。

### 局限

输出主要是室内 pathloss/radio map，不是复数 MIMO CSI。向 CKMSRF 迁移时，应重新设计角域/时延域扰动，并检查二值环境结论是否仅适用于单房间设置。

## 5. Environment-Aware Channel Prediction for Vehicular Communications: A Multimodal Visual Feature Fusion Framework

**作者**：Xuejian Zhang, Ruisi He, Minseok Kim, Inocent Calist, Mi Yang, Ziyi Qi  
**年份/类型**：2026，arXiv 预印本；论文说明早期 path-loss 版本已录用 IEEE ICC 2026  
**标识**：[arXiv:2604.02396](https://arxiv.org/abs/2604.02396)；[DOI: 10.48550/arXiv.2604.02396](https://doi.org/10.48550/arXiv.2604.02396)  
**PDF**：[官方 PDF](https://arxiv.org/pdf/2604.02396)  
**代码状态**：**未发现公开代码或数据**。论文未给仓库/数据可用性入口；题名、作者与 arXiv ID 的 GitHub 检索也未找到对应发布。

### 核心问题与方法

论文面向高速 V2I 环境，从 GPS 与全景 RGB 提取位置、语义和深度三类视觉特征，通过 squeeze-and-excitation（SE）attention 融合，并联合预测 path loss（PL）、delay spread（DS）、arrival/departure angular spread（ASA/ASD）以及 360 维 angular power spectrum（APS）。

在 926 个真实同步样本上，最佳三模态模型报告 3.26 dB PL RMSE、37.66 ns DS RMSE、5.05° ASA RMSE、5.08° ASD RMSE，以及 0.9342 的 APS 平均余弦相似度。一个值得保留的负结果是：去除动态散射体可改善角域预测与收敛，但会损害 PL/DS，说明环境预处理必须按任务设计。

### 与用户课题的关系

- **应用/系统验证**：把语义、深度、位置改成可缺失 condition tokens，生成或校正角域/时延域信道，再用真实移动链路的 PL/DS/AS/APS 检查生成先验是否具有物理意义。
- **高速场景接口**：可以把单帧条件扩展为轨迹窗口，和 RadioMapMotion 式时序上下文结合，评估速度/遮挡变化下的 posterior correction。
- **模态处理原则**：动态散射体保留与否应做 task-specific ablation，不能默认“语义清理越干净越好”。

### 为什么不是重复

**硬去重已排除；填补系统验证缺口。** 相比已收集的 MVX 协同感知工作，本篇新增真实同步 V2I、多任务信道统计和 360 维 APS；它是应用/系统强候选，不是生成式核心方法锚点。

### 局限

样本量仅 926，缺少代码和公开数据，当前更适合提炼条件设计、指标与消融逻辑，而非作为近期主复现对象。

## 最小可行实验（MVP）

### 实验 A：位置条件 cFMM + 现有导频后验修正

1. 在现有复数 16×64 信道数据上复现论文 1 的 coordinate-conditioned cFMM。
2. 依次增加：`coordinate only -> coordinate + CKM feature -> coordinate + CKM + modality mask`。
3. 生成先验 `H_0` 后，接现有 RC/PBG 或 PnP 数据一致性：

\[
H^{k+1}=\operatorname{Prior}_{\theta}(H^k,r,e,M)
\quad\rightarrow\quad
H^{k+1}\leftarrow H^{k+1}+\eta\,\mathcal A^{H}\bigl(Y-\mathcal A(H^{k+1})\bigr).
\]

4. 指标：NMSE-SNR、pilot residual、beam consistency、effective rank、NFE/latency、CSI compression/beam alignment。

**验收标准**：相对 unconditional SRF 和 coordinate-only cFMM，环境条件提高跨位置/跨场景性能；加入数据一致性后 pilot residual 稳定下降，且下游指标不因 NMSE 优化而恶化。

### 实验 B：不完整/噪声条件鲁棒性

1. 对坐标、AoA/AoD 图、环境图分别构造缺失 mask、位置偏差、结构缺失和语义噪声。
2. 比较无增强、随机增强、论文 4 的任务化增强，以及任务化增强 + sparse pilot correction。
3. 按城市构造 coordinate-only、angle-only 和 unseen-city split。

**验收标准**：不仅同分布测试提高，未见城市和缺失模态下的最坏组性能也改善；同时报告每种条件损坏的敏感性。

### 实验 C：有限数据后验坍缩诊断

1. 在 10%、25%、50%、100% 训练量下训练 conditional FM。
2. 同时记录验证 conditional loss、posterior sample variance、coverage、NMSE 和相近观测条件下的样本最近邻距离。
3. 比较固定 epoch、验证损失早停与 diversity-aware 早停。

**验收标准**：能够识别“NMSE 尚可但后验方差已坍缩”的区间，并给出不依赖测试集标签的早停代理指标。

**摘要：** 多径无线信道可由多径分量（MPC）完整刻画，包括复信道增益、传播时延、离开角（AoD）以及方位与俯仰到达角（AoA）。以射线追踪（RT）的保真度生成这些参数仍是一个开放问题。现有方法要么需要承担 RT 的计算开销，要么需要在推理阶段显式提供三维场景几何。我们提出 CITYMPC——一个条件变分自编码器（cVAE），它仅凭视点影像与地形高度图即可预测完整的逐径 MPC 参数集，从而在推理阶段无需任何三维场景几何即可实现环境感知的信道生成。我们在覆盖 427,397 条链路的五个城市环境中训练并评估 CITYMPC，其与 RT 真值的差距为：接收功率平均绝对误差（MAE）1.29 dB、$\tau_0$ MAE 7.25 ns。CITYMPC 是一个生成式信道建模框架¹与可复现基准，并与一个大规模多城市射线追踪数据集²一同发布，以加速未来场景条件化信道建模研究。我们进一步分析跨城市分布偏移，以刻画该基准的逐城市多样性。

## 1 引言

第六代（6G）无线通信系统预计将从根本上拓展网络在连通性之外的角色。6G 被设想为一个服务平台，支撑沉浸式通信、大规模通信、泛在连接、超可靠低时延通信、人工智能与通信融合、以及通感一体化（ISAC）等用例 [1–4]。支撑这一切的是前几代未能满足的一项要求：网络必须在每条链路上具备丰富的、站点特定的传播环境知识。6G 所要求的物理层功能直接受限于信道模型的保真度。在更高频段，6G 系统将使用数百个天线阵元来克服严重的路径损耗。这类系统需要显式掌握每个 MPC，包括方位与俯仰的 AoD 与 AoA、额外传播时延以及复路径增益 [5, 6]。6G 也被视为第一代将 AI 原生嵌入无线接入网的网络，这本身就要求一个丰富的

已有两大范式主导信道建模，各有结构性权衡。其一是几何随机信道模型（GBSM），在 3GPP TR 38.901 [8] 中标准化。GBSM 把 MPC 组织成簇，簇参数从经测量活动校准的统计分布中抽取 [6]。该模型计算高效但与环境无关，且忽略了视距（LoS）与非视距（nLoS）链路的根本差异。另一类是被确定性的 RT，例如 Sionna RT [9] 中的实现，它利用场景特定的三维几何为基于学习的无线模型生成合成数据集 [10]。RT 计算代价高、每条链路配置只产生一个确定性信道实现，并且预设可获得带地理配准的三维场景网格。它不产生可在实时查询、或在不同的传播环境间复用的紧凑信道分布表示。这种推理阶段对场景几何的依赖，正是促使我们研究学习型代理模型的根本局限。

**相关工作。** 3GPP TR 38.901 [8] 与 NYUSIM [11] 等随机信道模型提供闭式参数分布，但缺乏站点特定条件化。Sionna RT [9] 与 Wireless InSite [12] 等射线追踪工具以高计算代价产生物理精确的信道，需要详细的三维几何并逐链路执行。近期基于学习的方法可分为三类。生成式模型 [13–16] 从数据中学习信道分布，但不以站点特定场景信息为条件。WiNeRT [17] 与 GeNeRT [18] 等神经 RT 代理预测逐径 MPC 参数，但推理时需要三维场景网格。坐标条件化与无线电地图方法 [19–22] 预测聚合信号量或部分 MPC 信息，而不产生完整的逐径参数集。与现有工作的详细比较与完整讨论见附录 A。

### 1.1 贡献概述

**完整 MPC 刻画。** 我们形式化“无几何”的 MPC 预测任务：仅凭视点（PoV）多通道影像与地形高度图预测完整的逐径参数集，推理阶段无法访问射线几何或三维网格。所预测参数包括方位与俯仰的 AoA 与 AoD、额外时延、复增益、飞行时间（ToF）以及接收功率。据我们所知，这是首个仅以场景影像为条件预测逐径 AoA 与 AoD 俯仰角的工作，使 CITYMPC 成为未来场景条件化信道模型研究的基准。

**以生成方式匹配 RT 性能。** 我们提出一种基于 Transformer 的 cVAE 架构，通过可学习槽查询（slot query）[23] 生成完整的结构化 MPC 参数集，并采用 Kendall 不确定性加权 [24] 进行多任务损失平衡。模型在约 50 万条 Tx-Rx 链路上训练与评估，这些链路横跨美国五座城市，由 DeepMIMO [25] 与 Sionna RT [9] 生成。CITYMPC 学习站点特定的信道分布，其生成的 MPC 实现在所有预测参数上都与射线追踪真值相匹配。

**数据集生成器与数据集发布。** 在某座城市的射线追踪数据上训练后，CITYMPC 在推理时无需射线追踪或三维场景网格，即可按更低的计算代价生成任意多条物理上有效的 MPC 实现。这使 CITYMPC 成为实用的数据集生成

## 2 系统模型与数据集

### 2.1 多径无线信道

Tx 与 Rx 之间的射频（RF）传播经历反射、折射、绕射与散射，从而产生多条以不同时延与方向到达接收机的离散传播路径。图 1 给出了这一原理的基本示意。我们把无线信道建模为线性时变（LTV）系统 [7, 26]，表示为

$$h(t,\Theta,\Phi)=\sum_{\ell=1}^{L}m_\ell(t)\alpha_\ell(t)\delta(t-\tau_\ell(t))\delta(\Theta-\Theta_\ell(t))\delta(\Phi-\Phi_\ell(t)),\tag{1}$$

其中 $\mathbf{m}=[m_1,\dots,m_L]$ 为路径存在掩码，活跃路径 $m_\ell=1$，否则 $m_\ell=0$。每条活跃路径 $\ell$ 携带复基带增益 $\alpha_\ell\in\mathbb{C}$、绝对传播时延 $\tau_\ell\in\mathbb{R}^{+}$、方位与俯仰 AoD $\Theta_\ell=(\theta_\ell^{az},\theta_\ell^{el})\in[-\pi,\pi)\times[0,\pi]$，以及方位与俯仰 AoA $\Phi_\ell=(\phi_\ell^{az},\phi_\ell^{el})$。函数 $\delta(\cdot)$ 表示 Dirac delta。在准静态假设 [7] 下，信道参数在一个相干间隔内近似不变，因此我们去掉时间依赖，把每条链路建模为单个静态快照 $\{m_\ell,\alpha_\ell,\tau_\ell,\Theta_\ell,\Phi_\ell\}_{\ell=1}^{L}$。于是信道建模归结为对每条链路预测这些逐径参数，以及 ToF 时间 $\tau_0=\min\{\tau_\ell:m_\ell=1\}$ 与聚合接收功率 $P_{rx}=10\log_{10}(\sum_\ell m_\ell|\alpha_\ell|^2)$ dB（归一化细节见附录 B）。

### 2.2 训练/测试数据集的构建

**信道提取。** 我们采用 DeepMIMO [25] 在 20 个美国城市城市场景中提取逐链路 MPC 参数，仅选取以 Sionna RT [10] 为射线追踪后端、工作于 3.5 GHz 的场景。每个场景覆盖 $512\times512$ m 的城区，从而在所有城市间保持一致的地理足迹。我们把 DeepMIMO 配置为每条链路最多生成 $L=25$ 条路径，每条路径携带复增益 $\alpha_\ell$、绝对时延 $\tau_\ell$、AoD $\Theta_\ell$ 与 AoA $\Phi_\ell$。信道按功率排序，即 $|\alpha_1|\ge|\alpha_2|\ge\cdots\ge|\alpha_L|$，这并不意味着到达时间 $\tau_\ell$ 也按同序排列。链路级与路径级过滤准则见附录 D。

**场景渲染。** 对每座城市，我们把 DeepMIMO 场景几何转换为 Sionna 兼容的 Mitsuba XML 场景 [27]，并渲染两个 12 通道的 PoV 图像栈（分别来自 Tx 与 Rx），分辨率为 $128\times128$。每个 PoV 栈捕获 Tx 或 Rx 所见的局部几何视角，编码出射线在其传播路径上发生反射、绕射与散射的 3D 物体。除 RGB 外观、深度与表面法向之外，每个栈还编码可见表面的无线电材料属性，即相对介电常数 $\varepsilon_r$、电导率 $\sigma$、散射系数、交叉极化系数与材料厚度——它们通过麦克斯韦方程支配射线-表面相互作用 [10]。与 PoV 栈一同，我们还通过捕获整个场景的宏观建筑布局生成 $128\times128$ 分辨率的全局高度图，从而在推理阶段无需三维场景网格即可提供完整的环境几何与电磁描述。由于三维网格覆盖 $512\times512$ m 的区域，全局高度图的空间分辨率为每像素 4 m。转换与渲染流水线的完整细节见附录 C。

**数据集统计与划分。** 本文所用 DeepMIMO 数据集覆盖 5 座美国城市——达拉斯、沃斯堡、纽约、丹佛与奥斯汀——共 427,397 条在 3.5 GHz 下经 Sionna RT 生成的 Tx-Rx 链路，详见表 8。这些城市覆盖多样的城市形态，从密集高层环境到低层蔓延网格，为训练与评估提供了多样的传播条件。每座城市按 70/15/15 划分为训练、验证与测试集，使用空间上不相交的 Tx 与 Rx 网格区域以防泄漏。归一化统计量（$\mu_{log}$、$\sigma_{log}$、$\mu_{rx}$、$\sigma_{rx}$）仅由各城市训练集计算，并按城市独立应用。

**输入与输出。** 记 $c=\{I_{tx}\in\mathbb{R}^{12\times128\times128},I_{rx}\in\mathbb{R}^{12\times128\times128},I_g\in\mathbb{R}^{1\times128\times128},s\in\mathbb{R}^{6}\}$ 为条件化信息，包含 Tx 与 Rx 的 PoV 图像栈、全局高度图以及以米为单位的原始 Tx 与 Rx 笛卡尔坐标。PoV 栈 $I_{tx}$ 与 $I_{rx}$ 编码 Tx 与 Rx 所见的局部几何与电磁视角，捕获射线在每条传播路径上与之相互作用的 3D 表面（见 2.2 节）。全局高度图 $I_g$ 提供整个场景的宏观建筑布局。坐标 $s$ 经正弦傅里叶特征编码 [28] 嵌入，详见附录 E。作用于每个条件化输入的归一化与预处理细节也见附录 E。记 $\mathbf{x}=[\mathbf{x}_1,\dots,\mathbf{x}_L]\in\mathbb{R}^{L\times10}$ 为逐径信道数据，其中每个槽向量为

$$\mathbf{x}_\ell=\left[\tilde{\alpha}_\ell^{\Re},\tilde{\alpha}_\ell^{\Im},\tilde{\tau}_\ell,\hat{\mathbf{d}}_\ell^{d},\hat{\mathbf{d}}_\ell^{a},m_\ell\right]\in\mathbb{R}^{10}.\tag{2}$$

这里 $\tilde{\tau}_\ell$ 是路径 $\ell$ 相对于 ToF 时间 $\tau_0$ 的归一化额外时延。$\hat{\mathbf{d}}_\ell^{d}$ 与 $\hat{\mathbf{d}}_\ell^{a}$ 分别是 AoD $\Theta_\ell$ 与 AoA $\Phi_\ell$ 的单位向量编码。$[\tilde{\alpha}_\ell^{\Re},\tilde{\alpha}_\ell^{\Im}]$ 是路径 $\ell$ 的归一化复基带增益。$m_\ell\in\{0,1\}$ 是路径 $\ell$ 的路径存在指示。所有量的完整归一化细节见附录 B。训练后网络的最终目标是输出一个有效的信道实现

$$\hat{\mathbf{x}}=\{\hat{\tau}_0,\hat{P}_{rx},\hat{\mathbf{m}},\hat{\boldsymbol{\tau}},\Re(\hat{\tilde{\boldsymbol{\alpha}}}),\Im(\hat{\tilde{\boldsymbol{\alpha}}}),\hat{\mathbf{D}}^{d},\hat{\mathbf{D}}^{a}\}\in\mathbb{R}^{2+10\cdot L}.\tag{3}$$

逐径分量与式 (2) 中的 $\mathbf{x}$ 对应，另有链路级标量输出 $\hat{\tau}_0$（预测的 ToF 时间）与 $\hat{P}_{rx}$（预测的接收功率，dB）。所有输出按附录 B 归一化，再经各城市逆变换恢复绝对单位取值。

## 3 模型架构

架构的目标是学习映射 $\hat{\mathbf{x}}=f(c)$，仅凭场景条件化信息生成物理上有效的信道实现，推理阶段无射线几何可用。我们通过 cVAE [29, 30] 学习该

<span id="page-5"></span>

（接上页）映射：cVAE [29, 30] 把 $\hat{\mathbf{x}}$ 的生成通过隐变量 $z\in\mathbb{R}^{d_z}$ 分解，并优化 $p(\mathbf{x}|c)$ 的证据下界（ELBO）来训练。整体架构如图 3 所示，包含四个模块：条件化编码器（CE）、先验网络（PN）、后验编码器（PE）与解码器（DEC）。模型维度见附录 F。

**条件化编码器。** CE 把原始环境输入 $c$ 映射为场景 token 与紧凑的场景嵌入 $c'\in\mathbb{R}^{d_{scene}}$，供其余模块使用。³ 三个独立的 ChannelViT [31] 塔分别处理全局高度图、Tx PoV 栈与 Rx PoV 栈，在具有不同物理含义的异构模态之间保持逐通道的身份区分。Tx 与 Rx 坐标经傅里叶编码 [28] 并投影为一个标量 token，在构建交叉注意力记忆时追加到场景 token 之后。全局、Tx 与 Rx 的 token 经均值池化，并与该标量特征通过多层感知机（MLP）融合，产生 $c'$。

**先验网络。** PN 通过一个 MLP 从 $c'$ 学习条件先验 $p_\psi(z|c)$，输出 $(\mu_p,\log\sigma_p^2)\in\mathbb{R}^{d_z}$。与采用固定 $\mathcal{N}(0,I)$ 先验的标准 cVAE [30] 不同，这里的场景相关先验能更好地刻画多径信道跨环境的结构化变异性 [32]。推理时，$z\sim\mathcal{N}(\mu_p,\mathrm{diag}(\sigma_p^2))$ 在无信道观测的情况下采样。

**后验编码器。** PE 只在训练时工作，学习近似后验 $q_\phi(z|\mathbf{x},c)$。逐径参数向量被投影为带正弦位置编码的 $L$ 个 token 序列，通过堆叠 Transformer 层与场景 token 记忆做交叉注意力。输出的路径 token 按路径存在性池化，与 $P_{rx}$、$\tau_0$ 及 $c'$ 拼接，再投影为 $(\mu_q,\log\sigma_q^2)\in\mathbb{R}^{d_z}$。训练时 $z$ 通过重参数化技巧 [29] 采样，并用 free bits [33] 对相对 $p_\psi$ 的 Kullback-Leibler（KL）散度做正则，以防后验坍缩。

**解码器。** DEC 由 $L$ 个可学习槽查询（slot query）[23] 生成 $\hat{\mathbf{x}}$；每个槽查询通过把 $z$ 的投影加到可学习嵌入上初始化，使隐变量从第一层起就影响每个槽。由于 MPC 按接收功率排序，槽查询内化了这种序结构，为每个槽分配反映路径秩而非序列位置的角色。槽查询通过堆叠 Transformer 层与场景 token 记忆交叉注意力，产生 $L$ 个槽 token。逐径头预测路径存在性、额外时延、复增益以及 AoD/AoA 单位向量；链路级标量头从均值池化的槽 token 预测 $\hat{\tau}_0$ 与 $\hat{P}_{rx}$。AoD 与 AoA 单位向量分别由独立的交叉注意力层产生，它们只分别关注 Tx 与 Rx 的场景 token，从而把几何信息以物理启发的方式路由到相应的角度预测。

> ³ 为表述清晰起见，我们把后续各模块的分布写成以 $c$ 为条件，而非以 CE 的输出为条件。

## 4 训练

模型通过最大化 $p(\mathbf{x}|c)$ 的 ELBO 进行训练：

$$\mathcal{L}=\mathbb{E}_{q_\phi(z|\mathbf{x},c)}\left[\log p_\theta(\mathbf{x}|z,c)\right]-\beta\cdot D_{\mathrm{KL}}\left(q_\phi(z|\mathbf{x},c)\,\|\,p_\psi(z|c)\right),\tag{4}$$

其中 $\beta$ 在最初若干训练步内从零线性退火，以防止 KL 坍缩 [34]。重构项分解为 7 个逐任务损失（每个输出头一个），总损失为

$$\mathcal{L}(\mathbf{x},\hat{\mathbf{x}})=\beta\cdot D_{\mathrm{KL}}\left(q_\phi(z|\mathbf{x},c)\,\|\,p_\psi(z|c)\right)+\sum_{k=1}^{7}w_k\mathcal{L}_k(\mathbf{x},\hat{\mathbf{x}}),\tag{5}$$

其中每个任务使用与输出相适应的损失（路径存在性用二元交叉熵（BCE），标量回归用均方误差（MSE），逐径回归用掩码 MSE，方向单位向量用掩码余弦损失），权重 $w_k$ 由 Kendall 不确定性加权 [24] 学习得到。完整的逐任务损失定义见附录 G。模型用 AdamW [35] 优化，采用带线性预热的余弦衰减学习率计划，并对每个 KL 维度施加 free bits [33]，以防训练早期的后验坍缩。完整训练超参数见附录 F。

## 5 实验结果

我们在取自 DeepMIMO 数据集的五个城市环境上评估 CITYMPC：奥斯汀、达拉斯、沃斯堡、丹佛与纽约。每座城市在 Tx 与 Rx 网格位置上使用空间不相交的 70/15/15 训练/验证/测试划分，确保训练中见过的链路不会出现在测试阶段。逐城市训练与硬件细节见附录 H。

**基线。** 我们把 CITYMPC 与一个 MLP 基线对比：后者共享相同的 cVAE 框架与 Kendall 不确定性加权 [24]，但把 ChannelViT 条件化编码器与 Transformer 解码器替换为 ResNet-18 场景编码器、隐藏宽度 512 的融合 MLP 后验编码器，以及隐藏宽度 512、带逐径输出头的平坦 MLP 解码器主干。其余训练超参数在两个模型间完全一致，见附录 F。

**指标。** 我们在每座城市留出测试集上用八个指标评估信道生成质量。路径存在 F1 分数（F1）度量在全部 $L=25$ 个槽上二元活跃路径掩码的准确度。ToF MAE 度量预测 ToF 时间 $\tau_0$ 的绝对误差（纳秒）。平均时延 MAE 度量功率加权平均绝对时延 $\bar{\tau}=\sum_\ell|a_\ell|^2\tau_\ell/\sum_\ell|a_\ell|^2$ 的绝对误差（纳秒），与 Orekondy 等人 [17] 及 Bian 等人 [18] 的定义一致。接收功率 MAE 度量总接收功率的绝对误差（分贝）。平均 AoD 方位角 MAE、平均 AoD 俯仰角 MAE、平均 AoA 方位角 MAE 与平均 AoA 俯仰角 MAE 分别度量链路级活跃路径上功率加权平均角的绝对误差，计算方式与上述平均时延指标类似 [17, 18]。详细评估指标见附录 I。由于 CITYMPC 是生成式模型，即使训练良好，非零 MAE 也在预期之中——它反映所学信道分布的随机性，而非确定性回归误差。

## 6 结论与局限

我们提出了 CITYMPC——首个仅凭场景影像预测完整逐径 MPC 参数集的生成式模型，它联合预测路径存在性、复增益、方位与俯仰 AoD 与 AoA、额外时延、ToF 时间与接收功率，而推理阶段无需访问三维场景几何。CITYMPC 采用以多通道 PoV 影像与地形高度图为条件的 Transformer 型 cVAE，并用 Kendall 不确定性加权在七个预测任务上训练。在五个美国城市上评估，CITYMPC 取得很强的信道生成保真度，生成的 MPC 分布在所有预测参数上都与射线追踪真值高度吻合。所附的跨五座城市、427,397 条射线追踪链路的数据集，与已发布的模型代码和生成流水线一起，为未来生成式信道建模研究提供了可复现的基准。我们的跨城市迁移分析揭示每座城市都呈现出不同的信道分布；逐城市训练的模型为未来多城市泛化研究建立了强分布内基线。

CITYMPC 尚未用真实世界的信道测量进行验证，仿真到现实的差距仍是一个开放挑战。由于跨城市泛化会随分布偏移而退化（如 5.2 节所示），目前需要逐城市训练。从多城市预训练模型出发做微调，是降低逐城市数据需求的自然下一步。当前模型面向 3.5 GHz、全向天线的室外城市宏蜂窝环境。扩展到室内场景、

<span id="page-10"></span>

## 附录 A 扩展相关工作与比较

面向信道建模的深度学习方法可分为三类。我们逐一展开，以更完整地刻画 CITYMPC 在这一格局中的位置。

**生成式信道模型。** 早期工作把生成对抗网络（GAN）[38]、变分自编码器（VAE）[29] 与去噪扩散概率模型（DDPM）[39] 用于从数据中学习信道分布。[13] 与 [40] 学习多输入多输出（MIMO）信道矩阵上的分布。基于扩散的模型在信道分布学习上取得了很好的结果 [14–16, 41]。物理启发的生成模型把物理或几何结构纳入生成过程 [42–44]。这些方法都不以站点特定场景信息为条件，因此同一位置的样本都来自单一全局分布，与局部传播环境无关。

**无线电地图与信道预测。** 另一些工作从地理或场景输入预测聚合信号量或信道响应。Wang 等人 [19] 通过扩散模型生成包含接收功率、到达方向与到达时间的三维无线电地图。可学习数字孪生 [20] 结合三维几何与学习到的逐物体电磁属性重建电磁场，并预测 MIMO 信道矩阵。这些方法预测的是聚合或位置级信道量，不产生 Tx 与 Rx 两端的离散逐径增益、时延、AoD 与 AoA。

**神经射线追踪代理。** 更近期的工作用神经网络作为 RT 的代理，仍以三维场景网格作为输入。WiNeRT [17] 在室内环境中验证，训练 MLP 通过时间-角度 CIR 表示预测逐径增益、时延、AoD 方位角与 AoA 方位角，但不预测俯仰角。GeNeRT [18] 在 WiNeRT 基础上改进，用极化驱动的双分支网络预测逐径增益、时延以及方位与俯仰的 AoD 与 AoA，并展示了向未见室外环境的零样本迁移。Park 等人 [21] 训练以 Tx 与 Rx 坐标为基础的条件去噪扩散概率模型（cDDPM），在角度-时延域合成信道，推理阶段无需三维场景几何。该合成采用二维图像表示，一个轴编码传播时延、另一个轴编码 Tx 侧 AoD 方位角；Rx 侧 AoA 未被预测，且评估限于单一环境。

我们提出的 cVAE 模型 CITYMPC 填补了这一格局中尚存的空白。它以 Tx 与 Rx 两侧的 PoV 影像以及地形高度图为条件，在无需三维网格的情况下编码每个端点处的局部散射几何。CITYMPC 预测完整的逐径参数集：方位与俯仰的 AoD 与 AoA、逐径额外时延、ToF 时间、接收功率以及复基带增益。表 IV 在五个与逐径 MPC 生成相关的属性上把 CITYMPC 与代表性已有方法进行比较。“No 3D”表示方法在推理时无需三维场景网格；“Per-path Delay”表示预测离散的逐径时延而非时延扩展或聚合地图；“Gen”表示模型是否为生成式；“Cross-scene”表示单个训练好的模型能否在不做逐场景重训练或微调的情况下泛化到留出场景。

**复增益。** 令 $P_{tot}=\sum_{\ell:m_\ell=1}|\alpha_\ell|^2$ 表示总接收功率。归一化路径系数为

$$\tilde{\alpha}_\ell=\frac{\alpha_\ell}{\sqrt{P_{tot}}},\tag{6}$$

从而按构造有 $\sum_\ell m_\ell|\tilde{\alpha}_\ell|^2=1$。原始增益由 $\alpha_\ell=\tilde{\alpha}_\ell\sqrt{P_{tot}}$ 恢复。

**额外时延。** 时延表达为相对于 ToF 时间 $\tau_0=\min\{\tau_\ell:m_\ell=1\}$ 的量，并裁剪到与 3GPP TR 38.901 时延扩展定义 [8] 一致的宽度 $W=1\ \mu$s 窗口内：

$$\tilde{\tau}_\ell=\mathrm{clip}\left(\frac{\tau_\ell-\tau_0}{W},0,1\right).\tag{7}$$

**角度编码。** 每个 AoD 方向 $\Theta_\ell=(\theta_\ell^{az},\theta_\ell^{el})$ 与 AoA 方向 $\Phi_\ell=(\phi_\ell^{az},\phi_\ell^{el})$ 都通过标准球面到笛卡尔的映射编码为 $S^2$ 上的单位向量：

$$\hat{\mathbf{d}}(\theta^{az},\theta^{el})=\begin{bmatrix}\sin(\theta^{el})\cos(\theta^{az})\\ \sin(\theta^{el})\sin(\theta^{az})\\ \cos(\theta^{el})\end{bmatrix}\in S^2\subset\mathbb{R}^3.\tag{8}$$

这避免了仅方位角参数化的 $\pm180^\circ$ 环绕不连续，并允许在单位球面上使用平滑的余弦损失。原始角度由 $\theta^{az}=\mathrm{atan2}(\hat{d}_2,\hat{d}_1)$ 与 $\theta^{el}=\arccos(\hat{d}_3)$ 恢复。

**ToF 时间。** 城市链路上 $\tau_0$ 的分布可用对数正态很好地近似 [26]，因此我们用各城市训练统计量 $(\mu_{log},\sigma_{log})$ 做对数 z-score 变换：

$$\tilde{\tau}_0=\frac{\log(\tau_0^{ns}+\epsilon)-\mu_{log}}{\sigma_{log}},\tag{9}$$

其中 $\tau_0^{ns}=\tau_0\times10^9$ 以纳秒计，$\epsilon=10^{-12}$ 用于避免数值问题。

**接收功率。** 接收功率 $P_{rx}=10\log_{10}(P_{tot})$ dB 在给定城市的条件下近似服从高斯分布，因此我们用各城市统计量 $(\mu_{rx},\sigma_{rx})$ 做 z-score：

$$\tilde{P}_{rx}=\frac{P_{rx}-\mu_{rx}}{\sigma_{rx}}.\tag{10}$$

**无线电材料赋值。** 每个物体携带一个材料标签，映射到 materials.mat 中存储的电磁属性。我们通过 register_radio_material_bsdf() 注册自定义 Mitsuba BSDF 插件（radio_material），在每个形状上保存五个标量电磁场。该 BSDF 对每个唯一材料标签实例化一次，并赋给共享该标签的所有形状，使 Sionna RT 求交引擎能在射线追踪时查询逐表面电磁属性。天空与地平面等背景几何被赋予 $\varepsilon_r=1$、$\sigma=0$、散射与交叉极化系数为零的默认属性。

**PoV 渲染。** Mitsuba XML 场景载入 Sionna RT 后，我们为每条链路渲染两个 12 通道 PoV 栈。相机置于 Tx 位置朝向 Rx（反之亦然），视场角固定为 $45^\circ$，RGB 通道每像素 128 个采样。Mitsuba 直接暴露每个渲染视点的逐像素颜色、度量深度、几何表面法向与形状索引图。形状索引标识渲染图像每个像素处可见的三维物体。我们用该形状索引查找赋给可见形状的无线电材料 BSDF，从而把三维物体的电磁属性直接迁移到 PoV 图像的像素空间。12 个通道的组成如下：通道 0–2 为经 Sionna 视觉场景流水线渲染的 RGB；通道 3 为度量深度；通道 4–6 为几何表面法向；通道 7–11 为每个像素处相交形状的无线电材料属性（$\varepsilon_r$、$\sigma$、散射系数、交叉极化系数与材料厚度）。这一设计意味着 PoV 栈不仅编码 Tx 或 Rx 视点可见的几何，还编码每个可见表面的完整电磁特性，而推理阶段无需三维网格。全局高度图以场景俯视正交投影渲染，在 $512\times512$ m 的完整场景足迹上以每像素 4 m 的分辨率捕获建筑高度。所有渲染数据由 export_channels_and_env.py 与信道张量一起打包进逐城市的 NPZ 归档。

## 附录 F 模型维度与训练超参数

**Token 数。** 每个 ChannelViT 塔把输入图像划分为 $32\times32$ 像素的不重叠空间块。对 $128\times128$ 的输入分辨率，每个图像通道产生 $\lfloor128/32\rfloor^2=16$ 个空间块。全局高度图有 $C=1$ 个通道，产生 16 个全局 token；Tx 与 Rx 的 PoV 栈各有 $C=12$ 个通道，每个模态产生 192 个 token。Tx 与 Rx 坐标的标量特征向量被投影为单个标量 token，在 PE 与 DEC 中构建交叉注意力记忆时追加到图像 token 之后。因此完整的交叉注意力记忆包含 $16+192+192+1=401$ 个维度为 $d_{model}$ 的 token。对物理启发的角度头，AoD token 关注 $16+192+1=209$ 个 token 的纯 Tx 记忆，AoA token 关注 $16+192+1=209$ 个 token 的纯 Rx 记忆。

## 附录 G 逐任务损失、Kendall 不确定性加权与训练超参数

**逐任务损失函数。** 令 $\mathbf{m}=[m_1,\dots,m_L]$ 为真值存在掩码，$m_\ell\in\{0,1\}$。对逐径标量目标 $a\in\mathbb{R}^L$ 与预测 $\hat{a}\in\mathbb{R}^L$ 的存在掩码 MSE 为

$$\mathcal{L}_m(a,\hat{a};\mathbf{m})=\frac{1}{\|\mathbf{m}\|_1}\sum_{\ell=1}^{L}m_\ell\,(a_\ell-\hat{a}_\ell)^2.\tag{11}$$

对单位向量矩阵 $\mathbf{D}\in\mathbb{R}^{L\times3}$ 与 $\hat{\mathbf{D}}\in\mathbb{R}^{L\times3}$ 的存在掩码余弦损失为

$$\mathcal{L}_c(\mathbf{D},\hat{\mathbf{D}};\mathbf{m})=\frac{1}{\|\mathbf{m}\|_1}\sum_{\ell=1}^{L}m_\ell\left(1-\hat{\mathbf{d}}_\ell^{\top}\mathbf{d}_\ell\right).\tag{12}$$

表 XI 列出分配给 $K=7$ 个任务中每一个的损失函数。

**Kendall 不确定性加权。** 尽管所有目标在训练前都已归一化（附录 B），表 XI 中的七个任务跨越根本不同的输出空间，即二元分类、无界标量回归与单位球面上的方向回归。对如此异构的输出手工调校权重 $w_k$ 代价过高。我们改为把每个权重视为来自逐任务噪声参数 $\sigma_k$，其量级反映该任务被预测的难度 [24]。

**表 XI：** 重构损失。$\mathbf{m}=[m_1,\dots,m_L]$ 为真值存在掩码（$m_\ell=1$：活跃；$m_\ell=0$：不活跃）。$\mathcal{L}_m$ 与 $\mathcal{L}_c$ 定义于式 (11)–(12)。BCE 表示二元交叉熵。标量头作用于 z-score 后的目标，掩码头只作用于活跃路径。

| $k$ | 任务 | 符号 | 空间 | 损失（$\mathcal{L}_k$） | 掩码 |
|---|---|---|---|---|---|
| 1 | 路径存在 | $\mathbf{m}$ | 二元 | $\frac{1}{L}\sum_\ell\mathrm{BCE}(m_\ell,\hat{m}_\ell)$ | 无 |
| 2 | ToF | $\tau_0$ | z-score（log ns） | $(\tau_0-\hat{\tau}_0)^2$ | 无 |
| 3 | 接收功率 | $P_{rx}$ | z-score（dB） | $(P_{rx}-\hat{P}_{rx})^2$ | 无 |
| 4 | AoA 方向 | $\mathbf{D}^{a}$ | 单位球面 | $\mathcal{L}_c(\mathbf{D}^{a},\hat{\mathbf{D}}^{a};\mathbf{m})$ | 活跃 |
| 5 | AoD 方向 | $\mathbf{D}^{d}$ | 单位球面 | $\mathcal{L}_c(\mathbf{D}^{d},\hat{\mathbf{D}}^{d};\mathbf{m})$ | 活跃 |
| 6 | 额外时延 | $\tilde{\boldsymbol{\tau}}$ | $[0,1]$ | $\mathcal{L}_m(\tilde{\boldsymbol{\tau}},\hat{\tilde{\boldsymbol{\tau}}};\mathbf{m})$ | 活跃 |
| 7 | 基带增益 | $\Re(\boldsymbol{\alpha}),\Im(\boldsymbol{\alpha})$ | $[0,1]$ | $\mathcal{L}_m(\Re(\boldsymbol{\alpha}),\Re(\hat{\boldsymbol{\alpha}});\mathbf{m})$ | 活跃 |

对**回归**任务，假设高斯观测似然 $p(\mathbf{x}|f(z))=\mathcal{N}(f(z),\sigma_k^2)$ 并最大化对数似然，得到加权任务贡献

$$\frac{1}{2\sigma_k^2}\mathcal{L}_k+\log\sigma_k,\tag{13}$$

其中第一项以 $1/\sigma_k^2$ 下调任务损失，第二项惩罚过大的不确定性。

对**分类**任务（路径存在），假设伯努利似然按 $1/\sigma_k^2$ 缩放，得到类似的贡献 [24]

$$\frac{1}{\sigma_k^2}\mathcal{L}_k+2\log\sigma_k.\tag{14}$$

<span id="page-22"></span>

（接上页）两种情形下，较大的 $\sigma_k$ 都会降低该任务的有效权重，使模型能自动平衡难度不同的任务。每个 $\sigma_k$ 参数化为 $\sigma_k=\exp(s_k)$，其中 $s_k$ 是可学习标量，初始化为 $s_k=0$（即 $\sigma_k=1$），并与模型权重联合优化。

**UW 的局限。** 当任一任务的 $\sigma_k\to\infty$ 时，式 (13)–(14) 的 Kendall 形式可能退化：数据拟合项 $\mathcal{L}_k/\sigma_k^2$ 消失，而正则项 $\log\sigma_k$ 在允许联合损失取负值时无上界。这一失效模式是多任务学习文献中记载的 UW 已知局限，称为任务放弃（task abandonment）[36, 37]。常见缓解手段包括 Liebel-Körner 正则在 $\log(1+\sigma_k^2)$ [37]、GradNorm 式直接梯度平衡 [50]，以及带 softmax 归一化权重的解析 UW 变体 [36]。我们把这些替代方案留待未来工作整合。

**定量结果的过滤判据。** 我们剔除在最终训练步时学到的 UW 任务不确定性 $\sigma_{presence}$ 超过 $10^{-3}$ 的运行。该阈值把收敛运行（达到约 $10^{-4}$）与表现出 UW 任务放弃失效模式的运行区分开来 [24, 36, 37]。该判据只使用训练期的 UW 参数，不引入测试集泄漏，最终为奥斯汀、达拉斯、丹佛、沃斯堡与纽约分别留下 $n=3,4,4,4,4$ 个运行。

## 附录 I 评估指标

所有指标都在每座城市的留出测试集上计算。令 $N$ 表示测试链路数。对链路 $n$，令 $\mathbf{m}(n)=[m_1,\dots,m_L]$ 为真值存在掩码（$m_\ell\in\{0,1\}$），$\alpha_\ell^{(n)}\in\mathbb{C}$ 为路径 $\ell$ 的复增益，$\tau_\ell^{(n)}$ 为其绝对时延。

**路径存在 F1。** 路径存在 F1 是在全部 $L=25$ 个槽与全部 $N$ 条测试链路上，对二元存在掩码 $\mathbf{m}$ 计算的精确率与召回率的调和平均。

**ToF MAE。** ToF MAE 是预测的 $\tau_0=\min\{\tau_\ell:m_\ell=1\}$ 的平均绝对误差，

$$\mathcal{M}_{\tau_0}=\frac{1}{N}\sum_{n=1}^{N}\left|\hat{\tau}_0^{(n)}-\tau_0^{(n)}\right|,\tag{15}$$

以纳秒为单位报告。

**平均时延 MAE。** 某链路的功率加权平均绝对时延为

$$\bar{\tau}^{(n)}=\frac{\sum_{\ell=1}^{L}m_\ell^{(n)}|\alpha_\ell^{(n)}|^2\tau_\ell^{(n)}}{\sum_{\ell=1}^{L}m_\ell^{(n)}|\alpha_\ell^{(n)}|^2},\tag{16}$$

平均时延 MAE 为

$$\mathcal{M}_{\bar{\tau}}=\frac{1}{N}\sum_{n=1}^{N}\left|\hat{\bar{\tau}}^{(n)}-\bar{\tau}^{(n)}\right|,\tag{17}$$

以纳秒为单位报告。该定义与 Orekondy 等人 [17] 以及 Bian 等人 [18] 一致。

**接收功率 MAE。** 接收功率 MAE 是总接收功率 $P_{rx}=10\log_{10}(P_{tot})$ dB 的平均绝对误差，

$$\mathcal{M}_{P_{rx}}=\frac{1}{N}\sum_{n=1}^{N}\left|\hat{P}_{rx}^{(n)}-P_{rx}^{(n)}\right|,\tag{18}$$

以分贝为单位报告。

**平均角度 MAE。** 每个角度维度 $\phi\in\{\theta_{AoD}^{az},\theta_{AoD}^{el},\phi_{AoA}^{az},\phi_{AoA}^{el}\}$ 都由预测单位向量 $\hat{\mathbf{D}}$ 经 $\theta^{az}=\mathrm{atan2}(\hat{d}_2,\hat{d}_1)$ 与 $\theta^{el}=\arccos(\hat{d}_3)$ 恢复，与式 (8) 一致。对每条链路，活跃路径上的功率加权平均角为

$$\bar{\phi}^{(n)}=\frac{\sum_{\ell=1}^{L}m_\ell^{(n)}|\alpha_\ell^{(n)}|^2\phi_\ell^{(n)}}{\sum_{\ell=1}^{L}m_\ell^{(n)}|\alpha_\ell^{(n)}|^2},\tag{19}$$

其中方位角平均用经 atan2 的圆均值，并映射到 $[0^\circ,360^\circ)$。每个维度的平均角度 MAE 为

$$\bar{\mathcal{M}}_{\phi}=\frac{1}{N}\sum_{n=1}^{N}\left|\hat{\bar{\phi}}^{(n)}-\bar{\phi}^{(n)}\right|,\tag{20}$$

以度为单位报告。我们报告四个平均角度 MAE：AoD 方位角、AoD 俯仰角、AoA 方位角与 AoA 俯仰角。

## 阅读提示

- 核心主张：多径信道可由逐径 MPC 参数集完整刻画，因此“信道建模=逐径参数预测”。CITYMPC 用 cVAE 从 Tx/Rx 视点影像 + 地形高度图直接生成完整 MPC 参数集（路径存在、复增益、方位/俯仰 AoD 与 AoA、额外时延、ToF、接收功率），推理时不访问任何三维场景几何——这是与 Sionna RT 与神经 RT 代理（WiNeRT/GeNeRT 仍需 3D 网格）的根本区别。
- 输入设计值得注意：12 通道 PoV 图像不仅含 RGB/深度/法向，还含 5 个无线电材料属性（εr、σ、散射系数、交叉极化系数、厚度），通过 Mitsuba 形状索引从 3D 物体查表迁移到像素空间；配合 4 m/像素的全局高度图，等价于在推理阶段“以图像代替网格”。
- 架构要点：条件化编码器三塔 ChannelViT（全局/Tx/Rx）保持模态身份；场景相关先验 p(z|c) 替代固定 N(0,I)；解码器用 L 个可学习槽查询（DETR 式）——因路径按功率排序，槽查询内化了“秩”而非“位置”；AoD 与 AoA 分别只 attend 纯 Tx / 纯 Rx 记忆，是物理启发的几何路由。
- 训练：ELBO + 7 个逐任务损失（BCE/MSE/掩码 MSE/掩码余弦），权重由 Kendall 不确定性加权自动学习；但 UW 存在已知失效模式（某任务 σ_k 发散→任务放弃），作者用 σ_presence>1e-3 的训练期判据过滤发散种子，最终每城市仅保留 n=3~4 个种子——这是结果可信度的重要前提。
- 结果口径：表 I 显示除 F1（MLP 略优）与丹佛接收功率（差 0.02 dB）外，CITYMPC 全面优于 MLP 基线；ToF MAE 差距最大（低 1.5~3.2 倍）；参数仅 15.8 M（基线 35.5 M）。表 III：端到端推理比 RT 快 1.90×、仅模型快 9.88×（均在单块 H100 上）。注意 MAE 非零是生成式模型的正常现象，不是回归误差。
- 跨城市泛化（5.2 节、图 7）：不做域自适应时，接收功率 MAE 从 <2.1 dB 升到 >7 dB、ToF MAE 从 <7.5 ns 升到 >20 ns，但存在性 F1 仍 >0.7；说明单城市训练模型迁移后仍能预测信道结构，但精度显著下降——这正是作者强调需要逐城市训练的原因，也是未来多城市预训练+微调的动机。
- 局限（作者自述+阅读补充）：未用真实测量验证（sim-to-real gap 未解）；仅 3.5 GHz 室外城市宏蜂窝、全向天线的 SISO 链路；UW 导致训练可能发散；数据集尚未实际公开（论文标注“发表后提供”）；表 VII 的 20 城市总计 1,374,669 条链路中本文只用 5 城 427,397 条。

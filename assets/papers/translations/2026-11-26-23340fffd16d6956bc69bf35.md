## 摘要

大规模多输入多输出（MIMO）有望为 5G 及未来系统带来前所未有的频谱效率增益，但在商业部署中面临一个实际挑战，即“移动性诅咒”。随着用户速度升高，大规模 MIMO 性能显著下降。本文提出一种新的信道状态信息（CSI）获取框架，处理频分双工（FDD）大规模 MIMO 的这一问题。提出联合角度–时延–多普勒（JADD）宽带预编码器，用于信道训练。基本思想是利用 FDD 信道的部分互易性与信道的角度–时延–多普勒结构。具体而言，基站（BS）采用矩阵束（MP）方法，利用上行（UL）导频估计上行信道的角度、时延和多普勒信息，再由提取的参数计算宽带 JADD 预编码器。随后，用户估计并反馈若干标量系数，供基站重构预测的下行（DL）信道。渐近分析表明，随着基站天线数和带宽增加，CSI 预测误差趋于零。使用工业信道模型的数值结果表明，本文框架可适应高速（350 km/h）、较大 CSI 时延（10 ms）以及信道样本噪声。

**关键词** 大规模 MIMO、移动性诅咒、信道预测、FDD、角度–时延域、部分互易性、矩阵束、5G。

## I. 引言

5G 无线通信正进入实际部署，并被寄予高吞吐率、低时延和高可靠性的期望。实现这些优势离不开大规模 MIMO 技术。通过在基站部署大量天线并消除不相关噪声与快速衰落，可以获得这些收益 [1]。大规模 MIMO 系统在提高频谱效率（SE）和能量效率（EE）方面显示出很大潜力 [2]。虽然导频污染会限制大规模 MIMO 系统性能 [3]，但可通过利用信道的角域结构 [4] 与信道功率差异 [5] 缓解其影响。

较高的 SE 依赖准确的 CSI。由于时分双工（TDD）的信道具有互易性，获取 CSI 所需的导频训练开销随用户设备（UE）数量增长，且不随基站天线数增长，因此开销可以接受。TDD 可能是大规模 MIMO 系统的有利选择。不过，目前相当大一部分蜂窝通信系统采用 FDD 模式，因此 FDD 大规模 MIMO 同样重要。文献 [6] 在 2.6 GHz 对两种模式进行了实测，得出两者分别在不同场景中各有优势的结论。

FDD 的上、下行信道不互易，因而需要训练及反馈开销，获取 CSI 更具挑战性。已有许多工作提出 FDD 大规模 MIMO CSI 获取的可能方案。文献 [7, 8] 利用统计信道信息与用户分组设计预波束形成器，以减少导频训练与反馈开销，该方法称为联合空间分割与复用（JSDM）。文献 [9] 考虑信道相关矩阵的低秩性，在空间相关信道模型下设计导频训练与反馈。压缩感知（CS）也可利用大规模 MIMO 信道的空间稀疏性。文献 [10] 在毫米波大规模 MIMO 中用 CS 提取信道参数以估计信道。另一类方法以信道参数提取处理 FDD 大规模 MIMO 信道估计。通过离散傅里叶变换（DFT）投影利用角度信息 [11]，可分别估计角度信息与信道增益，再重构下行信道。文献 [12] 引入 Newtonized 正交匹配追踪（NOMP）来检测角度、时延和增益，并根据多径信道模型重构信道。深度学习也被用于重构下行信道 [13]。但上述论文主要考虑在一段时间内假定信道恒定的块衰落场景，该假设在静止或低移动场景中合理。

实际中，即使在 TDD 模式下，移动场景的系统性能也可能显著下降 [14, 15]。其起因在于信道的时变性。过时的 CSI 会严重损害 SE。相比静止场景，移动环境中的多普勒频移不可忽略。文献 [16] 提出基于变分贝叶斯推断（VBI）框架的高移动场景数据辅助信道预测方法。文献 [17] 提出一种基于最大似然的方法，估计车车通信（V2V）MIMO 系统中的信道参数。

<a id="page-2"></a>

已有一些研究从理论上考察了 CSI 时延对信道的影响 [18, 19]。文献 [15] 利用基于 Prony 法的角度–时延域信道预测来解决移动性问题。文献 [20] 从深度学习角度处理大规模 MIMO 移动性。然而，这些论文主要关注 TDD。

FDD 与 TDD 不同，CSI 必须由 UE 闭环反馈给基站。除会增大 CSI 时延之外，这还引入 CSI 量化误差。特别在高移动场景中，信道相干时间比低移动场景短得多，而且 FDD 上下行工作频带不同，难以及时反馈。训练与反馈开销也远高于 TDD，需要降低。先进的 CS [10]、深度学习 [20] 和 JSDM [8] 方法主要致力于减少导频训练与反馈开销。一些研究采用最大似然 [17]、深度学习 [20] 和机器学习 [21] 来解决 TDD 中的 CSI 老化问题。文献 [22] 利用角度支撑上的部分信道互易性，辅助 TDD 中收发天线数量不相等的 UE 反馈 CSI。文献 [23] 提出一种 TDD 系统中基于 CSI-RS 与 SRS 的信道重构方法。然而，这些方法未考虑 FDD 的移动性问题，所给出的方案大多为 NP-hard。由于高移动性要求及时获取 CSI 并高效预测信道，这些方法无法直接用于高移动的 FDD 大规模 MIMO。近期有工作 [24, 13] 提出面向 FDD 大规模 MIMO 的信道预测方法，但在多径数量较多的丰富散射环境中，其性能可能难以保证，尤其是在高移动场景。作者所知，在实际多径信道模型下同时处理这些现实问题的工作很少。

本文拟通过易于部署、具有多项式复杂度的新型 CSI 获取框架解决该问题。FDD 无法像 TDD 那样利用完整信道互易性，但部分与频率无关的参数在上下行之间互易 [25–27]。实测信道工作 [28] 验证了 FDD 部分互易性。利用部分互易性，可从上行信道估计中提取角度、时延、多普勒频移等信息。本文使用称为 MP 的高效线性预测方法 [29] 提取这些信息。

获取上述信息后，为宽带下行导频传输设计 JADD 空间–频率预编码器。预编码器利用信道在角度–时延域中的稀疏性及信道部分互易性，以降低训练开销并便于重构下行信道。该预编码器为宽带设计，需要基站与 UE 联合操作。随后，UE 根据预编码后的下行训练信号估计若干复标量系数并反馈至基站。最后，基站利用这些系数及上行提取的信道参数重构下行 CSI。

不同于此前的信道重构方法 [24, 12, 23, 13, 15]，本文设计了宽带预编码器以及 JADD 反馈框架。本文框架优于传统方法，后者通常依赖 NP-hard 的解法，或无法及时更新 CSI。此外，所提方法能够以多项式复杂度预测信道。第三代合作伙伴计划（3GPP）信道模型下的仿真表明，所提框架在 UE 速度高达 350 km/h 及 CSI 时延较大的场景中具有稳健性。还在不同散射环境、基站天线配置以及信道样本含噪的情况下测试了该框架。数值结果表明其具备稳健性。

本文的主要贡献如下。

- 在工业多径信道模型下处理 FDD 大规模 MIMO 的移动性问题，以往文献很少考虑这一问题。利用信道的角度–时延–多普勒结构与部分互易性，提出 JADD CSI 获取框架，同时解决下行 CSI 过时并降低训练开销。
- 提出在信道较稀疏的角度–时延域中采用 MP 方法提取多普勒频移。凭借宽带大规模 MIMO 系统较高的空间和频率分辨率，该方法使用较少信道样本即可准确估计多普勒。
- 提出用于 FDD 大规模 MIMO 的新型训练与反馈框架。关键环节为下行导频宽带预编码和 UE 端下行路径复系数计算。这一预编码方法需要基站和 UE 分两步联合操作，只向基站反馈标量系数。该框架的训练与反馈开销取决于信道的角度–时延稀疏性和 MP 方法的预测阶数，与基站天线数及带宽无关。
- 推导有限基站天线数与带宽下的下行信道预测误差上界。渐近分析表明，只需两个上行信道样本，预测误差就会在基站天线数与带宽增加时趋于零。还给出了应用本文方法时的预测阶数选择。

## II. 系统模型

本文考虑一个宽带 FDD 大规模 MIMO 系统，基站配备均匀面阵（UPA）。采用传统的正交频分复用（OFDM）调制，有 $N_f$ 个子载波，子载波间隔为 $f_\Delta$。基站天线数为 $N_t=N_vN_h$，$N_v$、$N_h$ 分别为原文所指一行和一列中的天线数。上行和下行中心频率分别为 $f^u$、$f^d$。

本文采用文献 [30] 的多径信道模型，信道的路径数记为 $P$。每条路径 $p$ 的相应参数为复幅度 $\beta_p$、导向向量 $\boldsymbol\alpha^u(\theta_p^u,\phi_p^u)$、多普勒频移 $\omega_p$ 及路径时延 $\tau_p$。因此，在时刻 $t$ 与频率 $f$ 下，基站和 UE $k$ 之间的上行信道为

$$
{\mathbf{h}}_{k,r}^u\left( {t,f} \right) = \sum\limits_{p = 1}^P {\beta _{p}^u{ {\boldsymbol{\alpha}}^u}\left( {\theta _{p}^u,\phi _{p}^u} \right){e^{ - j2\pi f\tau _{p}^u}}{e^{jw_{p}^ut}}},
\tag{1}
$$

其中下标 $k,r$ 表示 UE $k$ 的第 $r$ 根天线，上标 $u$ 表示上行信道。为简洁起见，下文省略下标 $r$ 和 $k$。上行多普勒频移定义为 $w_p^u=v\cos\varphi_p^u f^u/c$，其中 $v$ 为 UE 速率，$\varphi_p^u$ 是路径 $p$ 与 UE 三维速度向量 $\mathbf v$ 的夹角，$c$ 为光速。将天顶角与方位角分别记为 $\theta_p^u$、$\phi_p^u$。图 1 给出了三维笛卡尔坐标系中的 UPA 天线配置，以及天顶角 $\theta$、方位角 $\phi$ 和路径与 UE 速度向量夹角 $\varphi$。发射导向向量 $\boldsymbol\alpha^u(\theta_p^u,\phi_p^u)\in\mathbb C^{N_t\times1}$ 建模为垂直导向向量 $\boldsymbol\alpha_v^u(\theta_p^u)$ 与水平导向向量 $\boldsymbol\alpha_h^u(\theta_p^u,\phi_p^u)$ 的 Kronecker 积：

$$
{ {\boldsymbol{\alpha}}^u}\left( {\theta _{p}^u,\phi _{p}^u} \right) = {\boldsymbol{\alpha}}_h^u\left( {\theta _{p}^u,\phi _{p}^u} \right) \otimes {\boldsymbol{\alpha}}_v^u\left( {\theta _{p}^u} \right),
\tag{2}
$$

其中

$$
{\boldsymbol{\alpha}}_h^u\left( {\theta _{p}^u,\phi _{p}^u} \right) = \left[ {\begin{array}{cccccccccccccccccccc}
1\\
{ {e^{j2\pi \frac{ { {l_h}{f^u}}}{c}\cos \theta _{p}^u\cos \phi _{p}^u}}}\\
 \cdots \\
{ {e^{j2\pi \frac{ { {l_h}{f^u}}}{c}\left( { {N_h} - 1} \right)\cos \theta _{p}^u\cos \phi _{p}^u}}}
\end{array}} \right],
\tag{3}
$$

$$
{\boldsymbol{\alpha}}_v^u\left( {\theta _{p}^u} \right) = \left[ {\begin{array}{cccccccccccccccccccc}
1\\
{ {e^{j2\pi \frac{ { {l_v}{f^u}}}{c}\cos \theta _{p}^u}}}\\
 \cdots \\
{ {e^{j2\pi \frac{ { {l_v}{f^u}}}{c}\left( { {N_v} - 1} \right)\cos \theta _{p}^u}}}
\end{array}} \right],
\tag{4}
$$

$\ell_v,\ell_h$ 分别是垂直和水平方向上的天线间距。类似地，将下行信道建模为

$$
{\mathbf{h}}^d\left( {t,f} \right) = \sum\limits_{p = 1}^P {\beta _{p}^d{ {\boldsymbol{\alpha}}^d}\left( {\theta _{p}^d,\phi _{p}^d} \right){e^{ - j2\pi f\tau _{p}^d}}{e^{ - j2\pi \left( { {f^d} - {f^u}} \right)\tau _{p}^d}}{e^{jw_{p}^dt}}},
\tag{5}
$$

其中 $d$ 表示下行信道。FDD 的上下行之间仅部分参数互易 [26]：

$$
\tau _{p}^u = \tau _{p}^d,\theta _{p}^u = \theta _{p}^d,\phi _{p}^u = \phi _{p}^d,\frac{ {w_{p}^u}}{ {w_{p}^d}} = \frac{ { {f^u}}}{ { {f^d}}}.
\tag{6}
$$

下行导向向量 $\boldsymbol\alpha^d(\theta_p^d,\phi_p^d)$ 与频率有关。对上行导向向量 $\boldsymbol\alpha^u(\theta_p^u,\phi_p^u)$ 应用旋转矩阵，即可计算：

$$
{ {\boldsymbol{\alpha}}^d}\left( {\theta _p^d,\phi _p^d} \right) = \left( { { {\mathbf{R}}_h}\left( {\theta _p^d,\phi _p^d} \right) \otimes { {\mathbf{R}}_v}\left( {\theta _p^d} \right)} \right) \cdot 
 { {\boldsymbol{\alpha}}^u}\left( {\theta _{p}^u,\phi _{p}^u} \right),
\tag{7}
$$

其中

$$
{ {\mathbf{R}}_h}\left( {\theta _p^d,\phi _p^d} \right) = {\mathrm{diag}}\left( {\begin{array}{cccccccccccccccccccc}
    1\\
    { {e^{j2\pi \frac{ { {l_h}\left( { {f^d} - {f^u}} \right)}}{c}\cos \theta _p^d\cos \phi _p^d}}}\\
     \cdots \\
    { {e^{j2\pi \left( { {N_h} - 1} \right)\frac{ { {l_h}\left( { {f^d} - {f^u}} \right)}}{c}\cos \theta _p^d\cos \phi _p^d}}}
    \end{array}} \right),
\tag{8}
$$

$$
{ {\mathbf{R}}_v}\left( {\theta _p^d} \right) = {\mathrm{diag}}\left( {\begin{array}{cccccccccccccccccccc}
    1\\
    { {e^{j2\pi \frac{ { {l_v}\left( { {f^d} - {f^u}} \right)}}{c}\cos \theta _p^d}}}\\
     \cdots \\
    { {e^{j2\pi \left( { {N_v} - 1} \right)\frac{ { {l_v}\left( { {f^d} - {f^u}} \right)}}{c}\cos \theta _p^d}}}
    \end{array}} \right),
\tag{9}
$$

分别是水平旋转矩阵与垂直旋转矩阵。

在 FDD 模式下，上行与下行符号在时域依次传输。图 2 展示本文框架的流程。基站利用探测参考信号（SRS）提取信道参数，据此计算下行导频的宽带预编码器。根据文献 [31]，SRS 可配置为周期模式，周期 $T_{\mathrm{SRS}}$ 以时隙为单位灵活设置。在 30 kHz 子载波间隔这一常见配置下，最小 SRS 周期 $T_{\mathrm{SRS}}$ 可短至 0.5 ms。记 CSI 时延为 $T_d=N_dT_{\mathrm{SRS}}$，其中<a id="page-4"></a>$N_d$ 是以时隙为单位的时延。UE 收到下行导频后，计算并反馈复值下行路径系数。基站最终根据反馈信息和提取的参数重构下行 CSI。

## III. 上行信道参数提取

利用 FDD 部分信道互易性的优势，所提框架依赖上行信道参数的提取。基站一侧通过 SRS 较容易估计上行信道参数。为更好地利用多径信道稀疏性，下面在角度–时延域讨论上行信道参数提取。

### A. 角度–时延域投影

在宽带大规模 MIMO 系统中，时域上行信道可写为

$$
{ {\mathbf{h}}^u}\left( {t,f_n^u} \right) = \sum\limits_{p = 1}^P {\beta _p^u{ {\mathbf{\boldsymbol{\alpha} }}^u}\left( {\theta _p^u,\phi _p^u} \right){e^{ - j2\pi f_n^u\tau _p^u}}{e^{jw_p^ut}}} ,
\tag{10}
$$

其中 $f_n^u$（$n\in\{1,\ldots,N_f\}$）是第 $n$ 个子载波的频率。全部子载波上的上行信道可写成矩阵形式：

$$
{ {\mathbf{H}}^u}\left( t \right) = \left[ { { {\mathbf{h}}^u}{ {\left( {t,f_1^u} \right)}}, \cdots { {\mathbf{h}}^u}{ {\left( {t,f_{ {N_f}}^u} \right)}}} \right].
\tag{11}
$$

式 (11) 的向量形式为

$$
{ {\mathbf{h}}^u}\left( t \right) = {\mathbf{vec}}\left( { { {\mathbf{H}}^u}\left( t \right)} \right) = \sum\limits_{p = 1}^P {\beta _p^u{e^{ - j2\pi {f^u}{\tau^u_p}}}{e^{jw_p^ut}}{ {\mathbf{r}}_p^u}},
\tag{12}
$$

其中 $\mathbf r_p^u=\mathbf c(\tau_p^u)\otimes\boldsymbol\alpha^u(\theta_p^u,\phi_p^u)$ 为路径 $p$ 的角度–时延结构，$\mathbf c(\tau_p^u)$ 是时延向量：

$$
{\mathbf{c}}\left( {\tau _p^u} \right) = {e^{ - j2\pi {f^u}{f_\Delta }{\tau _p^u}}}{\left[ {1 \cdots {e^{ - j2\pi {\tau _p^u}\left( { {N_f} - 1} \right){f_\Delta }}}} \right]^T}.
\tag{13}
$$

类似地，向量化的下行信道为

$$
{ {\mathbf{h}}^d}\left( t \right) = \sum\limits_{p = 1}^P {\beta _p^d{e^{ - j2\pi {f^d}{\tau^d _p}}}{e^{jw_p^dt}}{\mathbf{r}}_p^d}.
\tag{14}
$$

用矩阵 $\mathbf Q\in\mathbb C^{N_tN_f\times N_tN_f}$ 将 $\mathbf h^u(t)$ 投影到角度–时延域 [32,33]：

$$
{\mathbf{Q}}= {\mathbf{W}}{\left( { {N_f}} \right)^H} \otimes {\mathbf{W}}\left( { {N_h}} \right) \otimes {\mathbf{W}}\left( { {N_v}} \right).
\tag{15}
$$

DFT 矩阵 $\mathbf W(X)$ 由下式计算：

$$
{\mathbf{W}}\left( X \right) = \frac{1}{ {\sqrt X }}\left[ {\begin{array}{cccccccccccccccccccc}
1&1& \cdots &1\\
1&{ {w^{1 \cdot 1}}}& \cdots &{ {w^{1 \cdot \left( {X - 1} \right)}}}\\
 \vdots & \vdots & \ddots & \cdots \\
1&{ {w^{\left( {X - 1} \right) \cdot 1}}}& \cdots &{ {w^{\left( {X - 1} \right)\left( {X - 1} \right)}}}
\end{array}} \right],
\tag{16}
$$

其中 $w=e^{j2\pi/X}$。从而角度–时延域信道 $\hat{\mathbf g}^u(t)\in\mathbb C^{N_tN_f\times1}$ 为

$$
{\hat {\mathbf{g}}^u}\left( t \right)= { {\mathbf{Q}}^H}{ {\mathbf{h}}^u}\left( t \right).
\tag{17}
$$

将 $\mathbf h^u(t)$ 投影到角度–时延域后，可以利用信道稀疏性，得到

$$
{ {\mathbf{h}}^u}\left( t \right)= \sum\limits_{i = 1}^{ {N_t}{N_f}} {\hat g_i^u\left( t \right){ {\mathbf{q}}_i}},
\tag{18}
$$

其中 $\mathbf q_i$ 是 $\mathbf Q$ 的第 $i$ 列，$\hat g_i^u(t)=\mathbf q_i^H\mathbf h^u(t)$ 为相应复幅度。由于角度–时延域信道稀疏，$\mathbf h^u(t)$ 可用 $\mathbf Q$ 中较少数量的所选列的线性组合近似，这些列包含 $\mathbf h^u(t)$ 的大部分功率。$\mathbf Q$ 中所选列的索引集合由下式确定：

$$
{\mathcal{S}} = \mathop {\arg \min }\limits_{\left|{\mathcal{S}} \right|} \{ \sum\limits_{l = 1}^{ {N_L}} {\sum\limits_{i \in {\mathcal{S}}} { { {\left| {\hat g_i^u\left( { {t_l}} \right)} \right|}^2}}  \ge \eta } \sum\limits_{l = 1}^{ {N_L}} { { {\left| { { {\hat {\mathbf{g}}}^u}\left( { {t_l}} \right)} \right|}^2}} \},
\tag{19}
$$

其中 $\hat g_i^u(t_l)$ 是 $\hat{\mathbf g}^u(t_l)$ 的第 $i$ 行，$\eta$ 是功率阈值。每次上行信道参数提取使用 $N_L$ 个信道样本。集合 $\mathcal S$ 的大小记为 $N_s$，即 $\mathbf Q$ 中所选列的总数。

索引集合 $\mathcal S$ 随时间变化，并在每次提取上行信道参数时更新。为简化记号，下文省略自变量 $t$。尽管 $N_s$ 随信道样本和时间变化，实际实现中通常寻求一个满足式 (19) 的固定 $N_s$，使用起来更方便。$N_s$ 同时影响估计精度及计算复杂度，需要谨慎选择。因此，选择 $N_s$ 涉及性能与复杂度之间的折中。可以用 $N_s$ 个角度–时延向量近似上行信道：

$$
{\widetilde {\mathbf{h}}^u}\left( t \right)= \sum\limits_{i \in {\mathcal {S}}} {\hat g_i^u\left( t \right){ {\mathbf{q}}_i}}.
\tag{20}
$$

比较式 (20) 与式 (12)，复幅度 $\hat g_i^u(t)$ 具有隐含的物理意义。各 $\mathbf q_i$ 映射到角度–时延结构 $\mathbf r_p^u$，相应的 $\hat g_i^u(t)$ 则映射到复增益及多普勒因子 $\beta_p^u e^{-j2\pi f^u\tau_p}e^{jw_p^u t}$。用 $M$ 阶指数叠加拟合复幅度 $\hat g_i^u(t)$：

$$
\hat g_i^u\left( t \right)  \buildrel \Delta \over  = \sum\limits_{m = 1}^M {a_m^u} \left( i \right){\left( {z_m^u\left( i \right)} \right)^t},
\tag{21}
$$

<a id="page-5"></a>

其中 $z_m^u(i)$ 表示多普勒频率，$a_m^u(i)$ 表示相应的复幅度。则上行信道可近似为

$$
{\widetilde {\mathbf{h}}^u}\left( t \right) = \sum\limits_{i \in {\mathcal{S}}} {\sum\limits_{m = 1}^M {a_m^u\left( i \right){\left( {z_m^u\left( i \right)} \right)^t}{ {\mathbf{q}}_i}} } .
\tag{22}
$$

为简便起见，假设对全部所选角度–时延向量使用同一个 $M$。选择 $M$ 时需考虑复杂度、多普勒频率的多样性及 DFT 投影失配问题。更多细节见第 V 节。下一小节使用 MP 方法估计多普勒频率 $z_m^u(i)$。

### B. 基于矩阵束的多普勒估计

由式 (21) 中的信道样本估计 $z_m^u(i)$，是一个复指数叠加问题，特别适合采用 MP 方法。与 ESPRIT 或 Prony 等传统多项式方法相比，MP 计算复杂度低，对噪声不敏感 [29]。因此，在角度–时延域应用该方法提取多普勒。

先引入假设 1，它意味着参数的平稳时间长于 CSI 时延。

**假设 1** 在 CSI 时延 $T_d$ 内，角度与多普勒频移等信道参数近似不变。

在中等移动性场景下，这一假设通常成立 [34]。例如，若 CSI 时延为 5 ms，UE 速度为 100 km/h，则该时延期间 UE 大约移动 0.14 m。与 UE 至基站的距离相比，这一变化很小，可近似认为 UE 位置不变。因此，角度与多普勒等信道参数在 CSI 时延内几乎不变。

先简要介绍 MP 方法的原理。多普勒 $z_m^u(i)$ 在 MP 中称为极点。该方法的三个关键参数是样本量 $N_L$、预测阶数 $L$ 和极点 $z_m^u(i)$。根据复增益 $\hat g_i^u(t)$ 生成预测矩阵 $\mathbf P_1(i)$、$\mathbf P_0(i)$：

$$
{ {\mathbf{P}}_1}\left( i \right)= \left[ {\begin{array}{cccccccccccccccccccc}
{\hat g_i^u\left( { {t_{L + 1}}} \right)}&{\hat g_i^u\left( { {t_L}} \right)}& \cdots &{\hat g_i^u\left( { {t_2}} \right)}\\
{\hat g_i^u\left( { {t_{L + 2}}} \right)}&{\hat g_i^u\left( { {t_{L + 1}}} \right)}& \cdots &{\hat g_i^u\left( { {t_3}} \right)}\\
 \vdots & \vdots & \ddots & \vdots \\
{\hat g_i^u\left( { {t_{ {N_L}}}} \right)}&{\hat g_i^u\left( { {t_{ {N_L} - 1}}} \right)}& \cdots &{\hat g_i^u\left( { {t_{ {N_L} - L + 1}}} \right)}
\end{array}} \right],
$$

$$
{ {\mathbf{P}}_0}\left( i \right)= \left[ {\begin{array}{cccccccccccccccccccc}
{\hat g_i^u\left( { {t_L}} \right)}&{\hat g_i^u\left( { {t_{L{\mathrm{ - }}1}}} \right)}& \cdots &{\hat g_i^u\left( { {t_1}} \right)}\\
{\hat g_i^u\left( { {t_{L + 1}}} \right)}&{\hat g_i^u\left( { {t_L}} \right)}& \cdots &{\hat g_i^u\left( { {t_2}} \right)}\\
 \vdots & \vdots & \ddots & \vdots \\
{\hat g_i^u\left( { {t_{ {N_L}{\mathrm{ - }}1}}} \right)}&{\hat g_i^u\left( { {t_{ {N_L} - 2}}} \right)}& \cdots &{\hat g_i^u\left( { {t_{ {N_L} - L}}} \right)}
\end{array}} \right].
$$

为简便起见，省略上标 $u$，构造三个矩阵：

$$
{ {\mathbf{Z}}_0} = {\mathrm{diag}}\left\{ { {z_1}\left( i \right),{z_2}\left( i \right), \cdots {z_M}\left( i \right)} \right\},
\tag{23}
$$

$$
{ {\mathbf{Z}}_1} = \left[ {\begin{array}{cccccccccccccccccccc}
  1&1& \cdots &1 \\ 
  { {z_1}\left( i \right)}&{ {z_2}\left( i \right)}& \cdots &{ {z_M}\left( i \right)} \\ 
   \vdots & \vdots & \ddots & \vdots  \\ 
  { {z_1}{ {\left( i \right)}^{ {N_L} - L - 1}}}&{ {z_2}{ {\left( i \right)}^{ {N_L} - L - 1}}}& \cdots &{ {z_M}{ {\left( i \right)}^{ {N_L} - L - 1}}} 
\end{array}} \right],
$$

$$
{ {\mathbf{Z}}_2} = \left[ {\begin{array}{cccccccccccccccccccc}
  { {z_1}{ {\left( i \right)}^{L - 1}}}&{ {z_1}{ {\left( i \right)}^{L - 1}}}& \cdots &1 \\ 
  { {z_1}{ {\left( i \right)}^{L - 1}}}&{ {z_2}{ {\left( i \right)}^{L - 2}}}& \cdots &1 \\ 
   \vdots & \vdots & \ddots & \vdots  \\ 
  { {z_M}{ {\left( i \right)}^{L - 1}}}&{ {z_M}{ {\left( i \right)}^{L - 2}}}& \cdots &1 
\end{array}} \right].
\tag{24}
$$

复幅度 $a_m^u(i)$ 表示为对角矩阵：

$$
{\mathbf{A}}_u\left( i \right) = {\mathrm{diag}}\left\{ { {a_1^u}\left( i \right),{a_2^u}\left( i \right), \cdots {a_M^u}\left( i \right)} \right\}.
\tag{25}
$$

根据文献 [29]，如下关系成立：

$$
\left\{ \begin{array}{l}
{ {\mathbf{P}}_0}\left( i \right)= { {\mathbf{Z}}_1}\left( i \right){\mathbf{A}}_u\left( i \right){ {\mathbf{Z}}_2}\left( i \right),\\
{ {\mathbf{P}}_1}\left( i \right)= { {\mathbf{Z}}_1}\left( i \right){\mathbf{A}}_u\left( i \right){ {\mathbf{Z}}_0}\left( i \right){ {\mathbf{Z}}_2}\left( i \right).
\end{array} \right.
\tag{26}
$$

为说明取得极点的机制，引入引理 1 [29]。

**引理 1** 若 $M\leq L\leq N_L-M$，则求解如下奇异广义特征值问题可得极点 $z_m^u(i)$：

$$
\left( { { {\mathbf{P}}_0}{ {\left( i \right)}^\dagger }{ {\mathbf{P}}_1}\left( i \right)} \right){\mathbf{x}} = z{\mathbf{x}},
\tag{27}
$$

每个特征值 $z$ 等于一个极点 $z_m^u(i)$，$\mathbf x$ 是相应特征向量。

得到全部极点后，即可计算多普勒频率。算法 1 说明如何估计上行信道参数，如多普勒频移和角度–时延索引集合。

**算法 1：** 基于矩阵束的多普勒估计。

1. 初始化 $N_L,L,M$、开始时刻 $t_s$、结束时刻 $t_e$，并取得信道样本 $\mathbf h^u(t)$。
2. 由式 (18) 将 $\mathbf h^u(t)$ 投影至角度–时延域。
3. 找到满足式 (19) 的合适 $N_s$。
4. 对 $t\in[t_s,t_e]$ 循环。
5. 取得索引集合 $\mathcal S$。
6. 对 $n_i\in[1,N_s]$ 循环。
7. 生成预测矩阵 $\mathbf P_1(n_i)$、$\mathbf P_0(n_i)$。
8. 用式 (27) 计算特征值矩阵 $\mathbf Z_0(n_i)$。
9. 更新 $n_i=n_i+1$。
10. 结束内层循环。
11. 更新 $t=t+1$。
12. 结束外层循环。
13. 返回上行角度–时延索引集合及多普勒频移。

### C. 含噪信道样本分析

上述讨论假设信道样本无噪声，此时为简便起见，可设预测阶数 $L=M$。在实际中，通常只能获得含噪信道样本。此时，本文提出<a id="page-6"></a>采用最小描述长度（MDL）准则 [35] 检测式 (22) 中的 $M$，并用 $M$ 阶截断奇异值分解（SVD）去噪，其中预测阶数满足 $L>M$。在无需预先决定或假设 $M$ 的情况下，按 MDL 准则求最小值得到 $M$：

$$
M = \mathop {\min }\limits_{x \in \left\{ {0,1 \cdots L - 1} \right\}} \left\{ {\log { {\left( {\frac{ {\prod\limits_{m = x + 1}^L { {z_m}{ {\left( i \right)}^{ {1 \mathord{\left/
 {\vphantom {1 {\left( {L - x} \right)}}} \right.
 \kern-\nulldelimiterspace} {\left( {L - x} \right)}}}}} }}{ {\frac{1}{ {L - x}}\sum\limits_{m = x + 1}^L { {z_m}\left( i \right)} }}} \right)}^{ - {N_L}\left( {L - x} \right)}}} \right\},
$$

其中 $z_m(i)$ 为下列矩阵的奇异值：

$$
{ {\mathbf{P}}_{1,0}} = \left[ {\begin{array}{cccccccccccccccccccc}
{ {\mathbf{p}}\left( { {t_{L + 1}}} \right)}&\vline& { { {\mathbf{P}}_0}}
\end{array}} \right],
\tag{28}
$$

其中 $\mathbf p(t_{L+1})$ 是 $\mathbf P_1$ 的第一列。得到 $M$ 后，经秩为 $M$ 的截断 SVD 计算预测矩阵 $\mathbf P_{1,0}$：

$$
{ {\mathbf{P}}_{1,0}} = { {\mathbf{U}}_M}{ {\mathbf{\Lambda }}_M}{\mathbf{V}}_M^H,
\tag{29}
$$

其中 $\mathbf U_M$、$\boldsymbol\Lambda_M$、$\mathbf V_M$ 分别为 $\mathbf P_{1,0}$ 截断到 $M$ 的左奇异向量、奇异值和右奇异向量。引理 1 的式 (27) 可改写为

$$
\left( { { {\mathbf{P}}_{0,M}}{ {\left( i \right)}^\dagger }{ {\mathbf{P}}_{1,M}}\left( i \right)} \right){\mathbf{x}} = z{\mathbf{x}},
\tag{30}
$$

其中

$$
\left\{ \begin{array}{l}
{ {\mathbf{P}}_{0,M}}\left( i \right) = { {\mathbf{U}}_M}{ {\mathbf{\Lambda }}_M}{ {\mathbf{V}}_{M\left( {1:M - 1,:} \right)}}^H,\\
{ {\mathbf{P}}_{1,M}}\left( i \right) = { {\mathbf{U}}_M}{ {\mathbf{\Lambda }}_M}{ {\mathbf{V}}_{M\left( {2:M,:} \right)}}^H,
\end{array} \right.
\tag{31}
$$

$\mathbf V_{M(1:M-1,:)}$ 表示由第一行至第 $M-1$ 行组成的子矩阵，$\mathbf V_{M(2:M,:)}$ 则由第二行至第 $M$ 行组成。在含噪样本情形下，求式 (30) 的特征值等价于求极点 $z_m(i)$。

本节已在基站与 UE 得到多普勒频移和角度–时延向量等上行信道参数，下一节利用这些参数进行下行训练。

## IV. 下行训练与信道预测

本文的 CSI 获取框架依赖从上行信道样本估计的信道参数。第 III 节已经得到上行角度–时延向量 $\mathbf q_i$ 和多普勒频率 $z_m^u(i)$。本节介绍基于所提取信道参数的 JADD 导频预编码方案，以及下行信道重构过程。

### A. 由上行信道参数提取下行参数

由于上下行工作于不同频带，需要对从上行信道样本获得的角度–时延向量及多普勒频移作变换，以适配下行频带。定义所选的上行角度–时延向量：

$$
{ {\mathbf{u}}_j} = \left\{ { { {\mathbf{q}}_i}|i = {i_{ {s_j}}},j \in \left\{ {1,2 \cdots {N_s}} \right\}} \right\},
\tag{32}
$$

其中 $i_{s_j}$ 表示上行角度–时延向量索引集合 $\mathcal S$ 中的第 $j$ 个索引。为将上行角度–时延向量变换为下行向量，引入命题 1。

**命题 1** 下行角度–时延向量 $\mathbf d_j$ 可由上行角度–时延向量 $\mathbf u_j$ 得到：

$$
{ {\mathbf{d}}_j} = \left( { { {\mathbf{I}}_{ {N_f}}} \otimes {\mathbf{R}}\left( {\theta _j^d,\phi _{ {j}}^d} \right)} \right){ {\mathbf{u}}_j},j \in \left\{ {1,2 \cdots {N_s}} \right\},
\tag{33}
$$

其中 $\mathbf R(\theta_j^d,\phi_j^d)=\mathbf R_h(\theta_j^d,\phi_j^d)\otimes\mathbf R_v(\theta_j^d)$。

**证明** 见附录 A。

命题 1 说明 UE 配备单根天线时，如何由上行角度–时延向量求取下行角度–时延向量。实际中，UE 可使用双极化天线。方法可直接推广，见说明 1。

**说明 1** 如果 UE 使用双极化天线，DFT 矩阵 $\mathbf W(N_t)$ 变为

$$
{\mathbf{W}}\left( { {N_t}} \right)= \left[ {\begin{array}{cccccccccccccccccccc}
    { {\mathbf{W}}\left( { {N_h}} \right) \otimes {\mathbf{W}}\left( { {N_v}} \right)}&{}\\
    {}&{ {\mathbf{W}}\left( { {N_h}} \right) \otimes {\mathbf{W}}\left( { {N_v}} \right)}
    \end{array}} \right].
$$

于是，第 $j$ 个下行角度–时延向量为

$$
{ {\mathbf{d}}_j} = \left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left[ {\begin{array}{cccccccccccccccccccc}
    { {\mathbf{R}}\left( {\theta _j^d,\phi _j^d} \right)}&{}\\
    {}&{ {\mathbf{R}}\left( {\theta _j^d,\phi _j^d} \right)}
    \end{array}} \right]} \right){ {\mathbf{q}}_i}.
\tag{34}
$$

随后，利用由上行信道样本得到的极点 $z_m^u(i)$ 计算下行多普勒频移：

$$
{e^{jw_m^d\left( j \right)}} = {e^{j\frac{ {\arccos \left( {\Re \left\{ {\frac{ { {z_m^u}\left( i \right)}}{ {\left| { {z_m^u}\left( i \right)} \right|}}} \right\}} \right){f^d}}}{ { {f^u}}}}}.
\tag{35}
$$

### B. 下行导频预编码和 CSI 重构

给定下行信道角度–时延向量及多普勒频移，可按如下方式重构下行 CSI：

$$
{\widetilde {\mathbf{h}}^d}\left( t \right) = \sum\limits_{j = 1}^{ {N_s}} {\sum\limits_{m{\text{  =  }}1}^M {a_m^d\left( j \right){e^{jw_m^d\left( j \right) {t} }}{ {\mathbf{d}}_j}} } ,
\tag{36}
$$

其中 $a_m^d(j)$ 是与 $\mathbf d_j$ 对应的第 $m$ 个复幅度。要重构下行信道，需估计 $a_m^d(j)$。本文提出用 JADD 预编码的导频信号进行估计。所提前置预编码矩阵还利用 $\widetilde{\mathbf h}^d(t)$ 的稀疏结构降低训练开销。

向量化下行信道 $\widetilde{\mathbf h}^d(t)$ 可分解为三个矩阵：

$$
\widetilde {\mathbf{h}}^d\left( t \right) = { {\mathbf{D}}}{ {\mathbf{E}}}\left( t \right){ {\mathbf{a}}^d}.
\tag{37}
$$

下行角度–时延向量矩阵 $\mathbf D\in\mathbb C^{N_fN_t\times N_s}$ 为

$$
{ {\mathbf{D}}} = \left[ {\begin{array}{cccccccccccccccccccc}
{ {\mathbf{d}}_1}&{ {\mathbf{d}}_2}& \cdots &{ {\mathbf{d}}_{N_s}}
\end{array}} \right].
\tag{38}
$$

多普勒矩阵 $\mathbf E(t)\in\mathbb C^{N_s\times N_sM}$ 定义为

$$
{\mathbf{E}}\left( t \right) = \left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{e}}_1}\left( t \right)}&{}&{}&{}\\
{}&{ { {\mathbf{e}}_2}\left( t \right)}&{}&{}\\
{}&{}& \ddots &{}\\
{}&{}&{}&{ { {\mathbf{e}}_{N_s}}\left( t \right)}
\end{array}} \right],
\tag{39}
$$

其中

$$
{ {\mathbf{e}}_j}\left( t \right) = \left[ {\begin{array}{cccccccccccccccccccc}
  { {e^{jw_1^d\left( j \right) {t} }}}&{ {e^{jw_2^d\left( j \right) {t} }}}& \cdots &{ {e^{jw_M^d\left( j \right) {t} }}} 
\end{array}} \right].
\tag{40}
$$

<a id="page-7"></a>

下行复幅度向量 $\mathbf a^d\in\mathbb C^{N_sM\times1}$ 为

$$
{ {\mathbf{a}}^d} = {\left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{a}}^d}\left( 1 \right)}&{ { {\mathbf{a}}^d}\left( 2 \right)}& \cdots &{ { {\mathbf{a}}^d}\left( { {N_s}} \right)}
\end{array}} \right]^T},
\tag{41}
$$

其中

$$
{ {\mathbf{a}}^d}\left( j \right) = {\left[ {\begin{array}{cccccccccccccccccccc}
{a_1^d\left( j \right)}&{a_2^d\left( j \right)}& \cdots &{a_M^d\left( j \right)}
\end{array}} \right]}.
\tag{42}
$$

利用式 (37)，可设计辅助下行导频训练的预编码矩阵。根据下行多普勒频移及角度–时延向量构造该矩阵。传统预编码在空间域进行，从接收机角度看，信号在无线传播过程中合成。本文采用的是广义宽带空间–频率联合预编码。实质上，训练信号先在基站一侧作空间域组合，再在 UE 一侧作频域组合 [36]。

将预编码矩阵记为 $\mathbf F(t)\in\mathbb C^{N_tN_f\times N_sM}$：

$$
{\mathbf{F}}\left( t \right) = \left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{f}}_1}\left( t \right)}&{ { {\mathbf{f}}_2}\left( t \right)}& \cdots &{ { {\mathbf{f}}_{ {N_s}M}}\left( t \right)}
\end{array}} \right].
\tag{43}
$$

$\mathbf F(t)$ 的每一列，例如 $\mathbf f_n(t)\in\mathbb C^{N_fN_t\times1}$，由用于全部 $N_f$ 个子载波的预编码向量组成：

$$
{ {\mathbf{f}}_n}\left( t \right) = {\left[ {\begin{array}{cccccccccccccccccccc}
  { { {\mathbf{f}}_n}{ {\left( {t,{f_1}} \right)}^T}}&{ { {\mathbf{f}}_n}{ {\left( {t,{f_2}} \right)}^T}}& \cdots &{ { {\mathbf{f}}_n}{ {\left( {t,{f_{ {N_f}}}} \right)}^T}} 
\end{array}} \right]^T},
$$

其中 $\mathbf f_n(t,f_l)\in\mathbb C^{N_t\times1}$ 为宽带预编码器 $\mathbf f_n(t)$ 中用于第 $l$ 个子载波的预编码向量。将导频矩阵 $\mathbf S$ 记为

$$
{\mathbf{S}}{\mathrm{ = }}{\left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{s}}_1}^T}&{ { {\mathbf{s}}_2}^T}& \cdots &{ { {\mathbf{s}}_{ {N_s}M}}^T}
\end{array}} \right]^T},{ {\mathbf{s}}_n} \in {\mathbb{C}^{1 \times \tau }}.
\tag{44}
$$

其中 $\tau$ 为导频序列长度。基站在第 $l$ 个子载波发送的导频序列为

$$
{ {\mathbf{g}}^d}\left( {t,{f_l}} \right) = \sum\limits_{n = 1}^{ {N_s}M} { { {\mathbf{f}}_n}\left( {t,{f_l}} \right){ {\mathbf{s}}_n}}.
\tag{45}
$$

UE 在第 $l$ 个子载波接收的导频信号为

$$
{ {\mathbf{x}}^d}\left( {t,{f_l}} \right) = { {\mathbf{h}}^d}{\left( {t,{f_l}} \right)^T}{ {\mathbf{g}}^d}\left( {t,{f_l}} \right) + {\mathbf{n}}\left( {t,{f_l}} \right),
\tag{46}
$$

其中 $\mathbf h^d(t,f_l)$ 表示第 $l$ 个子载波上的下行信道，$\mathbf n(t,f_l)$ 为该子载波上的噪声。UE 对全部子载波求和：

$$
{ {\mathbf{y}}^d}\left( t \right) = \sum\limits_{l = 1}^{ {N_f}} { {\mathbf{x}^d}\left( {t,{f_l}} \right)}  + {\mathbf{n}}\left( t \right).
\tag{47}
$$

上述训练信号的空间–频率联合预编码也可写成矩阵形式：

$$
{ {\mathbf{y}}^d}\left( t \right) = { {\mathbf{h}}^d}{\left( t \right)^T}{\mathbf{F}}\left( t \right){\mathbf{S}} + {\mathbf{n}}\left( t \right).
\tag{48}
$$

接下来设计预编码矩阵 $\mathbf F(t)$。按照本文框架，按式 (37) 重构下行信道，故可将式 (48) 改写为

$$
{\widetilde {\mathbf{y}}^d}\left( t \right) = \left( { { {\left( { { {\mathbf{a}}^d}} \right)}^T}{\mathbf{E}}{ {\left( t \right)}^T}{ {\mathbf{D}}^T}{\mathbf{F}}\left( t \right)} \right){\mathbf{S}} + {\mathbf{n}}\left( t \right).
\tag{49}
$$

高斯噪声向量 $\mathbf n(t)\in\mathbb C^{1\times\tau}$ 服从 $\mathbf n(t)\sim\mathcal{CN}(0,\sigma^2\mathbf I)$，其中 $\sigma^2$ 为噪声功率。目标是估计系数向量 $\mathbf a^d$，并将其反馈给基站。

$\mathbf E(t)^T\mathbf D^T$ 的秩为 $N_s$，不存在右逆。$\mathbf E(t)^T$ 满列秩，$\mathbf D^T$ 满行秩。因此，$\mathbf D^T$ 存在右逆，而 $\mathbf E(t)^T$ 不存在右逆。为此引入 $\mathbf E(t)^T$ 的 Moore–Penrose 伪逆，将预编码矩阵设计为

$$
{ {\mathbf{F}}}\left( t \right) = {\left( { { {\mathbf{D}}}{^T}} \right)^\dagger }{\left( { { {\mathbf{E}}}{ {\left( t \right)}^T}} \right)^\dagger }.
\tag{50}
$$

将式 (50) 的 $\mathbf F(t)$ 代入式 (49)，得

$$
\widetilde {\mathbf{y}}^d\left( t \right) = \left( { { { {\left( { { {\mathbf{a}}^d}} \right)}^T}}{ {\mathbf{E}}}{ {\left( t \right)}^T}{ {\left( { { {\mathbf{E}}}{ {\left( t \right)}^T}} \right)}^\dagger }} \right){\mathbf{S}} + { {\mathbf{n}}}\left( t \right).
\tag{51}
$$

应用预编码矩阵后，式 (49) 中 $\mathbf S$ 的维数减小为 $\mathbb C^{N_sM\times\tau}$。由于角度–时延域的信道稀疏且 $M$ 较小，预编码矩阵还能降低训练开销，使之不随基站天线数或带宽增加。

原则上应保证 $\tau\geq N_sM$。为简便起见，设训练序列长度为 $\tau=N_sM$，将 $\mathbf S$ 设计成酉矩阵。由式 (51)，可通过最小二乘（LS）估计获得未知参数 $\mathbf a^d$：

$$
{\hat{\mathbf{a}}^d}={\left( { {\mathbf{S}}{}^T{ {\mathbf{E}}}{ {\left( t \right)}^\dagger }{ {\mathbf{E}}}\left( t \right)} \right)^\dagger }\widetilde {\mathbf{y}}^d{\left( t \right)^T}.
\tag{52}
$$

UE 应将估计出的复系数向量 $\hat{\mathbf a}^d$ 反馈给基站。于是，基站可直接重构经历 CSI 时延 $T_d$ 后的下行信道：

$$
{\widetilde {\mathbf{h}}^d}\left( {t + {T_d}} \right) = \sum\limits_{j = 1}^{ {N_s}} {\sum\limits_{m = 1}^M { {\hat{a}}_m^d\left( j \right){e^{jw_m^d\left( j \right)\left( {t + {T_d}} \right)}}{ {\mathbf{d}}_j}} }.
\tag{53}
$$

重构的下行信道用于数据传输的下行预编码。

## V. 性能分析

在本文框架中，$N_s$ 和 $L$ 的选择影响信道预测性能与计算复杂度。本节着重分析 $N_s$ 与 $L$ 对预测性能、计算复杂度和反馈开销的影响。

### A. 信道预测性能分析

下行信道预测误差用归一化均方误差（NMSE）定义：

$$
\varepsilon  \buildrel \Delta \over = 10\log \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( {t + {T_d}} \right) - {\mathrm{ }}{ {\widetilde {\mathbf{h}}}^d}\left( {t + {T_d}} \right)}}{ { { {\mathbf{h}}^d}\left( {t + {T_d}} \right)}}} \right\|_2^2} \right\}.
\tag{54}
$$

定义预测时刻 $t_p=t+T_d$。回到下行信道重构式 (37)，将其中的 $\mathbf a^d(t)$ 按式 (52) 替换：

$$
{\widetilde {\mathbf{h}}^d}\left( { {t_p}} \right) = \widetilde {\mathbf{h}}_1^d\left( { {t_p}} \right) + \widetilde {\mathbf{h}}_2^d\left( { {t_p}} \right),
$$

其中

$$
{\widetilde {\mathbf{h}}_1^d}\left( t_p \right) ={ {\mathbf{D}}}{ {\mathbf{E}}}\left( t_p \right){\left( { { {\mathbf{D}}}{ {\mathbf{E}}}\left( t_p \right)} \right)^\dagger }{\mathbf{h}}^d\left( t_p \right) = { {\mathbf{D}}}{ {\mathbf{D}}}{^\dagger }{\mathbf{h}}^d\left( t_p \right),
\tag{55}
$$

$$
{\widetilde {\mathbf{h}}_{2}^d}\left( t_p \right) = { {\mathbf{D}}}{ {\mathbf{E}}}\left( t_p \right){\left( { { {\mathbf{S}}^\dagger }} \right)^T}{ {\mathbf{n}}}{\left( t_p \right)^T}.
\tag{56}
$$

<a id="page-8"></a>

于是式 (54) 变为

$$
{\varepsilon } \buildrel \Delta \over = 10\log \mathbb{E}\left\{ {\left\| {\frac{ { {\mathbf{h}}^d\left( t_p \right) - { {\widetilde {\mathbf{h}}}_{1}^d}\left( t_p \right) - { {\widetilde {\mathbf{h}}}_{2}^d}\left( t_p \right)}}{ { {\mathbf{h}}^d\left( t_p \right)}}} \right\|_2^2} \right\} .
\tag{57}
$$

下面的定理给出下行信道预测误差的下界，由令 $N_s$ 取最大值，即 $N_s=N_fN_t$ 得到。

**定理 1** 所提 CSI 获取框架的下行信道预测误差下界为

$$
{\varepsilon } = 10\log \left( {\frac{ { {\sigma ^2}{N_s}M}}{ {\mathbb{E}{ {\left\| { {\mathbf{h}}^d\left( t_p \right)} \right\|}_2}^2}}} \right).
\tag{58}
$$

**证明** 见附录 B。

定理 1 给出考虑 $\mathbf Q$ 中所有角度–时延向量时的信道预测误差下界。但由于反馈开销极大、复杂度很高，这一条件可能难以实现。多径角度与时延的稀疏性使本文框架可以选用小得多的 $N_s$。

另一个重要参数是预测阶数 $L$，其在宽带大规模 MIMO 情形下可以保持较小，如下列定理所示。先将 $N_P$ 定义为所有下行路径中互不相同的角度–时延结构的数量。

**定理 2** 当 $L=1$、$N_L=2$、$N_s=N_P$ 时，下行信道预测误差随基站天线数与带宽增加而趋于零：

$$
\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - {\mathrm{ }}{ {\widetilde {\mathbf{h}}}^d}\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} = 0.
\tag{59}
$$

**证明** 见附录 C。

定理 2 给出框架的渐近信道预测性能。在天线数和带宽有限时，说明 2 可指导选择适当的预测阶数 $L$。

**说明 2** 给定满足 $M\leq L\leq N_L-L$ 的任意 $L$，信道预测误差满足

$$
\begin{split}
        &\mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} - \mathbb{E}\left\{ {\frac{ { {N_s}M{\sigma ^2}}}{ {\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right\} \le \varepsilon  \\
        &\le \mathbb{E}{}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} + \mathbb{E}\left\{ {\frac{ { {N_s}M{\sigma ^2}}}{ {\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right\}
\end{split}
\tag{60}
$$

**证明** 见附录 D。

信道预测误差的上下界之差为 $\mathbb E\{2N_sM\sigma^2/\|\mathbf h^d(t_p)\|_2^2\}$，与 $1/\mathrm{SNR}$ 成比例，在天线数和带宽很大时非常小。通常无法提前知道 $M$，在无噪声样本条件下假定 $M=L$，在含噪声样本条件下假定 $M<L$。因此，增大 $L$ 无法带来显著性能改善。说明 2 表明，给定 $M$ 和 $N_L$ 时，应选择尽可能小的 $L$。第 VI 节仿真也证实了这一点。

不过，天线数有限会产生 DFT 失配。因此，每个 $\mathbf d_j$ 无法准确映射下行信道的精确角度–时延结构，各角度–时延向量可能对应多个多普勒频移。较大的 $L$ 可能更好地拟合各角度–时延向量对应的多普勒频率，因而 $L$ 的选择存在折中。实际应用中，无法预知多普勒频移的多样性，难以获得最优 $L$。因此建议取满足 $M\leq L\leq N_L-L$ 的较小 $L$。

### B. 复杂度与反馈开销分析

本文的下行信道重构框架由五部分组成：DFT 投影、基于 MP 的多普勒估计、角度–时延向量及多普勒参数的上下行变换、下行训练和信道重构。DFT 投影可由快速傅里叶变换（FFT）实现，复杂度为 $\mathcal O(N_fN_t\log_2(N_fN_t))$。MP 的复杂度主要由 SVD 决定，即 $\mathcal O((N_L-L)^2L+(N_L-L)L^2)$。参数变换复杂度为 $\mathcal O(N_sN_v+N_sN_h)+\mathcal O(N_f^2N_t^2)+\mathcal O(N_sM\log^2(N_sM))+\mathcal O(N_fN_tN_s^2M^2)$。下行训练包含一次矩阵求逆，复杂度为 $\mathcal O(N_fN_tN_sM)$。信道重构涉及矩阵求逆与 SVD，复杂度为 $\mathcal O(N_s^3M+N_s^3M^2)+\mathcal O(N_s^3M^2)+\mathcal O(N_s^2M^2)+\mathcal O((N_sM)^{2.37})$。信道重构过程的总体复杂度为 $\mathcal O(N_fN_tN_s^2M^2)$。因此，该框架具有多项式复杂度，无需像 CS 或机器学习方法一样迭代计算。

现在针对给定信道相干时间 $T_c$ 分析反馈开销。在增强型 II 型码本 [37] 中，反馈开销随 $L_1L_2$ 增长，其中 $L_1,L_2$ 小于 $N_t,N_f$。对于文献 [38] 中的经典 CS 方法，反馈开销取决于降维后的信道维数 $N_r$，随 $N_rN_f$ 增长。在 NOMP [12] 与深度学习 [13] 等其他方法中，反馈开销取决于路径数 $L_p$。丰富散射环境下 $L_p$ 较大。在宽带系统中，这些方法的反馈开销随 $L_pN_f$ 增长。借助信道预测，在一个信道相干时间 $T_c$ 内，本文框架的反馈开销为 $N_sM/N_c$ 个标量，其中 $N_c\geq1$ 表示在 $N_cT_c$ 的时间间隔内只需一组 $N_sM$ 个反馈系数。因此，与这些传统方法相比，本文框架的反馈开销更低。

## VI. 数值结果

本节采用 3GPP 定义的工业成簇延迟线 A（CDL-A）信道模型 [30]，在丰富散射场景验证所提 JADD 框架。除非另有说明，CDL-A 信道模型包含<a id="page-9"></a>23 个簇，每个簇包含 20 条路径。采用文献 [39] 的 n65 新空口（NR）频段，上行中心频率为 1.92 GHz，下行中心频率为 2.11 GHz。上下行带宽均为 20 MHz，子载波间隔为 30 kHz，故每时隙可用 51 个资源块（RB）。在这一配置中，每个时隙包含 14 个 OFDM 符号，长度短至 0.5 ms，即 SRS 信号周期长度。基站天线配置为 $(N_v,N_h,P_t)=(2,8,2)$，其中 $P_t$ 为每个阵元的极化数。垂直和水平方向的天线间距均为 $0.5c/f^d$。除非另有说明，其他仿真参数见表 I。下行预编码采用特征迫零（EZF）[40]，UE 使用最小均方误差干扰抑制合并（MMSE-IRC）接收机。框架性能以 SE 与预测误差（PE）衡量，PE 由式 (54) 定义。在一段时间内对所有子载波计算频谱效率 $R_s$：

$$
{R_s}{\mathrm{  =  }}\mathbb{E}\left\{ {\sum\limits_{k = 1}^K { {\mathrm{log}}\left( {1 + \frac{ {\left\| {\overline {\mathbf{h}} _k^d\left( {t,f} \right){ {\mathbf{G}}_k}\left( {t,f} \right)} \right\|_2^2}}{ {\sigma _k^2 + \sum\limits_{j \ne k}^K {\left\| {\overline {\mathbf{h}} _j^d\left( {t,f} \right){ {\mathbf{G}}_j}\left( {t,f} \right)} \right\|} }}} \right)} } \right\},
$$

其中 $\mathbf G_k(t,f)$ 为预编码矩阵，$\bar{\mathbf h}_k^d(t,f)$ 为估计信道，$\sigma_k^2$ 为 UE $k$ 的噪声功率。

## VII. 结论

本文提出一种新的信道预测框架，用于解决 FDD 大规模 MIMO 的移动性诅咒。该系统同时面临 CSI 老化与训练开销较大两个问题。本文框架结合 FDD 部分信道互易性与多径信道的角度–时延–多普勒结构。利用从上行信道参数提取的参数及 UE 反馈的若干系数重构下行信道。具体而言，基站计算上行信道的角度–时延向量，并使用 MP 方法估计多普勒频移。提出宽带 JADD 预编码矩阵，以便获取所需系数并减少训练开销。在 UE 侧，只需计算若干标量系数并反馈给基站。渐近分析表明，仅使用两个上行信道样本，预测误差随基站天线数增加而趋于零。本文还讨论了合适预测阶数的选择。数值结果表明，即使在有较大 CSI 时延的高移动场景中，所提框架仍表现良好。

### A. 命题 1 的证明

**证明** 首先需要推导索引 $i$ 与 $j$ 之间的关系。DFT 矩阵的第 $i$ 列为

$$
{ {\mathbf{q}}_i} = {\left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{w}}_i}}&{ {e^{ - j\frac{ {2\pi }}{ { {N_f}}}i}}{ {\mathbf{w}}_i}}& \cdots &{ {e^{ - j\frac{ {2\pi }}{ { {N_f}}}\left( { {N_f} - 1} \right)i}}{ {\mathbf{w}}_i}}
\end{array}} \right]^T},
\tag{61}
$$

其中 $\mathbf w_i=[1,e^{-j(2\pi/N_t)i},\ldots,e^{-j(2\pi/N_t)i(N_t-1)}]^T$。比较式 (61) 中的 $\mathbf q_i$ 和式 (12) 中的 $\mathbf r_p$，角度信息 $\theta_p^u,\phi_p^u$ 与时延信息 $\tau_p^u$ 均与 $\mathbf q_i$ 的元素紧密相关。每个角度–时延向量索引 $i$ 对应一个索引组合 $(i^a,i^h,i^v)$，其中 $i^a$ 为角度索引，$i^h$ 为水平角度索引，$i^v$ 为垂直角度索引。$i^a$ 和 $i$ 之间的关系为

$$
{i^a} = \left\{ \begin{array}{l}
\bmod \frac{i}{ { {N_t}}},\bmod \frac{i}{ { {N_t}}} \ne 0,\\
{N_t},\bmod \frac{i}{ { {N_t}}} = 0.
\end{array} \right.
\tag{62}
$$

随后按如下方式计算水平和垂直角度索引：

$$
{i^h} = \left\{ {\begin{array}{llllllllllllllllllll}
{\frac{ {\left( { {i^a} - {i^v}} \right)}}{ { {N_v}}} + 1,{i^v} \ne 0,}\\
{\frac{ { {i^a}}}{ { {N_v}}},{i^v} = 0,}
\end{array}} \right.
\tag{63}
$$

$$
{i^v} = \left\{ {\begin{array}{llllllllllllllllllll}
{\bmod \frac{ { {i^a}}}{ { {N_v}}},\bmod \frac{ { {i^a}}}{ { {N_v}}} \ne 0,}\\
{ {N_v},\bmod \frac{ { {i^a}}}{ { {N_v}}} = 0.}
\end{array}} \right.
\tag{64}
$$

因此，每一个上行角度–时延索引 $i$ 映射到一个下行信道角度索引 $j$，其中 $j\in\{1,2,\ldots,N_s\}$：

$$
\sin {\theta _j}\sin {\phi _j} = \frac{ { {i^h}c}}{ { {l_h}{f^u}{N_h}}},\cos {\theta _j} = \frac{ {c{i^v}}}{ { {l_v}{f^u}{N_v}}}.
\tag{65}
$$

由式 (7)，下行角度–时延结构可计算为

$$
\begin{split}
&{ {\boldsymbol{r}}^d}\left( { {\theta _j},{\phi _j}} \right) = \left( { { {\mathbf{I}}_{ {N_f}}}{\mathbf{c}}\left( {\tau _i^u} \right)} \right) \otimes \left( {\left( { { {\mathbf{R}}_h}\left( { {\theta _j},{\phi _j}} \right) \otimes { {\mathbf{R}}_v}\left( { {\theta _j}} \right)} \right){ {\boldsymbol{\alpha}}^u}\left( { {\theta _i},{\phi _i}} \right)} \right)\\
 &= \left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left( { { {\mathbf{R}}_h}\left( { {\theta _j},{\phi _j}} \right) \otimes { {\mathbf{R}}_v}\left( { {\theta _j}} \right)} \right)} \right) \cdot \left( { {\mathbf{c}}\left( {\tau _i^u} \right) \otimes { {\boldsymbol{\alpha}}^u}\left( { {\theta _i},{\phi _i}} \right)} \right).
\end{split}
$$

用角度–时延向量近似下行角度–时延结构：

$$
{\mathbf{d}}_j \buildrel \Delta \over = \left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left( { { {\mathbf{R}}_h}\left( { {\theta _{ {j}}},{\phi _{ {j}}}} \right) \otimes { {\mathbf{R}}_v}\left( { {\theta _{ {j}}}} \right)} \right)} \right){ {\mathbf{u}}_j}.
\tag{66}
$$

至此，命题 1 得证。

### B. 定理 1 的证明

**证明** 向量化下行信道可由一系列角度–时延向量叠加估计，这些向量由 DFT 矩阵 $\mathbf Q$ 的各列映射得到。$N_s$ 增加时角度–时延分辨率提高，功率泄漏问题减轻，因此 $\varepsilon$ 降低。

<a id="page-12"></a>

当 $N_s=N_fN_t$ 时，$\mathbf D\mathbf D^\dagger=\mathbf I_{N_fN_t}$ 成立。式 (54) 的预测误差变为

$$
\begin{split}
  \varepsilon & = 10\log \left( {\frac{ { {\mathbb{E}}\left\| { { {\mathbf{h}}^d}\left( t_p \right) - { {\mathbf{h}}^d}\left( t_p \right){\mathbf{I}} - \widetilde {\mathbf{h}}_2^d\left( t_p \right)} \right\|_2^2}}{ { {\mathbb{E}}\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right) \\
   &= 10\log \left( {\frac{ { {\mathbb{E}}\left\{ {\widetilde {\mathbf{h}}_2^d\left( t_p \right)\widetilde {\mathbf{h}}_2^d{ {\left( t_p \right)}^H}} \right\}}}{ { {\mathbb{E}}\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right)  \\
  & = 10\log \left( {\frac{ { {\mathbb{E}}\left\| { {\mathbf{DE}}\left( t_p \right){ {\left( { { {\mathbf{S}}^\dagger }} \right)}^T}} \right\|_2^2{\mathbb{E}}\left\| { {\mathbf{n}}{ {\left( t_p \right)}^T}} \right\|_2^2}}{ { {\mathbb{E}}\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right).  \\ 
\end{split}
\tag{67}
$$

将训练序列矩阵写成列向量与行向量两种形式：

$$
\begin{split}
{\left( { { {\mathbf{S}}^\dagger }} \right)^T} &= {\left[ {\begin{array}{cccccccccccccccccccc}
{ { {\mathbf{s}}_{1,1}}}&{ { {\mathbf{s}}_{1,2}}}& \cdots &{ { {\mathbf{s}}_{ {N_s},M}}}
\end{array}} \right]^T}\\
 &= \left[ {\begin{array}{cccccccccccccccccccc}
{ {\mathbf{s}}\left( 1 \right)}&{ {\mathbf{s}}\left( 2 \right)}& \cdots &{ {\mathbf{s}}\left( { {N_s}M} \right)}
\end{array}} \right],
\end{split}
\tag{68}
$$

其中 $\mathbf s_{j,m}=[s_{j,m}(1),s_{j,m}(2),\ldots,s_{j,m}(N_sM)]$，$\mathbf s(n)=[s_{1,1}(n),s_{1,2}(n),\ldots,s_{N_s,M}(n)]^T$。计算矩阵

$$
\begin{array}{l}
{ {\mathbf{D}}}{ {\mathbf{E}}}\left( t_p \right){\left( { { {\mathbf{S}}^\dagger }} \right)^T}
{ = }{\left[ {\begin{array}{cccccccccccccccccccc}
{\sum\limits_{j = 1}^{ {N_s}} { {\mathbf{d}}_j\sum\limits_{m = 1}^M { {e^{jw_{j,m}^d\left( t_p \right)}}{s_{j,m}}\left( 1 \right)} } }\\
{\sum\limits_{j = 1}^{ {N_s}} { {\mathbf{d}}_j\sum\limits_{m = 1}^M { {e^{jw_{j,m}^d\left( t_p \right)}}{s_{j,m}}\left( 2 \right)} } }\\
 \cdots \\
{\sum\limits_{j = 1}^{ {N_s}} { {\mathbf{d}}_j\sum\limits_{m = 1}^M { {e^{jw_{j,m}^d\left( t_p \right)}}{s_{j,m}}\left( { {N_s}M} \right)} } }
\end{array}} \right]^T}
\end{array}.
\tag{69}
$$

令 $\sum_{m=1}^M e^{jw_{j,m}^d(t_p)}s_{j,m}(n)=\lambda_{j,n}(t_p)$，得到

$$
\begin{split}
        &{\left\| { {\mathbf{DE}}\left( t_p \right){ {\left( { {\mathbf{S}}{ {\left( t_p \right)}^\dagger }} \right)}^T}} \right\|_2^2}\\ &= \sum\limits_{n = 1}^{ {N_s}M} {\left( {\left( {\sum\limits_{j = 1}^{ {N_s}} { {\lambda _{j,n}}{ {\left( t_p \right)}^H}{\mathbf{d}}_j^H} } \right)\left( {\sum\limits_{j = 1}^{ {N_s}} { {\lambda _{j,n}}\left( t_p \right){ {\mathbf{d}}_j}} } \right)} \right)}.
    \end{split}
\tag{70}
$$

下列引理表明各 $\mathbf d_j$ 的范数为 1，且彼此正交。

**引理 2** 对任意 $i,j=1,\ldots,N_s$，有

$$
{\mathbf{d}}_i{^H}{\mathbf{d}}_j = \left\{ \begin{array}{l}
            1,i = j\\
            0,i \ne j
            \end{array} \right..
\tag{71}
$$

**证明** 式 (71) 可由如下关系推得：

$$
\begin{split}
            &{\mathbf{d}}_i^H{\mathbf{d}}_j
            = { {\mathbf{q}}_i}^H{\left( {\left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left( { { {\mathbf{R}}_h}\left( { {\theta _{ {i}}},{\phi _i}} \right) \otimes { {\mathbf{R}}_v}\left( { {\theta _{ {i}}}} \right)} \right)} \right)} \right)^H}\\
             &\cdot \left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left( { { {\mathbf{R}}_h}\left( { {\theta _{ {j}}},{\phi _j}} \right) \otimes { {\mathbf{R}}_v}\left( { {\theta _{ {j}}}} \right)} \right)} \right){ {\mathbf{q}}_j}\\
              &= { {\mathbf{q}}_i}^H\left( { { {\mathbf{I}}_{ {N_f}}} \otimes { {\mathbf{R}}_{i,j}}} \right){ {\mathbf{q}}_j},
            \end{split}
\tag{72}
$$

其中

$$
{ {\mathbf{R}}_{i,j}} = \left( { { {\mathbf{R}}_h}{ {\left( { {\theta _{ {i}}},{\phi _i}} \right)}^H}{ {\mathbf{R}}_h}\left( { {\theta _{ {j}}},{\phi _j}} \right)} \right)\otimes \left( { { {\mathbf{R}}_v}{ {\left( { {\theta _{ {i}}}} \right)}^H}{ {\mathbf{R}}_v}\left( { {\theta _{ {j}}}} \right)} \right).
$$

当 $i=j$ 时，由于 $\mathbf q_i$ 是 DFT 矩阵 $\mathbf Q$ 的一列，式 (72) 变为

$$
\begin{split}
            {\mathbf{d}}_j^H{\mathbf{d}}_j &= { {\mathbf{q}}_i}^H\left( { { {\mathbf{I}}_{ {N_f}}} \otimes \left( { { {\mathbf{I}}_{ {N_h}}} \otimes { {\mathbf{I}}_{ {N_v}}}} \right)} \right){ {\mathbf{q}}_i}=1.\\
            \end{split}
\tag{73}
$$

式 (8) 的 $\mathbf R_h(\theta,\phi)$ 和式 (9) 的 $\mathbf R_v(\theta)$ 均为酉矩阵，且对任意 $i\ne j$ 有 $\mathbf q_i^H\mathbf q_j(t)=0$，因此对任意 $i\ne j$ 有 $\mathbf d_i^H\mathbf d_j=0$。

由引理 2，可直接计算以下期望：

$$
\begin{gathered}
  {\mathbb{E}}{\left\| { {\mathbf{DE}}\left( t_p \right){ {\left( { {\mathbf{S}}{ {\left( t_p \right)}^\dagger }} \right)}^T}} \right\|_2^2}  \\
   = \sum\limits_{n = 1}^{ {N_s}M} {\left( {\left( {\sum\limits_{j = 1}^{ {N_s}} {\sum\limits_{m = 1}^M { {e^{ - jw_{j,m}^d\left( t_p \right)}}{s_{j,m}}{ {\left( n \right)}^H}} } } \right) \cdot } \right.}   \\
  \left. {\left( {\sum\limits_{j = 1}^{ {N_s}} {\sum\limits_{m = 1}^M { {e^{jw_{j,m}^d\left( t_p \right)}}{s_{j,m}}\left( n \right)} } } \right)} \right)  \\
   = \sum\limits_{n = 1}^{ {N_s}M} { {\mathbf{s}}{ {\left( n \right)}^H}{\mathbf{s}}\left( n \right)}  = {N_s}M.  \\ 
\end{gathered}
\tag{74}
$$

将其代入式 (67)，得到定理 1 的结果。

### C. 定理 2 的证明

**证明** 当 $N_t,N_f\to\infty$ 时，隐含有以下关系：

$$
{\widetilde {\mathbf{h}}^u}\left( t_p \right) = \sum\limits_{i = 1}^{ {N_f}{N_t}} {\hat g_i^u\left( t_p \right){ {\mathbf{q}}_i}}  = \sum\limits_{i \in {\mathcal{S}}} {\hat g_i^u\left( t_p \right){ {\mathbf{q}}_i},\left| {\mathcal{S}} \right| = { {\mathcal{N}}_P}},
\tag{75}
$$

其中 $\mathbf q_i$ 是 DFT 矩阵 $\mathbf Q$ 的第 $i$ 列，$\hat g_i^u(t_p)=\mathbf q_i^H\mathbf h^u(t_p)$，$\mathcal S$ 由满足 $\hat g_i^u(t_p)\ne0$ 的索引组成。将由索引属于 $\mathcal S$ 的 $\mathbf q_i$ 张成的空间定义为

$$
{ {\mathcal{U}}_P} = {\mathrm{span}}\left\{ { {\mathbf{q}}_i:i \in { {\mathcal{S}}}} \right\}.
\tag{76}
$$

将 $N_P$ 定义为上行信道中互不相同的角度–时延结构的数量。两条不重合路径 $p,q$ 的角度–时延结构渐近正交 [15]：

$$
\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ { { {\left( { {\mathbf{r}}_p^u} \right)}^H}{\mathbf{r}}_q^u}}{ {\sqrt { {N_t}{N_f}} }} = 0.
\tag{77}
$$

根据 [15]，将两路径 $p,q$ 的角度–时延结构投影至由 DFT 矩阵表示的正交空间 $\mathbf S$ 后，仍保持正交性。事实上，当 $N_t,N_f\to\infty$ 时，角度–时延结构 $\mathbf r_p^u$ 位于空间 $\mathcal U_P$ 中。因此，下列关系成立：

$$
\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ {\left\| { { {\mathbf{U}}_p}^H{\mathbf{r}}_p^u} \right\|_2^2}}{ { {N_t}{N_f}}} = 1,\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ {\left\| { { {\mathbf{U}}_q}^H{\mathbf{r}}_p^u} \right\|_2^2}}{ { {N_t}{N_f}}} = 0,
\tag{78}
$$

其中 $\mathbf U_p$ 是由 $i\in\mathcal S_p$ 的各 $\mathbf q_i$ 组成的子矩阵。索引集合 $\mathcal S_p$ 定义为

$$
\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \left| {\frac{ { {q_i}^H{\mathbf{r}}_p^u}}{ { {N_t}{N_f}}}} \right| > 0,i \in { {\mathcal{S}}_p},\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \left| {\frac{ { {q_i}^H{\mathbf{r}}_p^u}}{ { {N_t}{N_f}}}} \right| = 0,i \notin { {\mathcal{S}}_p}.
$$

子矩阵 $\mathbf U_q$ 和集合 $\mathcal S_q$ 类似地定义。此外，由于 $\mathcal S_p$ 与 $\mathcal S_q$ 正交，有 $N_P=\mathcal N_P$。

条件 $L=1,N_L=2$ 给出矩阵束参数配置的下界，即只需估计一个极点，亦即<a id="page-13"></a>$M=1$。于是，式 (20) 的上行信道变为

$$
{\widetilde {\mathbf{h}}^u}\left( t_p \right) = \sum\limits_{i \in {\mathcal{S}}} { {a^u}\left( i \right){z^u}{ {\left( i \right)}^{t_p}}{ {\mathbf{q}}_i}} .
\tag{79}
$$

与式 (22) 比较，式 (79) 表明每个角度–时延向量 $\mathbf q_i$ 仅对应一个多普勒频移 $z^u(i)$。给定任意 $N_d$，可按算法 1 计算极点 $z^u(i)$，即获得与 $\mathbf q_i$ 对应的多普勒频移。

接下来分析下行信道。引理 2 已证明，下行角度–时延向量 $\mathbf d_j$ 具有与 $\mathbf q_i$ 相同的正交性，故式 (77) 至 $\mathcal S_p$ 定义处的渐近性质也适用于 $\mathbf r_p^d$ 和 $\mathbf d_j$。各 $\mathbf d_j$ 由式 (33) 计算。将全部 $\mathbf d_j$ 的集合记为 $\mathbf D_a\in\mathbb C^{N_tN_f\times N_tN_f}$，它是酉矩阵。类似地，将 $\mathcal D$ 按式 (75) 中 $\mathcal S$ 的方式定义，将 $\mathcal D_p$ 按 $\mathcal S_p$ 的方式定义。条件 $N_s=N_P$ 保证下列关系成立：

$$
\left\| { { {\mathbf{D}}_a^H}{ {\mathbf{h}}^d}\left( t_p \right)} \right\|^2_2{\mathrm{ = }}\left\| {\sum\limits_{j \in {\mathcal{D}},p \in {\mathcal{D}}_p} {\beta _p^d{e^{ - j2\pi {f^d}{\tau _p}}}{e^{jw_p^dt_p}}{ {\mathbf{d}}_j}^H{\mathbf{r}}_p^d} } \right\|^2_2.
$$

根据式 (35)，下行多普勒频移满足

$$
{e^{j{w^d}\left( j \right)}} = {e^{jw_p^d}},j \in {\mathcal{D}},p \in { {\mathcal{D}}_p}.
\tag{80}
$$

下行信道预测的渐近性能为

$$
\begin{gathered}
  \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \varepsilon = \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ {\left\| { { {\mathbf{D}}_a}\left( { {\mathbf{D}}_a^H{ {\mathbf{h}}^d}\left( t_p \right) - {\mathbf{D}}_a^H{ {\widetilde {\mathbf{h}}}^d}\left( t_p \right)} \right)} \right\|_2^2}}{ { {N_t}{N_f}{ {\left( {\sum\limits_P {\left| {\beta _p^d} \right|} } \right)}^2}}}  \\ 
   = \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ {\left\| { {\mathbf{D}}_a^H{ {\mathbf{h}}^d}\left( t_p \right) - {\mathbf{D}}_a^H{ {\widetilde {\mathbf{h}}}^d}\left( t_p \right)} \right\|_2^2}}{ { {N_t}{N_f}{ {\left( {\sum\limits_P {\left| {\beta _p^d} \right|} } \right)}^2}}}.  \\
 \end{gathered}
\tag{81}
$$

利用范数的性质，可以放宽式 (81)：

$$
\begin{gathered}
     \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \varepsilon  \\
   \leq \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ {\left\{ \begin{gathered}
  \left\| {\sum\limits_{j \in D,p \in {D_p}} {\beta _p^d{e^{ - j2\pi {f^d}{\tau _p}}}{e^{jw_p^dt_p}}{ {\mathbf{d}}_j}^H{\mathbf{r}}_p^d} } \right\|_2^2  \\
   + \left\| {\sum\limits_{j \in D} { {a^d}\left( j \right){e^{j{w^d}\left( j \right)t_p}}} } \right\|_2^2  \\ 
\end{gathered}  \right\}}}{ { {N_t}{N_f}{ {\left( {\sum\limits_P {\left| {\beta _p^d} \right|} } \right)}^2}}}  \\
   \leq \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ { { {\left( {\sum\limits_{j \in D,p \in {D_p}} {\left| {\beta _p^d} \right|} } \right)}^2} + { {\left( {\sum\limits_{j \in D} {\left| { {a^d}\left( j \right)} \right|} } \right)}^2}}}{ { {N_t}{N_f}{ {\left( {\sum\limits_P {\left| {\beta _p^d} \right|} } \right)}^2}}}. \\
\end{gathered}
\tag{82}
$$

其中
$\bigl[(\sum_{j\in D,p\in D_p}|\beta_p^d|)^2+(\sum_{j\in D}|a^d(j)|)^2\bigr]/(\sum_P|\beta_p^d|)^2$
是与 $N_tN_f$ 无关的常数。因此，式 (82) 变为

$$
\begin{array}{llllllllllllllllllll}
  {\mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ { { {\left\| { { {\mathbf{h}}^d}\left( t_p \right) - { {\widetilde {\mathbf{h}}}^d}\left( t_p \right)} \right\|}^2}}}{ { { {\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|}^2}}}} \\ 
  { \leq \mathop {\lim }\limits_{ {N_t},{N_f} \to \infty } \frac{ { { {\left( {\sum\limits_{j \in D,p \in {D_p}} {\left| {\beta _p^d} \right|} } \right)}^2} + { {\left( {\sum\limits_{j \in D} {\left| { {a^d}\left( j \right)} \right|} } \right)}^2}}}{ { {N_t}{N_f}{ {\left( {\sum\limits_P {\left| {\beta _p^d} \right|} } \right)}^2}}} = 0,} 
\end{array}
\tag{83}
$$

至此，定理 2 得证。

### D. 说明 2 的证明

**证明** 当 $N_s=N_fN_t$ 时，$L$ 的取值显然不影响 $\varepsilon$。只需证明 $N_s<N_fN_t$ 的情形。$\tilde{\mathbf h}_1^d(t_p)$ 与 $M$ 无关，故只需分析 $\tilde{\mathbf h}_2^d(t_p)$。附录 B 已证明 $\|\mathbf D\mathbf E(t_p)(\mathbf S^\dagger)^T\|_2^2=N_sM$。式 (57) 中的期望项可计算为

$$
\begin{split}
&\mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right) - \widetilde {\mathbf{h}}_2^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
& \le \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} + \mathbb{E}\left\{ {\left\| {\frac{ {\widetilde {\mathbf{h}}_2^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
& \le \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} + \mathbb{E}\left\{ {\left\| {\frac{ { {\mathbf{DE}}\left( t_p \right){ {\left( { { {\mathbf{S}}^\dagger }} \right)}^T}{\mathbf{n}}{ {\left( t_p \right)}^T}}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
&\le \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} \\
&+ \mathbb{E}\left\{ {\left\| { {\mathbf{DE}}\left( t_p \right){ {\left( { { {\mathbf{S}}^\dagger }} \right)}^T}} \right\|_2^2\left\| {\frac{ { {\mathbf{n}}{ {\left( t_p \right)}^T}}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
& \le \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} + \mathbb{E}\left\{ {\frac{ { {N_s}M{\sigma ^2}}}{ {\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right\}.
    \end{split}
\tag{84}
$$

类似地，可以得到

$$
\begin{split}
&\mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right) - \widetilde {\mathbf{h}}_2^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
 &\ge \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} - \mathbb{E}\left\{ {\left\| {\frac{ { {\mathbf{DE}}\left( t_p \right){ {\left( { { {\mathbf{S}}^\dagger }} \right)}^T}{\mathbf{n}}{ {\left( t_p \right)}^T}}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\}\\
 &\ge \mathbb{E}\left\{ {\left\| {\frac{ { { {\mathbf{h}}^d}\left( t_p \right) - \widetilde {\mathbf{h}}_1^d\left( t_p \right)}}{ { { {\mathbf{h}}^d}\left( t_p \right)}}} \right\|_2^2} \right\} - \mathbb{E}\left\{ {\frac{ { {N_s}M{\sigma ^2}}}{ {\left\| { { {\mathbf{h}}^d}\left( t_p \right)} \right\|_2^2}}} \right\}.
    \end{split}
\tag{85}
$$

至此，说明 2 得证。
